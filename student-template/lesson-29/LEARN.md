# 第29课知识准备 · 政策效果的双重差分评估

## 本课要解决的问题

选择哪些对照地区和观察时段？按地区等权还是按人口加权？在什么假设下，可以把双重差分解释为政策效应？可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 双重差分 | 处理组前后变化减对照组前后变化。 | 利用对照组估计共同的时间变化 |
| 平行趋势 | 无政策时两组结果趋势应具有所需可比性，是反事实假设。 | 说明因果解释的条件 |
| 事件时间 | 把各时间点表示为相对政策开始的距离。 | 检查动态和事前走势 |
| 聚类推断 | 允许同一地区不同月份结果相关。 | 避免夸大独立信息 |
| 安慰剂与干扰 | 虚假时点/未受影响结果用于排查；地区间传播可能破坏对照。 | 比较替代解释 |

双重差分（DiD）写作 DiD=(Ȳ处理,后−Ȳ处理,前)−(Ȳ对照,后−Ȳ对照,前)。本数据中各处理地区在同一月份实施政策，应选择与这一设计相符的方法，不必使用专门针对分期实施政策的方法。按地区进行自助抽样时，应将抽中地区的整条时间序列一同纳入；地区数较少时，区间估计仍需谨慎解释。

横线Ȳ表示相应组和时期按声明权重计算的平均结果；变化与DiD的单位都与outcome指数相同。等地区平均与按人口平均的目标不同，不能中途互换。

## 先思考，再看例子

处理组从50降到44，对照组从40降到38。处理组前后差为−6，双重差分为(44−50)−(38−40)=−4。它不是自动的政策效果；若对照也受到政策传播影响，−4对应的比较就需要重新解释。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

计算并可视化处理与对照的前后变化，用双重差分或等价的面板模型进行估计；推断应考虑地区内重复观测，不能把864行当864个独立地区。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

相似的政策前趋势与平行趋势假设相容，但不能证明没有政策时两组必然保持平行趋势。事前检验未拒绝原假设，也不等于证明因果识别条件成立；合成数据的生成参数同样不能证明现实政策的因果效应。

## 学习自查

进入项目后应能解释：

1. 为什么不能把处理组的前后差直接当成政策效果？
2. 平行趋势针对哪个无法同时观察的反事实，事前检验能证明它吗？
3. 月18实施政策时，月15和月21的事件时间分别是多少？
4. 为什么864行地区月度资料不等于864个独立地区？
5. 如果附近对照也受政策传播，应该怎样调整解释和对照选择？

## 进一步学习

可按需使用地区/时间固定效应、事件时间图或聚类自助。本数据集中的处理地区同时实施政策，方法复杂度不是目标；关键是对照、窗口、权重和干扰假设。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
