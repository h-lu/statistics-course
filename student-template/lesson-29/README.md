# 第29课 · 政策效果的双重差分评估

## 项目背景

八个地区从月18起实施服务政策。附近地区可能受到人员流动或政策传播影响，较远地区环境也不完全相同。负责人需要一份说明估计结果及其局限性的政策评价简报。

选择哪些对照地区和观察时段？按地区等权还是按人口加权？在什么假设下，可以把双重差分解释为政策效应？

可用资料为[政策与决策数据集](../data/policy/README.md)中的`district_panel.csv`。**资料全部为教学合成数据。** 数据字典说明记录单位、字段、时点和局限；你可以全程使用AI完成编程、分析、写作与提交，也可以复用前课代码。

## 分析任务

1. 明确政策时点、处理地区和目标量，比较附近/远处对照的事前轨迹与背景。确定等地区或按人口加权的目标并保持一致。

2. 计算并可视化处理与对照的前后变化，用双重差分或等价的面板模型进行估计；推断应考虑地区内重复观测，不能把864行当864个独立地区。

3. 更换有业务意义的对照或时间窗口，做前期安慰剂/事件时间检查。解释结果变化及可能干扰、同期冲击；前趋势不显著不能证明平行趋势。

4. 在报告中区分数据直接显示的变化、依赖明确假设的政策效应解释，以及暂时不能作出的因果判断，并提出一项可能改变结论的进一步核查。

以上均为本课需要完成的任务，分析方法和报告形式可以自行选择。评价不以图表或模型数量为依据。使用外部资料时注明来源，补充的业务假设应明确标注，不得当作已知事实。

## 课堂安排（90分钟）

- 0—12分钟：阅读[知识准备](LEARN.md)和项目背景，明确分析问题；需要时可延长到17分钟，相应减少重复操作和排版时间。
- 12—55分钟：选择方法、开展分析或研究设计，并比较不同方案；遇到不熟悉的概念可随时查阅知识准备或询问AI。
- 55—68分钟：核对一项主要结论的计算结果、假设与替代解释，完成分析报告。
- 68—75分钟：重新运行程序，检查结果并提交；提前完成时，可进一步检验报告中的重要结论。
- 75—90分钟：[知识自查](https://hblu.top/stat-check/)，确认页面为当日V2课次，建议先完成A版基础题，再向AI学习不熟悉的概念，随后完成B版变式题。

## 示例代码与运行方法

从仓库根目录运行：

```bash
python scripts/course.py start 29
python scripts/course.py run 29
```

本课`analysis.py`读取数据并生成`artifacts/starting_summary.json`，用于熟悉数据结构。**请在此基础上完成本课分析任务，形成自己的分析方案和结论。** 可使用Python标准库、numpy/scipy、pandas、statsmodels、scikit-learn或其他合适工具；说明新增依赖与运行命令。

## 成果要求与提交

- `report.md`：面向报告使用者，写清分析问题、方法依据、主要结果、适用范围和建议。
- 可复现的分析程序或研究设计文件，以及报告引用的计算结果和图表；不要手工修改原始数据。
- `submission.json`：将`status`设为`complete`，`report`指向分析报告，`artifacts`列出支持报告结论的结果文件路径，`run`填写可复现分析的命令。

仅运行示例代码或粘贴模型输出，还没有完成本课分析任务。合格简报应说明对照组、目标权重、聚类单位和识别假设；更好的简报会根据更换对照组后的结果调整结论，不仅依赖一个p值判断政策效果。

完成后执行`python scripts/course.py check 29`，按[项目工作流](../docs/WORKFLOW.md)提交并创建`v2-l29-final`标签；有修订时保留原标签。自查按[知识自查说明](../docs/KNOWLEDGE_CHECK.md)进行。项目分析允许全程使用AI，不要求提交AI对话记录。
