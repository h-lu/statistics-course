# 第13课支持路线 · 把置信区间转成行动建议

## 先知道今天要交出什么

你要依据80条成本记录，为部门提出全面行动、有限试点或继续收集信息的建议。最终应提交行动简报、点估计与区间结果、区间方法的覆盖实验，以及改变样本量、尾部或阈值后的敏感性结果。

入门跟做只完成一次样本分析和区间解释，不能代替方法比较、覆盖实验与行动取舍。

## 核心概念与原理

**点估计**给总体平均成本一个估计值；**置信区间**用一套重复抽样程序表达估计的不确定性。95%置信水平描述该程序长期覆盖固定真值的比例，不表示本次真值有95%概率落入已经算出的区间。

部门阈值45是行动输入，不是从样本中寻找出来的显著门槛。区间完全高于、完全低于或跨过45，会给出不同证据范围；行动仍需考虑延迟、试点和改造的代价。

**自助法**从现有独立观测单位有放回地重抽相同大小的样本。它能近似当前样本所支持的抽样变动，却不能创造样本从未包含的极端机制或修复选择偏差。

## 基础练习（可信起点）：入门跟做

先在**仓库根目录**打开终端，完整运行：

```bash
python scripts/course.py start 13
python scripts/course.py run 13
```

第二条命令成功时，终端会提示概览已经写入`lesson-13/artifacts/starting_inventory.json`。打开这个文件；它只是数据起点，不是本课答案。若文件没有生成，先按后面的排错顺序处理，再继续。

### 第一步：只看决策样本

- **动作**：从仓库根运行`python scripts/course.py run 13`，先只读取`decision_sample.csv`，核对80行、`sample_id`唯一和`cost`单位。
- **目的**：保持“本次80条样本分析”与“完整教学总体的方法实验”分开。
- **成功信号**：你有样本量、均值、中位数、标准差和高分位数，但没有用总体真值替代样本结果。
- **反思**：哪个统计量提示长尾可能影响均值区间？

### 第二步：解释一个小区间

- **动作**：对小例子“估计50，95%区间[44,56]，阈值45”写两句话：数据支持哪些参数值，不能排除哪些行动情境。
- **目的**：避免把“跨过阈值”机械翻译为“没有问题”或“无效”。
- **成功信号**：文字没有写“真值有95%概率在区间内”，也没有只按p值下结论。
- **反思**：若延迟行动代价很高，为什么区间跨阈值仍可能支持有限试点？

### 第三步：计算主区间与替代区间

- **动作**：选一种有依据的均值区间，再选一种替代方法；记录置信水平、重抽单位、重复次数和端点算法。
- **目的**：检查长尾下结论对区间方法是否敏感。
- **成功信号**：两种方法估计同一总体参数，或者明确说明目标参数不同；每个端点单位都是成本单位。
- **反思**：区间宽度差异来自方法、目标量还是随机重抽？

### 第四步：用教学总体检查覆盖率

- **动作**：从`estimation_populations.csv`选择与决策样本来源相应的教学总体，重复抽取80条、计算区间并记录是否覆盖已知总体均值。
- **目的**：评价区间程序，而不是用总体真值替代对80条样本的分析。
- **成功信号**：覆盖率分母等于模拟次数；同时报告蒙特卡洛误差；总体文件的结果单独标为方法实验。
- **反思**：覆盖率接近目标是否足以证明这种方法适用于所有长尾数据？

### 入门反思

分别写出“样本告诉我们的”“区间方法实验告诉我们的”和“部门阈值决定的”。三者不能互相替代。

## 标准任务（本课应完成）

1. 只用80条样本完成尾部、点估计和阈值关系分析。
2. 构造主区间并比较一种有依据的替代方案，说明各自条件。
3. 用完整合成总体做覆盖实验，报告重复次数与蒙特卡洛误差。
4. 改变尾部、样本量或行动阈值，检查建议是否稳定。
5. 把证据、行动成本和风险态度结合为全面行动、有限试点或继续收集的明确建议。

## 提高与拓展（提前完成后）

- 比较双侧区间与针对“是否超过45”的单侧区间，并说明问题如何改变。
- 计算追加样本对区间宽度或错误决策风险的预期影响。
- 研究极端值对不同区间方法端点的影响，明确稳健方法是否仍估计平均成本。
- 为有限试点制定可更新的决策阈值和停止条件。

## 卡住时按顺序排查

1. 确认本次80条样本分析读取`decision_sample.csv`，方法实验才读取完整总体。
2. 自助样本量错误时，检查每次是否有放回抽取同样的80个观测单位。
3. 区间每轮相同时，检查随机数生成和统计量是否在循环内重新计算。
4. 覆盖率异常时，核对真值、区间端点和情境分组。
5. 文字解释混乱时，先写“参数固定、区间随机”这一重复抽样视角。
6. 建议无法确定时，列出不同错误行动的代价，而不是强求唯一答案。
