# 第13课 · 置信区间能否支持决策

部门拿到80次成本观测，若平均成本持续高于45就值得启动改进，但全面改造有实施风险。你要说明现有证据支持全面行动、有限试点还是继续收集，而不只是输出一个区间。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

样本均值超过45，是否已经足以证明平均成本超过45？先说明你还想知道什么。

先打开[支持路线](SUPPORT.md)确认第一个动作和成功信号，再阅读[知识准备](LEARN.md)理解必要概念；计算和复杂实现可以交给工具。

## 学习路线与任务层级

前置回顾：[第12课](../lesson-12/README.md)中的抽样分布、标准误和覆盖率。先按[支持路线](SUPPORT.md)建立可信起点，再用[知识准备](LEARN.md)解释结果。

### 基础练习（可信起点）

只用80条`decision_sample.csv`检查尾部、点估计和阈值关系，计算一条有依据的区间并正确解释。此层只建立分析起点，**不能冒充本课完成**。

### 标准任务（本课应完成）

完成下方三项分析任务：比较区间方案，用完整合成总体评价覆盖率，并把区间、尾部、行动阈值和敏感性结果转成全面行动、有限试点或继续收集的建议。

### 提高与拓展（提前完成后）

比较单侧与双侧区间、追加样本的预期信息，或为有限试点设计更新规则；保持概率解释和目标参数一致。提高任务应改变统计判断，不能只增加代码、模型或图表数量。

## 分析任务

1. 先仅用80条decision_sample定义平均成本目标，展示尾部、点估计及与行动阈值45的关系；明确阈值是部门决策输入，不是由样本寻找出来的。

2. 构造有理由的置信区间，比较一种有依据的替代分析方案。用完整合成总体作为实验基准检查这种区间的覆盖表现，严格区分“对80条样本的实际分析”和“利用已知合成总体评价区间方法”。

3. 把区间、样本尾部和成本门槛一起转成行动建议；说明追加信息或有限试点能解决什么。改变尾部/抽样量或阈值后检查建议是否改变。

## 需要你作出的选择

可选均值t区间、自助百分位或其他有依据的方法；可以保守试点，但需说明代价和证据。不允许把区间跨过45自动翻译成“没有问题”，也不允许用总体基准替代抽样报告。

自助法必须按原始独立观测单位重抽样；报告重复次数、区间水平和端点算法；覆盖率实验需给出重复次数与模拟误差。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

行动简报、可复核区间和覆盖实验、阈值/样本变化的敏感性结论。明确当前建议哪些部分依赖估计方法，哪些依赖决策者风险态度。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。置信水平描述区间程序长期覆盖率，不能把它解释为固定真值以该概率落入本次已经算出的固定区间。自助法不能凭空创造样本未包含的极端机制，也不能修复选择偏差。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。
