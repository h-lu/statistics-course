# 第13课｜置信区间与调查决策

一次调查得到“45%的人有需求”，还不能说明这个估计有多精确。本课沿用第11课的4000人教学合成总体，从一份样本构造置信区间，再用重复调查检验区间方法，最后讨论是否达到服务扩容门槛。

## 本课要学会什么

- 区分点估计、置信区间和覆盖率，正确解释95%置信水平。
- 从第一轮样本追踪比例、区间上下限与行动判断。
- 在相同条件下比较方法或样本规模，同时评价覆盖率和宽度。
- 用可复算的证据提出建议，而不是只凭点估计作决定。

前课已经讨论抽样误差和抽样分布。本课把“估计会波动”转化为区间；第14课再讨论预算有限时怎样分配样本。

## 学习顺序

1. 阅读[知识讲解](LEARN.md)，先理解点估计与区间、95%的含义，再学习比例区间、自助法和覆盖评价。
2. 完成[练习第一部分](EXERCISES.md#一概念与手算)，写下自己的判断，再按需查看[分层提示](HINTS.md)。
3. 按[运行帮助](SUPPORT.md)生成默认结果，依次读样本、单轮结果和汇总，完成数值追踪。
4. 选择一个比较问题，先确定改什么、哪些条件保持不变，再运行并解释结果。
5. 完成报告与复现检查。课堂选择题按教师开放的场次完成“A版→概念学习→B版”。

## 课堂任务

你要为周末服务需求写一份调查行动简报。预先选择需求比例门槛，并说明业务理由；课堂示例采用0.40。门槛是决策标准，不是看到结果后再调整的数字。

以下两条路线任选一条即可：

- **方法比较**：固定一次调查人数、调查轮数、种子和门槛，比较两种区间方法。例如Wilson与带有限总体修正的Wald区间。
- **样本规模比较**：固定方法、调查轮数、种子和门槛，比较两种调查人数。例如80人与160人。

每条路线都完成以下四步：

1. 从第一轮样本计算需求人数与比例，核对区间上下限及宽度。
2. 判断区间在门槛上方、下方还是跨过门槛，说明它支持什么行动判断。
3. 比较多轮调查的覆盖率、平均宽度和覆盖率模拟标准误；不能只挑最窄的方法。
4. 给出建议，并讨论调查成本、无回答或抽样方式改变后还需核实什么。

课堂模拟采用完整名册上的等概率无放回抽样、全部回答。总体真值供模拟评价使用，不作为学生构造区间的输入。

## 运行与提交

在学生仓库根目录运行：

```sh
python3 lesson-13/analysis.py
```

默认结果写入 `lesson-13/artifacts/baseline/`。这个命令适合第一次观察结果；反复运行和正式提交请使用[运行帮助中的重建脚本](SUPPORT.md#四让自己的比较可以重复运行)。

提交材料包括：

- [报告](report.md)：问题与预先选择、一轮数值追踪、公平比较、建议及适用范围。
- 自己的配置文件和重建脚本：明确两个条件，不靠手工修改结果文件。
- 两个条件的 `plan.json`、`first_sample.csv`、`trials.csv` 和 `summary.json`。
- `submission.json`：登记报告、重建命令和产物，完成后把 `status` 改为 `complete`。

```sh
python3 scripts/course_l1314.py check 13
python3 scripts/course_l1314.py ci 13
```

通过检查后按既有课程流程提交，标签仍为 `v2-l13-final`，评分要求不变。可用AI辅助编程与分析，无需提交对话日志；报告中的数值要能在自己的产物中找到。
