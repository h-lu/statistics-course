# 第13课｜置信区间与调查决策

沿用第11课的4000人教学合成总体，研究一次需求调查的不确定性。先构造区间，再通过重复抽样评价方法，最后结合行动门槛提出建议。

## 学习顺序

1. 阅读[知识讲解](LEARN.md)：点估计与区间、95%的含义、比例区间、自助法、覆盖评价与决策。
2. 完成[概念与手算练习](EXERCISES.md)，分清一次调查人数 $n$ 、调查重复次数 $R$ 和自助重抽次数 $B$ 。
3. 按[运行帮助](SUPPORT.md)复算默认调查，再设计自己的比较。

## 课堂任务

为周末服务需求确定有业务依据的门槛和行动规则。选择两种区间方法，或选择两种样本规模作比较，说明哪些条件保持相同。

追踪一轮样本的比例、上下限及行动判断；再比较重复调查的覆盖率、平均宽度和模拟误差，形成建议。数据采用完整名册上的等概率无放回抽样、全部回答；将结论用于真实调查时，说明无回答等因素的影响。

## 运行与提交

在学生仓库根目录运行 `python3 lesson-13/analysis.py`，默认结果位于 `lesson-13/artifacts/baseline/`。自己的比较使用另存配置和新的输出目录。

在[报告](report.md)中整理问题、方法、数值追踪、比较与建议；在 `submission.json` 中登记重建命令和产物，完成后将 `status` 设为 `complete`。运行 `python3 scripts/course_l1314.py check 13` 与 `python3 scripts/course_l1314.py ci 13`，提交标签沿用 `v2-l13-final`，评分要求不变。

可使用AI辅助编程与分析，无需提交对话日志。课堂选择题按教师开放的场次完成A→概念学习→ $B$ 。
