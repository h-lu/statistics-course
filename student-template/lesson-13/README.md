# 第13课｜置信区间能否支持决策

## 项目背景
第11课问谁能代表总体，第12课问换样本会波动多少。本课把这些知识用于一次调查：用置信区间说明一个需求比例估计有多大不确定性，能否支持预先设定的行动门槛。沿用第11课固定4000人教学合成名册，不冒充真实调查。

## 学习入口
[LEARN](LEARN.md)解释概念、公式和例子；[SUPPORT](SUPPORT.md)提供按需运行帮助。已有思路可直接分析，不强制统一顺序。

## 课堂任务
先为需求决策选择有业务依据的门槛和行动规则，再选择两种区间方法或两种样本规模作公平比较。一次样本给估计与区间；重复抽样给覆盖率、平均宽度和模拟误差。追踪一轮上下限如何算出，解释建议和适用条件。允许结论不明确，不为得到支持移动门槛。

标准任务不是运行默认配置即完成。你可以借助AI修改程序或另写等价分析，用证据说明选择；不要求统一赢家、统一结论或AI对话日志。

## 资源与约束
数据在`lesson-11/data/`，共用工具保留原始CSV。基准为完整名册、概率抽样、全部回答；真实调查的无回答与追访成本要另外说明。工具每次只运行一个你选择的条件，不替你选择最终建议。

## 怎样核对
在学生仓库根目录执行 `python3 lesson-13/analysis.py`，得到`lesson-13/artifacts/baseline/`。用另存配置和新的输出目录做比较，避免覆盖第一份证据。先核对`first_sample.csv`与`trials.csv`第一行，再读`summary.json`；详细字段见操作支持。

## 基础、标准与提高
基础小例见学习页和[EXERCISES](EXERCISES.md)，不代替完整任务。标准任务交一个比较与决策作品。提高题是选做，深化方法适用性、误差或预算敏感性，而非重复凑图。

## 成果与提交
用[report.md](report.md)组织问题、选择、数值追踪、比较、限制和建议，保存自己的配置、代码、数据来源与结果。`submission.json`列自己的重建命令和产物，完成后设`complete`。沿用`v2-l13-final`与原评分；用`python3 scripts/course_l1314.py check 13`检查。课末按教师开放的场次完成A→概念学习→B，本课包不自动开场。

已有个人仓库取得新课及标签检查路由见[更新说明](../docs/LESSONS13_14_UPDATE.md)，保留自己的旧报告与成果。
