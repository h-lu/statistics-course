# 第13课｜置信区间与调查决策

第11课讨论样本能否代表总体，第12课通过重复抽样观察估计值的波动。本课进一步问：只有一次调查时，怎样表达估计的不确定性？

沿用4000人的教学合成名册，从中等概率、无放回抽取80人，所有人均回答。第一轮有36人表示需要周末服务，样本比例为45%。若事先设定的扩容门槛是40%，仅凭45%还不足以判断总体需求是否超过门槛，因为换一批人，估计结果会变化。

## 1. 从点估计到置信区间

样本比例p̂=36/80=0.45是**点估计（point estimate）**，用一个数估计总体比例p。**标准误（standard error，SE）**描述估计量在重复抽样中的波动大小；现实调查通常用当前样本估计它。

当标准化估计误差近似服从标准正态分布时，可以构造：

**置信区间（confidence interval，CI） = 点估计 ± 1.96 × 估计SE。**

标准正态分布约95%的概率位于−1.96到1.96之间，这就是系数的来源。举一个手算例：某总体均值的估计为10，估计SE为2，区间是10±3.92，即[6.08,13.92]。区间表达总体均值估计的不确定性，而非个体观测的分布范围。

## 2. 95%的含义

总体真值固定，样本随抽样变化，因此每次算出的区间也不同。**95%的置信水平（confidence level）指构造方法的长期覆盖目标：在适用条件下，重复抽样所得到的区间约有95%覆盖真值。**

![重复抽样区间与总体真值](figures/coverage.png)

图中每条横线是一轮调查得到的区间，竖线是固定的总体比例。跨过竖线表示覆盖。已算出的一条区间要么覆盖、要么不覆盖；95%描述这种构造程序，而不是真值在该区间内的概率。

本课合成总体的比例为41%，因此能检查覆盖情况。计算每条区间时仍只使用相应样本，41%仅用于事后评价方法。

## 3. 计算比例的区间

### 正态近似：Wald区间（Wald interval）

记总体人数为N，样本人数为n。本课无放回简单随机抽样的估计标准误为：

**SE = √[(1−n/N) × p̂(1−p̂)/(n−1)]。**

这个式子由SE²=(1−n/N)s²/n得到；0/1数据的样本方差s²=n p̂(1−p̂)/(n−1)。其中1−n/N是有限总体修正（finite population correction，FPC）：抽中的人数越接近总体人数，剩余抽样不确定性越小。将SE代入上一节的“估计±余量”，得到程序中的 `wald_fpc` 区间。

这一方法在比例接近0或1时可能表现较差。例如样本全部为1，代入公式会得到SE=0和区间[1,1]；小样本中出现这种结果，并不意味着总体比例已确定。

### 改善边界表现：Wilson区间（Wilson interval）

Wilson方法在二项模型下构造区间，同时调整中心和半宽，样本全0或全1时仍保留不确定性。令z≈1.96，计算：

- d = 1+z²/n；
- 中心 c = (p̂+z²/(2n))/d；
- 半宽 r = z√[p̂(1−p̂)/n+z²/(4n²)]/d；
- 区间为[c−r,c+r]。

代入n=80、p̂=0.45，得到c≈0.452291、r≈0.106514，区间约为 **[0.3458,0.5588]**，即34.58%至55.88%。程序采用更精确的z值，因此末位可能与用1.96手算略有差异。

本课抽样比例为80/4000=2%，将Wilson作为低抽样比例下的近似方法，再用模拟检查覆盖。当抽样比例较大时，需要考虑有限总体的抽样设计；若无测量错误地调查全部总体，则没有抽样不确定性。[Wilson公式参考](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)

## 4. 从一份样本重抽：自助法

**自助法（bootstrap）**从已有样本中有放回地抽取n条记录，计算一次估计；重复B次后，将估计值排序，取2.5%和97.5%分位数作为百分位区间（percentile interval）。

例如样本[0,1,1,0]的比例为0.5。一份重抽样本可能是[1,0,1,1]，比例0.75；另一份可能是[0,0,1,0]，比例0.25。重抽是在已有记录上模拟波动，不是再去调查新的人。

若原样本是[1,1,1,1]，每份重抽样本的比例都为1，百分位区间就是[1,1]。相比之下，四个1的Wilson区间约为[0.510,1]。

![边界样本的自助重抽](figures/bootstrap-boundary.png)

这个例子说明，自助法的表现取决于原样本提供的信息。课堂将普通百分位自助法作为低抽样比例下的比较方法，检查它的覆盖率与宽度。对于自愿回答造成的偏差，需要改善取样机制，区间计算本身不能修复代表性。

## 5. 用重复调查评价方法

先区分三个数：

|符号|含义|增加它主要改变什么|
|---|---|---|
|n|一次调查的人数|这次估计的信息量|
|R|从总体重复调查的次数|评价区间方法的精度|
|B|一次调查内部的自助重抽次数|自助分位数的模拟精度|

对固定总体重复R次调查，每次计算区间[Lᵢ,Uᵢ]，再汇总：

**覆盖率（coverage） = 覆盖真值的区间数/R；平均宽度 = Σ(Uᵢ−Lᵢ)/R。**

默认Wilson实验使用n=80、R=500、起始种子1301，得到482次覆盖，覆盖率96.4%，平均宽度约0.2094，即20.94个百分点。这是本次有限模拟的结果。其覆盖率的蒙特卡洛标准误（Monte Carlo standard error，MCSE）为：

**√[0.964×(1−0.964)/500] ≈ 0.00833，即0.83个百分点。**

它衡量模拟覆盖率的波动，区别于一次调查中比例估计的SE。增大R能使评价更稳定，却没有为第一轮调查增加受访者。

比较方法时固定n、总体、抽样机制及每轮样本；在程序中保持n和seed相同即可。若研究样本量的作用，则固定方法，只改变n。运行命令及结果字段见[运行帮助](SUPPORT.md)。

## 6. 用区间讨论行动

依据业务收益和错误代价，事先确定门槛τ。采用以下三分规则：

- 下限大于τ：证据支持总体比例高于门槛；
- 上限小于τ：证据支持总体比例低于门槛；
- 区间包含τ：当前证据尚不明确。

默认区间[0.3458,0.5588]包含0.40，因此这次调查尚不足以支持“总体需求明确超过40%”。后续可根据追加调查成本、试行成本与判断失误的代价选择行动。
