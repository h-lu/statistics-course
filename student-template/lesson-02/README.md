# 第2课：分析结论对统计口径有多敏感

本课使用教学合成数据。你可以使用 AI 帮助计算和写作，但要自己核对分析范围、分母、单位和结论。

先读本课[支持路线](SUPPORT.md)，再读[知识准备](LEARN.md)。

## 先做一个小判断

同一组等待时间，均值较小是否一定代表大多数记录较好？把“只看已服务工单”改成“全部登记工单”，这是换算法还是换了统计口径？写下你的预计，课程结束后回看。

## 项目背景

上一课得到初步描述。本课要问：采用另一种有理由的记录范围、统计量或比较方式，结论会不会改变？**敏感性分析**就是改变一个有依据的方法或假设，观察结果和建议怎样变化，不是反复调数直到得到喜欢的答案。

## 分析任务

1. 写清原有结论、时期、分析单位、纳入规则、指标和比较对象；
2. 选择一到两种有理由的替代统计口径，实际计算而不是只讨论；
3. 列出每种方案的记录数、分母、单位、结果和差值，解释差异来源；
4. 判断结论在已检查的范围内是否稳健，哪些表述需要修改；
5. 写清不能由这些比较证明的内容。
