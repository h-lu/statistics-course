# 第2课：分析结论对统计口径有多敏感

已完成前七次作业的同学无需重交。

本课使用**教学合成数据**。可以全程使用 AI；待检查的结论、比较方案、方法及建议由你确定。先读本页，明确需要完成什么；遇到不熟悉的概念时查 [LEARN](LEARN.md)，遇到困难时选择 [SUPPORT](SUPPORT.md) 中相关的提示。分析顺序和方法可自行安排。工具操作见[阅读与运行指南](../docs/READING_GUIDE.md)。

## 情境与目标

管理者准备引用第 1 课简报中的一句话，希望知道换一种合理的分析选择后，是否仍能这样表述。**统计口径**指纳入哪些记录、指标怎样定义和计算。例如，描述已服务工单的等待，与描述所有登记工单在开始服务或离开前的等待，纳入范围不同。**敏感性分析**有依据地改变分析选择，实际重算，检查结论和行动是否变化。你可以选择一句值得核实的探索性结论，比较哪些中心、采用什么指标和方法由你决定。

## 可用资源

继续使用第一期 `data/service/tickets.csv`、`windows.csv` 和 `business_types.csv`。日期、业务及等待时间计到何时，见[数据说明](../data/service/README.md)。本课无需处理第 3 课的第二期原始导出。没有上一课报告时，可自行计算一项待核实的结论，作为比较起点；仍应写清它的用途和数据范围。

`analysis.py` 是示例程序，会生成 `lesson-02/artifacts/starting_overview.json`。这份概览将所有中心的已服务工单合并，描述等待时间；它提供了一个比较起点，没有计算替代方案。你可复用程序中的读表和统计函数、自写代码或使用其他合理工具。

## 三层任务

### 基础练习（可信起点）

选一句具体结论，说明时期、分析单位、记录范围、指标、分母与单位。分析单位指结果针对工单还是来访者等对象，第 1 课的解释见 [LEARN](../lesson-01/LEARN.md#必须理解的概念)。用概览或自己的计算核对一个结果，再说明一种有理由的替代选择，以及你预期它可能怎样影响结果。明确比较问题只是起点，标准任务还需实际比较和修订结论。

### 标准任务（本课应完成）

提交结论稳定性报告、并列展示原方案与替代方案结果的表或图，以及可运行程序。这里的稳定性指结论在已检查的合理变化下能否保持。成果需覆盖以下五项要求，可自行安排研究顺序：

- 明确原结论、用途和基准方案，即作为比较起点的分析方案。写清时期、分析单位、纳入规则、指标与比较对象。
- 选择一至两种有理由的替代统计口径并实际计算。至少比较基准方案和一种替代方案。
- 列出每种方案的记录数、分母、单位、指标结果与差值。差值始终按同一顺序计算，例如始终用“甲中心减乙中心”，并注明这个顺序；解释结果变化来自哪里。
- 判断差值方向、大小和建议采取的行动是否变化。区分改变同一问题的计算选择，与更换目标人群或评价目的；据此决定保留原结论、补充条件还是修订结论。
- 说明检查过哪些变化，以及这些比较仍不能证明什么。同一批数据用于发现问题和做敏感性分析，仍属于探索；只有用未参与形成原发现的资料检验明确的问题，才有独立验证的依据。这些比较也不自动证明因果效果。

**至少两项重要决定由你作出：**第一，哪一句结论值得核实，以及它的使用目的；第二，哪种替代范围、指标或方法有实际依据。最终的稳定性判断、报告措辞和行动建议也由你决定。多种合理路线均可接受；结果没有反转不是失败，缺少计算与解释才是证据不足。

### 提高与拓展（提前完成后）

选择一个有理由的新问题，可自拟，也可参考以下方向：同时改变两项分析选择，检查在什么条件下建议的行动开始变化，将分析用于另一项事先确定的业务或时期，比较平均负担与不易受极端值影响的稳健描述，或独立复算关键分位数。这些是可选方向。说明新增结果如何改变结论的使用范围、行动或表述；先限定有实际依据的比较范围，事后出现的新发现要标为探索性发现，不只挑选支持原结论的结果。

## 证据自检与提交

各方案均已实际计算，差值的相减顺序一致，算法与单位清楚；指标名称相同而纳入范围不同时，已注明范围差别；结果能由程序重新生成；分母为 0 或没有记录的组，指标注明无法计算；原始 CSV 保持不变。

在有 `scripts/`、`data/` 和 `lesson-02/` 的学生仓库根运行：

```bash
python3 scripts/course.py start 02
python3 scripts/course.py run 02
```

以上命令使用 `python3`；如果你的电脑用 `python` 运行 Python 3，可将命令中的 `python3` 换成 `python`。成功运行后应看到 `lesson-02/artifacts/starting_overview.json` 的路径，并能打开该文件。**仅提交这份概览还没有完成作业**，它没有替代比较与稳定性论证。修改代码或另写分析，将结果存到 `lesson-02/artifacts/`。

在 `submission.json` 中，`report` 填实际报告路径，`artifacts` 填结果文件路径列表，`run` 填能重新生成这些结果的命令参数列表。路径从学生仓库根目录写起；完成标准任务后才把 `status` 设为 `complete`，再运行：

```bash
python3 scripts/course.py run 02
python3 scripts/course.py check 02
```

本地 `check` 只检查状态、路径、文件是否存在且非空，**不会重新运行分析**或评价结论。按[工作流](../docs/WORKFLOW.md)核对暂存内容并提交，使用 `v2-l02-final` 标签；修订保留旧标签。

[五组独立自检](LEARN.md#独立自检与迁移)供你检查理解，并在新情境中运用概念。课堂选择题按[知识自查说明](../docs/KNOWLEDGE_CHECK.md)打开 <https://hblu.top/stat-check/>，确认教师已开放当天第 2 课的场次；页面不可用时按课堂约定补做。
