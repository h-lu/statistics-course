# 第2课：分析结论对统计口径有多敏感

本课使用教学合成数据。你可以使用 AI 帮助计算和写作，但要自己核对分析范围、分母、单位和结论。

第一次使用这个仓库时，可以先看[阅读与运行指南](../docs/READING_GUIDE.md)。先读本课[支持路线](SUPPORT.md)，再读[知识准备](LEARN.md)。

## 先做一个小判断

同一组等待时间，均值较小是否一定代表大多数记录较好？把“只看已服务工单”改成“全部登记工单”，这是换算法还是换了统计口径？写下你的预计，课程结束后回看。

## 项目背景

上一课得到初步描述。本课要问：采用另一种有理由的记录范围、统计量或比较方式，结论会不会改变？**敏感性分析**就是改变一个有依据的方法或假设，观察结果和建议怎样变化，不是反复调数直到得到喜欢的答案。

## 分析任务

1. 写清原有结论、时期、分析单位、纳入规则、指标和比较对象；
2. 选择一到两种有理由的替代统计口径，实际计算而不是只讨论；
3. 列出每种方案的记录数、分母、单位、结果和差值，解释差异来源；
4. 判断结论在已检查的范围内是否稳健，哪些表述需要修改；
5. 写清不能由这些比较证明的内容。

## 难度分层

下面三层按顺序使用。基础练习建立可信起点，不能代替标准任务；标准任务保留本课原有要求；提高与拓展供提前完成者继续检验结论。

### 基础练习（可信起点）

1. 选定一句要核实的结论，写清它的时期、分析单位、记录范围、指标、分母和单位；
2. 运行起始程序，把一个结果翻译成完整句子；
3. 预先写下一种有实际理由的替代统计口径，以及你预计它会怎样影响结果。

完成基础练习只说明比较问题已经定义清楚，还需要实际计算和解释替代方案。

### 标准任务（本课应完成）

完成上面的五项分析任务。至少比较“基准方案＋一种替代方案”；也可以比较两种替代方案。两种方案都要由程序实际计算，并列出记录数、分母、单位和差值。最后说明原结论应保留、增加条件还是改变。这一层不要求为了出现反转而继续调参数。

### 提高与拓展（提前完成后）

标准任务完成后任选一项：

- **二维敏感性分析：**预先选择两个有实际依据的分析选择，例如两个记录范围和三个固定阈值，分别只改变一项并整理成表。指出哪些组合会改变建议，不能看到结果后继续添加有利参数；
- **决策边界：**在事先说明的合理范围内，找出第一次会改变行动建议的阈值或记录范围。如果没有改变，就报告已经检查的范围，不写成“任何条件下都稳健”；
- **时间或业务迁移：**把同一分析方案用于两个预先确定的时期或业务类别，比较方向、大小和适用范围。它仍使用同一数据来源，不能称为独立验证；
- **独立复算：**用另一种实现从原始数据重算一个关键差值或分位数，核对筛选条件与分位数算法，并解释任何不一致。

提高部分的价值来自结论经受了更有针对性的检查，而不是生成更多相似图表。

## 运行和提交

```bash
python scripts/course.py start 02
python scripts/course.py run 02
```

打开 `lesson-02/artifacts/starting_overview.json`，把起点结果翻译成完整句子。修改 `analysis.py` 或另写程序，把两种方案的结果保存到 `artifacts/`。完成后运行：

仅提交这个概览还没有完成作业；你仍要实际计算替代方案、比较差异并修订结论。

```bash
python scripts/course.py run 02
python scripts/course.py check 02
```

填写 `submission.json`，按工作流提交并创建 `v2-l02-final` 标签。检查通过不代表统计结论自动合理。
