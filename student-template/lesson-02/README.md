# 第2课｜结论的敏感性分析

选择第1课的一句探索性结论，检查换一种合理分析选择后是否仍成立。

## 学习顺序

先读[知识讲解](LEARN.md)，完成手算与自检，再按本页设计正式分析。遇到具体操作问题查[运行帮助](SUPPORT.md)。已完成的作业无需重交。

## 数据与条件

本课数据为教学合成资料，不对应真实机构或个人。

沿用第1课 `data/service/` 的第一期教学工单与字段说明，不修改原始CSV。

已服务等待只纳入明确未放弃且等待有效的工单；放弃者的等待计到离开。比例按字段有效的指定范围计算，分母为零标为未定义。

## 标准任务

1. 写明原结论、用途、时期、分析单位、纳入规则、指标和比较对象。
2. 提出一至两种有理由的替代选择，至少实际比较基准与一种替代方案。
3. 并列每种方案的记录数、分母、单位、结果及按相同方向计算的差值。
4. 分别判断方向、大小与行动建议是否改变，并区分改变计算选择与改变目标人群。
5. 说明已检查的范围；同一期反复分析仍属探索，独立验证需要未参与发现的资料。

至少自主决定核实哪句结论，以及采用哪种有依据的替代范围、指标或方法。提交稳定性报告、并列表或图及可运行程序。

## 运行与提交

在学生仓库根目录运行：

```sh
python3 scripts/course.py start 02
python3 scripts/course.py run 02
```

默认输出是分析起点，正式作品还需上述比较与建议。保存原始CSV，自己的结果放在 `lesson-02/artifacts/`。在 `submission.json` 中登记报告路径、产物和重建命令参数列表，完成后设 `status=complete`。

```sh
python3 scripts/course.py check 02
```

`check`核对状态、路径和文件，不重新运行分析。按[提交工作流](../docs/WORKFLOW.md)提交，标签沿用 `v2-l02-final`，修订保留旧标签。课堂选择题按教师开放场次完成，说明见[知识自查](../docs/KNOWLEDGE_CHECK.md)。

## 可选拓展

围绕同一作品增加一个有实际用途的检查，如另一种范围、指标或假设，并解释新增证据怎样影响建议。AI可辅助学习、编程与写作；分析选择和结果解释由你完成。评分与原作业要求不变。
