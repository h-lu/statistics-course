# 第2课 · 分析结论对统计口径有多敏感

本课使用**教学合成数据**，即为学习而生成的数据，不是真实机构或个人的记录。你可以全程使用AI帮助理解概念、编程、分析和写作，但提交前要核对结果和结论。

第一次使用这些资料时，可先看[阅读材料与运行程序的小指南](../docs/READING_GUIDE.md)。

## 项目背景

上一课形成了初步结论。本课进一步问：采用另一种同样有道理的计算范围或方法，结论会不会改变？这就是敏感性分析。它不是反复调数直到得到喜欢的结果，而是说明结论在什么条件下成立。

本课不计分，但须完成项目和知识自查；入门成果在第二周开始前补齐。

## 可用数据

继续使用第一期 `data/service/tickets.csv`、窗口表和业务类型表，必要时使用满意度或排班资料。字段解释见[数据说明](../data/service/README.md)，概念和算例见[知识准备](LEARN.md)。

只分析已服务工单、纳入放弃者、计算均值或中位数，可能回答不同问题。比较分析口径时应说明采用哪些记录。第二期是不同时间的资料，不能把时期变化当成第一期换计算方法的效果。

## 分析任务

1. **确定原有结论和基准方法。** 基准方法就是用来与其他方法比较的原方案；可以延续第1课，也可以在本课数据中提出新的初步结论。写清时期、分析对象、纳入规则、指标含义、计算方法和比较对象。
2. **选择两到三种有理由的替代口径。** 可比较已服务与全部登记工单、合并与分层结果、不同统计量，或有业务依据的日期范围。一次改变一个主要选择；同时改变多项时说明各项是什么。
3. **列出比较结果。** 用一张表说明每种方法的理由、采用的记录、每组记录数、分母、结果和单位。报告差异的方向与大小，不能只写“有变化”。先固定差值顺序，例如“中心A减中心B”；负数表示A的该项指标较小，各方案不要交换顺序。某组没有记录或分母为0时，说明无法计算，不填0来制造差异。
4. **解释为什么不同。** 是在同一个问题下换了算法，还是换了统计量或研究对象？均值与中位数不同不表示计算错误；分层结果不同也不自动证明因果关系。
5. **修改结论。** 哪些表述仍可保留，哪些需要说明条件，哪些建议应调整？没有方向反转也是结果。同一批数据反复分析，不能称为已经完成独立验证。

## 需要提交什么

报告包含原有结论、基准方法、两到三种替代口径及理由、比较表和修订后的结论。关键结果应能由程序重新计算，分位数算法应注明并保持比较一致。

原方法和替代方法都要与实际问题有关。可以借助AI实现计算，但不要只保留符合预期的结果。进一步完善应解释变化为什么影响建议，不必增加无关模型。

## 课堂安排

0—12分钟阅读知识与例子；12—22分钟确定原结论和基准方法；22—53分钟比较；53—68分钟解释并修改报告；68—75分钟检查提交；75—90分钟知识自查。可直接复用第1课的读表程序。

## 示例运行后，接下来做什么

初次运行会生成本课的 `artifacts/starting_overview.json`。JSON是一种按字段名保存结果的文本格式，可以用编辑器打开。终端打印的是文件位置，不是完整分析报告。

`n` 是所有中心合并后的已服务工单数；`mean`、`median` 分别是均值、中位数，`q1`、`q3` 是第一、第三四分位数，`p90` 是第90百分位数。它没有分中心比较，也没有计算你的替代口径。

先阅读输出中与你的问题有关的内容，再按上面的分析任务扩展程序。自己的计算结果可以另存文件；仅提交这个概览还没有完成作业。

## 运行与提交

在自己的学生仓库根目录运行命令，也就是包含 `scripts/` 和 `data/` 的文件夹。若使用完整课程资料库，先进入 `student-template/`。

```bash
python scripts/course.py start 02
python scripts/course.py run 02
```

`analysis.py` 只演示读取数据和简单统计，不是完整作业。根据本课问题修改或替换程序，将结果和图表保存到本课 `artifacts/` 文件夹，并在 `report.md` 中解释和引用。原始数据保持不变；程序使用的新软件包写入 `requirements.txt`。

完成后，在 `submission.json` 中将 `status` 改为 `complete`，填写报告路径 `report`、结果文件列表 `artifacts` 和运行命令 `run`。路径从学生仓库根目录写起；更换程序时要相应更新命令。然后重新运行并检查：

```bash
python scripts/course.py run 02
python scripts/course.py check 02
```

**`run` 执行程序；`check` 只检查完成状态、路径和文件是否存在且非空，不会重新运行分析，也不判断统计结论。** 按[操作与提交步骤](../docs/WORKFLOW.md)提交并推送到个人仓库，创建本课最终标签 `v2-l02-final`，再查看自动检查结果。自动检查可以核对程序能否重新生成所列结果，但不能代替对分母、方法和结论的判断。

已有最终标签不要覆盖，修改时保留原版本。遇到网络、环境或检查失败，保存本地文件和提交，并向教师说明。详细命令、结果文件设置和修订办法见上述操作说明，评分见[成果与评分](../docs/ASSESSMENT.md)。

最后约15分钟进入[知识自查](https://hblu.top/stat-check/)，确认页面为第2课。建议先完成A题，学习不熟悉的概念，再完成B题并阅读反馈。AI始终可用，不要求提交对话；正确率用于反馈，不直接计分。详见[知识自查说明](../docs/KNOWLEDGE_CHECK.md)。
