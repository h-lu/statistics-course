# 第2课：分析结论对统计口径有多敏感

本课使用**教学合成数据**。可以全程使用 AI；待检查的结论、比较方案、方法及建议由你确定。先读本页明确目标；需要概念时查 [LEARN](LEARN.md)，遇阻时任选 [SUPPORT](SUPPORT.md) 的提示，不要求采用同一分析路线。工具操作见[阅读与运行指南](../docs/READING_GUIDE.md)。

## 情境与目标

管理者准备引用第 1 课简报中的一句话，希望知道在另一种有理由的分析选择下，它还应怎样表述。**统计口径**是纳入哪些记录、指标怎样定义和计算；**敏感性分析**有依据地改变一个选择，实际重算，检查结论和行动的变化。你可以选择另一句值得核实的探索性结论，不限定中心对、指标或比较方式。

## 可用资源

继续使用第一期 `data/service/tickets.csv`、`windows.csv` 和 `business_types.csv`。日期、业务与等待终点见[数据说明](../data/service/README.md)。本课无需处理第 3 课的第二期原始导出。没有上一课报告时可自行建立待核实基准，仍应写清它的用途和数据范围。

`analysis.py` 仅给原合并已服务概览，生成 `lesson-02/artifacts/starting_overview.json`，并提供读表、分位数、描述统计和比例基础函数。可以复用、自写代码或使用别的合理工具；没有锁定候选方案的菜单或一键完整分析。

## 三层任务

### 基础练习（可信起点）

选一句具体结论，说明时期、分析单位、记录范围、指标、分母与单位；用概览或自己计算核对一个结果，再说明一个有理由的替代选择及预计。定义比较问题尚未完成本课，标准任务还需实际比较和结论修订。

### 标准任务（本课应完成）

提交结论稳定性报告、并列比较证据与可运行程序。成果需覆盖以下五项要求，可自行安排研究顺序：

- 固定原结论、用途和基准方案，包括时期、单位、纳入规则、指标与比较对象。
- 选择一至两种有理由的替代统计口径并实际计算，最低为基准＋一种替代。
- 列每种方案的记录数、分母、单位、指标结果和统一方向差值，解释变化来源。
- 判断方向、大小和行动是否变化，区别改变同一问题的计算选择与更换目标人群/评价目的；保留、加条件或修订原结论。
- 说明已检查范围、不能由这些比较证明什么。同一批数据找发现和做敏感性仍属探索，不自动是独立验证或因果效果。

**至少两项重要决定留给你：**第一，哪一句结论值得核实及其使用目的；第二，哪种替代范围、指标或方法有实际依据。最终的稳定性判断、发布措辞和行动也由你决定。多种合理路线均可接受；没有反转不是失败，缺少计算与解释才是证据不足。

### 提高与拓展（提前完成后）

选择有理由的新问题，自拟或参考以下方向：分析两项选择共同作用，检查行动变化的边界，迁移到另一预定业务/时期，比较总负担与稳健描述，或独立复算关键分位数。它们不是必做方法菜单。说明新增结果如何改变使用范围、行动或表述；先限定有实际解释的范围，事后新发现标为探索，不无限扫描挑喜欢的结果。

## 证据自检与提交

各方案实际计算、差值顺序一致、算法与单位清楚；范围改变不能藏在同名指标里；结果能由程序重建；零分母和空组不写成 0；原始 CSV 未覆盖。

在有 `scripts/`、`data/` 和 `lesson-02/` 的学生仓库根运行：

```bash
python3 scripts/course.py start 02
python3 scripts/course.py run 02
```

本环境使用 `python3`；`python` 若是 Python 3，可用 `python scripts/course.py run 02`、`python scripts/course.py check 02`。**仅提交这个概览还没有完成作业**，它没有替代比较与稳定性论证。修改代码或另写分析，结果存到本课 `artifacts/`。

填写 `submission.json` 的报告、实际结果路径和重跑命令参数列表；完成后才设为 `complete`：

```bash
python3 scripts/course.py run 02
python3 scripts/course.py check 02
```

本地 `check` 只检查状态、路径、文件是否存在且非空，**不会重新运行分析**或评价结论。按[工作流](../docs/WORKFLOW.md)核对暂存内容并提交，使用 `v2-l02-final`，修订保留旧标签。
