# 第2课可选支持：比较问题由你确定

README 给情境、成果与证据边界。先自主分析；遇到阻塞时按相关问题选择下面的提示，不需要逐项跟做，不限定你的基准和替代方法。

## 选不出值得核实的结论

**轻提示：**找一句会影响使用者行动的具体话，说明它描述谁、什么时期、什么指标。没有第 1 课报告也可以自己建立基准。

**更具体的提示：**“最好”通常太宽；可以把它缩为关于某个经历或结果的可计算描述。具体目标仍由你定，不要求比较 A 与 B，也不规定均值。成功信号是读者知道这句话为什么值得核查，而非只知道要多算指标。

## 不确定指标和算法

**轻提示：**均值、中位数、分位数与离散程度描述不同方面；先明确目标，算法写清。

**更具体的提示：**看 LEARN 的四条独立记录手算例子，固定差值方向与线性插值位置。`analysis.py` 提供 `read`、`linear_quantile`、`describe`、`rate` 基础函数，可供自己的任何合理分析复用；你决定筛选、分组、指标和比较。空组/零分母返回 `None`，不是零。

## 不知道哪些备选合理

**轻提示：**写清原方案保持什么、替代改变什么，以及改变为何与问题有关。备选须实际计算，不要求结论反转。

**更具体的提示：**替代可涉及记录范围、描述目标、分组方式、合法算法或别的有依据选择；这些是类型提示，不是候选菜单。若同时改变多项，考虑如何判断变化来源。成功信号是能解释它仍描述同一问题，还是转到另一人群/目标。

## 结果不同，但不知道怎样判断

**轻提示：**分别看方向、大小和行动，不把“没反转”当“完全一样”。差值先定谁减谁；分钟差还是比例差要区分。

**更具体的提示：**对自己的结果问：“这项变化只影响措辞，还是会改变行动？检查范围之外还有什么未知？”若改了指标目标，两种结果可能都正确；只检查有限变化，结论也限于该范围。LEARN 有单位和探索/验证解释，没有正式项目参考结论。

## 标准已完成，需要更深的问题

从原结论的薄弱处自选新检查，如两项选择共同作用、行动边界、业务/时期迁移、总负担与稳健描述取舍或独立复算，也可自拟。你决定有意义的范围、方法和行动规则。完整报告新增证据的后果，不挑选唯一有利结果；事后新问题标为探索。

## 操作或提交卡住

- 在能看到 `scripts/`、`data/`、`lesson-02/` 的学生仓库根运行。终端命令不是在 `>>>` 输入；本环境用 `python3`，基础函数标准库可离线运行。
- 基础入口是 `python3 scripts/course.py run 02`，只有 `starting_overview.json`，它不计算你的替代方案。自行写/改分析或用其他工具，将支持报告的结果保存到本课 `artifacts/`。
- 数字不一致先查日期、对象、纳入规则、单位和分母，再查算法与差值方向；不要改结果使其符合预计。
- `submission.json` 的 `run` 是实际命令参数列表，能重建所列文件；默认基础入口不会记住额外手动分析。完成标准任务后才设 `complete`。
- 运行 `python3 scripts/course.py run 02` 和 `python3 scripts/course.py check 02`，再按[工作流](../docs/WORKFLOW.md)检查暂存内容；文件齐全不能代替结论与证据一致。
