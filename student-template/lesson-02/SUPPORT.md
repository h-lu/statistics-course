# 第2课可选支持：比较问题由你确定

README 说明情境、成果与证据要求。你可直接开展分析；遇到困难时选择下面相关的提示，无需逐项跟做。基准方案和替代方法由你决定。

## 选不出值得核实的结论

**轻提示：**找一句会影响使用者行动的具体结论，说明它描述谁、什么时期、什么指标。没有第 1 课报告，也可以自己先计算一项结果作为比较起点。

**更具体的提示：**“最好”通常不够具体，可以改为描述某种经历或结果的句子，并让它能由数据检查。目标仍由你定，比较对象和指标由你选择。应让读者知道这句话为什么值得核查，而不只是列出更多指标。

## 不确定指标和算法

**轻提示：**均值、中位数、分位数与离散程度描述不同方面；先明确目标，算法写清。

**更具体的提示：**看 LEARN 中两组各四张工单的手算例子，核对差值的相减顺序和线性插值位置。`analysis.py` 中，`read` 用于读表，`linear_quantile` 计算分位数，`describe` 给出描述统计，`rate` 计算比例。你决定纳入哪些记录、怎样分组、使用什么指标和比较方式。没有记录时，描述指标返回 `None`；比例的分母为 0 时，`rate` 也返回 `None`。保存为 JSON 后显示为 `null`，表示无法计算，不是零。

## 不知道哪些备选合理

**轻提示：**写清原方案保持什么、替代改变什么，以及改变为何与问题有关。备选须实际计算，不要求结论反转。

**更具体的提示：**替代可涉及记录范围、描述目标、分组方式、不同的分位数计算约定或其他有依据的选择。若同时改变多项，考虑如何判断变化来源。应能解释替代方案是在检查同一问题，还是转向了另一人群或目标。

## 结果不同，但不知道怎样判断

**轻提示：**分别看差值方向、大小和行动建议，不把“没反转”当“完全一样”。先定谁减谁；等待时间的差用分钟，两个比例的差用百分点。

**更具体的提示：**对自己的结果问：“这项变化只影响措辞，还是会改变行动？检查范围之外还有什么未知？”若改变了指标所描述的目标，两种结果可能都正确；只检查有限变化，结论也限于该范围。概念不清楚时，可查 LEARN 中关于单位、探索与验证的解释。

## 标准任务已完成，想继续深入

针对原结论中证据不足的部分，自选一项新检查。可同时改变两项选择，研究在什么条件下建议的行动开始变化，将分析用于其他业务或时期，比较平均负担与稳健描述，或独立复算；也可自拟。范围、方法和行动规则由你决定。完整报告新增结果对建议的影响，不只留下有利结果；事后出现的新问题要标为探索性问题。

## 操作或提交卡住

- 在能看到 `scripts/`、`data/`、`lesson-02/` 的学生仓库根目录运行命令。命令要在终端输入，不在 Python 的 `>>>` 后输入。以上命令使用 `python3`；示例程序只用 Python 自带的标准库，无需安装第三方包。
- 运行 `python3 scripts/course.py run 02` 会生成 `lesson-02/artifacts/starting_overview.json`，它不计算你的替代方案。自行编写或修改分析程序，也可用其他工具，将支持报告的结果保存到本课 `artifacts/`。
- 数字不一致先查日期、对象、纳入规则、单位和分母，再查算法与差值方向；不要改结果使其符合预计。
- `submission.json` 的 `run` 是实际命令参数列表。例如 `["python3", "lesson-02/analysis.py"]` 相当于在学生仓库根目录运行 `python3 lesson-02/analysis.py`。如果另写程序或增加参数，要填写实际命令，使它能重新生成 `artifacts` 中列出的文件；单独做过的计算不会自动纳入这条命令。完成标准任务后才把 `status` 设为 `complete`。
- 运行 `python3 scripts/course.py run 02` 和 `python3 scripts/course.py check 02`，再按[工作流](../docs/WORKFLOW.md)检查暂存内容；文件齐全不能代替结论与证据一致。
