# 第2课知识准备：为什么统计口径会改变结论

本课学习一个重要习惯：看到结果先问“这些记录怎样选、这个指标怎样算”。

## 1. 分位数和离散程度

**分位数**是排序后的位置。第50百分位数是中位数，第90百分位数表示约90%的纳入记录不超过这个值，不等于最大值。不同软件可能采用不同插值约定，报告应说明采用的方法。

**离散程度**描述记录相差多大。四分位距是第三四分位数减第一四分位数，标准差描述数据围绕均值的离散程度。它们回答“差异有多大”，不是“平均等待多少”。

## 2. 一个可手算的比较

两组等待：X=4、5、5、6、40，Y=8、9、10、11、12。X均值12、中位数5；Y均值10、中位数10。若关心中间记录，中位数偏向X；若关心长等待或均值，Y更好。两种结果都可能正确，因为评价问题不同。

删除X的40后均值变成5，不能说服务改善，因为那张长等待仍发生过。排除规则必须在看结果前有理由。

## 3. 什么是敏感性分析

先固定基准方案，再改变一个有理由的选择，重新计算并比较。可以改变统计量、记录范围、阈值或分组方式。报告要说：改了什么、影响了哪些记录、结果变多少、建议是否改变。只检查过三种阈值，不能声称在所有阈值下稳健。

## 4. 回到项目

为每个方案写清分析单位、纳入记录、指标、分母和单位。均值、中位数、分位数没有谁在所有问题上都更正确；选择取决于使用者关心通常水平、长尾、总量还是超过门槛的记录。关联差异也不自动等于因果效果。

## 自测

如果两种方案的结果相同，是否说明方案没有区别？不一定，记录范围和风险解释仍可能不同。先写你的答案，再回看“改了什么、保持什么”的记录。

## 3. 一个完整的敏感性分析记录

可以用下面的表记录你的比较：

| 项目 | 基准方案 | 替代方案 |
|---|---|---|
| 记录范围 | 例如已服务工单 | 例如全部登记工单 |
| 指标 | 例如中位数 | 例如均值 |
| 分母 | 有效等待记录数 | 登记工单数或有效记录数 |
| 预计变化 | 运行前写 | 运行后填写 |
| 结果和单位 | 运行后填写 | 运行后填写 |
| 建议 | 保留、加条件或改变 | 保留、加条件或改变 |

先填预计，再运行。若结果没有变化，检查是否真的改变了纳入记录或算法，不要为了“看到变化”继续修改无关设置。

## 练习：结论的边界

如果只检查了三个合理阈值，结论应写“在这三个阈值下结果相近”，不能写“无论阈值怎样结论都不变”。如果替代方案改变了分析单位，就要说明它已经回答了不同问题，不能把它当作同一个指标的简单复核。
