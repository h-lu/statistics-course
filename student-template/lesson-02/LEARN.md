# 第2课知识准备 · 换一种合理方法，结论会怎样

两种计算结果不同，不一定有一种算错了。本课学习先看它们回答的问题是否相同，再判断结论对分析选择是否敏感。

## 1. 先说明统计口径

**统计口径**是对分析范围、指标含义和计算方法的约定。例如，“第一期已服务工单的平均等待时间”说明了时期、记录范围和统计量。只写“平均等待”还不够清楚。

**敏感性分析**是有理由地改变分析中的方法或假设，查看结果怎样变化。若结论在所考察的合理变化下大体保持，可说它较为**稳健**。这只针对已经考察的条件，不表示任何情况下都成立。

改变分析方法时，还要区分是否换了问题。例如，均值与中位数描述不同特征；只看已服务工单与纳入放弃者，也描述不同的经历。

## 2. 先认识分位数和四分位距

将数据从小到大排列，**第90百分位数（P90）**描述接近排序后90%位置的数值，可以帮助观察较长的等待。它不是最大的90个值的平均数。样本较小或有并列值时，不应理解成恰好90%的记录小于这个数。

第一四分位数和第三四分位数分别对应约25%和75%的位置。两者之差称为**四分位距（IQR）**，主要反映中间一半数据的分散程度。**标准差**也是描述离散程度的统计量，但较大的偏离对它影响更明显。它们的单位与原变量相同。

## 3. 两组等待时间的完整例子

以下两组都是另设的已服务工单，单位为分钟：X为2、3、4、31，Y为8、9、10、13。先预测：两组均值一样，能否说等待情况完全相同？

| 统计量 | X | Y | X减Y |
|---|---:|---:|---:|
| 均值 | 10 | 10 | 0 |
| 中位数 | 3.5 | 9.5 | −6 |
| P90，采用线性插值 | 22.9 | 12.1 | 10.8 |

X的均值为(2＋3＋4＋31)÷4＝10；Y的均值也为10。中位数分别为(3＋4)÷2＝3.5和(9＋10)÷2＝9.5。X中间位置的等待较短，但有一条31分钟的长等待。

本例用**线性插值**计算分位数：所需位置落在两个数之间时，按距离在两者之间取值。4个数的P90位置为1＋(4−1)×0.9＝3.7，即第3与第4个数之间。因此X的P90为4＋0.7×(31−4)＝22.9，Y为10＋0.7×(13−10)＝12.1。

较准确的结论是：“两组均值相同，但中位数和较高分位数不同。”中位数差为−6不能推翻均值差为0，因为它们回答不同的问题。

## 4. 稳健不等于忽略长等待

再看2、4、6、8、40：均值12，中位数6，按上述方法计算的四分位距为8−4＝4。将40改成80后，均值变为20，中位数和四分位距不变。

这说明中位数和四分位距受这个极端变化的影响较小，但总等待时间确实增加了。若管理者关心总等待负担，不能只报告中位数没有变化。

## 5. 分层比较与结论的适用条件

**分层比较**是先按业务类型等特征分组，再在同一组内比较中心。复杂业务比例不同，可能使合并结果与同类业务比较不同。若合并方向与各层方向相反，称为**辛普森悖论**；应核对各层人数和比例，而不是立即认定计算错误。

相同业务类型内部仍可能存在难度差异，分层不自动证明因果关系。反复使用同一批数据寻找模式，仍属于**探索性分析**。在多种方法下得到相似结论，也不等于用另一批未参与分析的数据完成了独立验证。

## 在项目中使用

先写原有结论和计算方法，再选择两到三种有理由的替代口径。列出每种方法采用哪些记录、记录数、结果和单位，说明结果变化后哪句话或哪项建议需要修改。没有方向反转也可以是有价值的结果。

某组没有记录时，均值或比例不能计算；不能填0后再计算组间差异。分位数算法要保持一致。计算标准差时，应注明采用分母n还是n−1，其中n为参与计算的记录数；标准差不要与后续课程中的标准误混用。

```python
# learning-example
import json
import statistics as st
def quantile(values, p):
    x = sorted(values)
    h = (len(x) - 1) * p
    lo = int(h)
    return x[lo] + (h - lo) * (x[min(lo + 1, len(x) - 1)] - x[lo])
x, y = [2, 3, 4, 31], [8, 9, 10, 13]
result = {"mean_difference": st.mean(x) - st.mean(y),
          "median_difference": st.median(x) - st.median(y),
          "p90_x": quantile(x, .9), "p90_y": quantile(y, .9),
          "p90_difference": quantile(x, .9) - quantile(y, .9)}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
