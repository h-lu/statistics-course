# 知识准备 · 结论对哪些选择敏感

## 必须理解：先固定问题，再比较方案

基础阅读建议7—10分钟。**统计口径（分析规格）**是单位、纳入范围、变量定义、统计量、比较对象和时期的完整约定。**估计对象（目标量）**是希望回答的具体数量或比较，例如本期已服务工单的平均等待差。

**敏感性分析**有理由地改变关键选择，研究方向、大小或行动如何变化；**稳健性**表示在所考察变化下结论较稳定，不表示适合所有目标。把均值换成中位数，或把已服务工单换成全部登记工单，可能已经改变目标，不能把所有差异都解释为原方法不可靠。

## 完整例子：三种统计量，各自回答什么

两组均为已服务工单：X为2、3、4、31分钟，Y为8、9、10、13分钟。先固定这两组记录，预测“平均一样”是否意味着分布一样。

| 统计量 | X（分钟） | Y（分钟） | X−Y（分钟） |
|---|---:|---:|---:|
| 均值 | 10 | 10 | 0 |
| 中位数 | 3.5 | 9.5 | −6 |
| P90，线性插值 | 22.9 | 12.1 | 10.8 |

均值差0描述总等待负担平均分摊的差；中位数差−6描述中间位置差，不能“推翻”均值；P90描述较高累计位置。应把“X与Y等待一样”改成“本例两组均值相同，但中间位置和较高分位不同”，并根据使用目标选择重点。

分位数不是最大的90个值的平均数。本例排序位置从0开始，`h=(n−1)p`；P90有h=2.7，X为4+0.7×(31−4)=22.9，Y为10+0.7×(13−10)=12.1。小样本与插值不保证恰有90%的记录低于结果，更不能保证未来90%的人如此；报告算法而不只写函数名。

## 离散与极端值

IQR=Q75−Q25，描述中间一半的跨度；标准差描述围绕均值的离散，单位与原变量相同，注明使用分母n还是n−1。标准差不是标准误，也不是均值是否可信的直接概率。

另例2、4、6、8、40的均值12、中位数6、IQR4；把40改成80，均值变20，中位数与IQR不变。稳健统计保护中部描述，但总等待负担确实增加，不能据“中位数没变”否认尾部问题。

## 分层、目标和验证

**分层比较**在同类业务内比较。业务构成可能影响合并差异；若合并方向与各层方向相反，可能出现辛普森悖论，要先看分母和构成，不立即认定软件出错。相同业务层仍可能有未记录难度差异，不能自动作因果解释。

同一数据上反复尝试仍是探索。方案间一致可支持“在考察的口径下较稳定”，不等于独立验证；发现后再挑出一致的方案也不能证明稳健。

## 回到项目

基准之外选两到三种有实际理由的替代口径，记录哪些条件变了、目标是否相同、各组n、数值、单位，以及哪句话或哪项行动需要改。一次改变一个主要选择，或说明同时改变的因素。没有反转也是结果；空组记未定义，不能以0制造差值。

可以让AI提出候选口径，但要排除无用途的参数遍历，不只留下喜欢的结果。可请AI换一个情境检查你能否区分“换目标”与“同目标下不同算法”，无需提交对话。

## 按需核算：线性分位数

```python
# learning-example
import json
import statistics as st
def quantile(values, p):
    x = sorted(values)
    h = (len(x) - 1) * p
    lo = int(h)
    return x[lo] + (h - lo) * (x[min(lo + 1, len(x) - 1)] - x[lo])
x, y = [2, 3, 4, 31], [8, 9, 10, 13]
result = {"mean_difference": st.mean(x) - st.mean(y),
          "median_difference": st.median(x) - st.median(y),
          "p90_x": quantile(x, .9), "p90_y": quantile(y, .9),
          "p90_difference": quantile(x, .9) - quantile(y, .9)}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
