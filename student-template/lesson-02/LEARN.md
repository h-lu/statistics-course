# 第02课 · 平均都等10分钟，体验就一样吗？

假设两组人工工单的等待时间分别是：

|组别|四张工单的等待（分钟）|
|---|---|
|X|2、3、4、31|
|Y|8、9、10、13|

你可能马上注意到：X有三张很快，却有一张特别慢；Y较集中。两组总等待都是40分钟，平均都是10分钟，但单凭这个平均数，还看不出刚才两种不同的等待经历。

本课沿用这两组记录，先比较中间位置和较长等待，再问：如果换一种有理由的指标或统计范围，原来的建议还成立吗？这叫作**敏感性分析（sensitivity analysis）**。目的不是挑一个喜欢的答案，而是弄清一句结论依赖什么。

需要复习均值、中位数和比例时，可以回看[第1课](../lesson-01/LEARN.md)。

## 1. 先比较中间位置，再看较长等待

继续使用上面的两组已服务工单。先猜哪组的中间等待较短、哪组的长等待更突出，再跟着计算。所有差值都按“X减Y”，这样负号和正号才有一致含义。

两组等待时间之和都是 40 分钟，均值均为 `40/4=10` 分钟，均值之差为 0 分钟。中位数分别为 `(3+4)/2=3.5` 和 `(9+10)/2=9.5` 分钟，差为 `3.5−9.5=−6` 分钟。负号表示 X 的中位数较低，不能据此说 X 的总等待时间也较少。

本课用线性插值法（linear interpolation）计算第90百分位数（90th percentile），即在相邻两个排序值之间，按所需位置计算一个中间值。对 `n` 个排序值，位置为 `h=(n−1)×p`：`n` 是记录数，第 90 百分位数用 `p=0.9`；排序位置从 0 开始，所以四个值的位置依次为 0、1、2、3。

可以先把X的排序位置单独写出来：

|从0开始的位置|0|1|2|3|
|---|---:|---:|---:|---:|
|X等待（分钟）|2|3|4|31|

两组均有 `n=4`，因此位置都是 `h=(4−1)×0.9=2.7`，位于位置 2 和位置 3 之间，从前者向后者走了这段距离的 70%。X 的位置 2、3 分别为 4、31，所以结果为 `4+0.7×(31−4)=22.9` 分钟；Y 的位置 2、3 分别为 10、13，所以结果为 `10+0.7×(13−10)=12.1` 分钟。两组差值为 `22.9−12.1=10.8` 分钟。不同软件可能采用其他分位数计算约定，比较时要固定算法并说明。

三个差值不矛盾：均值回答平均每张工单等多久，中位数回答排序中间的等待是多少，第90百分位数帮助我们观察较长的等待。使用者关心的目标不同，建议的行动可能不同。这两组各四条记录的例子用于学习算法，不能直接预测未来体验。

这段代码输入仍是X、Y的四个等待时间。函数linear_percentile先排序，再找位置和相邻数值；结果会打印在终端。运行后检查mean_difference为0、median_difference为−6、p90_difference约为10.8。小数显示有极小舍入差异时，先核对算法，不必把显示位数当作新的统计差异。

```python
# learning-example
import json
import statistics


def linear_percentile(values, probability):
    ordered = sorted(values)
    position = (len(ordered) - 1) * probability
    lower = int(position)
    upper = min(lower + 1, len(ordered) - 1)
    weight = position - lower
    return ordered[lower] * (1 - weight) + ordered[upper] * weight


x = [2, 3, 4, 31]
y = [8, 9, 10, 13]
p90_x = linear_percentile(x, 0.9)
p90_y = linear_percentile(y, 0.9)
result = {
    "mean_difference": statistics.mean(x) - statistics.mean(y),
    "median_difference": statistics.median(x) - statistics.median(y),
    "p90_x": p90_x,
    "p90_y": p90_y,
    "p90_difference": p90_x - p90_y,
}
print(json.dumps(result, ensure_ascii=False, sort_keys=True))
```

## 2. 刚才的比较，分别在描述什么？

| 术语 | 含义与本课例子 | 常见混淆 |
|---|---|---|
| 分位数（quantile） | 按数据排序后的位置确定的数值；第 90 百分位数对应排序中较靠后的位置，算法见前面的手算 | 不必等于最大值，也不保证未来恰有 90% 的记录不超过它 |
| 离散程度（dispersion） | 记录彼此相差多少；四分位距看排序后中间一半的跨度，标准差看数据在均值周围的离散程度 | 描述数值之间的差异，与均值或中位数描述的中心水平不同 |
| 统计口径（analysis definition） | 纳入哪些记录、指标怎样定义和计算 | 换人群或目标不能当成同一指标的算错 |
| 敏感性分析与稳健性（robustness） | 敏感性分析改变有理由的选择后重算；稳健性指结论在这些合理变化下仍能保持的程度 | 结论仅在已检查的范围内得到支持，不以挑到喜欢的结果或制造反转为目的 |
| 探索（exploration）与验证（validation） | 探索从已有资料提出发现；独立验证用未用于发现的资料检验明确的问题 | 同一期反复算、多画图或换代码不自动成为独立验证 |

## 3. 不只看位置，还要看相差多大

**四分位距（interquartile range，IQR）**是第三四分位数减第一四分位数，描述排序后中间一半数据的跨度，单位与原变量相同。第一、第三四分位数分别对应第 25、第 75 百分位数，所以上述四条记录的排序位置为 `3×0.25=0.75` 和 `3×0.75=2.25`。

用同一插值算法，X 的第一四分位数为 `2+0.75×(3−2)=2.75` 分钟，第三四分位数为 `4+0.25×(31−4)=10.75` 分钟，四分位距为 8 分钟。Y 的第一、第三四分位数分别为 `8+0.75×(9−8)=8.75` 和 `10+0.25×(13−10)=10.75` 分钟，四分位距为 2 分钟。四分位距不描述全部数值的跨度，也不直接表示最长等待是多少。

**标准差（standard deviation）**描述数据在均值周围的波动。另用2、4、6分钟这个小例，按四步算：

1. 均值是4分钟。
2. 每个数减4，得到−2、0、2分钟。
3. 把这些差平方再相加：4+0+4=8平方分钟。平方避免正负相互抵消。
4. 描述这三条记录时，按本课约定先除以3，再开平方：√(8÷3)≈1.633分钟。开平方把单位恢复成分钟。

计算器可以帮你开平方，但要知道8和3从哪里来。常见的样本标准差用n−1=2作分母，得到√(8÷2)=2分钟。两个数采用了不同计算约定，报告时不能不加说明地混用。

使用分母 `n` 不意味着这些记录覆盖了目标总体；报告时要说明计算约定。**标准误（standard error）**描述样本均值等统计估计在反复抽样时的变动，后续课程会进一步学习；它与描述数据离散程度的标准差不同。示例程序中的 `describe` 函数会输出 `std_n`。这个名字表示按记录数 `n` 作分母计算的标准差；输入是分钟，输出也以分钟为单位。

## 4. 怎样作一次有意义的敏感性分析

分析路线可自行安排，报告应让读者看清以下内容：

- 基准方案：谁使用结论，分析哪个时期、哪些对象和记录，采用什么指标，差值按谁减谁计算。
- 替代方案的理由与预期：看结果前，说明改变什么、保持什么，以及为什么与问题有关。
- 实际比较：记录两种方案的记录数、分母、结果，并按同一顺序计算差值。
- 结果的影响：分别判断差值方向、大小和行动建议是否变化；没有变化也报告已检查范围。
- 修订后的结论：换对象或评价目的时说明新目标；事后发现的新问题标为探索性发现，不说成事先计划的验证。

把 31 删除后，X 的均值变小，只说明分析排除了长等待，实际经历并未改善。长等待不一定是录入错误。若有独立测量证据表明某条记录错误，可以按有依据的规则处理，但仍需报告理由及其对结果的影响；若只是研究不易受极端值影响的稳健描述，可同时保留原始数据的平均等待，分别说明两种描述的用途。

## 5. 写结论时，单位和范围一起写

本课等待时间的均值、中位数、分位数及四分位距之差仍以分钟为单位。两个比例相减用**百分点（percentage point）**：某比例从 10% 上升到 20%，增加 `20%−10%=10` 个百分点；相对增幅以原来的 10% 为分母，是 `(20%−10%)/10%=100%`。这两种变化不能混写。没有记录的组无法计算这些描述指标，分母为 0 时也无法计算比例，要注明无法计算，不能填 0 或写成没有差异。

“方向在两个合理范围均保持”不等于“大小相同”，更不等于“行动永远不变”。若只检查三个门槛，就写“在这三个门槛下……”。有业务依据的完整比较比无限扫描更多参数更有价值。

## 6. 完成到什么程度？

- **基础完成：**算清X、Y的均值与中位数，再按步骤复算一个第90百分位数。用自己的话说明三个指标为何不矛盾。

1. **分位数：**A，排序 1、2、4、9 的第 75 百分位数按 `(n−1)p` 算多少？B，运输时长 3、3、7、15 的第 90 百分位数是多少？为什么不能直接取最大值？

3. **口径与目标：**A，从只看已服务工单的等待，改为纳入所有登记工单在开始服务或放弃离开前的等待，新增了谁的经历，等待计到何时？B，把全体学生的课程成绩改为仅到课学生的成绩，能直接说原先关于全体学生的结论被“纠正”了吗？

5. **探索与验证：**A，用同一期反复换指标检查发现，能称独立验证吗？B，事先固定规则后在后来的另一时期检查，较独立在哪里，仍需核查哪些可比条件？
