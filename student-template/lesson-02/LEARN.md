# 第02课｜相同均值，不同分布

上一课用均值、中位数和比例描述记录。这一课比较两组均值相同的等待，进一步看分布差异，以及结论是否依赖某一种分析选择。

|组别|四张已服务工单的等待（分钟）|
|---|---|
|X|2、3、4、31|
|Y|8、9、10、13|

两组总等待均为40分钟，均值均为10分钟。X有三张很快、一张很慢；Y较集中。

## 1. 比较中心与较长等待

差值统一按“X减Y”计算。两组中位数分别为3.5和9.5分钟，差为−6分钟；均值之差则为0。

**分位数**（quantile）可以进一步描述排序位置。本课程采用**线性插值**（linear interpolation）。用 $Q_p$ 表示第 $p$ 分位数。对排好序的 $n$ 个数，其位置为：

$$
h=(n-1)p.
$$

位置从0开始；第90百分位数使用 $p=0.9$ 。本例 $h=3\times0.9=2.7$ ，位于第2与第3号位置之间，从前者向后者走70%的距离。

$$
\begin{aligned}
Q_{0.9,X}&=4+0.7(31-4)=22.9,\\
Q_{0.9,Y}&=10+0.7(13-10)=12.1.
\end{aligned}
$$

第90百分位数相差10.8分钟。中位数、均值与较高分位数回答不同问题，因此可能支持不同的建议。比较时采用同一种分位数算法。

## 2. 用IQR与标准差描述离散程度

**离散程度**（dispersion）描述记录彼此相差多大。**四分位距**（interquartile range，IQR）为：

$$
\mathrm{IQR}=Q_{0.75}-Q_{0.25}.
$$

本例第一、第三四分位数的位置分别为0.75和2.25。

|组别|第一四分位数|第三四分位数|IQR（分钟）|
|---|---:|---:|---:|
|X|2.75|10.75|8|
|Y|8.75|10.75|2|

IQR描述中间一半的跨度，不能单独说明最长等待。

**标准差**（standard deviation，SD）描述数据在均值周围的波动。用2、4、6分钟手算：均值为4，偏差为−2、0、2，平方和为8。按本课描述性计算约定，用记录数作分母：

$$
\mathrm{SD}_n=\sqrt{\frac{4+0+4}{3}}\approx1.633\text{ 分钟}.
$$

平方避免正负抵消，开平方恢复分钟单位。常见的样本标准差（sample standard deviation）使用 $n-1$ 作分母，本例为 $s=\sqrt{8/2}=2$ 分钟。报告时注明约定；程序字段 `std_n` 表示前一种计算。

标准差描述观测值之间的差异；**标准误**（standard error，SE）描述反复抽样时估计值的波动，第12课再展开。

## 3. 什么是敏感性分析

**统计口径**（analysis definition）包括纳入哪些记录、指标怎样定义和计算。**敏感性分析**（sensitivity analysis）改变一个有理由的选择后重算，检查结论怎样变化。结论在合理变化下保持的程度称为**稳健性**（robustness）。

一次比较按以下顺序完成：

1. 写明原问题、记录范围、指标、单位与差值方向。
2. 说明替代选择的理由及运行前的预期。
3. 并列记录两种方案的条数、分母与结果。
4. 分别判断差异的方向、大小与建议是否变化。
5. 将结论限定到实际检查过的范围。

例如，改用中位数可以研究较典型的等待；删掉31则改变了纳入记录。后者使均值变小，并不表示服务经历已经改善。若有独立证据表明记录错误，应保存修正依据及其影响。

## 4. 百分点与相对变化

两个比例直接相减用**百分点**（percentage point）。从10%升至20%，增加10个百分点；相对增幅以原值为分母：

$$
\frac{20\%-10\%}{10\%}=100\%.
$$

等待时间、分位数和IQR的差仍用分钟表示。没有有效记录时，指标应标为未定义，并注明原因。

## 5. 探索与验证

**探索**（exploration）利用已有资料发现问题；**独立验证**（validation）使用未参与发现的资料检查明确的问题。同一期数据反复改指标仍是探索，不会因运行次数增加而成为独立验证。

```python
# learning-example
import json
import statistics


def linear_percentile(values, probability):
    ordered = sorted(values)
    position = (len(ordered) - 1) * probability
    lower = int(position)
    upper = min(lower + 1, len(ordered) - 1)
    weight = position - lower
    return ordered[lower] * (1 - weight) + ordered[upper] * weight


x = [2, 3, 4, 31]
y = [8, 9, 10, 13]
p90_x = linear_percentile(x, 0.9)
p90_y = linear_percentile(y, 0.9)
result = {
    "mean_difference": statistics.mean(x) - statistics.mean(y),
    "median_difference": statistics.median(x) - statistics.median(y),
    "p90_x": p90_x,
    "p90_y": p90_y,
    "p90_difference": p90_x - p90_y,
}
print(json.dumps(result, ensure_ascii=False, sort_keys=True))
```
