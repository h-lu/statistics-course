# 知识准备 · 结论对哪些选择敏感

## 为什么正确计算也会产生不同报告

分析通常不止一条合理路线。若使用者关心总负担，均值有意义；若关心排序中间的体验，中位数更贴近问题。变化有时说明原结论不稳定，有时只是两个分析回答了不同问题。本课要学会区分这两种情况。

## 必须理解

| 概念 | 含义 | 在项目中怎样使用 |
|---|---|---|
| 分位数 | 排序后某个累计位置对应的值 | P90描述较高位置，但不是“最大的90个值的平均” |
| 离散程度 | 记录彼此差异的大小 | 均值相同仍可能有不同波动、尾部和风险 |
| 分析口径 | 对象、范围、变量定义、算法等约定 | 比较前明确哪些保持相同、哪些改变 |
| 稳健性 | 少量极端变化下统计量或结论是否大幅改变 | 稳健不等于对任何使用目标都更合适 |
| 敏感性分析 | 有依据地改变关键选择，观察后果 | 报告方向、大小和行动建议是否改变 |
| 探索与验证 | 从数据中形成初步假设；用独立数据检验预先提出的假设 | 同一批数据反复尝试后得到的稳定表象，不自动成为独立验证 |

本课分位数采用线性插值：n个值从小到大排序，以从0开始的位置h＝(n−1)p寻找p分位数；若h不是整数，在相邻位置按小数部分插值。软件可能采用不同算法，方法名相同不保证小样本数值完全相同。

四分位距IQR＝Q₃−Q₁，是中间一半位置的跨度，单位同原变量。当前批次描述性标准差sₙ＝√[Σ(xᵢ−x̄)²/n]，表达围绕均值的离散尺度。这里采用分母n描述现有记录，不表示记录就是目标总体。

## 微型例子

等待为2、4、6、8、40分钟。先想一想：只改变最后一项，哪个统计量变化较大？

均值12，中位数6，Q₁＝4、Q₃＝8、IQR＝4，P90＝8＋0.6×(40−8)＝27.2分钟。若将40改为80，均值变为20，中位数仍为6、IQR仍为4。稳健的位置和跨度保留了中部信息，却没有否认尾部变化的重要性。

直接删除40后均值变为5，不能因此宣称“真实平均只有5”：只有确认它不属于目标对象或测量错误，删除才可能符合主分析定义。否则应保留原结果并清楚呈现删除假设下的敏感性。

## 回到项目

先明确需要核实的结论，再选择与使用目标有关的变化，例如全部已登记工单与已服务工单、不同时间范围、业务分层。为每种方案记录对象、n、指标和结果。若指标换了问题，解释问题差异；若几种同样合理的分析选择就使建议相反，应明确说明结论成立的条件，或提出补充数据的计划。

## 借助AI分析与进一步学习

AI可以生成方案比较矩阵或连续敏感性曲线。变化网格不必越大越好；重点是选择理由与实际后果。按需了解截尾均值、缩尾、重抽样稳定性，但不要把它们当作自动清洗真值的工具。

可问AI：“举例说明‘中位数更稳健’为什么不等于‘中位数更适合计算总成本’，再给我一个反例让我判断。”
