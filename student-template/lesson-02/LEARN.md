# 第2课知识准备：为什么同一批数据会支持不同表述

## 为什么要检查合理变化

管理者可能把“均值较低”写成“多数记录和长等待都更好”。本课让结论分别经历记录范围、指标和比较方式的检查。敏感性分析的价值是说明一句话在哪些条件下可用，并据此修改行动或措辞。

学完应能解释分位数算法、离散程度、统计口径、敏感性与稳健性，以及探索性发现和独立验证的区别。

## 必须理解的概念

| 术语 | 含义与本课例子 | 常见混淆 |
|---|---|---|
| 分位数 | 排序后某个位置；第 90 百分位数描述较靠后的等待 | 不是最大值，也不保证未来恰有 90% 记录不超过它 |
| 离散程度 | 记录彼此相差多少；四分位距和标准差各看不同方面 | 不是等待的中心水平，也不是标准误 |
| 统计口径 | 纳入哪些记录、指标怎样定义和计算 | 换人群或目标不能当成同一指标的算错 |
| 敏感性分析与稳健性 | 改变有理由的选择后重算；判断在已检查范围内结论是否保持 | 不以挑到喜欢的结果或制造反转为目的 |
| 探索与验证 | 探索从已有资料提出发现；独立验证用未用于发现的资料检验明确的问题 | 同一期反复算、多画图或换代码不自动成为独立验证 |

## 微型例子：先预测，再计算

另设 X 等待 2、3、4、31 分钟，Y 等待 8、9、10、13 分钟，各四张已服务工单。先预计哪个均值较低，哪个中位数较低，哪个较靠后的等待较低。固定差值为“X 减 Y”。

均值分别为 `40/4=10` 与 `40/4=10`，差为 0 分钟。中位数分别为 `(3+4)/2=3.5` 与 `(9+10)/2=9.5`，差为 `−6` 分钟。负号表示 X 的中间位置较低，不表示总负担差异也是负的。

本课第 90 百分位数采用线性插值。对 `n` 个排序值，位置为 `h=(n−1)×p`，`p=0.9`；位置从 0 开始。两组均为 `n=4`，使用**同一个插值位置** `h=2.7`。从位置 2 到位置 3 走 0.7：X 为 `4+0.7×(31−4)=22.9` 分钟，Y 为 `10+0.7×(13−10)=12.1` 分钟，差为 `10.8` 分钟。不同软件可能采用其他合法约定，比较时固定算法并说明。

三个差值不矛盾：均值描述总等待负担平均到工单，中位数描述中间位置，第 90 百分位数描述较靠后位置。使用者关心的目标不同，行动可能不同。只有四条记录的例子用于学习算法，不能直接预测未来体验。

```python
# learning-example
import json
import statistics


def linear_percentile(values, probability):
    ordered = sorted(values)
    position = (len(ordered) - 1) * probability
    lower = int(position)
    upper = min(lower + 1, len(ordered) - 1)
    weight = position - lower
    return ordered[lower] * (1 - weight) + ordered[upper] * weight


x = [2, 3, 4, 31]
y = [8, 9, 10, 13]
p90_x = linear_percentile(x, 0.9)
p90_y = linear_percentile(y, 0.9)
result = {
    "mean_difference": statistics.mean(x) - statistics.mean(y),
    "median_difference": statistics.median(x) - statistics.median(y),
    "p90_x": p90_x,
    "p90_y": p90_y,
    "p90_difference": p90_x - p90_y,
}
print(json.dumps(result, ensure_ascii=False, sort_keys=True))
```

## 离散程度：必须理解与借助工具计算

**四分位距**是第三四分位数减第一四分位数，单位与变量相同，描述中间一半的跨度。用同一插值算法，X 的第一、第三四分位数为 2.75、10.75，四分位距 8；Y 为 8.75、10.75，四分位距 2。它不把最长等待的全部负担当作中心跨度。

**标准差**描述数据围绕均值的离散。另设 2、4、6 分钟，均值为 4，离均值平方和为 `4+0+4=8`。描述这三条现有记录用分母 `n=3`，标准差 `√(8/3)≈1.633分钟`；常见样本标准差用 `n−1=2`，结果 2 分钟。使用分母 n 不意味着这些记录覆盖目标总体。**标准误**描述估计量的抽样变动，本课尚不据此作正式推断；不能与标准差混用。基础函数 `describe` 返回的 `std_n` 用分母 n，单位与传入变量相同。

## 怎样做有理由的敏感性分析

1. 固定基准：谁用结论、时期、对象、记录范围、指标和比较方向。
2. 在看替代结果前说明理由和预计：改变什么，保持什么，为何与问题有关。
3. 实际计算，记录两方案数量、分母、结果和统一方向差值。
4. 分开判断方向、大小和行动变化；没有变化也报告已检查范围。
5. 修订结论。换对象或评价目的时说明新目标；若事后发现新问题，标为探索，不把它冒充原计划验证。

把 31 删除后 X 的均值变小，只说明分析排除了长等待，实际经历并未改善。长等待不是自动的录入错误。若有独立测量证据可排除错误记录，仍需报告影响和理由；若只是研究稳健描述，可同时保留原始总负担。

## 差值的单位和结论范围

均值、中位数、分位数及四分位距之差仍是分钟。两个比例相减用**百分点**：20% 减 10% 为 10 个百分点，相对增幅为 100%，两者不可混写。空组的指标和零分母比例未定义，不能填 0 或写没有差异。

“方向在两个合理范围均保持”不等于“大小相同”，更不等于“行动永远不变”。若只检查三个门槛，就写“在这三个门槛下……”。有业务依据的完整比较比无限扫描更多参数更有价值。

## 回到项目

你自行选定基准与替代。全登记与已服务可能改变等待终点，业务/时段限制改变范围，均值/中位数/第 90 百分位数改变描述目标；这些是理解区别的例子，不是必做菜单。说明自己选择的范围、数量、单位和理由。一次只改一项较容易解释来源，联合改变时需要能辨别来源的依据。

## 独立自检与迁移

先自己写解释、手算或核对逻辑，再使用本页概念检查；随后可让 AI 给新例子。

1. **分位数：**A，排序 1、2、4、9 的第 75 百分位数按 `(n−1)p` 算多少？B，运输时长 3、3、7、15 的第 90 百分位数是多少？为什么不能直接取最大值？
2. **离散程度：**A，两组 2、4、6 与 4、4、4 均值相同，哪组标准差更大？按分母 n 核算。B，四分位距相同能否保证最大值、均值和全部尾部相同？用一个理由说明。
3. **口径与目标：**A，把已服务等待改成全部登记的队列经过时间，改的是谁和哪种终点？B，把全体课程成绩改为仅到课学生成绩，能直接称原全体结论被“纠正”吗？
4. **敏感性与稳健性：**A，三个合理门槛均保持 A 比 B 低，能写任何门槛下都低吗？怎样改句子？B，先看结果再只留下支持原话的一种方案，为什么不能说明稳健？怎样记录事后新发现？
5. **探索与验证：**A，用同一期反复换指标检查发现，能称独立验证吗？B，事先固定规则后在后来的另一时期检查，较独立在哪里，仍需核查哪些可比条件？

## 按需深入与向 AI 求助

需要联合比较时先限定有业务解释的范围，保留完整表和单项对照；需要行动边界时先写行动规则。可问 AI：“为同一组四条记录设计均值与中位数指向不同建议的例子，说明两种建议各针对什么目标，再给我一道新题。”不要求保存对话。
