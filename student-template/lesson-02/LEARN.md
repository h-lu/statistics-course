# 第2课知识准备：为什么同一批数据会支持不同表述

## 为什么要检查合理变化

管理者可能把“均值较低”写成“通常的等待和少数长等待都更短”。均值并不能单独回答这些问题。本课通过改变合理的记录范围、指标或比较方式，检查原结论是否仍能成立。敏感性分析的价值是说明一句话在哪些条件下可用，并据此修改行动或措辞。

第 1 课已介绍：均值是数值总和除以记录数；中位数是排序后的中间值，记录数为偶数时取中间两个数的均值；比例是满足条件的数量除以指定范围的总数量。需要复习时见[第 1 课知识准备](../lesson-01/LEARN.md#必须理解的概念)。

学完应能解释分位数算法、离散程度、统计口径、敏感性与稳健性，以及探索性发现和独立验证的区别。

## 必须理解的概念

| 术语 | 含义与本课例子 | 常见混淆 |
|---|---|---|
| 分位数 | 按数据排序后的位置确定的数值；第 90 百分位数对应排序中较靠后的位置，算法见下例 | 不必等于最大值，也不保证未来恰有 90% 的记录不超过它 |
| 离散程度 | 记录彼此相差多少；四分位距看排序后中间一半的跨度，标准差看数据在均值周围的离散程度 | 描述数值之间的差异，与均值或中位数描述的中心水平不同 |
| 统计口径 | 纳入哪些记录、指标怎样定义和计算 | 换人群或目标不能当成同一指标的算错 |
| 敏感性分析与稳健性 | 敏感性分析改变有理由的选择后重算；稳健性指结论在这些合理变化下仍能保持的程度 | 结论仅在已检查的范围内得到支持，不以挑到喜欢的结果或制造反转为目的 |
| 探索与验证 | 探索从已有资料提出发现；独立验证用未用于发现的资料检验明确的问题 | 同一期反复算、多画图或换代码不自动成为独立验证 |

## 微型例子：先预测，再计算

另设两组已服务工单：X 的等待为 2、3、4、31 分钟，Y 为 8、9、10、13 分钟，每组各四张工单。先预测哪组均值较低、哪组中位数较低、哪组较靠后位置的等待较低。以下各指标的差值都按“X 减 Y”计算。

两组等待时间之和都是 40 分钟，均值均为 `40/4=10` 分钟，均值之差为 0 分钟。中位数分别为 `(3+4)/2=3.5` 和 `(9+10)/2=9.5` 分钟，差为 `3.5−9.5=−6` 分钟。负号表示 X 的中位数较低，不能据此说 X 的总等待时间也较少。

本课用线性插值法计算第 90 百分位数，即在相邻两个排序值之间，按所需位置计算一个中间值。对 `n` 个排序值，位置为 `h=(n−1)×p`：`n` 是记录数，第 90 百分位数用 `p=0.9`；排序位置从 0 开始，所以四个值的位置依次为 0、1、2、3。

两组均有 `n=4`，因此位置都是 `h=(4−1)×0.9=2.7`，位于位置 2 和位置 3 之间，从前者向后者走了这段距离的 70%。X 的位置 2、3 分别为 4、31，所以结果为 `4+0.7×(31−4)=22.9` 分钟；Y 的位置 2、3 分别为 10、13，所以结果为 `10+0.7×(13−10)=12.1` 分钟。两组差值为 `22.9−12.1=10.8` 分钟。不同软件可能采用其他分位数计算约定，比较时要固定算法并说明。

三个差值不矛盾：均值将总等待时间平均到工单，中位数描述中间位置，第 90 百分位数描述较靠后的位置。使用者关心的目标不同，建议的行动可能不同。这两组各四条记录的例子用于学习算法，不能直接预测未来体验。

```python
# learning-example
import json
import statistics


def linear_percentile(values, probability):
    ordered = sorted(values)
    position = (len(ordered) - 1) * probability
    lower = int(position)
    upper = min(lower + 1, len(ordered) - 1)
    weight = position - lower
    return ordered[lower] * (1 - weight) + ordered[upper] * weight


x = [2, 3, 4, 31]
y = [8, 9, 10, 13]
p90_x = linear_percentile(x, 0.9)
p90_y = linear_percentile(y, 0.9)
result = {
    "mean_difference": statistics.mean(x) - statistics.mean(y),
    "median_difference": statistics.median(x) - statistics.median(y),
    "p90_x": p90_x,
    "p90_y": p90_y,
    "p90_difference": p90_x - p90_y,
}
print(json.dumps(result, ensure_ascii=False, sort_keys=True))
```

## 离散程度：必须理解与借助工具计算

**四分位距**是第三四分位数减第一四分位数，描述排序后中间一半数据的跨度，单位与原变量相同。第一、第三四分位数分别对应第 25、第 75 百分位数，所以上述四条记录的排序位置为 `3×0.25=0.75` 和 `3×0.75=2.25`。

用同一插值算法，X 的第一四分位数为 `2+0.75×(3−2)=2.75` 分钟，第三四分位数为 `4+0.25×(31−4)=10.75` 分钟，四分位距为 8 分钟。Y 的第一、第三四分位数分别为 `8+0.75×(9−8)=8.75` 和 `10+0.25×(13−10)=10.75` 分钟，四分位距为 2 分钟。四分位距不描述全部数值的跨度，也不直接表示最长等待是多少。

**标准差**描述数据在均值周围的离散程度。另设等待 2、4、6 分钟，均值为 4 分钟，各值与均值的差为 −2、0、2 分钟；将差分别平方再相加，得到 `(-2)²+0²+2²=8` 平方分钟。描述这三条现有记录时，用记录数 `n=3` 作分母，再开平方，标准差为 `√(8/3)≈1.633` 分钟。平方根可借助计算器或工具求出。常见的样本标准差改用 `n−1=2` 作分母，结果为 `√(8/2)=2` 分钟。

使用分母 `n` 不意味着这些记录覆盖了目标总体；报告时要说明计算约定。**标准误**描述样本均值等统计估计在反复抽样时的变动，后续课程会进一步学习；它与描述数据离散程度的标准差不同。本课基础函数 `describe` 返回的 `std_n` 是使用分母 `n` 的标准差，单位与传入变量相同。

## 敏感性分析需要说明什么

分析路线可自行安排，报告应让读者看清以下内容：

- 基准方案：谁使用结论，分析哪个时期、哪些对象和记录，采用什么指标，差值按谁减谁计算。
- 替代方案的理由与预期：看结果前，说明改变什么、保持什么，以及为什么与问题有关。
- 实际比较：记录两种方案的记录数、分母、结果，并按同一顺序计算差值。
- 结果的影响：分别判断差值方向、大小和行动建议是否变化；没有变化也报告已检查范围。
- 修订后的结论：换对象或评价目的时说明新目标；事后发现的新问题标为探索性发现，不说成事先计划的验证。

把 31 删除后，X 的均值变小，只说明分析排除了长等待，实际经历并未改善。长等待不一定是录入错误。若有独立测量证据表明某条记录错误，可以按有依据的规则处理，但仍需报告理由及其对结果的影响；若只是研究不易受极端值影响的稳健描述，可同时保留原始数据的平均等待，分别说明两种描述的用途。

## 差值的单位和结论范围

本课等待时间的均值、中位数、分位数及四分位距之差仍以分钟为单位。两个比例相减用**百分点**：某比例从 10% 上升到 20%，增加 `20%−10%=10` 个百分点；相对增幅以原来的 10% 为分母，是 `(20%−10%)/10%=100%`。这两种变化不能混写。没有记录的组无法计算这些描述指标，分母为 0 时也无法计算比例，要注明无法计算，不能填 0 或写成没有差异。

“方向在两个合理范围均保持”不等于“大小相同”，更不等于“行动永远不变”。若只检查三个门槛，就写“在这三个门槛下……”。有业务依据的完整比较比无限扫描更多参数更有价值。

## 回到项目

你自行选定基准方案与替代方案。只看已服务工单时，等待计到开始服务；纳入全部登记工单时，还包含放弃者离开前的等待。限定某种业务或时段会改变记录范围；选择均值、中位数或第 90 百分位数会改变描述目标。这些是帮助理解区别的例子，采用什么方案由你决定。说明自己选择的范围、记录数、单位和理由。一次只改一项较容易解释变化来源；同时改变多项时，需要说明怎样区分各项变化的影响。

## 独立自检与迁移

先自己写解释、手算或核对逻辑，再使用本页概念检查；随后可让 AI 给新例子。

1. **分位数：**A，排序 1、2、4、9 的第 75 百分位数按 `(n−1)p` 算多少？B，运输时长 3、3、7、15 的第 90 百分位数是多少？为什么不能直接取最大值？
2. **离散程度：**A，两组 2、4、6 与 4、4、4 均值相同，哪组标准差更大？按分母 n 核算。B，四分位距相同能否保证最大值、均值和全部尾部相同？用一个理由说明。
3. **口径与目标：**A，从只看已服务工单的等待，改为纳入所有登记工单在开始服务或放弃离开前的等待，新增了谁的经历，等待计到何时？B，把全体学生的课程成绩改为仅到课学生的成绩，能直接说原先关于全体学生的结论被“纠正”了吗？
4. **敏感性与稳健性：**A，三个合理门槛均保持 A 比 B 低，能写任何门槛下都低吗？怎样改句子？B，先看结果再只留下支持原话的一种方案，为什么不能说明稳健？怎样记录事后新发现？
5. **探索与验证：**A，用同一期反复换指标检查发现，能称独立验证吗？B，事先固定规则后在后来的另一时期检查，较独立在哪里，仍需核查哪些可比条件？

## 按需深入与向 AI 求助

需要同时改变多项选择时，先限定有实际依据的范围，保留完整结果表，以及只改变其中一项时的对照。想研究在什么条件下行动改变时，先写清采取行动的规则。可问 AI：“为同一组四条记录设计均值与中位数指向不同建议的例子，说明两种建议各针对什么目标，再给我一道新题。”不要求保存对话。
