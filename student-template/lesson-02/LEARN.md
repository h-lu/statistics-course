# 知识准备：结论对哪些选择敏感

## 1. 正确计算也可能回答不同问题

同一批数据通常有多条合理的分析路线。把等待时间取平均，回答的是总等待负担平均分摊后的问题；用中位数，回答的是排序后的中间体验；把业务合并，回答的是所有记录总体的差异；按业务分层，回答的是相同业务类型内的差异。

这些数字不同，不一定是哪个算错了。首先要问：它们是否针对同一个**估计对象（estimand）**？估计对象就是你希望数据回答的那个具体数量或比较。

## 2. 什么是统计口径

**统计口径**或**分析规格**，是一次分析中对以下内容的完整约定：

- 分析单位是什么；
- 哪些记录纳入或排除；
- 结果变量如何定义；
- 使用哪个统计量；
- 比较哪些群体、时间和业务。

例如，“第一期已服务工单的平均等待差”与“第一期所有登记工单的等待负担差”使用的记录范围不同，估计对象也不同。写敏感性分析时，必须把每种口径写清楚。

## 3. 什么是敏感性分析和稳健性

**敏感性分析（sensitivity analysis）**是在有业务或统计理由的情况下改变一个关键选择，观察结果变化多大。**稳健性（robustness）**表示在这些合理变化下，结论方向或行动判断仍大体保持。

稳健不等于对所有目的都最合适。例如中位数对极端值通常更稳健，但如果管理者关心所有等待分钟的总负担，均值仍可能更直接。选择指标时要回到使用者的问题。

一个简单例子：等待时间为2、4、6、8、40分钟时，均值是12分钟，中位数是6分钟，第一和第三四分位数是4和8，四分位距（IQR）是4。把40改成80后，均值变成20，中位数和IQR仍不变。它们都提供信息：均值显示尾部对总负担的影响，中位数和IQR描述中部位置和跨度。

## 4. 分层比较和混杂

**分层比较**是把记录按一个重要变量分成相同或相近的层，再在每层内比较，例如分别比较常规业务和复杂业务。

如果一个变量同时与比较组和结果有关，它可能是**混杂变量**。例如两个中心承接的复杂业务比例不同，业务复杂程度既影响中心构成，也可能影响等待时间；合并所有业务的中心差异就不容易解释为中心本身的差异。

如果合并数据的方向与各业务层内的方向相反，可能出现**辛普森悖论（Simpson's paradox）**。这不是计算错误，而是提醒你：合并结果和分层结果对应的比较条件不同。

## 5. 分位数和离散程度

**分位数**是排序后某个累计位置的数值。P90表示约90%的观测不超过该值，不是最大的90个值的平均数。本课示例采用线性插值：把 `n` 个值排序，以位置 `h=(n−1)p` 计算 `p` 分位数，在相邻位置之间按小数部分插值。

**离散程度**描述数据彼此相差多大。四分位距IQR是中间一半数据的跨度；标准差描述观测值围绕均值的典型偏离程度。报告中使用这些统计量时，必须写清单位、分母和计算方法。

## 6. 探索不是验证

**探索性分析**是从数据中寻找模式、提出假设和比较合理方案；**验证性分析**是对预先规定的假设和方法使用独立数据或预先设计的检验。

本课在同一批数据上反复比较，属于探索性敏感性分析。即使某个结论在多种口径下都相同，也不能把它称为独立验证；可以说它在考察的口径范围内较稳定。

## 7. 用一张表保持透明

每个分析方案至少记录：

| 项目 | 要写什么 |
|---|---|
| 对象 | 结论针对工单、来访者还是其他对象 |
| 纳入规则 | 哪些记录进入分子和分母 |
| 结果变量 | 等待、满意度或其他指标如何定义 |
| 统计量 | 均值、中位数、P90、比例等 |
| 有效观测数 | 每组的 `n` 和缺失处理 |
| 结果 | 数值、单位、差值方向和大小 |

如果你无法解释一个方案为什么合理，就不要把它作为敏感性分析的主要结果。不要为了得到稳定结论而任意删数或只报告尝试成功的组合。
