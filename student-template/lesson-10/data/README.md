# 第10课需求模型

demand.csv为教学合成数据，每行描述一种可能情况，不是一条实际日记录。

- scenario：base（基准）或stress（压力）。
- demand：当天请求数，单位为台。
- probability：该请求数在相应情境中的概率。同一情境的概率和为1。

base的三个值为40、80、160，概率0.20、0.60、0.20。
stress的三个值为40、80、200，概率0.55、0.20、0.25。

两种情境的期望均为88台。这里没有给出某一种情境比另一种更可能，也没有给出连续日之间的关联。分别评价两个情境，不自行把它们合成带“真实概率”的新分布。

容量C为0至120的整数。预订费2C，短缺数max(0,D−C)，当天总成本2C+8max(0,D−C)。预订预算240不包括事后转送费。每一天单独处理，不模拟积压。

分位数使用离散累计概率定义：将相同短缺数的概率合并、按短缺从小到大累计，首次达到目标比例的数就是分位数。不能把不同情境的行混在一起累计。

数据与第9课的单台筛查概率不是同一个对象；本表未声称由上一课直接推导。可用Python标准库完成本课，不需要下载数据或安装新模型。
