## 我不知道该从哪里算起

先选一个容量C，再对需求表中的每一行算三件事：

1. 短缺 = max(0，需求−C)；
2. 总成本 = 2C + 8×短缺；
3. 将短缺是否大于0、短缺数量和总成本，分别按该行概率加权。

三个加权结果分别对应短缺概率、平均短缺数量和平均总成本。分清它们的分母与单位。

如果用表格软件，可以把这三列加在原表副本中；原始data/demand.csv保持不变。

## 想使用少量Python工具

本课capacity_tools.py提供读取、单方案精确计算和模拟工具。它不会替你挑选容量、比较目标或写结论。

在lesson-10目录中的自己脚本里可以写：

```python
from pathlib import Path
from capacity_tools import load_scenario, exact_metrics

here = Path(__file__).resolve().parent
states = load_scenario(here / "data/demand.csv", "base")
result = exact_metrics(states, capacity=60)
print(result)
```

60只是展示怎样调用，不是推荐容量。你需要选择自己的方案并解释。工具也可用于其他容量的小例，因此不会替你检查正式任务的240元预算；正式方案仍需自己核对2×容量不超过240。

## 我算出的短缺概率超过1了

检查是否把base与stress混在一起相加。每个情境是一份独立分布，概率应各自加到1。

也检查是否把“短缺台数×概率”当成短缺概率。短缺概率只把发生短缺的那些情况的概率相加。

## 模拟怎样与精确值核对？

先固定一个情境和容量。用精确加权得到平均成本，再按相同分布抽取很多天的需求，计算每天成本的平均。

工具的sample_demands返回日需求列表，sample_metrics根据容量算这批天的结果。同一批列表可以交给两个不同容量，便于公平比较。

记录模拟天数和随机种子。小差异通常是模拟波动；差异很大时，先检查费用、概率、情境和容量是否一致。不要通过不断换种子只留下最接近精确值的一次。

## 95%分位数怎样手算？

先把相同短缺数对应的概率合并，再按短缺由小到大累计。首次达到0.95的短缺数就是本课采用的95%分位数。

模拟时可以将短缺数排序，取向上取整的“0.95×模拟天数”位置；位置从1开始数。它与默认线性插值可能不同，本课使用前一种。

## 两种容量的平均成本一样怎么办？

先核对计算，再看其他后果：短缺概率、忙日短缺规模、预订支出可能不同。成本并列不意味着方案完全相同。

可以说明在当前费用下两者并列，然后按事先声明的服务目标选择。不要为了强行得到唯一答案而改动数据。
