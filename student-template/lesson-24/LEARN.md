# 第24课知识准备 · 模型比较与泛化能力评价

## 本课要解决的问题

模型将用于预测已有设备的后续工单，还是全新设备的工单？应如何划分数据，分别完成预处理、模型与阈值选择，以及独立评价？可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 训练、验证与测试 | 训练拟合；验证用于选择；测试评估冻结后的方案。 | 记录数据用途 |
| 交叉验证 | 在开发资料内部重复拆分评价，拆分方式须模拟用途。 | 选择模型与超参数 |
| 数据泄漏 | 把预测时不可得或评价资料的信息带入拟合或选择。 | 检查字段的可得时点与预处理 |
| 时间切分与设备分组 | 前者检验未来，后者检验新对象，二者回答不同问题。 | 分别报告两种泛化 |
| 独立评价与重复使用 | 看测试结果后再调模型，测试就参与了开发。 | 说明本轮评价数据的用途 |

评价目标决定拆分单位。预处理参数（例如均值、插补值、特征筛选）只在每个训练折上学习，再原样应用到验证/测试；不是只把标签列删掉就没有泄漏。

## 先思考，再看例子

每台设备有10个月记录。随机按行分成训练和测试，测试中仍有同一设备的其他月份；这可近似某些已知设备场景，但不能称为从未见过设备的评价。预测新设备必须把该设备的全部记录留在同一侧，还要防止未来月份进入训练。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

将缺失值插补、变量尺度标准化、特征选择与模型拟合纳入同一训练流程；每一步只用训练数据确定参数。比较针对同一预测目标、方法上有实质差别的候选方案，记录选择依据，并保存不再据测试结果调整的版本。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

同一测试集一旦被反复用于比较和调整方案，就已参与模型开发。报告应说明其实际用途，不再称其为未经使用的独立测试集。

## 学习自查

进入项目后应能解释：

1. 训练、验证和测试各负责什么，哪些选择只能用验证资料？
2. 预测新设备时，交叉验证为什么要按设备分组？
3. 哪些字段或预处理步骤可能把预测时不可得的信息带进模型？
4. 预测已知设备的未来与预测全新设备，需要怎样不同的拆分？
5. 看过测试结果后再调模型，这批资料还能称为未使用测试集吗？

## 进一步学习

可按需使用预处理管道、分组交叉验证和嵌套时间验证。每个步骤标清在哪里拟合、在哪里选择、在哪里只评价；如果拆分对象或预测时点改变，评价问题也会改变。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
