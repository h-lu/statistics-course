# 第09课 · 我的复核安排建议

可以沿下面的顺序写成一页左右的建议，也可以自行调整结构。保留必要的计算和比较表即可，不用另写一份长报告。

## 1. 我推荐怎样安排

常规组、重点组分别用哪种初筛？复核名额怎样分？

说明选择这两项安排的理由。如果目前还不能推荐，也可以说清缺少什么信息。

## 2. 先展示一个计算

选一组设备和一种初筛，写出：

- 预计故障与正常设备各有多少；
- 真阳性与假阳性各有多少；
- 阳性中的故障比例怎样算出来。

最后用一句话解释这个比例。不要把它与敏感度混在一起。

## 3. 与另一套安排比较

用表格列出两套安排的分组复核数、预计未发现故障、损失、初筛费用和复核费用。

说明两套安排是否都满足2000的初筛预算和90个复核名额。哪些条件相同，哪些选择改变了？如果同时改了初筛和分配规则，解释整套安排的差异即可。

## 4. 这项建议有什么取舍和限制

结合表中数字说明：你的安排改善了什么，又付出了什么代价？

再说明一个现实限制，以及什么条件变化后可能需要重新考虑建议。本课必做只需文字解释，不要求额外情境计算。

## 5. 计算结果在哪里

写明运行命令、程序和结果文件的位置，与 `submission.json` 保持一致。

如果完成了选做分析，可以放在报告末尾；不做选做也能完整完成本课。
