# 第11课 · 回答的人很多，就能代表所有人吗？

服务部门想知道：固定名册中的4000人，下个周末有多少人需要至少一次服务？问卷里的回答比例未必就是这4000人的需求比例。你要比较数据怎样取得，再给出一份有依据的调查或补采建议。

从本课到第14课沿用同一份教学合成总体。AI可以帮助理解、编程和分析，不要求提交对话记录。

## 1. 先学哪几件事？

[LEARN](LEARN.md)解释目标总体、抽样框、邀请和回答的区别，并用另设100人小例算清：回答者的70%怎样在条件成立时按构成调整为58%，为什么已知组人数仍不能消除组内选择。

可以先看小例，也可以在分析时按需查阅。[SUPPORT](SUPPORT.md)按卡点说明工具、输出和排错，不要求统一阅读或计算顺序。

## 2. 数据与已知条件

目标总体固定为4000人：A组3200人、B组800人。每人需求只有0或1；A/B是虚构联系组，不是现实身份，也不作因果解释。

- `data/frame.csv`提供编号、组别和是否在网上联系名单中，不含需求结果。
- **完整名册普通联系**：在4000人中等概率、无放回抽人邀请；A组受邀后回答概率0.8，B组0.6，模型假设同组内回答与需求独立。
- **网上邀请、自愿回答**：只在网上名单中等概率、无放回抽人邀请；有需求者回答概率0.85，无需求者0.25。名单外邀请机会为0。
- 本课另设每次邀请的教学费用为A组1单位、B组3单位，所有机制同口径。这是本课的邀请假设，并非历史“完成联系”费用或真实业务收费；不含追访或确保回答的费用。相同邀请数不等于相同成本或回答数。

完整需求文件只供模拟器生成回答和事后审计。先保存比较方案、取得回答并形成估计，再查看完整总体；不要用尚未观察的需求挑选邀请对象。文件在本地可读，这是一项学习协议。字段、来源和许可见[data说明](data/README.md)。

## 3. 课堂任务

为同一4000人总体比较完整名册普通联系与网上自愿机制。先保持邀请人数相同，具体人数与理由由你确定。若另选相同预算等口径，须保留这项共同邀请数比较，并解释新增比较改变了什么。

你还要决定是否采用按总体组别构成的调整，以及更值得优先改进哪一个取得环节。解释决定的依据；不要只因为一次估计更接近真值就选它。

标准作品应包含：

1. 一条正式模拟编号的取得轨迹，区分框外、框内未受邀、受邀未回答与已回答；没有观察到的需求不填0。
2. 两套事先保存的方案和可复跑结果。比较表写明框内人数、邀请数、回答数、A/B回答人数、两组回答者需求比例、未加权比例、构成调整比例及邀请费用；不能计算时保留未知并说明原因。
3. 取得后的完整总体审计，解释差异可能来自抽样波动、覆盖、无回答或组内选择，说明权重能处理和不能处理什么。
4. 一项调查或补采建议，说明依据、资源约束和仍依赖的假设。有证据地暂缓推广到全体，也是合理结论。

主目标不能从4000人改成“愿意上网回答的人”。可以增加B组等辅助问题，但须明确分开。

## 4. 从可运行的起点开始

先按教师提供的[第11课更新说明](../docs/LESSON11_UPDATE.md)取得新材料。在学生仓库根目录运行：

```sh
python3 scripts/course_l11.py start 11
python3 scripts/course_l11.py run 11
```

起点只运行另设100人小例和公开名册检查，输出`lesson-11/artifacts/example.json`，不替你抽取正式样本或完成比较。

正式取得工具在`sampling_tools.py`：`load_frame`读取规划名册，`make_request`构造方案，`write_request`保存方案，`run_request`产生一份观测。先保存所有比较方案，再取得回答。每份结果使用新目录，保留请求、观测和凭据；具体接口见SUPPORT。你可以组织自己的程序，也可以借助AI完成。

## 5. 不同完成程度怎样选择？

- **基础练习**：解释100人小例中的70%、58%、82%与缺组未知。这帮助起步，不能代替正式比较。
- **标准完成**：完成上述四项证据，形成可复跑的调查建议。
- **提高与拓展**：从[EXERCISES](EXERCISES.md)选择重复取得或资源取舍问题，研究更大网上样本为何仍可能有偏差；无需全部完成。

## 6. 怎样检查自己的证据？

先核对每个比例描述谁、分母是谁。相同邀请数只固定一项；不同名单、回答规则与实际费用仍可能不同。组内无人回答时，比例未定义，构成权重不能创造缺失信息。

完整总体是教学审计依据，现实调查通常没有免费真值。一次模拟与作者检查都不能证明现实效果；不要把无回答敏感性界限称为置信区间。
