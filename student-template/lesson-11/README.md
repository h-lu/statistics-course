# 第11课 · 回答的人很多，就能代表所有人吗？

服务部门想知道：名册中的4000人，下个周末有多少人至少需要一次服务？本课比较两种调查方式，判断回答者的比例能否代表这4000人。

## 本课怎么学

先读 [LEARN](LEARN.md)，用100人小例理解抽样框、无回答和构成加权；再完成下面的4000人调查比较。操作和排错查 [SUPPORT](SUPPORT.md)，拓展题见 [EXERCISES](EXERCISES.md)。可以使用AI协助学习和编程，无需提交对话记录。

## 调查情境

目标总体为4000人：A组3200人，B组800人。需求记为1或0。A/B是教学用的联系组，数据均为合成数据。

|调查方式|从哪里邀请|受邀后怎样回答|
|---|---|---|
|完整名册普通联系|从4000人中等概率、无放回抽取|A组回答概率0.8，B组0.6；同组内回答与需求独立|
|网上邀请、自愿回答|只从网上联系名单中等概率、无放回抽取|有需求者回答概率0.85，无需求者0.25|

两种方式的每次邀请费用均为A组1单位、B组3单位。费用只计算发出邀请，不包括追访。相同邀请人数可能得到不同的回答人数和费用。

规划时使用不含需求结果的 `data/frame.csv`。先保存比较方案，取得回答并形成估计，再查看完整总体作事后审计。数据字段和许可见 [数据说明](data/README.md)。

## 课堂任务

为同一4000人总体比较上述两种方式，保持邀请人数相同。人数、种子及选择理由由你确定；还可以增加相同预算等比较。

报告中完成四件事：

1. **追踪一个人。** 选一个正式模拟编号，说明他是否在抽样框内、是否受邀、是否回答，以及观察到的需求。未观察到的需求保留为空，不能记为0。
2. **比较两套结果。** 保存事先制定的方案和可复跑输出。表中列出框内人数、邀请数、回答数、A/B回答人数、组内需求比例、合并比例、构成调整比例和邀请费用。缺组时将无法计算的比例记为未知。
3. **解释差异。** 取得数据后与完整总体核对，分析覆盖、无回答、组内选择和随机波动的作用，说明构成加权是否合适。
4. **提出建议。** 在现有资源下，建议采用哪种调查或补采方式？还需要哪些信息？证据不足时也可以建议暂缓推广到全体。

小例用于练习；正式作品使用4000人数据。可另外研究B组等问题，但主要目标仍是全体需求比例。

## 开始运行

按 [第11课更新说明](../docs/LESSON11_UPDATE.md)取得材料，在学生仓库根目录运行：

```sh
python3 scripts/course_l11.py start 11
python3 scripts/course_l11.py run 11
```

起点程序运行100人小例并检查公开名册，结果在 `lesson-11/artifacts/example.json`。正式调查使用 `sampling_tools.py`：读取名册、制定并保存两份方案，再分别取得回答。函数说明见 [SUPPORT](SUPPORT.md)。每次运行使用新目录，保存方案、观测和凭据。

## 提交

用 [report.md](report.md)组织报告。在 `submission.json` 中登记实际运行命令和生成文件，将状态改为 `complete`，然后检查：

```sh
python3 scripts/course_l11.py check 11
```

按 [提交流程](../docs/WORKFLOW.md)提交，最终标签为 `v2-l11-final`。检查程序核对文件与复现；统计解释由报告呈现。课末按教师开放场次完成A题、AI辅助学习和B题。
