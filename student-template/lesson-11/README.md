# 第11课 · 自愿调查能够代表哪些人

服务部门准备决定下一个周末是否加开窗口。固定关心名册4000人中有需求者的比例，并补充了解B组。你要比较抽人和收集回答的方式，说明一份调查究竟能代表谁。总体结果文件是教学模拟用的审计真值，不是现实中可提前获取的答案。

**本课问题：调查数字不同，是服务需求不同，还是谁能进入调查不同？**

所有数据均为教学合成。AI可以完成方案、代码、分析、写作和提交，不要求编程先修、提示词日志或额外答辩。先用本页明确目标，再自行选择工作方式；[LEARN](LEARN.md)解释概念，[SUPPORT](SUPPORT.md)按卡点提供帮助，不要求按统一操作顺序完成。

## 数据、条件与选择

正式数据weekend_population.csv中，每行是一人；need_weekend为1表示指定周末有需求，0表示没有。四课始终估计这4000人的需求比例。程序知道完整结果是为课后核对模拟，抽人时不能偷看需求。普通联系表示有人不答；完成联系是假设抽中的人都答；网上自愿调查只联系网上名单内的人，且有需求者更愿意答。具体概率见共享说明。

[数据字段、抽人和回答规则](../data/inference-09-14/README.md)写明字段、预算和方法边界；最小程序为[analysis.py](analysis.py)，Python 3.10+标准库即可。共同数据是默认可运行路线，可替换计算工具，比较时应说明是否改变了目标人群、抽人或回答规则。

你决定优先采用完整名册邀请还是网上邀请、自愿回答的方式，以及是否按已知组别份额调整回答者结果。你也可选择普通联系与完成联系的资源取舍，但所有方案都估计同一名册总体，不能把更换目标人群当作改进。

## 基础练习（可信起点）

另设100人，A80人、B20人，各层需求比例50%、90%。若样本A/B各10人且层内比例可代表，总样本比例70%，按总体构成是0.8×50%+0.2×90%=58%。 可以手算、读代码或请AI换一个例子解释。基础例子的运行不代表完成标准任务。

## 标准任务（本课应完成）

追踪一个编号是否在可联系名单内（抽样框）、是否受邀、是否回答；在相同邀请人数下比较完整名册普通联系与网上邀请、自愿回答的方式。报告邀请数、回答数、A/B构成、直接用回答者计算和按总体A/B份额调整的需求比例；标明比较只固定邀请人数，不固定每人的入样机会、回答人数或成本。用完整总体作事后审计，解释差异可能来自偶然抽样、有人不在可联系名单内，或同组中某类人更愿回答。提出一次有理由的修改抽人/邀请方式或补充调查的建议，并说明权重仍解决不了什么。

最低证据是：**追踪一个例子、做一个公平比较、说明限制**。这里公平比较指清楚写出保持什么相同、只改变什么；不是各方案必须得出同样结论。至少两项有后果的决定由你选择并解释，结论不同、有证据的保留意见或暂缓建议均可。

## 提高与拓展（提前完成后）

用重复取得比较大样本网上自愿调查与较小概率样本的偏差；或改变组内回答依赖需求的程度，分析为什么仅调整A/B构成仍不够。
