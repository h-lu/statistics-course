# 第11课 · 自愿调查能够代表哪些人

校园服务团队收到一批自愿满意度问卷，准备向抽样框内3600人公布总体满意度并分配改进经费。问卷不是随机抽取，回答比例在不同校区和学习阶段之间不同。你要决定怎样报告，以及还缺什么信息。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

问卷数量超过1000，能否直接称为全体3600人的意见？先写出需要核对的一个代表性问题。

先打开[支持路线](SUPPORT.md)确认第一个动作和成功信号，再阅读[知识准备](LEARN.md)理解必要概念；计算和复杂实现可以交给工具。

## 学习路线与任务层级

前置回顾：[第07课](../lesson-07/README.md)中的调查覆盖与无回答，以及[第10课](../lesson-10/README.md)中的假设和敏感性分析。先按[支持路线](SUPPORT.md)建立可信起点，再用[知识准备](LEARN.md)解释结果。

### 基础练习（可信起点）

核对`person_id`连接、各层人数与回答率，并比较回答者和抽样框的一项已知特征。此层只建立分析起点，**不能冒充本课完成**。

### 标准任务（本课应完成）

完成下方三项分析任务：比较未加权、后分层及一个替代校正，说明各自假设，并通过层内无回答敏感性分析决定结论范围和补充调查对象。

### 提高与拓展（提前完成后）

比较校准或回答概率模型，检查极端权重与有效信息量，或设计分层补采方案；提高方法必须写清新增假设。提高任务应改变统计判断，不能只增加代码、模型或图表数量。

## 分析任务

1. 按person_id将问卷回答与完整抽样框连接，核对未匹配、重复、各层人数和回答率。比较回答者与抽样框的层构成及已知基线分数。

2. 明确目标总体与满意度目标量，比较回答者的未加权均值、分层加权结果及一个有依据的替代校正。每种方法都说明要求回答者与未回答者满足什么关系。

3. 对层内未回答者的满意度与回答者有系统差异作敏感性分析，给出不同假设下的结果、结论的适用范围和最需补充调查的人群。用具体阈值判断是否足以支持改进经费决策。

## 需要你作出的选择

可以采用后分层、校准或基于辅助变量的模型；决定什么差异范围值得认真考虑。不能任意删掉难代表的层来提高回答率，也不能用精确小数掩盖选择机制。

列出总体人数、回答人数、权重含义；将“样本抽取带来的随机误差”与“未回答者可能不同带来的偏差”分开。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

面向3600人总体的调查报告（或明确限于回答者的报告）、权重分布与抽样框覆盖情况分析、无回答敏感性结果与补采建议。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。当前自愿回答没有已知随机纳入概率。N_h/n_h是后分层校正权重，不自动成为真实抽样设计权重。只调整校区和学习阶段构成，不能保证每层回答者都能代表该层。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。
