# 模拟与事后审计输入

`weekend_population.csv`是固定4000人的**教学合成总体**。每一行包含虚构编号、组别、固定需求结果及网上名单状态。它由种子20261011生成，字节沿用课程历史固定总体；每次取得回答时不得重新生成。

模拟器内部需要完整结果，才能按“有需求者更愿回答”等规则产生回答。方案选择和邀请API只使用上一级`frame.csv`，对外观测只给回答者的结果，其他人的结果为未知。

本地文件可以读取。请先用公开名册写定比较方案并保留请求，再取得回答，最后用明确的审计步骤核对完整总体。这个顺序是透明的教学分析约定，不是技术防绕过保证；审计后产生的新想法应标明为事后修订。

全部为虚构教学数据，不是真实调查；许可沿用上一级[LICENSE.md](../LICENSE.md)。
