# 第11课支持路线 · 判断自愿调查能代表谁

## 先知道今天要交出什么

你要交出一份能明确说明“结论覆盖谁”的调查报告。最终至少包括目标总体与回答情况、权重或替代校正结果、无回答敏感性分析，以及补充调查建议。`artifacts/`中的表应让关键比例和加权结果可以复核。

入门跟做只完成连接与一项分层核对，不能替代完整的总体估计和敏感性分析。

## 核心概念与原理

**目标总体**是结论希望覆盖的全体；**抽样框**是实际可列出的名单。本课明确总体为抽样框内3600人，不能自动推广到其他学校或以后的人群。

**无回答**是被纳入调查范围的人没有提供所需回答。自愿参加若与满意度有关，会产生选择偏差。样本数量很大只能减小随机波动，不能自动消除这种系统差异。

**后分层权重**用各层总体人数与回答人数之比调整层构成。例如甲层总体80人、回答20人，乙层总体20人、回答20人，则甲层每个回答代表4人，乙层每个回答代表1人。它能修正已知层构成，却仍需要“层内回答者足以代表未回答者”的条件。

## 基础练习（可信起点）：入门跟做

先在**仓库根目录**打开终端，完整运行：

```bash
python scripts/course.py start 11
python scripts/course.py run 11
```

第二条命令成功时，终端会提示概览已经写入`lesson-11/artifacts/starting_inventory.json`。打开这个文件；它只是数据起点，不是本课答案。若文件没有生成，先按后面的排错顺序处理，再继续。

### 第一步：读取并确认连接键

- **动作**：从仓库根运行`python scripts/course.py run 11`，打开概览和`data/inference/README.md`。
- **目的**：确认`population_frame.csv`每行是一名框内人员，`voluntary_survey.csv`每行是一名回答者，两表通过`person_id`连接。
- **成功信号**：能报告两表行数、`person_id`重复数、问卷中未匹配抽样框的人数。
- **反思**：若连接后一名回答者出现两行，满意度均值会怎样受到影响？

### 第二步：核对一层的回答率

- **动作**：任选一个`stratum`，数出框内人数与回答人数，手算回答率，再与程序结果核对。
- **目的**：明确回答率分母是该层框内人数，不是全部回答者。
- **成功信号**：回答率在0到1之间；分层人数合计回到总体人数和回答总数。
- **反思**：回答率低说明代表性一定差吗？还需要知道什么？

### 第三步：比较构成与基线

- **动作**：按`campus`、`stage`或`stratum`比较总体和回答者构成，并比较已知`baseline_score`。
- **目的**：查找自愿回答与已知特征之间的系统差异。
- **成功信号**：结果同时显示人数、比例和基线差异，不只给一张图。
- **反思**：已知特征相近能否证明未观察到的满意度也相近？

### 第四步：建立未加权与后分层估计

- **动作**：计算回答者满意度未加权均值，再按层人数计算后分层均值；保留每层人数、回答人数和权重。
- **目的**：看层构成调整会怎样改变总体估计。
- **成功信号**：加权总权重可解释为目标总体规模或已规范化为1；你能说清每种实现。
- **反思**：两种估计很接近，是否就证明不存在层内选择偏差？

### 入门反思

用一句话分别说明：当前数据直接观察到什么；后分层依赖什么假设；哪类人最值得补充调查。把“标准误小”和“偏差小”分开写。

## 标准任务（本课应完成）

1. 完成连接质量、重复、未匹配、各层人数和回答率核对。
2. 明确目标总体和满意度目标量，比较未加权、后分层及一个有依据的替代校正。
3. 为每种方法写清层内回答者与未回答者需满足的关系，并报告权重分布。
4. 设置层内未回答者满意度系统偏低或偏高的合理情境，重算总体结果和经费建议。
5. 给出补充调查优先人群与具体决策阈值；若证据只覆盖回答者，应明确缩小结论范围。

## 提高与拓展（提前完成后）

- 比较后分层与基于`baseline_score`的校准或回答概率模型，并解释新增假设。
- 检查极端权重及其对有效信息量和结果稳定性的影响。
- 设计分层补采方案，比较把有限联系资源投向不同层的可能收益。
- 让敏感性参数在层之间不同，判断哪一层的未知差异最能改变建议。

## 卡住时按顺序排查

1. 确认命令在仓库根运行，先生成`starting_inventory.json`。
2. 连接行数膨胀时，分别检查两表`person_id`是否重复，再决定如何处理。
3. 回答率超过1时，检查分母是否误用了回答总数，或连接是否重复。
4. 加权均值异常时，先在一个层上手算，再核对权重是否重复应用。
5. 敏感性分析无变化时，检查设定是否真正作用于未回答者及相应人数。
6. 写报告时先分成“观察事实、校正假设、敏感性结果、建议”四部分。

- [ ] 权重含义和假设清楚，没有把它称为已知设计权重。
- [ ] 随机误差与可能的无回答偏差分开报告。
- [ ] 至少一个替代校正和一组敏感性情境实际运行。
