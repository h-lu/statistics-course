# 第23课知识准备 · 风险预测与复核决策

## 本课要解决的问题

根据工单登记时可得的信息制定复核规则：是否用满名额，如何处理相同风险分数，怎样权衡地区服务需求与误报、漏报损失？可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 逻辑回归与概率 | 以解释变量的线性组合描述对数优势，输出取值在0—1之间的事件概率。 | 估计工单登记时的升级风险 |
| 优势与优势比 | 优势为p/(1−p)；优势比不是概率之比。 | 解释条件关联 |
| 查准率与查全率 | 查准率TP/(TP+FP)，查全率TP/(TP+FN)。 | 评价有限复核名额 |
| ROC与PR | ROC曲线描述真阳性率与假阳性率的关系；PR曲线描述查准率与查全率的关系，帮助评价阳性检出和误报负担。 | 与基础率共同解释排序 |
| 阈值、损失与容量 | 行动依赖预算与损失，风险排序不直接决定用多少名额。 | 提交逐月可执行规则 |

log[p/(1−p)]=β₀+βx。x增加1单位时优势乘exp(β)，概率增加多少取决于起始p。情境损失=FP×1+FN×8；它评估给定复核决策，不能证明复核本身能消除8单位损失。

TP是真阳性数（报警且实际升级），FP是假阳性数（报警但未升级），FN是假阴性数（未报警但实际升级）。

式中p是事件概率，x是所讨论输入，β₀为截距、β为系数；多输入时用各项之和替代βx。ROC曲线下面积（AUC）概括正负例排序能力；不代表概率校准，也不代表某个阈值的行动损失。

## 先思考，再看例子

100条记录中10条实际为阳性。某规则报20条，其中8条是真阳性：查准率8/20=40%，查全率8/10=80%，假阳性率12/90约13.3%。如果最多复核10条，原规则即使指标好看也不能直接执行。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

形成概率或风险分层，解释逻辑回归中的概率、优势及优势比。用PR或ROC和基础率说明排序能力，不能只报准确率。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

目标是可行的风险筛查规则。样本上的预测关系和代价表不提供个体干预收益，不能宣称高风险者一定最能从干预获益。

## 学习自查

进入项目后应能解释：

1. 逻辑回归输出概率与一个确定的升级结论有什么区别？
2. 优势比为2时，为什么概率不一定翻倍？
3. 查准率和查全率各自的分母是谁？
4. 基础率很低时，为什么总体准确率可能不够用？
5. 每月25%的容量限制会怎样改变原本按成本选择的阈值？

## 进一步学习

可按需了解PR曲线、ROC曲线、概率校准和受容量约束的排序优化。把候选策略放在相同的逐月名额条件下比较，并说明并列分数如何处理。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
