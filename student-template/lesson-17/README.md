# 第17课 · 配对、独立样本与重复测量的比较

分析组收到了三份“比较两种方式”的数据：同一参与者交叉试用、不同人的独立比较、对同一批参与者连续跟踪6周。经理发现不同脚本给出很不一样的区间，你需要制定可复用的比较分析说明并判断哪些结论可以发布。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

数据有288行，计算标准误时就能把样本量当作288吗？先指出必须弄清的一项数据结构。

## 学习路线与任务层级

前置回顾：[第16课](../lesson-16/README.md)中的效应量、独立随机化单位与不确定性。先按[支持路线](SUPPORT.md)建立可信起点，再用[知识准备](LEARN.md)解释结果。

### 基础练习（可信起点）

分别核对唯一参与者数与每人行数，手算一名参与者的配对差，并比较正确配对与错误独立分析的方向。此层只建立分析起点，**不能冒充本课完成**。

### 标准任务（本课应完成）

完成下方三项分析任务：为三种结构给出效应和区间，保留配对、时期与人内相关，展示忽略结构的后果，并为至少一种结构完成有理由的替代分析。

### 提高与拓展（提前完成后）

加入时期或顺序项，比较个人汇总、混合效应和聚类稳健方法，或模拟不同人内相关对区间的影响。提高任务应改变统计判断，不能只增加代码、模型或图表数量。

## 分析任务

1. 为三份数据画出或写清分组机制、观测和分析单位，核对配对键、顺序、时期与重复次数；先匹配问题结构，再选择比较方法。数据是预置平衡的合成布局，不将它当成已验证的随机分配记录。

2. 对每种结构给出有单位的效应与区间，并展示忽略结构会如何改变结论。交叉试用需考察顺序/时期，重复测量需保留人内相关，不能把它们拼成一个更大样本。

3. 为至少一种结构给出有理由的替代分析，说明差异来自目标量、假设还是标准误。提交供同事以后使用的方法选择说明，包含不满足前提时的报告限制。

## 需要你作出的选择

配对差、独立Welch比较、个人汇总、混合效应或采用聚类稳健标准误的方法均可，取决于目标与结构；重复测量的平均效应与随时间变化效应不是同一问题。

报告每份数据中的独立单位数，按person_id识别配对，并检查不同试用顺序的结果。把保留与忽略相关性的分析作比较，是为了说明假设如何影响推断。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

数据分组与重复测量情况表、三类比较的可复核结果，以及忽略配对或重复观测相关性时的对照结果，以及分析方法选择说明。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。交叉设计需要考虑时期与残留效应；个人汇总可能舍去时间变化信息；稳健标准误也不修复目标错配或非随机选择。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。
