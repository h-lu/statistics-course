# 第17课支持路线 · 先识别数据结构，再选择比较方法

## 先知道今天要交出什么

你要为三种不同结构的数据提交可复核比较，并写一份方法选择说明。最终要有独立单位和重复结构表、三类有单位的效应与区间，以及忽略配对或人内相关时的对照结果。

入门跟做只帮助认清三份数据的独立单位，不能代替三类正式比较和替代分析。

## 核心概念与原理

**配对数据**要求两次观测存在有意义的一一关联，例如同一人使用两种方法。行数相等或排序相同不能构成配对。

配对分析先对每人计算差值，再研究这些差值。若方法差记为`B−A`，平均差的标准误由差值之间的变动决定。忽略配对会把人与人之间稳定的水平差异混入方法比较。

**重复测量**中同一个人的多周结果通常相关。六周六行仍只有一个独立参与者；把每行当作独立人常会低估标准误。交叉试用还要区分方法、时期、顺序与可能的残留效应。

## 基础练习（可信起点）：入门跟做

先在**仓库根目录**打开终端，完整运行：

```bash
python scripts/course.py start 17
python scripts/course.py run 17
```

第二条命令成功时，终端会提示概览已经写入`lesson-17/artifacts/starting_inventory.json`。打开这个文件；它只是数据起点，不是本课答案。若文件没有生成，先按后面的排错顺序处理，再继续。

### 第一步：画出三份数据结构

- **动作**：从仓库根运行`python scripts/course.py run 17`，分别数每张表的总行数、唯一`person_id`数和每人行数。
- **目的**：确认交叉配对、独立两组和六周重复测量的结构不同。
- **成功信号**：能够为每份数据写出观测单位、独立单位、分组字段和时间/时期字段。
- **反思**：哪一张表的行数最容易被误当成独立样本量？

### 第二步：核对一名参与者的配对

- **动作**：在`paired_study.csv`任选一人，按`period`检查两行、`sequence`和`method`，手算`B−A`。
- **目的**：建立真实配对键并确认差值方向。
- **成功信号**：每人恰有A、B各一次；程序计算与手算一致。
- **反思**：若少一时期记录，是否还能按同样方式形成完整配对？

### 第三步：比较配对与错误独立分析

- **动作**：计算所有人的配对差均值与区间，再把两列错误地当独立样本作一次对照，仅用于展示影响。
- **目的**：观察保留相关结构为何会改变标准误与区间。
- **成功信号**：两种结果分别标为正确主分析和结构忽略对照，不把后者作为发布结论。
- **反思**：差异主要来自效应估计，还是不确定性估计？

### 第四步：检查重复测量的分母

- **动作**：在`repeated_measurements.csv`按人汇总六周均值，同时保留按周结果；比较“48名参与者”与“288行记录”的含义。
- **目的**：确定目标是六周平均效果还是某一周效果。
- **成功信号**：任何区间或模型都明确人内相关的处理方式，不把288当作288个独立人。
- **反思**：若工具效果随周变化，只报告六周平均会遗漏什么？

### 入门反思

为三份数据各写一行：独立单位、目标效应、主要依赖结构和一个不能支持的解释。

## 标准任务（本课应完成）

1. 为三份数据核对配对键、组别、顺序、时期、周次与独立单位数。
2. 对每种结构给出有单位的效应和区间，交叉试用检查顺序/时期，重复测量保留人内相关。
3. 展示忽略配对或重复结构会怎样改变结果，并说明差异来自目标、假设还是标准误。
4. 为至少一种结构完成有理由的替代分析。
5. 写出供同事复用的方法选择说明及前提不满足时的报告限制。

## 提高与拓展（提前完成后）

- 为交叉设计加入时期或顺序项，检查方法效应的稳定性。
- 比较个人六周汇总、聚类稳健方法和混合效应模型，明确各自目标量。
- 模拟不同人内相关强度，展示把重复行当独立样本造成的区间偏窄程度。
- 检查残留效应情境下交叉设计需要怎样修改或限制解释。

## 卡住时按顺序排查

1. 先按`person_id`统计每人行数，确认没有把行号当配对键。
2. 差值方向不一致时，在代码和报告固定使用`B−A`或明确的另一顺序。
3. 配对合并出现多行时，检查`method`与`period`是否唯一。
4. 重复测量标准误异常小时，检查是否把288行当独立单位。
5. 模型过于复杂或不收敛时，回到与目标相符的个人汇总或简单稳健方法。
6. 报告按“结构—目标—方法—结果—限制”逐份数据组织。
