# 第31课陪做支持 · 追加调查是否值得：信息价值分析

这份材料帮助你在不知道下一步时建立可信起点。它不提供本课正式数据的答案，也不能代替 [README 主任务](README.md)；概念的完整解释见 [LEARN.md](LEARN.md)。

## 先知道今天要交出什么

- `report.md`：立即行动与追加调查的可执行比较。
- 可调整的行动—状态损失表、贝叶斯更新和信息价值结果。
- `submission.json`：列出主要决定与敏感性结果。

最低出口是：别人能够按你的命令重新生成报告引用的数字，并知道这些数字可以和不可以用于什么决定。

## 核心概念与原理

| 规范术语 | 通俗解释 | 怎样在自己的结果中检查 |
|---|---|---|
| 期望损失 | 按各状态概率加权某行动的损失，单位与损失表一致。 | 选择当前最小期望损失行动。 |
| 贝叶斯更新 | 结合先验概率和信号在各状态下出现的概率，得到观察信号后的状态概率。 | 分别处理调查阳性和阴性。 |
| 完美信息期望价值（EVPI） | 若能无误知道真实状态，事前最多可减少多少期望损失。 | 给任何实际调查的信息价值设上界。 |
| 样本信息期望价值（EVSI） | 收到有误差信号后重新选择行动，事前能减少多少期望损失。 | 衡量给定调查本身的价值。 |
| 净信息价值 | 样本信息价值再减调查和延迟成本。 | 决定是否开展调查。 |

### 先用一个小例子想清楚

先验高需求概率为0.5。若调查在高需求时80%阳性、低需求时20%阳性，则阳性总概率为0.5×0.8+0.5×0.2=0.5；阳性后高需求概率为0.4/0.5=0.8。得到新概率后必须重新比较行动，不能只说“阳性所以全面推出”。

这个例子只用于核对概念，不是正式数据的结论。正式项目必须使用自己的运行结果。

## 基础练习（可信起点）：入门跟做

以下命令都从仓库根目录运行，也就是同时能看到 `scripts/`、`data/` 和 `lesson-31/` 的目录。

```bash
python scripts/course.py start 31
python scripts/course.py run 31
```

第二条命令成功后，应看到终端提示结果已经生成，并能打开 `lesson-31/artifacts/starting_summary.json`。这个文件只是数据起点，不是本课完整答案。

若终端明确提示 `python: command not found`，按仓库首页说明，把上面两行开头的 `python` 换成 `python3`，其余内容不变。

### 第1步：核对行动、状态和单位

- **动作：** 运行起点程序，打开两个CSV，确认三种行动、两种互斥且穷尽的状态和共同损失单位。
- **目的：** 信息价值从明确的决定和后果开始。
- **成功信号：** 损失表六个组合齐全，两个先验概率之和为1。
- **想一想：** 这些损失是数据估计还是教学情境给定？

### 第2步：复算当前行动

- **动作：** 为每个行动计算期望损失，手工复算其中一个。
- **目的：** 建立不调查时的基准。
- **成功信号：** 程序和手算使用相同状态概率，选择最小期望损失行动。
- **想一想：** 若有安全红线，最小期望损失是否足够？

### 第3步：按信号更新并重选

- **动作：** 分别计算阳性、阴性概率及信号后的高需求概率，在每种信号下重新选行动。
- **目的：** 调查的价值来自它可能改变行动。
- **成功信号：** 联合概率和条件概率能加总核对；每个信号有对应行动。
- **想一想：** 如果两个信号下仍选同一行动，信息为何可能没有决策价值？

### 第4步：计算净价值并找边界

- **动作：** 比较无信息、完美信息、样本信息；再扣除8单位调查和3单位延迟成本，改变一个输入找决策切换点。
- **目的：** 把“多收数据”转成具体的成本和行动判断。
- **成功信号：** 结果分清毛信息价值、成本和净价值。
- **想一想：** 调查成本达到多少时不再值得？

完成这四步后，你已经有可信起点，但还没有完成整项主任务。

## 标准任务（本课应完成）

回到 [README](README.md) 完成全部标准任务，特别核对：

- 核对互斥穷尽状态、损失和先验。

把程序输出翻译成完整统计句子：对象是谁，比较什么，数值和单位是什么，哪些假设成立时可以怎样使用，哪些结论仍不能作出。

## 提高与拓展（提前完成后）

先完成标准任务，再选一项。提高的标准是让证据、适用范围或行动更可靠，而不是增加代码或图表数量。

- 求最优决策改变的先验或成本边界。
- 加入风险偏好或硬约束。
- 设计比当前信号更能改变行动的调查。

## 卡住时按顺序排查

- **阳性和阴性后的概率不合理：** 先用联合概率表核对四个“状态×信号”概率，确认总和为1，再计算条件概率。
- **EVSI大于EVPI：** 检查是否在每个信号和完美信息状态下都重新选了行动，以及是否混入或重复扣除了成本。
- **命令提示找不到文件：** 先运行 `pwd`，确认当前位置是仓库根目录；这里应同时看见 `scripts/` 和本课目录。
- **程序能运行但结果还是旧的：** 检查结果文件的修改时间，确认修改并运行的是本课 `analysis.py`；必要时删除自己生成的旧结果后重跑，但不要删除原始数据。
- **报告数字和程序输出不一致：** 从报告中的一个关键数字反向找到结果文件、筛选范围、分子和分母；不要手工把报告改成“看起来合理”的数字。
- **不知道怎样开始写报告：** 先写五句：谁使用、要决定什么、数据覆盖谁、一个主要结果、一个不能支持的结论，再补方法和证据。
