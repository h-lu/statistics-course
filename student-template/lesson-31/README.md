# 第31课 · 追加调查是否值得：信息价值分析

## 项目背景

部门面临低需求/高需求两种状态，可等待、先试点或全面推出。追加调查成本为8损失单位，延迟执行另损失3单位。负责人希望知道继续调查是否值得，而不是笼统地“需要更多数据”。

根据给定情境，比较立即行动与先开展追加调查再行动的方案，并说明先验概率、调查性能或成本变化时如何调整选择。

可用资料为[政策与决策数据集](../data/policy/README.md)中的`decision_options.csv`。**资料全部为教学合成数据。** 数据字典说明记录单位、字段、时点和局限；同时阅读同目录的`pilot_test.csv`。你可以全程使用AI完成编程、分析、写作与提交，也可以复用前课代码。

## 任务分层

开始前复习[第09课的条件概率与贝叶斯公式](../lesson-09/README.md)和[第10课的期望损失](../lesson-10/README.md)。第一次做这一类项目时，按[陪做支持](SUPPORT.md)完成每一步；概念解释见[知识准备](LEARN.md)。

### 基础练习（可信起点）

1. 从损失表核对三种行动、两种状态、损失单位和状态概率，手工复算一个行动的期望损失。
2. 分别在调查阳性和阴性时更新高需求概率，再在每种信号下重新选择行动。
3. 比较不调查、完美信息和样本调查的期望损失，并把调查成本与延迟成本计入最终决定。

基础练习帮助你得到可信的第一份结果，**并不等于已经完成本课**。继续完成下面的标准任务，才能把计算变成可使用的统计结论。

### 标准任务（本课应完成）

1. 读取损失表和状态概率，先核对损失单位和备选行动，并确认情境假定高、低需求两种状态互不重叠，且涵盖全部可能状态。计算各行动期望损失，另考虑一种不同风险偏好或决策约束下的选择。

2. 依据pilot_test.csv给出的条件信号概率，使用贝叶斯公式计算不同调查结果下的状态概率，再选择相应的最优行动。这里“阳性”表示调查提示高需求，“阴性”表示未提示高需求；所有概率均须注明为情境设定。

3. 比较不调查、完美信息和样本调查的期望损失；计算调查方案的总损失时加上调查与延迟成本，计算净信息价值时则减去这些成本。实际改变先验、调查准确性或成本，找出最优决策发生改变的条件。

4. 提交可调整的决策表与追加信息建议：该问什么、为谁采样、何时结束，以及哪种信息即使更精确也不改变行动。

以上均为本课需要完成的任务，分析方法和报告形式可以自行选择。评价不以图表或模型数量为依据。使用外部资料时注明来源，补充的业务假设应明确标注，不得当作已知事实。

### 提高与拓展（提前完成后）

完成标准任务后，从下面选择一项深入；重点是改善证据或决策，不按代码、图表或模型数量评价。

- 改变先验概率、信号性能或成本，找出最优行动或调查决定发生改变的边界。
- 加入安全红线、预算上限或风险厌恶，说明为何期望损失最小不再是唯一规则。
- 设计一个更有针对性的调查，说明采样对象、停止时间和哪些结果才会改变行动。
