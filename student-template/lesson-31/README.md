# 第31课 · 追加调查是否值得：信息价值分析

## 项目背景

部门面临低需求/高需求两种状态，可等待、先试点或全面推出。追加调查成本为8损失单位，延迟执行另损失3单位。负责人希望知道继续调查是否值得，而不是笼统地“需要更多数据”。

根据给定情境，比较立即行动与先开展追加调查再行动的方案，并说明先验概率、调查性能或成本变化时如何调整选择。

可用资料为[政策与决策数据集](../data/policy/README.md)中的`decision_options.csv`。**资料全部为教学合成数据。** 数据字典说明记录单位、字段、时点和局限；同时阅读同目录的`pilot_test.csv`。你可以全程使用AI完成编程、分析、写作与提交，也可以复用前课代码。

## 分析任务

1. 读取损失表和状态概率，先核对损失单位和备选行动，并确认情境假定高、低需求两种状态互不重叠，且涵盖全部可能状态。计算各行动期望损失，另考虑一种不同风险偏好或决策约束下的选择。

2. 依据pilot_test.csv给出的条件信号概率，使用贝叶斯公式计算不同调查结果下的状态概率，再选择相应的最优行动。这里“阳性”表示调查提示高需求，“阴性”表示未提示高需求；所有概率均须注明为情境设定。

3. 比较不调查、完美信息和样本调查的期望损失；计算调查方案的总损失时加上调查与延迟成本，计算净信息价值时则减去这些成本。实际改变先验、调查准确性或成本，找出最优决策发生改变的条件。

4. 提交可调整的决策表与追加信息建议：该问什么、为谁采样、何时结束，以及哪种信息即使更精确也不改变行动。

以上均为本课需要完成的任务，分析方法和报告形式可以自行选择。评价不以图表或模型数量为依据。使用外部资料时注明来源，补充的业务假设应明确标注，不得当作已知事实。

## 课堂安排（90分钟）

- 0—12分钟：阅读[知识准备](LEARN.md)和项目背景，明确分析问题；需要时可延长到17分钟，相应减少重复操作和排版时间。
- 12—55分钟：选择方法、开展分析或研究设计，并比较不同方案；遇到不熟悉的概念可随时查阅知识准备或询问AI。
- 55—68分钟：核对一项主要结论的计算结果、假设与替代解释，完成分析报告。
- 68—75分钟：重新运行程序，检查结果并提交；提前完成时，可进一步检验报告中的重要结论。
- 75—90分钟：[知识自查](https://hblu.top/stat-check/)，确认页面为当日V2课次，建议先完成A版基础题，再向AI学习不熟悉的概念，随后完成B版变式题。

## 示例代码与运行方法

从仓库根目录运行：

```bash
python scripts/course.py start 31
python scripts/course.py run 31
```

本课`analysis.py`读取数据并生成`artifacts/starting_summary.json`，用于熟悉数据结构。**请在此基础上完成本课分析任务，形成自己的分析方案和结论。** 可使用Python标准库、numpy/scipy、pandas、statsmodels、scikit-learn或其他合适工具；说明新增依赖与运行命令。

## 成果要求与提交

- `report.md`：面向报告使用者，写清分析问题、方法依据、主要结果、适用范围和建议。
- 可复现的分析程序或研究设计文件，以及报告引用的计算结果和图表；不要手工修改原始数据。
- `submission.json`：将`status`设为`complete`，`report`指向分析报告，`artifacts`列出支持报告结论的结果文件路径，`run`填写可复现分析的命令。

仅运行示例代码或粘贴模型输出，还没有完成本课分析任务。合格分析应正确更新概率，并计入调查和延迟成本；更好的分析还会找出最优决策发生变化的条件，解释哪些信息能改善决策，哪些精度改进不会改变行动。
