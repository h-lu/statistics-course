# 政策、预测与决策数据集

**全部为教学合成数据或明确给定的决策情境，不对应真实个人、地区或政策效果。** 固定种子2026090527；`python scripts/generate_policy.py`重建，原始CSV不手工修改。

| 文件 | 单位与规模 | 用途 |
|---|---|---|
| support_observational.csv | 每行一人，1400人 | L27—28支持项目观察研究 |
| district_panel.csv | 地区×月，24地区×36月=864行 | L29同时实施政策的面板比较 |
| weekly_demand.csv | 每行一周，156周 | L30四周需求预测 |
| decision_options.csv | 行动×状态，三行动×两状态 | L31—32损失情境 |
| pilot_test.csv | 状态，两行 | L31—32先验与调查信号性能 |

## 观察研究字段

`person_id`唯一；`severity`为处理前严重程度0—10，`baseline_burden`为处理前负担分数（越高越差），`access`为处理前服务可达性0/1，`age`为年龄（年）。`support`是是否接受支持0/1，非随机。`followup_burden`是随访负担分数，越低越好。`contact_after`是支持决定之后的联系强度；`responded_after`是之后是否参与回访。资料为合成完整分析文件，所有人的模拟随访结果均保留；若只分析参与回访者，须说明这种筛选可能带来的选择偏差。没有导出模拟中的所有共同原因。

## 地区面板字段

`district`标识地区；`month`为0—35；`group`分treated、near_control和far_control，各8地区；政策从月18起同时对treated实施，`policy_active`记录是否实施。`outcome`为服务负担指数，越低越好；`population`是地区规模。在本教学情境中，需要考虑政策可能影响附近地区，较远地区需核对可比性；这些都需在分析假设中讨论。不能只按名称自动认定某组对照正确。地区内存在时间相关，政策并非随机分配。

## 周需求字段

`week`从0到155，`demand`为该周需求件数，`holiday_known`为排班时已知的节假日标记，`available_capacity`为该周现有容量。真实未来需求在当时不可知。序列含趋势、季节和相关波动，不能随机打乱后声称检验了未来预测。

## 决策情境字段

`decision_options.csv`：`action`为wait/pilot/rollout，`state`为low/high，`loss`为共同损失单位，越低越好。不是现实货币估计；若改为金钱需另写换算依据。
`pilot_test.csv`：`prior_probability`为调查前状态概率，`positive_probability`为该状态下调查出现阳性信号（提示高需求）的概率。先验和信号性能均为给定情境，不是从面板估计所得。调查成本8、延迟成本3由L31项目背景给定，可进行敏感性分析，但须说明改动。

## 适用条件与局限性

生成脚本可以复现模拟。已知模拟设定不等于从观察资料识别出真实政策效应；模拟中某变量未导出，正是提醒现实观察研究不能假定已经测全共同原因。不同文件没有可直接连接的共同个体主键；不能直接将面板数据中的前后变化作为L31的先验概率或干预收益；若要使用，须说明估计方法、转换依据和不确定性。
