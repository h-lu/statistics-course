# 第9课数据与工具

**全部是教学合成数据与人为设定的业务条件，不是真实机构观察。** Python 3.10及以上，只用标准库；不需要安装requirements中的任何可选库。可以用AI改写代码、用电子表格或另建可复现程序。共同数据是默认路线，不要求全班采用相同操作或结论。

## 第9课：告警复核

延续第5课的告警复核用途，另设规划数据，不改第5课数据字节。`alert_groups.csv`一行一个来源组；daily_devices是每天待初筛设备数；base_low/base/base_high是故障基础率情境；miss_cost为每台未查出故障的损失单位。`screening.csv`一行一种初筛，sensitivity是在故障设备中阳性的比例，specificity是在非故障设备中阴性的比例；cost_per_device是初筛每台成本。性能是情境假设，不是现场已验证的效果。

L09：初筛预算2000成本单位；复核每天90台，每台复核成本3，复核无误且复核出的故障均可修复。复核优先顺序须只依赖组别和初筛结果；同组阳性随机选取。对全部待筛设备选定初筛方法，预算只计初筛；报告另外列出复核成本和未发现故障损失。可留名额保障低基础率组，也可按每个名额可避免的期望损失排序。未复核阳性中的故障和初筛阴性中的故障都计入未发现故障。


`toolkit.py`提供读表与自然频数计算；正式方案仍由学生选择、比较并解释。
