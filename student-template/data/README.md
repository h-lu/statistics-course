# 当前课程数据

以下均为固定种子生成的教学合成数据，不是现实学校、企业或个人的记录。情境约束用于练习统计判断，分析结果不能当作现实机构的事实或政策效果。

- [service](service/README.md)：第1–4、6–8课使用的服务工单、满意度、业务与窗口、排班和接触记录。
- [alerts](alerts/README.md)：第5课使用的设备风险分数、故障标签、设备信息和每日复核容量。

先读数据字典，确认观测单位、变量含义、观测时间与结果变量。保持原始数据不变，另存处理后的数据与计算结果。对应的 `scripts/generate_service.py` 与 `scripts/generate_alerts.py` 可重建共享数据；分析时直接读取提供的CSV。

第9–32课目前只有大纲，尚未提供新课包与新数据。
