# 知识准备 · 把告警分数转成行动

## 必须理解：名单、错误和后果不是一回事

基础阅读建议7—10分钟。**经验累积分布函数ECDF**为 `F_n(t)=分数≤t的记录数/n`，描述累计比例，不是分数t的故障概率。**分位数**可以帮助定位分数线，但并列值可能让阈值无法精确满足名额；本例最近秩算法取排序后第ceil(np)个值，0<p≤1、序号从1开始，它不同于线性插值。

**假正例FP**是无故障却复核，**假负例FN**是有故障未复核；TP是真故障且复核，TN是无故障且未复核。**假阳性率FPR=FP/(FP+TN)**，分母为实际无故障记录；**假阴性率FNR=FN/(FN+TP)**，分母为实际故障记录。分母为0时未定义，不填0。

**损失与容量**决定行动后果和可行性。每次复核都有成本，不同故障损失可能不同；低错误数量不自动对应低损失。容量按日约束，不是跨日平均。

## 完整例子：先定名单，后看标签

另设一天4台设备，最多复核2台，复核成本均为3、故障损失均为100，可避免比例85%。先只看前两列，规则为分数降序、同分按编号升序，再看最后一列核算。

| 设备 | 行动前分数 | 行动后才知道的故障标记 |
|---|---:|---:|
| D1 | 80 | 1 |
| D2 | 40 | 0 |
| D3 | 40 | 1 |
| D4 | 20 | 0 |

名单为D1、D2。ECDF在40处为3/4；分数≥40选3台超容量，>40只选1台。编号只是本例预先声明的并列办法，不代表业务价值；不能看见D3故障后换并列规则，仍称本批是独立评价。

此时TP=1、FP=1、FN=1、TN=1，两种错误率都为50%。情境总损失为漏报100+真阳性剩余损失15+两次复核6=121；不复核损失200。在85%效果假设下减少79，不是实验证明的因果收益。

再看100条记录例子：实际故障10，复核20，其中6故障，则TP=6、FP=14、FN=4、TN=76。FPR=14/90≈15.56%，而名单中无故障比例14/20=70%，不能混用。假设损失100、成本3，避免80%时总损失为400+120+60=580；改成项目85%则为400+90+60=550。公式正确还要核对参数来自哪个情境。

## 从概率到选择

如果用过去资料估得故障概率p、故障损失L、复核成本c，情境期望净收益为 `p×可避免比例×L−c`。p是有依据的概率估计，不是分数除以100；分数乘损失只是启发式。允许不用满容量，剩余名额不迫使你选负收益对象。

总损失下降可能伴随某类设备覆盖下降，需查看群体后果并说明保障及代价。复核效果是假设，标签完整不证明干预效果已识别。

## 时间顺序决定结果怎样解释

前42天用于制定和选择，后14天用于规则冻结后的评价。整个开发期拟合再计算开发表现是回代，不能说每一天都只用了此前资料。后期风险转换、阈值和同分办法保持不变；标签只用于后果核算。看后期后修改是探索修订，这批资料不再是未使用过的评价数据。

条件变化可以是固定名单重算损失，也可以是按新假设重做名单，要分别解释。设备反复出现，设备日不保证独立；一个后期的好表现不保证未来相同。

## 回到项目与按需深入

写可执行规则、一个有意义备选、每日容量检查、后期结果、重要条件变化和监测建议。可以让AI实现风险估计、优化或校准，但不必为了难度增加模型；复杂方法应说明数据时点和新假设。可让AI换成库存复核例子解释FPR的分母，无需提交对话。

## 按需核算：名单与损失

```python
# learning-example
import json
rows = [("D1", 80, 1), ("D2", 40, 0), ("D3", 40, 1), ("D4", 20, 0)]
selected = {r[0] for r in sorted(rows, key=lambda r: (-r[1], r[0]))[:2]}
counts = {"TP": 0, "FP": 0, "FN": 0, "TN": 0}
loss = 0
for device, score, label in rows:
    chosen = device in selected
    key = "TP" if chosen and label else "FP" if chosen else "FN" if label else "TN"
    counts[key] += 1
    loss += 3 + label * 100 * .15 if chosen else label * 100
result = {"selected": sorted(selected), "ecdf40": sum(r[1] <= 40 for r in rows) / len(rows),
          "counts": counts, "loss85": loss, "large_fpr": 14 / 90,
          "large_list_nonfault": 14 / 20, "large_loss80": 4*100+6*100*.20+20*3,
          "large_loss85": 4*100+6*100*.15+20*3}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
