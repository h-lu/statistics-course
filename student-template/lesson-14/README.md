# 第14课 · 在有限预算下设计一项调查

服务团队接受了自愿调查不能自动代表所有人的结论，批准6000预算开展新一轮调查。不同层联系成本、回答率和满意度波动不同；还需保证小层有可用结果。你要提交可以实际抽出名单的方案。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

把预算平均分给六层，是最公平也最精确的方案吗？先指出至少一个可能冲突的目标。

先打开[支持路线](SUPPORT.md)确认第一个动作和成功信号，再阅读[知识准备](LEARN.md)理解必要概念；计算和复杂实现可以交给工具。

## 学习路线与任务层级

前置回顾：[第11课](../lesson-11/README.md)中的无回答与权重，以及[第13课](../lesson-13/README.md)中的精度与决策。先按[支持路线](SUPPORT.md)建立可信起点，再用[知识准备](LEARN.md)解释结果。

### 基础练习（可信起点）

核对抽样框与成本表，手算一层的联系成本、预计完成数和纳入概率，并建立一个简单可行分配。此层只建立分析起点，**不能冒充本课完成**。

### 标准任务（本课应完成）

完成下方三项分析任务：比较简单与改进分配，生成无放回抽样名单，报告精度与权重，并在三档预算、回答率或层内波动变化下制定调整规则。

### 提高与拓展（提前完成后）

比较比例分配、Neyman分配和成本最优分配，或研究权重差异的设计效应及分批联系规则。提高任务应改变统计判断，不能只增加代码、模型或图表数量。

## 分析任务

1. 明确新调查的总体、主要目标量、分层依据、抽样单位和联系流程。利用现有数据作为规划输入，不能把已回答者当作新调查的全部候选名单。

2. 比较一个简单分配与一个有依据的改进分配，在成本、总体精度和每层最低完成数之间取舍。给出整数联系数、预计完成数、纳入概率和预算核算，并从完整框内随机抽出可复核名单。

3. 比较预算4500、6000、7500下的方案变化；通过敏感性分析考察回答率下降或层内标准差偏大时的后果，规定追加联系和未回答处理规则。区分抽样不确定性与仍可能存在的无回答偏差。

## 需要你作出的选择

可采用比例、等额、考虑成本的最优分配或多目标分配。最低每层预计完成15是当前约束，可讨论提高它的成本；不能用同一个号码重复抽出来填满样本。

检查抽样框是否重复，保存层内无放回抽样的随机种子与各层纳入概率。预计完成人数不等于实际一定能完成的人数。给出近似误差限或精度目标，并说明所用标准差与回答率的来源。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

调查实施方案、各层分配与成本表、可重跑抽样程序和抽中名单，以及预算/回答率变化时的调整规则。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。以回答者标准差规划可能低估未回答者差异；概率抽样解决纳入机制，不自动解决调查中的无回答。参考精度是简化设计近似，不代表任何复杂回答概率模型都满足。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。
