# 第14课｜有限预算下的分层调查

第13课讨论一次调查能给出多明确的区间证据。本课再向前一步：在调查开始前，怎样分配有限的人数和费用，使总体与较小群体都得到有用的估计？

沿用4000人的教学合成名册：A组3200人，B组800人；邀请A组一人成本1，B组一人成本3。课堂基准是在各层独立、等概率、无放回抽样，抽中者全部回答。

## 本课要学会什么

- 分清总体份额、样本份额、包含概率与设计权重。
- 从两组样本比例计算总体估计，解释为什么不能直接合并人数。
- 先检查预算可行性，再同时比较总体与B组的标准误。
- 将模拟比较写成实际联系计划，说明费用范围和无回答记录办法。

## 学习顺序

1. 阅读[知识讲解](LEARN.md)，从100人小例理解加权，再用1000人、同费用280的小例走完方差、SE与方案取舍，最后回到4000人正式名册。
2. 完成[概念与手算](EXERCISES.md)，需要时查看[分层提示](HINTS.md)。
3. 按[运行帮助](SUPPORT.md)生成默认结果，从第一轮受访者核对权重、总体估计和成本。
4. 写好比较计划，运行自己的分配方案；预算下降后重新选择人数。
5. 整理报告、联系方案与可重复运行的材料，再完成提交检查。

## 课堂任务

为同一总体设计下一次调查，完成以下工作：

1. **预算240下比较**：至少两个可行方案，其中一个按总体人数比例4∶1分配。写明各层人数、包含概率、设计权重和实际成本。
2. **追踪一轮样本**：从原始受访者记录计算组内比例与总体加权估计，核对未加权合并比例，解释差异。
3. **评价精度取舍**：保持总体、重复次数和评价口径相同，比较总体与B组估计的SE。区分“都在预算内”与“实际花费相同”。
4. **预算降为180**：重新给出一个可行方案，说明优先保障总体还是B组精度。只改预算数字不会自动改变抽样人数。
5. **形成联系方案**：说明使用哪份名册、怎样随机抽取、邀请费用包括什么，以及怎样记录未回答者与安排追访。

两项精度不一定能同时改善。建议可以保留原方案，也可以明确为了B组精度接受总体精度的部分损失；要用实际比较支持判断。追访等现实费用不在课堂邀请费用中，应另列，而不是假定免费。

## 运行与提交

在学生仓库根目录首次运行：

```sh
python3 lesson-14/analysis.py
```

默认输出位于 `lesson-14/artifacts/baseline/`。默认128/32方案成本224，是读懂文件的起点，不代替自己的比较。新实验另存配置；需要反复重建时，使用[运行帮助](SUPPORT.md)中的临时目录脚本。

提交材料包括：

- [报告](report.md)：问题与选择、一轮数值追踪、两预算下的结果、联系建议与适用条件。
- 各方案的配置与自己的重建脚本。
- 各方案的 `plan.json`、`first_sample.csv`、`trials.csv`、`summary.json`。
- `submission.json`：登记命令、产物和报告，完成后将状态设为 `complete`。

```sh
python3 scripts/course_l1314.py check 14
python3 scripts/course_l1314.py ci 14
```

提交标签仍为 `v2-l14-final`，评分要求不变。AI可辅助编程与分析，无需提交对话日志；课堂选择题按教师开放场次完成A→概念学习→B。
