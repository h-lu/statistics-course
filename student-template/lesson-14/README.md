# 第14课｜有限预算下的分层调查

承接第13课，设计下一次调查。沿用4000人的教学合成名册，比较不同分层人数方案对总体与B组估计精度的影响。

## 学习顺序

1. 阅读[知识讲解](LEARN.md)：分层抽样、包含概率、设计权重、成本与精度、加权方差。
2. 完成[手算练习](EXERCISES.md)，核对加权比例和邀请成本。
3. 按[运行帮助](SUPPORT.md)追踪默认样本，再运行自己的分配比较。

## 课堂任务

预算240下比较至少两个可行方案，其中一个按总体比例。记录各层人数、包含概率、设计权重、实际费用，以及总体和B组的SE。

再将预算改为180，重新分配人数，说明精度优先级，并写出联系与无回答记录办法。课堂基准为各层等概率无放回抽取且全部回答；现实方案需另外考虑追访费用和无回答影响。

## 运行与提交

在学生仓库根目录运行 `python3 lesson-14/analysis.py`，默认输出位于 `lesson-14/artifacts/baseline/`。其他方案另存配置，使用新的输出目录。

在[报告](report.md)中整理设计、数值追踪、比较与建议；在 `submission.json` 中登记重建命令和产物，完成后将 `status` 设为 `complete`。运行 `python3 scripts/course_l1314.py check 14` 与 `python3 scripts/course_l1314.py ci 14`，提交标签沿用 `v2-l14-final`，评分要求不变。

可用AI辅助编程与分析，无需提交对话日志。课堂选择题按教师开放场次完成A→概念学习→B。
