# 第14课支持路线 · 在预算内设计分层调查

## 先知道今天要交出什么

你要提交一套可以实际抽出名单的新调查方案。最终包括各层联系数和预计完成数、预算与精度比较、纳入概率、可重跑的无放回抽样名单，以及回答率变化时的调整规则。

入门跟做只建立一份简单分配草案，不等于完成方案比较、名单生成与敏感性分析。

## 核心概念与原理

**分层随机抽样**先把抽样框按预先知道的特征划成互不重叠的层，再在每层内随机抽人。每个人应只属于一层。

若一层有`N_h`人、计划无放回联系`m_h`人，每个人的纳入概率是`m_h/N_h`，设计权重是它的倒数。联系后是否回答是另一个过程；预计完成数约为联系数乘预计回答率，但不是保证。

样本分配需要同时考虑总体精度、每层结果可用性和成本。把所有样本都分给便宜或波动大的层，可能让小层没有足够信息；完全等额分配也可能浪费预算。

## 基础练习（可信起点）：入门跟做

先在**仓库根目录**打开终端，完整运行：

```bash
python scripts/course.py start 14
python scripts/course.py run 14
```

第二条命令成功时，终端会提示概览已经写入`lesson-14/artifacts/starting_inventory.json`。打开这个文件；它只是数据起点，不是本课答案。若文件没有生成，先按后面的排错顺序处理，再继续。

### 第一步：核对抽样框与成本表

- **动作**：从仓库根运行`python scripts/course.py run 14`，读取概览和数据说明；检查`person_id`唯一、每人恰属一个`stratum`。
- **目的**：确认完整抽样框才是候选名单，不能只从自愿回答者中抽样。
- **成功信号**：按层汇总的`population_frame.csv`人数与`sampling_costs.csv`中的`population_n`一致。
- **反思**：若只联系已经自愿回答过的人，新调查还解决了什么选择问题？

### 第二步：手算一层的联系与完成数

- **动作**：选一层，假设联系100人，用`expected_response_rate`计算预计完成数，再计算联系成本和纳入概率。
- **目的**：分清联系人数、预计完成人数与纳入概率。
- **成功信号**：预计完成数不超过联系数；成本用联系数而不是预计完成数相乘。
- **反思**：若回答率下降，预算是否自动减少？精度会怎样变化？

### 第三步：建立简单分配基准

- **动作**：在6000预算下建立一个易解释的比例或等额分配，取整数联系数，检查各层预计完成数是否至少15。
- **目的**：先得到可以比较的可行基准，再设计改进方案。
- **成功信号**：总成本不超过预算、每层联系数不超过层人数、最低完成约束有明确检查结果。
- **反思**：这套分配主要照顾总体精度、小层可用性还是实施简单性？

### 第四步：生成可复核名单

- **动作**：设置随机种子，在每层按联系数无放回抽取`person_id`，保存名单和每层纳入概率。
- **目的**：把纸面分配转成可实施的概率抽样。
- **成功信号**：名单没有重复ID，各层实际抽中数等于计划联系数，同一种子可以重现。
- **反思**：重复运行并挑一份“看起来更好”的名单，会改变已声明的随机机制吗？

### 入门反思

说明你的总体目标量、抽样单位、分层依据、成本单位和最低完成要求。再写一句：概率抽样解决了哪个过程，仍没有解决哪个无回答问题。

## 标准任务（本课应完成）

1. 明确总体、目标量、层、抽样单位和联系流程，核对抽样框质量。
2. 比较一个简单分配和一个有依据的改进分配，核算成本、总体精度及每层最低完成数。
3. 输出整数联系数、预计完成数、纳入概率、设计权重和预算表，并生成可复核名单。
4. 对预算4500、6000、7500重算方案；考察回答率下降和层内标准差上升。
5. 制定追加联系与无回答处理规则，分开报告抽样不确定性和潜在无回答偏差。

## 提高与拓展（提前完成后）

- 比较比例分配、Neyman分配和考虑成本的分配，解释各自优化目标。
- 对回答率和层内标准差同时变化做压力测试，寻找最容易失去最低完成数的层。
- 比较权重差异带来的设计效应，说明总体精度与小层可用性的冲突。
- 设计分批联系规则，使后续批次仍保持已知纳入概率。

## 卡住时按顺序排查

1. 抽样框人数不符时，先按`stratum`汇总并检查重复ID。
2. 预算超过时，检查成本是否按联系人数而非预计完成数计算。
3. 最低完成不足时，先反推所需联系人数，再重新分配剩余预算。
4. 名单重复时，确认每层使用无放回抽样且没有重复拼接。
5. 纳入概率超过1时，检查联系数是否超过层人数。
6. 报告从“可实施性、精度、小层结果、无回答风险”四项组织比较。
