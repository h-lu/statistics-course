# 第22课知识准备 · 多元回归的模型比较与解释

## 本课要解决的问题

围绕一项具体使用需求，在明确的地区和负荷条件下进行比较，判断是否需要交互项、非线性项，或采用较简单的描述方法。可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 多元回归 | 同时用若干变量描述条件均值，调整后仍是依赖模型的关联。 | 确定条件比较 |
| 分类变量与参照组 | 分类变量需明确编码和参照水平，系数含义随参照组变化。 | 解释地区和复杂度 |
| 交互作用 | 一个变量的关联随另一变量取值而变化。 | 决定是否使用共同斜率 |
| 多重共线性 | 解释变量提供大量重叠信息，单个系数可能不稳定。 | 比较负荷和排班指数 |
| 条件关联与推广 | 相同记录条件下的比较不自动代表总体或因果效果。 | 界定目标群体和负荷范围 |

“保持其他变量相同”指模型比较时把这些输入设成相同值，不表示现实中随机控制了它们。分类变量编码为0/1不会把类别变成有等距意义的数值尺度。

下例中的y为预计结果，x为连续输入，g为组别指示（0或1），xg为两者乘积；10、2、5、3分别是示例模型的截距和系数，并非本项目已估计结果。

## 先思考，再看例子

模型 y=10+2x+5g+3xg，g=0或1。先判断两组斜率：g=0时为2，g=1时为5；组间差为5+3x，不是固定5。若样本只见x在1—3之间，x=20的结论需要额外验证。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

比较统计含义不同的多元回归模型，例如各地区采用共同斜率或不同斜率，以及采用线性或非线性关系。说明比较时哪些变量保持相同。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

多变量调整有助于比较条件相近的观测，但仍可能受到遗漏变量、测量误差和模型形式不合适的影响。增加调整变量不等于满足因果识别条件。

## 学习自查

进入项目后应能解释：

1. 多元回归里“其他输入相同”与随机控制有什么区别？
2. 地区系数是在和谁比较，更换参照组会改变预测吗？
3. 有交互项时，为什么不能只读一个系数就说两组差多少？
4. 负荷和排班指数高度相关时，单项系数为什么可能不稳定？
5. 模型能输出从未见过的负荷条件，是否表示这个预测可用？

## 进一步学习

可按需了解虚拟变量编码、条件预测图、方差膨胀因子和正则化。比较地区时应选实际能出现的负荷组合；若某组合在数据中没有支持，应限制解释而不是只调用预测函数。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
