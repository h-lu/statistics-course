# 第8课 · 多表数据整合与统计指标核查

数据为**教学合成数据**，所有机构与编号虚构。AI可全程帮助编程、分析和写作；评价依据问题、选择、证据与结论适用范围。下面规定成果边界，你可以自行组织分析，不必按同一条路线完成。

## 问题情境

管理者要合并两期运营信息。工单、调查、接触和排班记录在描述不同对象，直接连接或静默删除未匹配对象，可能使一个看似正确的数字回答了另一个问题。请设计一份适合你所选用途、能够复核且范围清楚的分析报告。

第3课的数据质量、第4–6课的指标与比较、第7课调查覆盖可作为已有资源，无需重新完成旧作业。概念按需查 [LEARN.md](LEARN.md)，遇阻可选择 [SUPPORT.md](SUPPORT.md) 的对应提示；[EXERCISES.md](EXERCISES.md) 提供小例和可选挑战，[HINTS.md](HINTS.md) 是进一步帮助。先明确自己的问题，再选择需要的资源。

## 可用资料与工具

[七表说明](../data/service/README.md)：第一期工单3600行；第二期原始导出1265行/1200编号；调查4800、接触8921、窗口6、业务2、排班240行。原始行数、不同对象数和指标分母不是同一个数。完整两期ID不重叠、字段和单位统一后应有4800工单。

analysis.py可运行读入清单，另提供read、unique_index、group_totals通用函数。它没有清洗、连接或正式指标答案；可以改写、另写程序或用AI实现自己的方案。不是必须使用给定函数。

```bash
python3 scripts/course.py start 08
python3 scripts/course.py run 08
```

在学生仓库根目录（有scripts、data）运行；完整资料库先进入student-template。概览在lesson-08/artifacts/starting_overview.json，只是确认资料可读。所有资料可离线，已有Python3标准库足够；无需安装。

## 基础练习（可信起点）

如果还无法判断连接风险，可用两张工单的小例子先核对分析单位和均值，或先在七表中挑一个关系核对键；具体可选提示见SUPPORT。熟悉这些概念的同学可以直接进入标准任务。基础结果不能替代正式分析。

## 标准任务（本课应完成）

**用途由你确定。** 可以关注容量安排、流程改善、体验评价或另一项能由资料支持的管理问题。至少作出并解释两个会影响结果的重要决定，例如目标指标与分析单位、有效记录集合、未匹配处置、比较对象、汇总日期或发布标准。不要任意改参数后补理由。

成果需要满足这些证据要求：

- 说明输入与输出一行代表什么、用什么键识别；完整两期先处理修订、重复、单位和未知值后追加，保持原CSV不变。
- 同时处理工单、接触和窗口日三个层次，分别给出与你用途有关的结果；指标由你选，不限定等待/办结/满意度的固定套餐。每项有时期、单位、计算范围和分母。
- 提供数量与关键总量的核对，以及至少一项实际执行的防重复或遗漏检查。工单、接触和计划人时不能随连接重复累计。
- 实际比较一种有理由的替代分析方案或解释，说明其对象/分母/结果及对建议的影响。连接方式、有效集合、统计量、时间口径或另一项实质选择均可，不限给定菜单；相同结果也可以是有效发现。
- 区分未知窗口、缺排班、缺调查登记、未受邀和无回答对相关指标的影响；不用一律删除或填0代替解释。给出可发布、需附条件或暂缓的范围及下一期核查条件。

日期与测量有约束：工单date与接触contact_date含义不同；接触表未测实际办理窗口，用工单窗口归属需声明假设。人员分钟/60才与人时相同单位；排班staff_count×open_hours−absence_hours中缺勤已是合计。计划量不是实测劳动投入。报告计划期需说明无活动排班日与缺排班活动日怎样处理。

## 提高与拓展（提前完成后）

自行提出一个能检验报告最重要假设的新问题，可选连接范围、最新版本冲突、接触次数加权、日期覆盖、异常反追或其它有依据的方法比较。EXERCISES中的反例只是资源，可以改设反例或使用独立实现。新增成果须产生新的统计判断，不能用重复运行和排版代替深入。

## 成果与提交

报告形式可调整，report.md只是写作问题。提交自己的可运行程序、支持结论的结果、重要选择与理由、实算检查及替代方案证据。所有所列结果应能从原数据重现；在submission.json填写自己实际使用的run命令，而非只运行概览，report与artifacts分开填，完成后status为complete。

```bash
python3 scripts/course.py run 08
python3 scripts/course.py check 08
```

run执行你声明的程序；check只检查状态、路径和非空，不判断统计结论。按 [工作流](../docs/WORKFLOW.md) 提交，保留旧final。

报告末从第3–8课选择模块一代表作并给理由；若计划修订，写统计问题与依据，不修订则说明保留原版。截止下一次课前，保留v2-lNN-final，修订用v2-lNN-revision-1，评分沿 [成果与评分](../docs/ASSESSMENT.md)，不要求重做六课。

完成项目后进入 [课堂知识自查](https://hblu.top/stat-check/)，按教师指定的第8课场次完成A、概念学习、B和反馈。正式题答案不在本页；AI仍可使用。
