# 第8课可选支持

本页是遇到困难时的资源，不是一份所有人都必须按顺序执行的分析脚本。先明确自己的问题；选择需要的小例、检查或提示，之后回README完成自己的方案。工具和例子都可以替换。

## 先知道今天要交出什么

完整两期、工单/接触/窗口日三个层次的适用结果，至少两个重要决定及理由，实际核对、一种合理替代方案与有范围的报告。证据形式和指标随你的用途而定，概览不是完成作业。

## 核心概念与原理

主键识别记录，分析单位决定统计针对谁。工单有多次接触，展开后的工单均值可能改变权重；排班在日期+窗口层只累计一次。左/内连接影响覆盖，缺失对不同指标的作用不同。完整解释与手算见LEARN，可按概念查阅而不必逐页走完。

## 基础练习（可信起点）

**读表受阻时：** 在学生仓库根运行 `python3 scripts/course.py start 08` 与 `python3 scripts/course.py run 08`，打开lesson-08/artifacts/starting_overview.json。目的仅是确认读到七表；成功信号是1265导出行对应1200编号。反思：这证明主键唯一了吗？

**分析单位受阻时：** 选LEARN中2/10等待小例先预计再核算，或运行 `python3 lesson-08/experiments.py duplication`。打开lesson-08/artifacts/experiment_duplication.json，用分子/分母解释6、4、8和16分钟。目的是辨认重复权重，反思：不同工单等待恰好相同能否按数值去重？

**记录规则受阻时：** 可挑一张第二期工单，查最高数值revision和原始单位，再说明缺失编码先识别/真实秒数再换算。成功信号是能把处理后的值追到源字段，反思：该字段缺失是否使其它有效字段失效？选哪条记录由你决定。

## 标准任务（本课应完成）：可选问题提示

这些问题帮助检查自己的方案，不规定方法或执行先后：

- 我的用途需要描述哪种对象？哪些目标指标与行动相配，哪些资料只作背景？
- 哪两项决定会改变对象、权重、分母或报告范围？替代方案为什么也合理？
- 如何证明连接没有把同一工单或排班重复累计？有没有只修分母而分子仍重复的风险？
- 输入接触分钟可怎样分解为已分配与未分配？差额是否有具体去向？
- 缺调查登记与受邀无回答各影响什么？未知窗口是否仍保留适用的总体信息？
- 日期集合和缺计划量怎样影响容量报告？计划量能支持何种解释？
- 同样数据下另一合理选择后建议是否改变？如果不变，已经检查的范围是什么？

read、unique_index和group_totals是通用工具，可按需调用；清洗、指标与最终分析由你组织。可以让AI编程，也可以使用其它已有工具；不用复现某个固定文件布局或唯一数字套餐。

## 提高与拓展（提前完成后）

按需参考EXERCISES的unmatched、revision、staffing案例；每个命令只演示另设小例，不完成正式报告。可自行构造更适合自己问题的例子。先提出新的统计疑问，再找证据与解释；不要求固定数量案例。

## 卡住时按顺序排查

技术故障时先确认根目录含scripts/data、使用python3和正确路径；再看命令退出状态/本次输出，别用旧文件存在当成功。数字冲突时先查记录范围与单位，再查键和连接关系、版本与分母。未知值不猜填0，空分母未定义。保留完整错误，不手改结果掩盖问题。

## 提交前自检

原CSV未改；标准成果而非概览；至少两个重要决定可说清；每项数字有对象/分母/单位/时期；替代方案实际算过；未匹配去向可解释；submission的run能从原数据重建全部所列artifacts。自行修改命令后运行run/check并查看暂存，历史final保留。详细操作见 [工作流](../docs/WORKFLOW.md)。
