# 知识准备 · 连接正确才能汇总正确

## 必须理解：表之间的关系也是统计问题

基础阅读建议7—10分钟。**主键**唯一标识记录，**联合键**由多字段共同标识，例如排班的窗口与日期。**连接基数**是一对一、一对多或多对多的关系；工单到接触一对多，连接扩行不等于多了工单。

**记录层次与分析单位**决定哪些量可相加。等待属于工单、工作人员分钟属于接触、计划人时属于窗口日。**连接造成的重复计算**可改变均值的隐式权重和总量。**核对与未匹配**应检查数量、总量及被纳入的对象，不能只看文件能打开。

左连接保留左表记录，右边未匹配时为空；内连接仅保留两边匹配的对象。右表键不唯一时，两者都可能扩行，所以左连接并不保证均值正确，也不保证未知信息被补全。

## 完整例子：工单、接触、窗口日

同一窗口同一天，T1等待2分钟、T2等待10分钟。T1有三次接触，工作人员分钟为2、3、4；T2有一次为7。计划排班为8人时。

工单平均等待(2+10)/2=6分钟。直接展开接触后等待变成2、2、2、10，均值4分钟，T1被隐式赋予三倍权重。只把计数改成两个唯一工单并不能修复均值；展开等待合计16再除以2又会错成8。

先按工单汇总接触：T1为3次、9分钟，T2为1次、7分钟；再与工单一对一连接，保留2工单、4接触、16工作人员分钟和6分钟等待均值。不同接触可能耗时相同，不能按数值直接去重。

到窗口日再汇总并接排班，该日仍是8人时。按两张工单累加会错成16，按四次接触累加会错成32。工作人员分钟先除60才与人时同量纲；计划量不是实际劳动时间，也不直接支持个人效率判断。

## 加一条未匹配记录：均值相同也可能漏数据

另加T3：等待6分钟、窗口未知，有一次5分钟接触。全体3张工单均值仍6，接触共5次、21分钟；窗口报告只确认2张、4次、16分钟，未分配部分1张、1次、5分钟。

全体与已匹配组均值恰好相等，不能证明内连接没有遗漏。应核对“全体=已匹配+未匹配”，既看数量也看总量，且明确比较范围一致。

## 日期与零业务日

再设第二天有8人时排班但没有工单，两日计划共16人时。从工单作主表会漏掉第二天；报告整个计划期时，从该期排班窗口日集合出发连接业务汇总。确认没有业务才将计数设0，数据缺失或接口异常不是零业务。

接触工作量使用实际 `contact_date`。若跨日接触按工单 `date` 归集，就改变每日工作量含义；没有实际办理窗口字段时，还需说明按工单窗口分配工作量的假设。已知窗口缺排班与窗口身份未知应区分，缺调查登记与已登记无回答也不同。

## 回到项目与按需深入

先列各表单位、键和预期关系，再执行至少一项防重复或防遗漏检查，并报告工单数、接触数、关键总量、未匹配量和有效分母。满意度仍以有评价工单作相应分母，不用接触行数。引用第3课清洗规则即可，不要求重新造工具或搭数据库。

模块代表作从第3—8课选一件，写计划修订的统计理由，截止下一次课开始前；保留原final标签，修订用revision-1，不改变原按时完成分。可让AI用订单与配送解释隐式权重，无需提交对话。

## 按需核算：展开与汇总

```python
# learning-example
import json
waits = {"T1": 2, "T2": 10}
contacts = [("T1", 2), ("T1", 3), ("T1", 4), ("T2", 7)]
expanded = [waits[ticket] for ticket, minutes in contacts]
result = {"ticket_mean": sum(waits.values())/len(waits),
          "expanded_mean": sum(expanded)/len(expanded),
          "wrong_sum_over_distinct": sum(expanded)/len(waits),
          "contact_minutes": sum(minutes for ticket,minutes in contacts),
          "planned_day_hours": 8, "wrong_ticket_hours": 8*len(waits),
          "wrong_contact_hours": 8*len(contacts),
          "all_mean_with_unknown": (sum(waits.values())+6)/(len(waits)+1),
          "all_minutes_with_unknown": sum(m for t,m in contacts)+5,
          "two_day_plan": sum([8,8])}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
