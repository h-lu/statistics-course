# 第32课 · 面向新问题的统计分析综合报告

## 项目背景

从前31课的项目中选择一个主题，面向更具体的使用者和分析问题，完成一份综合统计分析报告。可以是值班人员所需的模型使用说明、管理者所需的政策评估简报、调查团队所需的抽样方案，或业务部门所需的决策分析。

新报告面向谁，要回答什么具体问题，结果适用于哪些条件？相较原报告，目标量、分析方法、适用范围或行动规则至少有一项需要实质修改。

可从[本学期的数据集](../data/README.md)选择与新用途相符的资料。**随课资料全部为教学合成数据。** 数据字典说明记录单位、字段、时点和局限。示例代码默认读取[政策与决策数据集](../data/policy/README.md)中的`decision_options.csv`与`pilot_test.csv`，但这不是选题限制。你可以全程使用AI完成编程、分析、写作与提交，也可以复用前课代码。

## 分析任务

1. 选择已有数据集和项目，写清新使用者、具体决定、目标量、时间范围和不能使用的情境。可复用旧代码和AI成果，不要求新建平台。

2. 重新运行从原始数据到分析结果的完整流程；检查旧稿的关键假设，完成一项会影响新用途的实质分析或设计修订，而不是只换标题与版式。

3. 为主要结论提供可追溯的计算结果，并报告不确定性或敏感性分析。根据结果判断是否建议使用、是否需要限制适用范围，或是否暂不建议采用。在使用说明中明确现有资料不能支持哪些结论。

4. 提交分析报告、可复现程序、计算结果和图表，以及简短的修订说明。若尚未确定主题，可使用本课示例代码读取L31决策数据，为“预算上限6单位的采购负责人”重新评价追加调查方案；须根据新的预算约束完成敏感性分析，并说明何时不再追加调查。

以上均为本课需要完成的任务，分析方法和报告形式可以自行选择。评价不以图表或模型数量为依据。使用外部资料时注明来源，补充的业务假设应明确标注，不得当作已知事实。

## 课堂安排（90分钟）

- 0—12分钟：阅读[知识准备](LEARN.md)和项目背景，明确分析问题；需要时可延长到17分钟，相应减少重复操作和排版时间。
- 12—55分钟：选择方法、开展分析或研究设计，并比较不同方案；遇到不熟悉的概念可随时查阅知识准备或询问AI。
- 55—68分钟：核对一项主要结论的计算结果、假设与替代解释，完成分析报告。
- 68—75分钟：重新运行程序，检查结果并提交；提前完成时，可进一步检验报告中的重要结论。
- 75—90分钟：[知识自查](https://hblu.top/stat-check/)，确认页面为当日V2课次，建议先完成A版基础题，再向AI学习不熟悉的概念，随后完成B版变式题。

## 示例代码与运行方法

从仓库根目录运行：

```bash
python scripts/course.py start 32
python scripts/course.py run 32
```

本课`analysis.py`读取数据并生成`artifacts/starting_summary.json`，用于熟悉数据结构。**请在此基础上完成本课分析任务，形成自己的分析方案和结论。** 可使用Python标准库、numpy/scipy、pandas、statsmodels、scikit-learn或其他合适工具；说明新增依赖与运行命令。若自选另一数据集，修改分析程序，并同步更新`submission.json`中的`run`命令和结果文件路径。

## 成果要求与提交

- `report.md`：面向报告使用者，写清分析问题、方法依据、主要结果、适用范围和建议。
- 可复现的分析程序或研究设计文件，以及报告引用的计算结果和图表；不要手工修改原始数据。
- `submission.json`：将`status`设为`complete`，`report`指向分析报告，`artifacts`列出支持报告结论的结果文件路径，`run`填写可复现分析的命令。

仅运行示例代码或粘贴模型输出，还没有完成本课分析任务。合格报告应明确新的使用者，能够复现分析结果，并有实质修订；更好的报告还会根据不确定性和局限性，给出具体的使用条件及暂停使用或重新分析的规则。

完成后执行`python scripts/course.py check 32`，按[项目工作流](../docs/WORKFLOW.md)提交并创建`v2-l32-final`标签；有修订时保留原标签。自查按[知识自查说明](../docs/KNOWLEDGE_CHECK.md)进行。项目分析允许全程使用AI，不要求提交AI对话记录。
