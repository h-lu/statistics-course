# 第32课知识准备 · 面向新问题的统计分析综合报告

## 本课要解决的问题

新报告面向谁，要回答什么具体问题，结果适用于哪些条件？相较原报告，目标量、分析方法、适用范围或行动规则至少有一项需要实质修改。可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 问题与目标量 | 先明确要回答什么、对谁、在何时，再选择统计量或模型。 | 明确新的分析问题 |
| 证据可追溯 | 数字可从原始资料、规则和版本重建。 | 提供可复现的分析程序 |
| 不确定性与敏感性 | 抽样波动与分析假设变化不是同一件事。 | 说明不确定性的来源 |
| 适用范围与因果解释 | 描述、预测和因果回答不同问题。 | 限定结论的适用范围 |
| 行动与修订 | 新证据或新用途应能改变规则，而非只改写文字。 | 说明结果的使用条件 |

提交前检查一项主要结论：分析问题、目标量、观测单位与样本范围、分析方法、不确定性及行动建议是否相互一致。说明每一步选择的依据，尤其要解释为什么计算结果能够支持所提出的建议。

## 先思考，再看例子

旧报告说明“历史平均等待较长”，新使用者却要“保证明天每个人都不超时”。两者的目标量不同，后者还提出了个体层面的保证要求。只把标题改成“明日承诺”不构成新成果；需要预测或容量证据，并说明仍不能保证的部分。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

先用已随第31课发布的[分析计划](../lesson-31/LESSON_32_PLAN.md)锁定新使用者、决定、目标量、数据和实质修订；没有课前计划时立即采用README中的默认路线。然后重新运行从原始数据到分析结果的完整流程；检查旧稿的关键假设，完成一项会影响新用途的实质分析或设计修订，而不是只换标题与版式。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

允许复用并诚实标明来源。合成数据的结果只能作为教学示范；不能将教学示范作为真实政策有效或个体能够获益的证明。

## 学习自查

进入项目后应能解释：

1. 新使用者的问题和目标量相较旧稿发生了什么变化？
2. 读者怎样从一条关键数字追溯到原始资料与计算规则？
3. 抽样区间和假设敏感性分别覆盖什么不确定性？
4. 哪些描述性、预测性或因果结论超出了当前资料能够支持的范围？
5. 你修改了哪项实质规则，什么新证据会再次改变它？

## 进一步学习

可复用任一前课方法；如果沿用L31示例代码，可以为“调查费用上限6个损失单位，延迟成本另计3个损失单位”的新使用者重新评价追加调查方案。若只改变调查费用，就要明确说明信号性能保持给定设定，不把“费用变了”误说成“调查准确度也变了”。新用途的约束、证据与修订必须一致；不要求增加方法数量，也不要求制作网页。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
