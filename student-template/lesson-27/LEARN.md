# 第27课知识准备 · 从观察关联到因果研究设计

## 本课要解决的问题

明确处理、比较条件、入组人群、起始时间、随访终点和目标效应；决定哪些变量可调整，哪些需要新设计或补测。可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 潜在结果 | 同一人在接受与不接受处理下各有一个潜在结果，通常只观察到其中一个。 | 定义因果效应 |
| 目标效应 | 在明确人群和时间内比较两种处理状态的平均结果。 | 撰写研究方案 |
| 混杂 | 处理与结果有共同原因，造成观察比较不可直接解释。 | 决定调整和补测 |
| 中介与碰撞变量 | 中介位于作用路径；碰撞变量受两个原因影响，调整可能引入偏差。 | 避免盲目控制 |
| 识别假设 | 从观察分布推到目标因果量所需的条件。 | 说明因果结论成立所需的条件 |

平均处理效应（ATE）写作 ATE=E[Y(1)−Y(0)]，其中1/0为两种支持策略。观察均值差E(Y|A=1)−E(Y|A=0)只有在相应识别条件满足时才等于它；同一个人的两个结果不能同时由这张表直接读出。

E表示在声明目标人群中取平均，Y(1)、Y(0)分别是接受与不接受所定义支持策略的潜在随访负担，A表示实际支持状态。效应的单位与负担分数相同。

## 先思考，再看例子

严重程度S影响是否接受支持A，也影响后续负担Y，形成A←S→Y。支持后联系次数M可能位于A→M→Y。若目标是总效应，控制M会改变问题。若回访参与R同时受A和Y影响，只分析R=1还可能形成选择偏差。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

写出目标研究方案，并以文字箭头、图或变量关系表表达因果假设。区分处理前共同原因、处理后中介和可能的选择/碰撞变量，说明未测量因素如何影响识别。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

数据由固定种子合成，生成脚本可用于理解模拟机制，但不能把代码里设定的效应当作观察资料在现实中已经识别的证据。课堂分析应依据可观测变量和明确列出的假设展开。

## 学习自查

进入项目后应能解释：

1. 为什么通常不能同时看到同一个人接受和不接受支持的结果？
2. 目标研究的处理、时间零点、人群和随访窗口是什么？
3. 严重程度怎样同时影响支持选择与后续负担？
4. 为什么支持后的联系次数和是否参与回访不能一律作为基线变量调整？
5. 因果图表达了哪些假设，其中哪些还需要额外证据？

## 进一步学习

可按需学习目标试验模拟、随机名额分配或准实验设计。先列出进入研究的资格、时间零点、处理策略、随访结果和目标量，再考虑怎样控制变量或获得对照。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
