# 第27课 · 从观察关联到因果研究设计

## 项目背景

支持项目负责人发现，接受支持者的随访负担分数反而更高，因此有人建议停止项目。她需要一份研究方案，评估项目是否有效，并说明现有观察数据能支持哪些结论。

明确处理、比较条件、入组人群、起始时间、随访终点和目标效应；决定哪些变量可调整，哪些需要新设计或补测。

可用资料为[政策与决策数据集](../data/policy/README.md)中的`support_observational.csv`。**资料全部为教学合成数据。** 数据字典说明记录单位、字段、时点和局限；你可以全程使用AI完成编程、分析、写作与提交，也可以复用前课代码。

## 任务分层

开始前可复习[第16课的目标效应](../lesson-16/README.md)和[第21课中关联与因果的区别](../lesson-21/README.md)。第一次做这一类项目时，按[陪做支持](SUPPORT.md)完成每一步；概念解释见[知识准备](LEARN.md)。

### 基础练习（可信起点）

1. 用现有资料比较接受与未接受支持者的基线严重程度和随访负担，明确这只是观察关联。
2. 写出目标研究的入组人群、时间零点、两种处理策略、随访终点和目标效应。
3. 用文字箭头或关系表标出至少一个处理前共同原因和一个处理后变量，说明哪些不能盲目调整。

基础练习帮助你得到可信的第一份结果，**并不等于已经完成本课**。继续完成下面的标准任务，才能把计算变成可使用的统计结论。

### 标准任务（本课应完成）

1. 核对支持选择与基线严重程度的关系，报告未经调整的差异及人群构成；这一部分用于界定问题，不作为效果结论。

2. 写出目标研究方案，并以文字箭头、图或变量关系表表达因果假设。区分处理前共同原因、处理后中介和可能的选择/碰撞变量，说明未测量因素如何影响识别。

3. 提出能实现的研究方案，例如随机分配支持名额、可实施的准实验或有明确假设的观察研究；比较资源、伦理和信息需求，不能只写“做随机实验”。

4. 向负责人说明现有资料能够支持的结论和暂时不能作出的因果判断，并提出调整当前政策前最值得补充收集的信息。因果图表达研究假设，不能由这些数据自动证明。

以上均为本课需要完成的任务，分析方法和报告形式可以自行选择。评价不以图表或模型数量为依据。使用外部资料时注明来源，补充的业务假设应明确标注，不得当作已知事实。

### 提高与拓展（提前完成后）

完成标准任务后，从下面选择一项深入；重点是改善证据或决策，不按代码、图表或模型数量评价。

- 把一个未测量共同原因转成具体的数据补采方案，说明测量时点和用途。
- 比较随机名额、准实验和观察研究的可行性、伦理限制与识别假设。
- 为干扰、失访或处理执行不一致补充研究方案，并说明目标效应是否随之改变。

## 课堂安排（90分钟）

- 0—12分钟：阅读[知识准备](LEARN.md)和项目背景；需要分步引导时打开[陪做支持](SUPPORT.md)，明确分析问题；需要时可延长到17分钟，相应减少重复操作和排版时间。
- 12—55分钟：选择方法、开展分析或研究设计，并比较不同方案；遇到不熟悉的概念可随时查阅知识准备或询问AI。
- 55—68分钟：核对一项主要结论的计算结果、假设与替代解释，完成分析报告。
- 68—75分钟：重新运行程序，检查结果并提交；提前完成时，可进一步检验报告中的重要结论。
- 75—90分钟：[知识自查](https://hblu.top/stat-check/)，确认页面为当日V2课次，建议先完成A版基础题，再向AI学习不熟悉的概念，随后完成B版变式题。

## 示例代码与运行方法

从仓库根目录运行：

```bash
python scripts/course.py start 27
python scripts/course.py run 27
```

本课`analysis.py`读取数据并生成`artifacts/starting_summary.json`，用于熟悉数据结构。**请在此基础上完成本课分析任务，形成自己的分析方案和结论。** 可使用Python标准库、numpy/scipy、pandas、statsmodels、scikit-learn或其他合适工具；说明新增依赖与运行命令。

## 成果要求与提交

- `report.md`：面向报告使用者，写清分析问题、方法依据、主要结果、适用范围和建议。
- 可复现的分析程序或研究设计文件，以及报告引用的计算结果和图表；不要手工修改原始数据。
- `submission.json`：将`status`设为`complete`，`report`指向分析报告，`artifacts`列出支持报告结论的结果文件路径，`run`填写可复现分析的命令。

仅运行示例代码或粘贴模型输出，还没有完成本课分析任务。合格研究方案明确时间零点、处理和目标效应；更好的研究方案把图中的未知因素转成可行补采或设计选择，并解释为什么不盲目控制事后变量。

完成后执行`python scripts/course.py check 27`，按[项目工作流](../docs/WORKFLOW.md)提交并创建`v2-l27-final`标签；有修订时保留原标签。自查按[知识自查说明](../docs/KNOWLEDGE_CHECK.md)进行。项目分析允许全程使用AI，不要求提交AI对话记录。
