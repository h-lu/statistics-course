# 第15课 · 设计能回答实际问题的随机实验

服务团队准备试用一套处理工具，希望知道它能否降低处理时间并值得推广。480名成员分属24队、4区组；同队会交流工作方法。你要在看实验结果前提交可执行的实验方案，而不只是随机分A/B。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

将480人随机分成两组，就一定足以得到可信的推广结论吗？先指出一个会使实际实施偏离分配的环节。

先打开[支持路线](SUPPORT.md)确认第一个动作和成功信号，再阅读[知识准备](LEARN.md)理解必要概念；计算和复杂实现可以交给工具。

## 学习路线与任务层级

前置回顾：[第14课](../lesson-14/README.md)中随机抽样与纳入概率的作用；本课要进一步区分‘从总体抽谁’和‘把已纳入单位分到哪种处理’。先按[支持路线](SUPPORT.md)建立可信起点，再用[知识准备](LEARN.md)解释结果。

### 基础练习（可信起点）

核对团队和区组结构，写出目标效应，并生成一份按区组进行的候选团队分配。此层只建立分析起点，**不能冒充本课完成**。

### 标准任务（本课应完成）

完成下方三项分析任务：预先定义目标、主要指标和约束，生成可复核分配与基线诊断，写意向性分析、失访、依从性、披露和停止规则，并比较一种替代设计。

### 提高与拓展（提前完成后）

模拟不同污染强度下团队与个人随机的表现，或设计受限随机化和干扰范围；所有规则在结果出现前确定。提高任务应改变统计判断，不能只增加代码、模型或图表数量。

## 分析任务

1. 明确工具推广的目标人群、主要效应、最小有实际意义的改善、观察期和主要指标；把效果问题与成本/安全约束分开。设计能控制主要污染风险的随机化单位和区组方案。

2. 根据名单实现可复核分配，检查单位只出现一次、各区组分配和基线构成，说明随机不平衡如何在分析中处理。不要反复换种子直到满意而不说明选择规则。

3. 写预分析计划与实施安排：意向性分析、失访、依从性、关键比较、结果披露和停止规则。把一种替代设计放在同一成本/污染/精度框架下比较，提交工作人员能据以执行的分配名单。

## 需要你作出的选择

可选团队或个人随机、不同区组/匹配，依据是干扰与实施条件。主要结局、成本门槛和分析方案在看结果前确定；不能用后续结果为当前实验方案挑指标。

明确随机化单位与分析单位；种子与分配比例；预定结局和缺失处理；解释为什么设计可以回答目标问题而不是只看分组均值接近。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

实验方案、分配名单与代码、基线平衡描述、预分析计划及实施偏离登记表（空模板即可）。本课不需要实验后结果。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。随机化使处理分配遵循预先规定的随机机制，但不保证每个变量完全相同、所有人依从或团队互不影响。未看到结果时无法保证显著，也不应承诺一定有效。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。
