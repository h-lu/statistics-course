# 第15课支持路线 · 设计可执行的随机实验

## 先知道今天要交出什么

本课只做实验设计，不查看实验后结果。你要提交实验方案、可复核的分配名单与程序、基线平衡描述、预分析计划，以及空的实施偏离登记表。

入门跟做只帮你认清随机化单位并生成一份候选分配，不能代替完整实验方案和替代设计比较。

## 核心概念与原理

**随机化单位**是被随机分配到工具或常规条件的基本单位；**观测单位**是记录结果的单位。本课若按团队分配，24个团队才是独立随机化单位，尽管结果有480行。

随机分配让处理安排不由潜在结果或研究者偏好决定，不保证每个基线变量完全相同。**区组随机化**在四个区组内分别分配团队，可保护重要结构并提高可比性。

**目标效应**应写清对谁、提供什么工具、与什么对照、在哪段时间比较哪个主要结局。处理时间、实施成本和安全结果承担不同角色，不能在看到结果后再挑最有利指标。

## 基础练习（可信起点）：入门跟做

先在**仓库根目录**打开终端，完整运行：

```bash
python scripts/course.py start 15
python scripts/course.py run 15
```

第二条命令成功时，终端会提示概览已经写入`lesson-15/artifacts/starting_inventory.json`。打开这个文件；它只是数据起点，不是本课答案。若文件没有生成，先按后面的排错顺序处理，再继续。

### 第一步：认识名单结构

- **动作**：从仓库根运行`python scripts/course.py run 15`，打开概览和实验数据说明；统计参与者、团队、区组和每队人数。
- **目的**：确认480人嵌套在24个团队和4个区组中。
- **成功信号**：每个`person_id`唯一，每个团队只属于一个区组，团队规模汇总清楚。
- **反思**：若团队成员会互相学习，个人随机化可能造成什么污染？

### 第二步：先写目标效应

- **动作**：用一句完整话写出目标人群、处理、对照、观察期、主要结局和改善方向，再写最小有实际意义的改善。
- **目的**：先定义要回答的问题，再选择随机化设计。
- **成功信号**：目标效应不是“看看哪个组更好”，且有分钟单位和明确方向。
- **反思**：平均改善是否意味着每名参与者都改善？

### 第三步：生成候选团队分配

- **动作**：选择并记录一个随机种子，在每个`block`内把团队随机分配到两组；不要反复换种子挑最好结果。
- **目的**：建立与污染风险相容、可复核的分配机制。
- **成功信号**：每个团队只在一个组，各区组两组团队数符合预定比例，同种子可重现。
- **反思**：基线略不平衡是否说明随机化失败？计划分析可怎样处理？

### 第四步：检查分配而不“优化答案”

- **动作**：按分配组汇总团队数、人数、`baseline_minutes`和`workload`，保存基线表。
- **目的**：发现实施错误并为分析计划准备协变量，而不是筛选最漂亮的种子。
- **成功信号**：检查包含团队层面和人员层面数量；没有使用实验后结果。
- **反思**：若采用受限随机化，需要在什么时候写出可接受标准？

### 入门反思

分别写出实验单位、随机化单位、观测单位和计划分析单位。再说明区组、污染和失访会在哪个环节处理。

## 标准任务（本课应完成）

1. 预先规定主要效应、最小有实际意义的改善、观察期、主要指标、成本与安全约束。
2. 选择能控制主要污染风险的随机化单位和区组方案，并生成可重现名单。
3. 核对唯一性、区组分配、团队与人员数及基线构成，说明随机不平衡的处理方式。
4. 写预分析计划：意向性分析原则、失访、依从性、主要比较、披露和停止规则。
5. 在同一成本、污染和精度框架下比较一种替代设计，并提供空的实施偏离登记表。

## 提高与拓展（提前完成后）

- 用模拟比较团队随机与个人随机在不同污染强度下的偏差或功效。
- 设计并预先记录受限随机化的可接受集合，再说明相应分析如何考虑分配机制。
- 对团队间交流建立不同干扰范围，说明目标效应需要怎样改变。
- 设计最小化选择性报告的结果清单和公开规则。

## 卡住时按顺序排查

1. 先核对团队与区组映射，避免同一团队被拆进两组。
2. 分配不均时，检查是否在每个区组内对团队而不是人员随机化。
3. 同种子不能重现时，固定排序后再随机，并保存种子与算法。
4. 基线表行数异常时，检查人员表与团队分配连接是否一对多正确。
5. 不知道写预分析计划时，从目标效应、主要方法、缺失、偏离、披露五项开始。
6. 切勿读取或使用`experiment_outcomes.csv`来挑本课设计。
