# 第16课 · 根据实验结果决定推广、试用或停止

团队试用已经完成。实际按4区组内团队随机，工具组与常规组均12队240人，存在未使用工具、对照组使用工具及失访。经理需要决定是否推广，并想知道每人8单位成本是否值得。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

只比较真正使用工具的人与没有使用的人，是否更接近工具效果？先说明这种比较可能改变什么。

先打开[支持路线](SUPPORT.md)确认第一个动作和成功信号，再阅读[知识准备](LEARN.md)理解必要概念；计算和复杂实现可以交给工具。

## 学习路线与任务层级

前置回顾：[第15课](../lesson-15/README.md)中的随机化单位、区组方案和预分析计划。先按[支持路线](SUPPORT.md)建立可信起点，再用[知识准备](LEARN.md)解释结果。

### 基础练习（可信起点）

按`person_id`连接名单与结果，核对分配、实际使用、随访和团队数，并固定`tool−usual`的效应方向。此层只建立分析起点，**不能冒充本课完成**。

### 标准任务（本课应完成）

完成下方三项分析任务：按初始分配并保留团队与区组结构估计效应和区间，完成缺失敏感性分析，再将3分钟实际门槛和实施成本用于推广、有限试用或停止决策。

### 提高与拓展（提前完成后）

比较团队汇总、基线调整或区组随机化检验，寻找缺失情境改变建议的界点，或审查小团队数下的推断稳定性。提高任务应改变统计判断，不能只增加代码、模型或图表数量。

## 分析任务

1. 对照L15实验方案和数据说明核对实际设计、分配人数、使用情况、缺失和基线。先明确目标是提供工具这一措施的效应，还是另有需要更强假设的问题。

2. 按随机分配进行主要比较，保留团队结构与区组；给出效应量、区间与一种符合原随机分配机制的检验或随机化分析。对缺失结果采用明确处理与敏感性分析方案，不把完整案例自动称为所有人的ITT效应。

3. 把效果、值得关注的改善3分钟、每人8单位实施成本及每分钟2单位价值一起报告。比较推广、有限试用和停止，说明哪些缺失/污染/外推情境会改变建议。

## 需要你作出的选择

可以分析随访值并调整基线、变化量或团队汇总，条件是估计目标明确、推断保留实际随机分配单位。缺失假设和政策门槛需要有依据；可以不推广，但不能只说p大或小。

报告全部随机化人数、实际有随访结果的人数、独立团队数；不将使用后分组当随机分组。效果符号明确：tool−usual为负表示处理时间下降。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

实验决策报告、分配/实施流程核对表、效应与不确定性分析、至少一项敏感性分析及成本判断。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。缺失和污染不会因随机化而自动消失；观察到的使用者效果不等于提供工具这一措施的效应。按原分配机制重新分配标签的随机化检验在存在处理影响缺失时需要额外假设，不能当作无条件精确证据。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。
