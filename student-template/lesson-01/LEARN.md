# 第1课知识准备 · 怎样用数据描述服务情况

一张表里有许多数字。本课先学习三个问题：这些数字描述谁？怎样概括它们？哪些结论能由这些记录支持？

## 1. 一行记录描述什么

**观测单位**是被观察、被记录的对象。例如，工单表一行记录一张工单，观测单位就是工单。**分析单位**是计算和比较时采用的对象。按工单分析与按来访者分析不同，因为同一个人可能办理多张工单。

**变量**是对象被记录的属性。等待时间是数值变量，可以用分钟表示；服务中心和是否预约是分类变量，用来区分类别。1—5级满意度是有序分类变量：等级有高低，但相邻等级的差距不一定相等，5级也不是1级的五倍满意。计算平均评分时，需要说明这种计算怎样解释。

**缺失值**表示本来需要的信息没有取得，例如没有填写的评价。它不自动等于0。字段名就是表中一列的名称，具体含义、取值和单位见数据说明；不要只凭英文名字判断。

## 2. 均值、中位数和比例

**算术平均数（简称均值）**是把所有数值相加，再除以数值的个数。它与原变量的单位相同：等待时间的均值仍以分钟表示。

**中位数**是把数值从小到大排列后的中间值。个数为偶数时，取中间两个数的平均。它不是“大多数人恰好取到的值”。

**比例**表示某一类记录占全部有关记录的多少。例如，放弃排队的工单数除以已登记工单数，得到放弃比例。分子是所关注的那一类，分母是用来比较的全部记录；写比例时要说明两者。

## 3. 用五张工单算一遍

以下是另设的学习例子，不是项目数据。0表示没有放弃，1表示放弃。先想一想：表里有几张工单、几个人？每个等待时间都以获得服务结束吗？

| 工单 | 来访者 | 等待时间（分钟） | 是否放弃 |
|---|---|---:|---:|
| E1 | P1 | 3 | 0 |
| E2 | P1 | 4 | 0 |
| E3 | P2 | 5 | 0 |
| E4 | P3 | 8 | 0 |
| E5 | P4 | 40 | 1 |

共有5张工单、4个人。全部工单的等待合计为60分钟，均值为60÷5＝12分钟，中位数为5分钟。这里的等待是从开始排队到开始服务或放弃离开的时间。

只看获得服务的4张工单，等待合计为20分钟，均值为20÷4＝5分钟，中位数为(4＋5)÷2＝4.5分钟。放弃比例为1÷5＝20%。E5等了40分钟后离开，不能说它在40分钟后获得服务。

因此可以写：“4张已服务工单平均等待5分钟，另有1张工单等待40分钟后放弃。”不能写“所有人只需等5分钟”。后一种写法把工单换成了人，也遗漏了放弃者。

## 4. 一个平均数不能说明全部情况

**分布**描述数值集中在哪里、彼此相差多大，以及是否有少数特别大或特别小的值。少数很长的等待会影响均值，所以还应结合中位数和图表来看。

**分位数**描述数据排序后不同位置的数值。第一、第二、第三四分位数分别对应约25%、50%、75%的位置，第二四分位数就是中位数。第三四分位数减第一四分位数称为**四分位距**，用来描述中间部分的分散程度。样本分位数有不同计算约定，使用软件时要说明采用的方法。

用前面的3、4、5、8、40算一次：本例采用线性插值，排序位置从1开始，位置＝1＋(记录数−1)×所求比例。第一四分位数的位置为1＋4×0.25＝2，取第2个数4；第三四分位数的位置为1＋4×0.75＝4，取第4个数8。四分位距为8−4＝4分钟。位置落在两数之间时怎样取值，第2课会继续用例子解释。

### 怎样选择图表

比较不同中心的放弃比例，可以用分组表或条形图，注明每个比例的分母。查看等待时间怎样分布，可以用直方图：把时间分成不重叠的区间，数一数各区间有多少记录。它与表示中心等类别的条形图回答不同问题。

例如把五个等待分为“不足10分钟”“10至不足20分钟”“20至不足30分钟”“30至不足40分钟”“40至不足50分钟”，各区间的记录数是4、0、0、0、1。40分钟归入最后一组，不重复计数。中间没有记录的区间也应保留，图题还要写清是全部登记工单还是已服务工单。改变区间宽度会改变图的外观，因此要结合原始记录和统计量解释。

## 5. 这些记录能代表谁

**总体**是研究对象的全体；**目标总体**是希望结论适用的全体对象。**样本**由从总体中选取的一部分单位组成，是否随机抽取要另行说明。

本课提供某段时间内全部已登记工单。这些记录可以用来描述这段时间的登记工单，但没有包含未取号的来访者，也不能自动代表其他月份。不能因为有一张数据表，就把它称为所有来访者的随机样本。

**描述性统计**概括已经观察到的数据。两个变量在记录中有联系，称为**关联**；要说改变一个因素会造成另一个结果改变，则涉及**因果关系**。例如，下午的记录等待较短，并不证明把上午的来访者改到下午就一定更快，业务类型和预约情况也可能不同。

```python
# learning-example
import json
import statistics as st
rows = [("P1", 3, 0), ("P1", 4, 0), ("P2", 5, 0), ("P3", 8, 0), ("P4", 40, 1)]
all_wait = [r[1] for r in rows]
served = [r[1] for r in rows if r[2] == 0]
result = {"tickets": len(rows), "people": len({r[0] for r in rows}),
          "all_mean": st.mean(all_wait), "all_median": st.median(all_wait),
          "served_n": len(served), "served_mean": st.mean(served),
          "served_median": st.median(served), "abandon_rate": sum(r[2] for r in rows) / len(rows)}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
