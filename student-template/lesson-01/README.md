# 第1课｜服务数据的探索性分析

用第一期3,600张教学合成工单，为服务中心提出一个值得核查的问题。

## 学习顺序

先读[知识讲解](LEARN.md)，完成手算与自检，再按本页设计正式分析。遇到具体操作问题查[运行帮助](SUPPORT.md)。已完成的作业无需重交。

## 数据与条件

数据在 `data/service/`：`tickets.csv` 为2026-03-02至04-10的登记工单，`windows.csv` 和 `business_types.csv` 解释归属和业务。其他表按问题选用，详见[数据说明](../data/service/README.md)。

已服务等待只纳入明确未放弃且等待有效的工单；放弃者的等待计到离开。比例按字段有效的指定范围计算，分母为零标为未定义。

## 标准任务

1. 明确报告使用者、时期、问题及分析单位：按工单还是按来访者汇总。
2. 检查重复、缺失、分类代码与时间单位，保存原始、纳入和排除数量及依据。
3. 选择合适的记录数、比例、均值、中位数、分位数或图表，写清单位、分母与理由。
4. 实际比较至少一种有理由的替代统计口径，或用数据检验另一种解释；并列结果及其对建议的影响。
5. 区分观察事实、可能解释与下一步调查，说明结果能描述的范围。

至少自主决定报告问题、单位和范围，以及指标、分组或替代检查。提交探索简报、可运行程序和支持结论的表或图。

## 运行与提交

在学生仓库根目录运行：

```sh
python3 scripts/course.py start 01
python3 scripts/course.py run 01
```

默认输出是分析起点，正式作品还需上述比较与建议。保存原始CSV，自己的结果放在 `lesson-01/artifacts/`。在 `submission.json` 中登记报告路径、产物和重建命令参数列表，完成后设 `status=complete`。

```sh
python3 scripts/course.py check 01
```

`check`核对状态、路径和文件，不重新运行分析。按[提交工作流](../docs/WORKFLOW.md)提交，标签沿用 `v2-l01-final`，修订保留旧标签。课堂选择题按教师开放场次完成，说明见[知识自查](../docs/KNOWLEDGE_CHECK.md)。

## 可选拓展

围绕同一作品增加一个有实际用途的检查，如另一种范围、指标或假设，并解释新增证据怎样影响建议。AI可辅助学习、编程与写作；分析选择和结果解释由你完成。评分与原作业要求不变。
