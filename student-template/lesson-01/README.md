# 第1课：服务数据的探索性分析

本课使用**教学合成数据**，不是真实机构或个人的记录。可以全程使用 AI 帮助学习、编程、分析和写作；问题、分析选择、结论与建议由你确定。先读本页明确成果；需要知识时查 [LEARN](LEARN.md)，遇到操作或分析阻塞时任选 [SUPPORT](SUPPORT.md) 中的提示，不需要全班走同一套分析步骤。初次使用工具可查[阅读与运行指南](../docs/READING_GUIDE.md)。

## 情境与目标

三个虚构服务中心准备召开改进会议。你要写一份有实际用途的探索简报，帮助管理者决定值得优先核查什么。**探索性分析**是描述已有记录中的位置、分布和差异，提出可继续核实的问题。你可以研究等待、时段、业务、预约、办结或其他有依据的问题，不要求宣布哪个中心最好。

## 可用资源

`data/service/tickets.csv` 包含 2026-03-02 至 2026-04-10 的 3,600 张登记工单。一张工单是一笔办理记录，同一个人可能有多张。`windows.csv` 对应窗口与中心，`business_types.csv` 解释业务类别；它们不是新的工单。满意度、接触和排班资料按问题选用，不要求全部使用。范围和字段见[数据说明](../data/service/README.md)。

`wait_minutes` 从开始排队计到开始服务或放弃离开，单位分钟。放弃者的时间不能解释成获服务等待，其 `service_minutes` 空白不是服务了 0 分钟。使用额外表时限定到与问题一致的工单/日期范围。

`analysis.py` 可运行并产生 `lesson-01/artifacts/starting_overview.json`，只有原始概览；可复用读表、分位数、描述统计和比例基础函数，也可自写程序或使用其他软件。它不会替你生成完整分析、挑选备选方案或填写建议。

## 三层任务

### 基础练习（可信起点）

任选一个关心的问题，从概览或自己的一项计算开始。至少核对一个原始记录或分组结果，把一项数字写成有对象、时期、单位和分母的句子；区分观察事实、可能解释和待补信息。需要帮助时再查 SUPPORT。基础练习建立起点，不能替代标准任务。

### 标准任务（本课应完成）

提交有用途的探索简报、可运行程序和支持结论的表或图。成果需覆盖以下五项要求，可自行安排分析顺序：

- 说明报告给谁看、支持什么决定，采用哪个时期、比较什么、按工单还是按人分析。
- 检查重复记录、缺失、分类代码和时间单位，报告原始、保留、排除数量与理由；不为展示清洗而删记录。
- 选适合问题的记录数、比例、均值、中位数、分位数或图表描述并比较，写单位、分母与方法依据。
- 实际计算至少一种合理替代统计口径或检查一种竞争解释，说明两种结果如何改变结论或建议。备选须与问题有关，不要求得到反转。
- 分开写观察事实、可能解释和下一步调查；说明适用范围，中心差异不直接解释为工作人员造成的效果。

**至少两项重要决定留给你：**第一，什么问题值得报告，以及采用什么单位和范围；第二，什么指标/分组/备选能检验它。最终结论与行动建议也由你确定。教师不预定唯一问题、方法或排名；相反判断只要依据合理、可复核，同样可以成立。

### 提高与拓展（提前完成后）

在标准任务基础上，选择一个会实际影响建议的新检查，也可自拟。可考虑总体差异与业务内差异、通常经历与长等待、按工单与按个人的不同权重、独立复算，或把可能解释转成有不同后果的调查设计。这些是可选方向，不是必做菜单。说明为什么检查、增加了什么证据及结论是否保留、加条件或改变；没有变化也报告检查范围，不靠重复图表或运行耗时提高难度。

## 证据自检与提交

报告主要数字能追到原始记录或生成结果；每个计算的对象、分子分母、单位和时期清楚；备选确实计算过；原始 CSV 保持不变；结论没有超出资料取得范围。

在能看到 `scripts/`、`data/` 和 `lesson-01/` 的学生仓库根运行：

```bash
python3 scripts/course.py start 01
python3 scripts/course.py run 01
```

本环境有 `python3`；若环境中的 `python` 是 Python 3，可用 `python scripts/course.py run 01`、`python scripts/course.py check 01`。**仅提交这个概览还没有完成作业**，它不含你选定的问题、完整备选比较与结论。

结果存到 `lesson-01/artifacts/`。`submission.json` 填实际报告与结果路径、可重建结果的运行参数列表；完成标准任务后才设为 `complete`。

```bash
python3 scripts/course.py run 01
python3 scripts/course.py check 01
```

本地 `check` 只检查状态、路径和文件是否存在且非空，**不会重新运行分析**或判断统计质量。按[工作流](../docs/WORKFLOW.md)核对暂存内容并提交，使用 `v2-l01-final` 标签；修订保留旧标签。
