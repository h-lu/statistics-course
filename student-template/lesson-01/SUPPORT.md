# 第1课可选支持：遇到阻塞时再查

先读 README 的情境和成果边界，自己决定问题与分析。下面按“你卡在哪里”提供提示，不是全班要执行的流程；只打开相关一项，够用后返回自己的项目。

## 不知道怎样开始

**轻提示：**先找一个管理者可能关心的现象，用一句话说明谁需要它、要决定什么。等待、办理结果、时间安排只是可能题材，不是指定答案。

**更具体的提示：**若一个数字都没有，可在学生仓库根运行 `python3 scripts/course.py run 01`，打开 `lesson-01/artifacts/starting_overview.json`。任选一个结果，问它描述谁、有几条记录、单位是什么、遗漏谁。成功信号是能把数字写成有范围的一句话；这还不是完整简报。

## 不清楚字段和记录含义

**轻提示：**用数据说明确定工单、来访者和变量含义，再选你的分析单位。编号是标识，不是连续数值大小。

**更具体的提示：**任选一条原始工单，用其窗口编号查中心、业务代码查类别，核对等待单位与放弃状态。成功信号是能找到原记录并解释每个用到字段；若按人分析，须自行定义多张工单如何汇总。空白服务时长是否与放弃相配，是一种可选核对，不意味着所有指标都应删除该行。

## 分母、均值或中位数不确定

**轻提示：**先写纳入哪些对象，再给分子分母。均值总量平均到记录，中位数描述排序中间位置，二者服务于不同用途。

**更具体的提示：**看 LEARN 五条独立小记录的完整手算。可从正式数据自行选一个小组复算计数或指标；它与程序结果一致只核对计算，不证明总体代表性。`analysis.py` 的 `read`、`linear_quantile`、`describe`、`rate` 是基础工具，你决定传入什么记录，不替你选方法。

## 不知道怎样选择合理备选

**轻提示：**找原结论最可能受影响的一个选择，问为何会影响使用者。备选不是为制造反转而任意改参数。

**更具体的提示：**如果只描述已服务者，可考虑遗漏放弃经历；如果比较总体，可考虑不同构成；如果只描述平均，可考虑长等待；也可以提出别的竞争解释。这里只提示问题类型，不规定你的备选。成功信号是已有实际计算或数据检查，并能说明建议为何保留、加条件或改变。

## 有数字但不会写结论

**轻提示：**把观察事实、原因假设和调查建议分开。报告一个能追溯的结果，再说明它对行动有什么含义及哪里仍缺证据。

**更具体的提示：**对自己的最重要数字问：“换合理口径是否仍支持原话？要向谁补哪项资料，什么结果会改变行动？”不需要填教师偏好的句子，也不靠罗列所有指标充实简报。

## 标准任务已完成，想继续深入

自己选择一项真正检验原建议的新比较。可研究单位权重、业务构成、长尾、独立复算或补充调查的不同后果；也可提出新方法。范围与方法由你定，说明真实取舍与结论变化。基本支持提示到此撤去，不再提供完整项目操作步骤。

## 工具或提交卡住

- 当前目录应能看到 `scripts/`、`data/` 和 `lesson-01/`；在终端运行命令，不在 Python 的 `>>>` 后输入。没有 `python` 时用 `python3`，基础代码无需安装第三方包。
- 确认本次运行成功、打开的是新结果；数字不一致先查记录范围、单位和分母，再查算法，不手改输出凑一致。
- `submission.json` 中 `run` 是命令参数列表，例如基础入口 `["python3", "lesson-01/analysis.py"]`；自己的入口和参数按实际填写，能重建所列结果。报告/结果路径从学生仓库根起写。
- 完成标准任务后才设 `complete`，运行 `python3 scripts/course.py run 01`、`python3 scripts/course.py check 01`；`check` 只验文件，不判断分析质量。
- 原始 CSV 未覆盖，关键数字可追溯，备选实际完成。按[工作流](../docs/WORKFLOW.md)检查差异和暂存内容，避免混入无关文件。

独立概念自检见 LEARN，提交目标和课堂选择题入口见 README。
