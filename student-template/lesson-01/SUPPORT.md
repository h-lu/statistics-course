# 第1课可选支持：遇到困难时再查

先读 README 的情境和成果要求，自己决定问题与分析方法。下面按“你卡在哪里”提供提示；选择与困难相关的一项，解决问题后返回自己的项目，无需逐项跟做。

## 不知道怎样开始

**轻提示：**先找一个管理者可能关心的现象，用一句话说明谁需要了解这个现象、要据此决定什么。等待、办理结果、时间安排只是可能的题材。

**更具体的提示：**若还没有算出结果，可在学生仓库根目录运行 `python3 scripts/course.py run 01`，打开 `lesson-01/artifacts/starting_overview.json`。任选一个结果，问它描述谁、有几条记录、单位是什么、遗漏谁。当你能把数字写成说明范围的一句话时，就有了分析的起点；还需要继续完成标准任务。

## 不清楚字段和记录含义

**轻提示：**用数据说明确定工单、来访者和变量含义，再选你的分析单位。编号是标识，不是连续数值大小。

**更具体的提示：**任选一条原始工单，用其窗口编号查中心、业务代码查类别，核对等待时间的单位与是否放弃。应能找到原记录，并解释每个用到的字段；若按人分析，还须自行定义多张工单如何汇总。可检查服务时长为空的工单是否为放弃者。即使某字段为空，其他字段仍可能用于分析，要根据指标决定是否保留该记录。

## 分母、均值或中位数不确定

**轻提示：**先写纳入哪些对象，再说明计算方法。均值把数值总和平均到纳入的记录，中位数描述排序后的中间位置；计算比例时，写出满足条件的数量和作为分母的总数量。

**更具体的提示：**看 LEARN 中另设的五张工单小例子及完整手算。可从正式数据自行选一个小组复算计数或指标；手算与程序结果一致，可以核对计算，但不能证明资料能代表目标总体。`analysis.py` 中，`read` 用于读表，`linear_quantile` 计算分位数，`describe` 给出描述统计，`rate` 计算比例。它们是基础工具，纳入哪些记录、采用什么方法由你决定。

## 不知道怎样选择合理备选

**轻提示：**找原结论最可能受影响的一个选择，问为何会影响使用者。备选不是为制造反转而任意改参数。

**更具体的提示：**如果只描述已服务工单，可考虑是否遗漏了放弃经历；如果比较所有业务合并后的结果，可考虑各中心业务构成是否不同；如果只描述均值，可考虑少数长等待的影响。也可以提出其他可能解释。备选由你选择；完成实际计算或数据检查后，应能说明建议为何保留、补充条件或改变。

## 有数字但不会写结论

**轻提示：**把观察事实、原因假设和调查建议分开。报告一个能追溯的结果，再说明它对行动有什么含义及哪里仍缺证据。

**更具体的提示：**针对自己最重要的数字问：“换一种合理统计口径后，结果是否仍支持原话？要向谁补充哪项资料，什么结果会改变行动？”选择能支持问题的指标，说明它们与结论的关系。

## 标准任务已完成，想继续深入

自己选择一项能进一步检验原建议的新比较。可研究工单和来访者的权重、业务构成、少数特别长的等待、独立复算或补充调查的不同后果，也可提出新方法。范围与方法由你定，说明为什么选择，以及结果如何影响结论。

## 工具或提交卡住

- 当前目录应能看到 `scripts/`、`data/` 和 `lesson-01/`；在终端运行命令，不在 Python 的 `>>>` 后输入。没有 `python` 时用 `python3`，基础代码无需安装第三方包。
- 确认本次运行成功、打开的是新结果；数字不一致先查记录范围、单位和分母，再查算法，不手改输出凑一致。
- `submission.json` 中 `run` 是命令参数列表。例如 `["python3", "lesson-01/analysis.py"]` 相当于在学生仓库根目录运行 `python3 lesson-01/analysis.py`。如果另写程序或增加参数，要填写实际命令，使它能重新生成 `artifacts` 中列出的文件。报告和结果文件的路径也从学生仓库根目录写起。
- 完成标准任务后才设 `complete`，运行 `python3 scripts/course.py run 01`、`python3 scripts/course.py check 01`；`check` 只验文件，不判断分析质量。
- 原始 CSV 未覆盖，关键数字可追溯，备选实际完成。按[工作流](../docs/WORKFLOW.md)检查差异和暂存内容，避免混入无关文件。

独立概念自检见 LEARN，提交目标和课堂选择题入口见 README。
