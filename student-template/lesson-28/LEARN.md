# 第28课知识准备 · 观察数据中的效应估计与共同支持

## 本课要解决的问题

先确定具有可比数据的人群，再选择调整方法；根据重叠、平衡等诊断结果，说明将调整后差异解释为因果效应还需要哪些条件。可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 结果标准化 | 在同一目标人群的协变量分布下平均各处理状态的预测结果。 | 获得同一人群的比较 |
| 倾向得分 | 给定处理前协变量时接受处理的概率，不是结果风险。 | 评估重叠与构造权重 |
| 重叠与正值性 | 目标人群相应协变量条件下两种处理都要有机会出现。 | 确定共同支持区域 |
| 平衡与有效样本量 | 加权后协变量可比性及权重集中导致的信息损失。 | 检查调整质量 |
| 条件可交换性与未测量混杂 | 给定所调整的协变量后，处理分配与潜在结果条件独立；平衡诊断只能检查已测变量。 | 说明因果识别条件 |

这里的“结果标准化”是将两种处理状态下的预测结果，分别在同一目标人群的协变量分布上取平均；它不同于把变量减去均值再除以标准差的“变量尺度标准化”。共同支持区域是指两组都有协变量相近的观测、能够进行比较的范围。

估计平均处理效应（ATE）时，逆概率权重可写为A/e(X)+(1−A)/(1−e(X))。分别将每组的加权结果总和除以该组权重总和，再计算两组之差，得到Hájek形式的估计量。有效样本量（ESS）写作 ESS=(Σw)²/Σw²；它不是原始人数。限制倾向得分范围后，目标人群可能改变，不得仍将结果称为原全体人群的ATE。

式中A为实际处理指示0/1，X为处理前协变量，e(X)=P(A=1|X)，w为每条记录的权重。标准化均值差（SMD）用共同尺度描述组间协变量差异；平衡表须交代采用的标准化分母。

## 先思考，再看例子

两名接受支持者的倾向得分分别0.5和0.99，用于估计ATE的处理组权重分别2和约1.01；一名未接受支持者的倾向得分为0.99，其对照组权重为100。后一种协变量条件下的未处理者很少，因此权重很大，估计可能不稳定。排除这些记录可能改变目标人群，需要说明。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

至少比较未经调整的差异与一种有依据的调整结果，例如结果标准化、匹配或倾向得分加权。采用加权时，应检查协变量平衡、极端权重和有效样本量，不能仅凭倾向得分模型的受试者工作特征曲线下面积（AUC）较高就认为调整成功。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

权重平衡不证明没有未测量混杂。在固定保留样本中计算的自助法区间，未涵盖样本保留规则的选择、模型设定错误及未测混杂造成的全部不确定性。

## 学习自查

进入项目后应能解释：

1. 进行结果标准化时，两种处理状态应该在哪个人群分布上平均？
2. 倾向得分与结果风险概率有什么区别？
3. 几乎人人接受支持的群体，未支持结果由哪些资料支撑？
4. 权重平衡改善后，为什么还需要看极端权重和有效样本量？
5. 已测变量平衡、区间较窄，为什么仍不能证明没有未测混杂？

## 进一步学习

可按需使用结果标准化、匹配、重叠权重或逆概率加权。不同方法可能针对不同目标人群；说明截断极端权重与排除共同支持不足的人群分别改变了什么，不能只保留一个更显著的估计。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
