# 第28课 · 观察数据中的效应估计与共同支持

## 项目背景

项目暂时无法随机分配支持，评估组计划用现有资料估计接受与未接受支持者的随访负担差异，并调整处理前协变量。严重程度较高者几乎都接受了支持，较低者多数未接受；负责人需要了解哪些人群具有可比数据，估计结果能适用于谁。

先确定具有可比数据的人群，再选择调整方法；根据重叠、平衡等诊断结果，说明将调整后差异解释为因果效应还需要哪些条件。

可用资料为[政策与决策数据集](../data/policy/README.md)中的`support_observational.csv`。**资料全部为教学合成数据。** 数据字典说明记录单位、字段、时点和局限；你可以全程使用AI完成编程、分析、写作与提交，也可以复用前课代码。

## 任务分层

本课必须先明确[第27课定义的处理、目标人群和目标效应](../lesson-27/README.md)。第一次做这一类项目时，按[陪做支持](SUPPORT.md)完成每一步；概念解释见[知识准备](LEARN.md)。

### 基础练习（可信起点）

1. 列出处理前协变量，分别查看接受与未接受支持者的分布；不要纳入支持后才产生的变量。
2. 画出或列出倾向得分重叠，指出两组都有可比记录的范围，并先声明目标人群。
3. 比较未经调整差异与一种调整结果，至少核对一项协变量平衡和权重是否过度集中。

基础练习帮助你得到可信的第一份结果，**并不等于已经完成本课**。继续完成下面的标准任务，才能把计算变成可使用的统计结论。

### 标准任务（本课应完成）

1. 定义目标量与处理前调整变量，检查支持与未支持人群的协变量分布、倾向得分重叠。决定保留全部人群、限制在共同支持区域内，或以重叠人群为目标，并说明目标人群是否改变。

2. 至少比较未经调整的差异与一种有依据的调整结果，例如结果标准化、匹配或倾向得分加权。采用加权时，应检查协变量平衡、极端权重和有效样本量，不能仅凭倾向得分模型的受试者工作特征曲线下面积（AUC）较高就认为调整成功。

3. 估计结果的不确定性，并实际改变一项重要的调整方法或共同支持区域选择，考察结果是否稳定。说明区间涵盖哪些不确定性，以及仍不能排除哪些未测量混杂。

4. 在报告中先说明目标人群和数据的共同支持情况，再报告效应估计值。分别给出不作因果假设时的关联解释，以及满足明确识别假设时的因果解释，并建议优先为哪些人群补充收集数据。

以上均为本课需要完成的任务，分析方法和报告形式可以自行选择。评价不以图表或模型数量为依据。使用外部资料时注明来源，补充的业务假设应明确标注，不得当作已知事实。

### 提高与拓展（提前完成后）

完成标准任务后，从下面选择一项深入；重点是改善证据或决策，不按代码、图表或模型数量评价。

- 比较结果标准化、重叠权重或匹配，说明它们实际针对的目标人群是否相同。
- 改变共同支持范围或极端权重处理，报告估计值、有效样本量与适用范围怎样一起变化。
- 针对一个可能的未测量混杂因素做定性或定量敏感性分析，并提出补采顺序。

## 课堂安排（90分钟）

- 0—12分钟：阅读[知识准备](LEARN.md)和项目背景；需要分步引导时打开[陪做支持](SUPPORT.md)，明确分析问题；需要时可延长到17分钟，相应减少重复操作和排版时间。
- 12—55分钟：选择方法、开展分析或研究设计，并比较不同方案；遇到不熟悉的概念可随时查阅知识准备或询问AI。
- 55—68分钟：核对一项主要结论的计算结果、假设与替代解释，完成分析报告。
- 68—75分钟：重新运行程序，检查结果并提交；提前完成时，可进一步检验报告中的重要结论。
- 75—90分钟：[知识自查](https://hblu.top/stat-check/)，确认页面为当日V2课次，建议先完成A版基础题，再向AI学习不熟悉的概念，随后完成B版变式题。

## 示例代码与运行方法

从仓库根目录运行：

```bash
python scripts/course.py start 28
python scripts/course.py run 28
```

本课`analysis.py`读取数据并生成`artifacts/starting_summary.json`，用于熟悉数据结构。**请在此基础上完成本课分析任务，形成自己的分析方案和结论。** 可使用Python标准库、numpy/scipy、pandas、statsmodels、scikit-learn或其他合适工具；说明新增依赖与运行命令。

## 成果要求与提交

- `report.md`：面向报告使用者，写清分析问题、方法依据、主要结果、适用范围和建议。
- 可复现的分析程序或研究设计文件，以及报告引用的计算结果和图表；不要手工修改原始数据。
- `submission.json`：将`status`设为`complete`，`report`指向分析报告，`artifacts`列出支持报告结论的结果文件路径，`run`填写可复现分析的命令。

仅运行示例代码或粘贴模型输出，还没有完成本课分析任务。合格报告应说明目标人群、重叠情况和区间估计；更好的报告还会比较不同的共同支持区域或调整方法，并据此修改结论的适用范围及补充数据的建议。

完成后执行`python scripts/course.py check 28`，按[项目工作流](../docs/WORKFLOW.md)提交并创建`v2-l28-final`标签；有修订时保留原标签。自查按[知识自查说明](../docs/KNOWLEDGE_CHECK.md)进行。项目分析允许全程使用AI，不要求提交AI对话记录。
