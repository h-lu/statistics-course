# 第21课 · 如何解释相关与回归结果

## 项目背景

服务改进负责人希望在月度例会上说明“积压与结单时长有什么关系”，并据此确定下一轮调查重点。这些观察记录不能直接说明增减人员会带来什么效果。

你需要说明分析覆盖哪些服务对象和负荷范围，提出有数据依据的结论，并指出现有观察数据不能支持哪些因果解释。

可用资料为[预测分析数据集](../data/prediction/README.md)中的`requests.csv`。**资料全部为教学合成数据。** 数据字典说明记录单位、字段、时点和局限；同时阅读`feature_availability.csv`。你可以全程使用AI完成编程、分析、写作与提交，也可以复用前课代码。

## 任务分层

开始前可复习[第02课的统计口径与敏感性分析](../lesson-02/README.md)和[第17课的重复观测](../lesson-17/README.md)。第一次做这一类项目时，按[陪做支持](SUPPORT.md)完成每一步；概念解释见[知识准备](LEARN.md)。

### 基础练习（可信起点）

1. 运行起点程序，打开 `artifacts/starting_summary.json`，确认月0—15、地区、积压量和结单时长的记录范围。
2. 只用月0—11画一张积压量与结单时长的散点图，并写下关系方向、可能的弯曲和数据覆盖范围。
3. 拟合一个简单线性关系，核对斜率的单位，并用月12—15检查关系方向是否延续。

基础练习帮助你得到可信的第一份结果，**并不等于已经完成本课**。继续完成下面的标准任务，才能把计算变成可使用的统计结论。

### 标准任务（本课应完成）

1. 限定月0—11为描述与建模资料，月12—15只用于检验关系在后续批次是否仍适用；保留月16—23供后续课程。识别同一服务对象的重复记录，说明结果的分析单位。

2. 比较能说明积压—时长关系的描述与模型；检查弯曲、残差随负荷变化和强影响观测值。根据诊断决定保留还是修改模型、范围或表述，并展示支持该决定的证据；不能只贴一份回归摘要。

3. 给关键斜率或指定负荷下的对比提供置信区间，明确同一服务对象的重复观测如何影响不确定性。比较保留全部记录与有根据的敏感性处理，保留原始数据。

4. 将结果写成供会议引用的关系报告：说明一个可用场景、一个不适用场景，提出下一步应采集或研究的信息。

这些要求共同构成本课主任务。方法和成果形式可以自行选择；图、表或模型数量不计作质量。使用外部资料时注明来源，不能用虚构事实填补约束。

### 提高与拓展（提前完成后）

完成标准任务后，从下面选择一项深入；重点是改善证据或决策，不按代码、图表或模型数量评价。

- 比较线性、分段线性或平滑关系；说明复杂形式是否改变会议上可以引用的结论。
- 比较普通区间、异方差稳健区间或按设备聚类的区间，并解释差异来自什么假设。
- 把一个强影响观测值的敏感性分析写成“保留时/有理由排除时”两种可用表述。

## 建议的90分钟

- 0—12分钟：阅读[知识准备](LEARN.md)和项目背景；需要分步引导时打开[陪做支持](SUPPORT.md)，明确今天要比较什么；不熟悉时可延长到17分钟，减少重复排版时间。
- 12—55分钟：建立分析或设计、运行分析程序并检查结果、比较有实际差别的方案。中途可回看知识准备，不要求等统一发布新文件。
- 55—68分钟：核对一条关键结论的数字来源、假设与替代解释，完成面向使用者的分析报告。
- 68—75分钟：重跑、检查和提交；若已提前完成，用余时改进同一成果的重要证据。
- 75—90分钟：[知识自查](https://hblu.top/stat-check/)，确认页面为当日课次，建议先自行判断A版基础题，再向AI询问概念，最后完成B版变式题。

## 运行示例代码

从仓库根目录运行：

```bash
python scripts/course.py start 21
python scripts/course.py run 21
```

本课`analysis.py`读取数据并生成`artifacts/starting_summary.json`，仅用于熟悉数据结构，**不是完整项目解法，也不给推荐结论**。可使用Python标准库、numpy/scipy、pandas、statsmodels、scikit-learn或其他合适工具；说明新增依赖与运行命令。

## 提交与检查

- `report.md`：面向报告使用者的成果，写清目标、依据、重要选择、可用范围和行动建议。
- 可复现分析/设计入口，以及实际用于分析结论的结果文件；原始数据不手改。
- `submission.json`：`status`为`complete`，`report`指向分析报告，`artifacts`列支持报告结论的结果文件路径，`run`为可重跑命令。

只运行示例代码或交一份模型摘要并未完成分析任务。合格报告说明单位、残差和关联结论的局限；高质量报告把诊断落实为适用范围或不同模型的选择，并说明该选择对会议分析结论的影响。

完成后执行`python scripts/course.py check 21`，按[项目工作流](../docs/WORKFLOW.md)提交并创建`v2-l21-final`标签；有修订时保留原标签。自查按[知识自查说明](../docs/KNOWLEDGE_CHECK.md)进行，不要求证明代码或文字由谁输入。
