# 第21课陪做支持 · 如何解释相关与回归结果

这份材料帮助你在不知道下一步时建立可信起点。它不提供本课正式数据的答案，也不能代替 [README 主任务](README.md)；概念的完整解释见 [LEARN.md](LEARN.md)。

## 先知道今天要交出什么

- `report.md`：面向月度例会的关系报告。
- 可重跑的分析程序，以及散点图、诊断或结果表。
- `submission.json`：列出真正支持报告结论的文件。

最低出口是：别人能够按你的命令重新生成报告引用的数字，并知道这些数字可以和不可以用于什么决定。

## 核心概念与原理

| 规范术语 | 通俗解释 | 怎样在自己的结果中检查 |
|---|---|---|
| 线性关联 | 两个变量沿直线方向共同变化；强关联仍不等于因果关系。 | 看散点图是否大致沿直线，并写清覆盖的积压范围。 |
| 回归斜率 | 积压量增加1单位时，模型给出的平均结单时长差；单位是“分钟/积压单位”。 | 从模型输出读出斜率后，同时写数值、单位和适用范围。 |
| 残差 | 实际时长减模型预测时长。残差仍有弯曲或扩散模式，说明直线或误差假设不足。 | 把残差按低、中、高负荷分组，检查平均位置和离散程度。 |
| 强影响观测值 | 一条记录是否会显著改变拟合；影响大不等于记录错误。 | 比较保留全部记录与有充分理由处理后的结果。 |
| 重复观测 | 同一设备多个月的记录彼此可能相关，行数不等于独立设备数。 | 同时报告记录数和设备数，并据此选择置信区间方法。 |

### 先用一个小例子想清楚

假设积压量为1、2、3时，结单时长为12、14、16分钟。直线斜率为2分钟/积压单位。若第四条为积压10、时长80，它可能强烈改变斜率；先核对记录，再比较保留与有理由处理两种结果，不能因为“不合群”直接删除。

这个例子只用于核对概念，不是正式数据的结论。正式项目必须使用自己的运行结果。

## 基础练习（可信起点）：入门跟做

以下命令都从仓库根目录运行，也就是同时能看到 `scripts/`、`data/` 和 `lesson-21/` 的目录。

```bash
python scripts/course.py start 21
python scripts/course.py run 21
```

第二条命令成功后，应看到终端提示结果已经生成，并能打开 `lesson-21/artifacts/starting_summary.json`。这个文件只是数据起点，不是本课完整答案。

若终端明确提示 `python: command not found`，按仓库首页说明，把上面两行开头的 `python` 换成 `python3`，其余内容不变。

### 第1步：建立数据边界

- **动作：** 运行 `python scripts/course.py start 21` 和 `python scripts/course.py run 21`，打开 `lesson-21/artifacts/starting_summary.json`，再查看数据字典。
- **目的：** 先确认可用月份、字段单位、记录数和同一 `entity_id` 是否重复。
- **成功信号：** 结果文件存在；你能说出一行对应“设备—月份”，并区分月0—11与12—15。
- **想一想：** 如果把多个月份当成互不相关的设备，会怎样影响区间？

### 第2步：先看关系再拟合

- **动作：** 只用月0—11画 `backlog` 对 `resolution_minutes` 的散点图，并在运行前写下你预计的方向和形状。
- **目的：** 模型形式应由要概括的关系和诊断共同决定。
- **成功信号：** 图上标有横纵轴名称、单位和数据范围；报告中有一句运行前预计。
- **想一想：** 高负荷区域是否有足够记录支持单独解释？

### 第3步：核对斜率和残差

- **动作：** 拟合一个起点模型，手工挑两组相差1个积压单位的预测值复算斜率；再看残差图。
- **目的：** 把软件系数翻译成可复核的统计含义，并检查直线是否合适。
- **成功信号：** 预测差与输出斜率一致；残差图能用于决定修改模型还是限制表述。
- **想一想：** 斜率描述的是观察关联，还是增加人员后的因果效果？

### 第4步：验证与敏感性

- **动作：** 在月12—15检查方向和误差，再改变一个有理由的模型形式、范围或影响点处理。
- **目的：** 检验关系能否延续，并判断分析选择是否改变会议结论。
- **成功信号：** 结果表明确区分开发与验证资料，并列出两种方案。
- **想一想：** 哪一项变化会让你停止引用原结论？

完成这四步后，你已经有可信起点，但还没有完成整项主任务。

## 标准任务（本课应完成）

回到 [README](README.md) 完成全部标准任务，特别核对：

- 说明分析单位、月份和负荷范围。
- 把残差、弯曲或影响诊断落实为模型或表述选择。
- 为关键对比给出考虑重复观测的置信区间。
- 写出一个可用场景、一个不适用场景和下一步补充信息。

把程序输出翻译成完整统计句子：对象是谁，比较什么，数值和单位是什么，哪些假设成立时可以怎样使用，哪些结论仍不能作出。

## 提高与拓展（提前完成后）

先完成标准任务，再选一项。提高的标准是让证据、适用范围或行动更可靠，而不是增加代码或图表数量。

- 比较分段线性或平滑关系与直线的实际解释差异。
- 比较不同区间方法并解释其假设。
- 把强影响记录的敏感性结果转成两套会议表述。

## 卡住时按顺序排查

- **置信区间异常窄：** 检查是否把同一设备的多个月当成完全独立记录，以及是否只用了模型默认标准误。
- **命令提示找不到文件：** 先运行 `pwd`，确认当前位置是仓库根目录；这里应同时看见 `scripts/` 和本课目录。
- **程序能运行但结果还是旧的：** 检查结果文件的修改时间，确认修改并运行的是本课 `analysis.py`；必要时删除自己生成的旧结果后重跑，但不要删除原始数据。
- **报告数字和程序输出不一致：** 从报告中的一个关键数字反向找到结果文件、筛选范围、分子和分母；不要手工把报告改成“看起来合理”的数字。
- **不知道怎样开始写报告：** 先写五句：谁使用、要决定什么、数据覆盖谁、一个主要结果、一个不能支持的结论，再补方法和证据。
