# 第26课 · 风险模型的校准与试运行评价

## 项目背景

升级风险模型即将试运行，数据供应商更新了传感器接口，后续记录的构成也可能变化。负责人要一份能交给值班人员的使用说明，而不只是历史受试者工作特征曲线下面积（AUC，衡量排序能力）。

模型适合在哪些人群和时段试运行？如何判断预测概率是否与实际发生比例相符，什么时候降级、复核或撤回？

可用资料为[预测分析数据集](../data/prediction/README.md)中的`requests.csv`。**资料全部为教学合成数据。** 数据字典说明记录单位、字段、时点和局限；同时阅读`feature_availability.csv`。你可以全程使用AI完成编程、分析、写作与提交，也可以复用前课代码。

## 任务分层

开始前回看[第23课的风险概率与行动阈值](../lesson-23/README.md)和[第24课的独立评价](../lesson-24/README.md)。第一次做这一类项目时，按[陪做支持](SUPPORT.md)完成每一步；概念解释见[知识准备](LEARN.md)。

### 基础练习（可信起点）

1. 明确月16—19已用于以前的评价，将其标作历史校准资料；把月20—23保留为本轮后续评价。
2. 在月16—19检查一张分箱校准表，逐箱列出预测概率、实际升级比例和记录数。
3. 冻结校准和阈值后，在月20—23报告排序、校准、基础率以及至少一个地区的结果。

基础练习帮助你得到可信的第一份结果，**并不等于已经完成本课**。继续完成下面的标准任务，才能把计算变成可使用的统计结论。

### 标准任务（本课应完成）

1. 复用已冻结模型，明确月16—19已被L24看过，可以明确改作进一步开发或校准所用的数据；把月20—23作为本轮后续评估，不使用它选择校准方法或阈值。

2. 同时检查排序能力、概率校准和总体/分地区表现，报告分箱样本量与不确定性；不要把AUC稳定解释为概率可靠。

3. 核对特征缺失、取值范围、基础率与预测误差的变化。区分无标签时能监测的输入变化与获得真实结果标签后才能评价的性能变化，提出实际阈值及复核频率。

4. 提交模型使用说明和试运行建议：输入要求、适用范围、人工复核职责、监测指标、降级或暂停使用的规则，以及按时间顺序进行的历史评估结果。选择限范围试用或暂不采用都可以，但须有数字支持。

以上均为本课需要完成的任务，分析方法和报告形式可以自行选择。评价不以图表或模型数量为依据。使用外部资料时注明来源，补充的业务假设应明确标注，不得当作已知事实。

### 提高与拓展（提前完成后）

完成标准任务后，从下面选择一项深入；重点是改善证据或决策，不按代码、图表或模型数量评价。

- 比较不校准与一种校准方法，并说明改善是否足以改变值班行动。
- 为缺失率、输入范围、概率偏差和结果标签延迟分别设置可执行的监测规则。
- 比较总体与地区结果，在样本不足时设计复核而不是给出过度确定的结论。

## 成果要求与提交

- `report.md`：面向报告使用者，写清分析问题、方法依据、主要结果、适用范围和建议。
- 可复现的分析程序或研究设计文件，以及报告引用的计算结果和图表；不要手工修改原始数据。
- `submission.json`：将`status`设为`complete`，`report`指向分析报告，`artifacts`列出支持报告结论的结果文件路径，`run`填写可复现分析的命令。

仅运行示例代码或粘贴模型输出，还没有完成本课分析任务。合格使用说明能让值班人员按规则行动；高质量作品针对实际出现的风险低估和缺失设置可执行复核方案，避免空泛“持续监测”。
