# 第26课知识准备 · 风险模型的校准与试运行评价

## 本课要解决的问题

模型适合在哪些人群和时段试运行？如何判断预测概率是否与实际发生比例相符，什么时候降级、复核或撤回？可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 校准 | 预测概率与相应记录中实际发生比例的吻合程度。 | 判断概率是否可用于成本决策 |
| Brier分数 | 预测概率与0/1结果的平均平方差，越小通常越好。 | 与排序指标并列 |
| 群体表现 | 按具有实际意义的群体分别检查误差、校准和样本量。 | 界定试运行范围 |
| 分布漂移 | 输入、基础率或条件关系随环境改变。 | 设计监测 |
| 撤回条件 | 预先说明何种证据触发暂停、降级或重新验证。 | 给值班人员行动规则 |

Brier=(1/n)Σ(pᵢ−yᵢ)²，其中p为预测概率、y为0/1结果，无量纲。它同时受校准、区分能力和基础率影响；不同人群不能只凭Brier大小判断公平。绘制校准曲线时，应报告每个分箱的记录数n。

式中n为用于评价的记录数，i标记第i条记录；各群体应分别使用自己的记录数作分母，不能把不同群体的分母混用。

## 先思考，再看例子

一组预测都为0.2的100条记录，后来40条发生事件；这组明显低估风险。即使分数排序没变、AUC相近，按概率决定复核预算也可能不合适。只有10条的群体出现同样比例时，应更谨慎解释波动。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

同时检查排序能力、概率校准和总体/分地区表现，报告分箱样本量与不确定性；不要把AUC稳定解释为概率可靠。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

在历史批次校准不保证未来仍校准。观察到输入漂移不证明性能一定变差；没有结果标签时也不能声称性能已经验证。

## 学习自查

进入项目后应能解释：

1. 排序不错但概率普遍偏低，会怎样影响行动？
2. Brier分数与AUC分别反映什么，能否互相替代？
3. 小群体错误率较高时，为什么必须同时报告样本量？
4. 没有新结果标签时，能监测什么，不能确认什么？
5. 什么具体证据会让值班人员限用、复核或暂停模型？

## 进一步学习

可按需了解逻辑校准、等距/等频分箱、群体区间和分布监测。分箱要显示样本量；历史校准资料与后续评价资料的用途要分别记录。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
