# 第18课支持路线 · 在预算内评估实验设计

## 先知道今天要交出什么

你要交出“开展、改设计、追加预算或先试点”的设计备忘录。最终包括预算内方案与至少一个超预算方案的功效、区间精度和费用对照，效果大小、变异程度或依从性变化下的敏感性结果，以及可复现模拟。

入门跟做只完成成本核算与一种简化设计检查，不能代替完整的方案比较和建议。

## 核心概念与原理

**功效**是在指定真实效应、变异程度、样本量、分配和分析方法下，统计程序拒绝零假设的概率。它不是研究成功概率，也不是零假设为假的概率。

**最小有实际意义的效应**由成本、收益或风险决定；**最小可检测效应（minimum detectable effect，MDE）**是在指定显著性水平与目标功效下，设计较容易检出的最小效应。两者不同：设计可能有能力检出一个业务上没有意义的小变化，也可能无力识别真正值得行动的变化。

团队随机实验的信息主要由独立团队数决定。团队内20人通常相关，不能把增加同一队内重复记录当作增加相同数量的独立团队。

## 基础练习（可信起点）：入门跟做

先在**仓库根目录**打开终端，完整运行：

```bash
python scripts/course.py start 18
python scripts/course.py run 18
```

第二条命令成功时，终端会提示概览已经写入`lesson-18/artifacts/starting_inventory.json`。打开这个文件；它只是数据起点，不是本课答案。若文件没有生成，先按后面的排错顺序处理，再继续。

### 第一步：读取规划输入

- **动作**：从仓库根运行`python scripts/course.py run 18`，读取名单、结果和成本概览；统计团队数、每队人数、随访与依从情况。
- **目的**：从前次实验提取合理的变异与实施范围，同时承认这些是估计值。
- **成功信号**：独立团队数与人员数分开；成本表中的固定、每人、每团队费用和预算单位明确。
- **反思**：把前次样本标准差当成精确常数，会忽略什么不确定性？

### 第二步：手算一个候选方案费用

- **动作**：任选团队数和每队人数，计算固定成本、人员成本和团队成本之和。
- **目的**：先排除预算上不可执行的方案。
- **成功信号**：费用不漏项，团队数和人数的乘法关系正确，能判断是否超过12000。
- **反思**：减少队内人数与减少团队数，哪一种对独立信息影响通常更大？

### 第三步：明确设计目标

- **动作**：写下3分钟为何是实际门槛、双侧或单侧检验、显著性水平，以及你更重视功效还是区间精度。
- **目的**：避免只套用“80%功效”而没有决策依据。
- **成功信号**：目标效应有分钟单位，检验方向与行动问题一致。
- **反思**：若区间仍可能包含业务上不可接受的伤害，高功效是否足以行动？

### 第四步：核对一条功效曲线的方向

- **动作**：用与计划分析相符的计算或模拟，比较较小、目标、较大效果；再把变异增大或依从性降低。
- **目的**：确认程序方向合理，再扩展候选设计。
- **成功信号**：其他条件相同，效果变大通常提高功效，变异增大通常降低功效；异常结果会被调查。
- **反思**：增加模拟次数会降低哪一种误差，又不会改变哪一种实际设计信息？

### 入门反思

写出一个预算内候选方案的独立团队数、总人数、费用、目标效应、变异假设和主要分析。少一个字段，功效数字就难以复核。

## 标准任务（本课应完成）

1. 从实际决策给出最小有实际意义的效应和精度要求，估计合理的变异与依从范围。
2. 比较至少一个预算内方案和一个超预算方案，报告功效、区间精度和总费用。
3. 使用与计划分析、团队随机结构相符的模拟或计算，报告显著性水平、方向、团队数和模拟误差。
4. 考察较小/目标/较大效果，以及变异或依从性恶化的情境。
5. 给出开展、改设计、追加预算或先试点的明确建议，说明新增信息来自哪里。

## 提高与拓展（提前完成后）

- 在固定预算下搜索团队数和队内人数的可行组合，展示成本与信息的前沿。
- 比较不调整与调整基线的计划分析，说明精度改善依赖的相关结构。
- 将前次方差估计的不确定性纳入设计，例如对多个合理标准差重复评估。
- 比较以功效达标和以区间宽度达标为目标时的推荐方案。

## 卡住时按顺序排查

1. 成本不对时逐项核对固定、每人和每团队费用。
2. 功效异常高时，检查是否把480个人误当480个独立随机化单位。
3. 模拟不稳定时，先固定种子并报告重复次数与蒙特卡洛误差。
4. 不同方案不可比时，确认真实效应、变异机制和分析方法一致。
5. 依从性情境无影响时，检查它是否实际进入观测效应或数据生成机制。
6. 不要用观察到的p值计算“事后功效”替代未来设计。
