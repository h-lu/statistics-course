# 第18课 · 预算允许的实验是否值得开展

下一轮实验预算12000。团队需要知道：若真正改善只有3分钟，现有资源能否给出足够有用的结论？你要提交“开展、改设计、追加预算或先做试点”的设计备忘录。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

已经计算出样本量，就能保证实验显著吗？先写出样本量计算依赖的一个未知量。

先阅读[知识准备](LEARN.md)。必要概念用于解释你的成果，计算和复杂实现可以交给工具。

## 可用材料

- [experiment_roster.csv](../data/experiments/experiment_roster.csv)
- [experiment_outcomes.csv](../data/experiments/experiment_outcomes.csv)
- [experiment_costs.csv](../data/experiments/experiment_costs.csv)

先读[数据字典与项目要求](../data/experiments/README.md)，核对观测单位、字段、分组/时间和已知局限。示例代码演示如何读取数据、计算简单的描述统计量。你需要继续完成本课分析，也可以改用其他可重现结果的程序。

## 分析任务

1. 从实际决策推导最小有实际意义的效应和精度要求，利用前次团队数据估计合理变异范围，并把依从性、团队大小与独立团队数分开。

2. 比较预算内及一条超出当前预算的方案的功效、区间精度和费用，必须使用与计划分析一致的模拟或计算。考察较小/目标/较大效果，以及变异或依从性恶化时表现。

3. 给出是否值得开展的建议：可以改区组/基线设计、增加独立团队、调整目标或承认现预算不足。说明修改增加的信息来自哪里，不用增加团队内重复行数假装增加随机化单位。

## 需要你作出的选择

效应阈值基于收益成本而非惯用小中大标签；可以优先精度而非80%功效，但须解释为什么结论仍可行动。设计改进必须在实施条件下可行。

报告显著性水平、单侧或双侧检验、主要效应目标、独立团队数、设计时采用的标准差，以及模拟次数和误差。不要用本次观察到的p值反算“事后功效”来替代下一轮实验设计。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

实验设计备忘录、功效/精度与成本对照、敏感性分析及可复现模拟。明确推荐方案和暂不能回答的问题。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。样本量设计采用的效应值和方差都不确定；功效是给定真实效应与机制下拒绝零假设的概率，不是研究成功概率或零假设为假的概率。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。

## 90分钟建议安排

| 时间 | 工作 |
|---|---|
| 0—5分钟 | 阅读项目背景，写下初步判断及理由 |
| 5—15分钟 | 阅读知识准备，核对小例子与必要概念 |
| 15—55分钟 | 完成主要分析或研究设计，比较替代方案，尽早写出报告草稿 |
| 55—68分钟 | 检查估计的不确定性、分析假设和适用范围，修订建议 |
| 68—75分钟 | 本地重跑、整理成果并提交 |
| 75—90分钟 | 知识自查、概念学习与变式反馈 |

遇到全班普遍存在的操作问题时，可适当调整时间。尽量在课堂完成；不以写代码行数、模型数量或耗满时间衡量成果。

## 运行与提交

从仓库根开始：

```bash
python scripts/course.py start 18
python scripts/course.py run 18
```

完成成果后，在`submission.json`填写支持报告结论的结果文件路径、运行入口并将状态改为`complete`，再运行：

```bash
python scripts/course.py check 18
```

按[课堂工作流](../docs/WORKFLOW.md)提交代码、报告与分析结果，本课最终标签为`v2-l18-final`。自动检查只确认文件和运行方式符合提交要求；分析是否合理，需要看报告中的方法说明和结果解释。

课末打开[知识自查](https://hblu.top/stat-check/)，确认页面为当日课次；可以先自己判断，再向AI询问概念并完成变式。参见[自查说明](../docs/KNOWLEDGE_CHECK.md)。
