# 第19课 · 大量发现中哪些可以对外发布

试用工具后记录了12项指标，业务方想挑出“有显著改善”的内容作发布。预先计划中有主指标、安全指标和探索指标。你需要制作完整的各指标分析结果表与发布规则，既不遗漏风险，也不把偶然发现包装成验证。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

12项指标各做一次5%检验，整份报告出现至少一个误报的机会仍是5%吗？先说明哪些假设检验需要共同控制错误率。

先打开[支持路线](SUPPORT.md)确认第一个动作和成功信号，再阅读[知识准备](LEARN.md)理解必要概念；计算和复杂实现可以交给工具。

## 学习路线与任务层级

前置回顾：[第16课](../lesson-16/README.md)中的实验效应、区间和实际门槛，以及[第18课](../lesson-18/README.md)中的第一类错误与功效。先按[支持路线](SUPPORT.md)建立可信起点，再用[知识准备](LEARN.md)解释结果。

### 基础练习（可信起点）

将12项指标与预先计划匹配，核对用途、单位、改善方向和实际门槛，并建立不遗漏任何指标的结果表。此层只建立分析起点，**不能冒充本课完成**。

### 标准任务（本课应完成）

完成下方三项分析任务：预先定义检验族，保留团队结构估计全部指标，分别采用合适的族错误率或错误发现率控制，并形成验证、安全、探索和后续验证清单。

### 提高与拓展（提前完成后）

比较不同校正方法在既定检验族中的后果，审查指标相关性的适用条件，或为安全指标建立预先的可接受伤害界值。提高任务应改变统计判断，不能只增加代码、模型或图表数量。

## 分析任务

1. 读预先指标计划，定义主要验证、安全约束和探索性发现各自的问题及检验族。核对指标单位、方向和实际重要门槛，按团队结构估计效果与不确定性。

2. 把原始结果与适合目的的多重比较控制并列，说明控制族错误率（family-wise error rate，FWER）或错误发现率（false discovery rate，FDR）分别意味着什么。比较规则改变了哪些可发布分析结论；不只列校正后的p值。

3. 完成包含所有指标的清单：改善、可能伤害、不确定和待验证，并说明有统计证据但实际很小、方向不利、或探索性结果该如何表达。制定后续验证而非从同一数据反复挑选规则。

## 需要你作出的选择

可对验证性假设使用Holm等FWER控制、对探索使用合适FDR；检验族根据发布用途事先定义。方法和检验族不能在看哪一种保留更多亮点后才决定。

明确每次多重检验校正包含哪些假设。分析仍需考虑团队随机分配造成的组内相关。报告每项结果的效应方向、区间、实际阈值，以及它属于主要、安全性还是探索性指标。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

完整的各指标分析结果表，包括每项效应、区间、原始p值及校正结果、分析报告与后续验证计划；保留无显著结果和不利指标。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。FDR不是每条被挑中结论为假的概率；未显著不证明安全或等同。检验族的定义或错误率控制方法不同，允许作出的检验结论也可能不同；应事先说明选择依据，不能按显著结果多少来切换。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。
