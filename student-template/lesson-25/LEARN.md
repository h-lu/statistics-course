# 第25课知识准备 · 预测性能与模型维护成本

## 本课要解决的问题

比较简单模型、复杂模型，以及关键输入缺失时可用的备用模型。分别报告预测误差和维护成本，并说明条件变化时如何调整选择。可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 偏差—方差权衡 | 更灵活可能降低系统误差，也可能更依赖样本细节。 | 解释复杂度取舍 |
| 正则化 | 对参数规模等施加约束，通常以部分偏差换稳定性。 | 比较开发表现 |
| 特征稳定性 | 样本或条件变化后特征贡献是否稳定；不等于真实因果重要性。 | 决定解释与维护范围 |
| 泛化误差 | 面对目标新记录的预测误差，不能用训练误差代替。 | 报告验证结果 |
| 降级与可用性 | 关键输入不可用时采用预定义可运行替代方案。 | 提出持续使用规则 |

岭回归最小化Σ(y−ŷ)²+λΣβ²（截距通常不惩罚）。λ越大通常收缩越强，但数值依赖特征尺度。变量尺度标准化所用的均值、标准差等参数也必须仅由训练资料确定；系数变小不等于该变量在现实中不重要。

式中y为实际结果、ŷ为模型预测；第一个Σ对训练记录求和，第二个Σ对非截距的输入系数求和。β为各输入系数，λ为惩罚强度。平方误差的单位是结果单位的平方，惩罚的数值含义与输入尺度和实现约定有关。

## 先思考，再看例子

模型甲的验证平均绝对误差（MAE）为5分钟，每条需0.5成本；模型乙的MAE为5.5分钟、无新增采集成本。不能仅说甲更好，也不能把5与0.5直接相加：只有使用者说明误差怎样转化为损失，才有共同比较尺度。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

检查正则化强弱、训练范围变化或相关变量取舍如何影响验证误差及关键特征稳定性。重复试验只用开发资料，不能把重复使用的16—19月当新的独立确认。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

验证集最优是当前开发情境中的结果。成本转换、未来字段可用性与目标范围改变，可能使排名改变。

## 学习自查

进入项目后应能解释：

1. 训练误差更低，为什么未来误差仍可能更高？
2. 正则化解决什么问题，为什么需要注意特征尺度？
3. 一个特征的系数随窗口变号时，应如何限制解释？
4. 为何候选方案必须在相同目标记录与指标上比较？
5. 关键字段缺失时，备用程序会怎样改变误差和维护成本？

## 进一步学习

可按需使用岭回归、套索、树或集成方法，比较它们解决的非线性、方差或维护问题。新增依赖需写明；低维护成本的替代方案必须在缺少相应字段时真的能够运行。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
