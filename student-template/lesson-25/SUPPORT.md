# 第25课陪做支持 · 预测性能与模型维护成本

这份材料帮助你在不知道下一步时建立可信起点。它不提供本课正式数据的答案，也不能代替 [README 主任务](README.md)；概念的完整解释见 [LEARN.md](LEARN.md)。

## 先知道今天要交出什么

- `report.md`：分别呈现预测误差、维护成本和采纳条件。
- 正常方案与关键字段缺失时都可运行的分析入口。
- `submission.json`：列出性能比较和备用方案结果。

最低出口是：别人能够按你的命令重新生成报告引用的数字，并知道这些数字可以和不可以用于什么决定。

## 核心概念与原理

| 规范术语 | 通俗解释 | 怎样在自己的结果中检查 |
|---|---|---|
| 平均绝对误差 | 预测与实际时长差的绝对值平均，单位仍是分钟。 | 在同一验证记录上比较方案。 |
| 泛化误差 | 模型面对目标新记录时的误差。 | 使用验证资料而不是训练误差作主要比较。 |
| 正则化 | 约束模型参数，以部分拟合偏差换取稳定性。 | 检查复杂模型对样本细节的依赖。 |
| 特征稳定性 | 输入贡献在训练窗口或设定改变后是否稳定；不代表因果重要性。 | 限制解释和维护承诺。 |
| 降级方案 | 关键字段缺失或越界时使用预先验证的替代流程。 | 保证系统故障时仍有明确行动。 |

### 先用一个小例子想清楚

模型甲的平均绝对误差为5分钟，每条记录需0.5个维护成本单位；模型乙为5.5分钟，新增维护成本为0。分钟与成本单位不能直接相加。应先分别报告，再由使用者说明0.5分钟改善是否值得该维护投入。

这个例子只用于核对概念，不是正式数据的结论。正式项目必须使用自己的运行结果。

## 基础练习（可信起点）：入门跟做

以下命令都从仓库根目录运行，也就是同时能看到 `scripts/`、`data/` 和 `lesson-25/` 的目录。

```bash
python scripts/course.py start 25
python scripts/course.py run 25
```

第二条命令成功后，应看到终端提示结果已经生成，并能打开 `lesson-25/artifacts/starting_summary.json`。这个文件只是数据起点，不是本课完整答案。

若终端明确提示 `python: command not found`，按仓库首页说明，把上面两行开头的 `python` 换成 `python3`，其余内容不变。

### 第1步：统一比较条件

- **动作：** 运行起点程序，固定月0—11开发、12—15验证和同一批有结果的记录。
- **目的：** 只有目标记录与指标相同，性能差异才可比较。
- **成功信号：** 每个模型的验证记录数和指标单位一致。
- **想一想：** 某模型因缺失删除更多记录，还能直接比较误差吗？

### 第2步：建立基线与改进模型

- **动作：** 先运行简单基线，再增加能解决非线性、相关输入或方差问题的结构。
- **目的：** 复杂度需要对应实际统计问题。
- **成功信号：** 结果表说明每个模型增加了什么、验证误差怎样变化。
- **想一想：** 改善来自真正泛化，还是更多拟合自由度？

### 第3步：分开记录性能与成本

- **动作：** 计算平均绝对误差并另列 `workload` 的0.5单位维护成本。
- **目的：** 不同单位不能在没有换算依据时直接求和。
- **成功信号：** 报告有并列的“分钟误差”和“成本单位”列。
- **想一想：** 多大误差改善才值得维护，由谁决定？

### 第4步：实际运行备用方案

- **动作：** 制造 `workload` 不可用的输入，运行不依赖它的备用模型并比较误差。
- **目的：** “可以降级”必须由可运行程序和结果支持。
- **成功信号：** 备用入口成功输出预测，且报告触发条件和后果。
- **想一想：** 字段缺失时应继续、人工复核还是暂停？

完成这四步后，你已经有可信起点，但还没有完成整项主任务。

## 标准任务（本课应完成）

回到 [README](README.md) 完成全部标准任务，特别核对：

- 比较简单、改进和低维护方案。
- 检查正则化、训练范围或相关变量取舍的稳定性。
- 模拟关键输入缺失并运行备用流程。
- 分别报告性能和成本，给出采纳与降级规则。

把程序输出翻译成完整统计句子：对象是谁，比较什么，数值和单位是什么，哪些假设成立时可以怎样使用，哪些结论仍不能作出。

## 提高与拓展（提前完成后）

先完成标准任务，再选一项。提高的标准是让证据、适用范围或行动更可靠，而不是增加代码或图表数量。

- 寻找性能改善值得维护投入的情境边界。
- 模拟输入越界和多个字段缺失。
- 比较不同训练窗口下关键特征与误差。

## 卡住时按顺序排查

- **备用模型仍报缺少 `workload`：** 检查预处理、特征列表和公式是否仍间接引用该字段。
- **命令提示找不到文件：** 先运行 `pwd`，确认当前位置是仓库根目录；这里应同时看见 `scripts/` 和本课目录。
- **程序能运行但结果还是旧的：** 检查结果文件的修改时间，确认修改并运行的是本课 `analysis.py`；必要时删除自己生成的旧结果后重跑，但不要删除原始数据。
- **报告数字和程序输出不一致：** 从报告中的一个关键数字反向找到结果文件、筛选范围、分子和分母；不要手工把报告改成“看起来合理”的数字。
- **不知道怎样开始写报告：** 先写五句：谁使用、要决定什么、数据覆盖谁、一个主要结果、一个不能支持的结论，再补方法和证据。
