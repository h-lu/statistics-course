# 在项目中使用AI

你可以让AI阅读完整仓库、编写与运行代码、选择候选方法、制作图表、起草报告，以及在你授权后使用已登录的Git提交。课程不要求逐行手写，也不收完整聊天记录。

建议向AI提供项目背景、分析任务、数据字典和实际条件，让它解释不同方案可能得到的结果。你可以追问：这个比例的分母是什么？这项结论依赖哪些假设？改变样本范围或指标定义后，结果会怎样？目前还缺少哪些支持这项建议的依据？

提交前核对结论与分析结果，删除没有依据的说法，说明分析的适用范围和局限性。不要把合成数据的分析结果写成现实学校、企业或个人的事实。课程资料使用规范统计术语，AI的解释与资料不一致时，可以继续追问或向教师核对。

密码、访问令牌、SSH私钥、验证码、他人的私有数据和未经授权的个人信息不能交给AI或写进仓库。让AI使用已登录的本地工具，不在聊天中发送凭据。提交前查看`git diff --cached`。
