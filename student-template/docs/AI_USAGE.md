# 在项目中使用AI

你可以让AI阅读本课文件、解释术语、编写和运行代码、比较候选方法、制作图表和起草报告。课程不要求逐行手写代码，也不要求提交完整聊天记录。

为了得到有用的帮助，先给AI：本课README、数据说明、你的问题、运行命令和实际报错。可以追问：

- 这个指标的观测单位和分母是什么？
- 这段代码保留或排除了哪些记录？
- 如果换一种合理口径，结果可能怎样变化？
- 这个结论能支持什么，不能支持什么？

AI给出的代码和数字必须实际运行并核对。提交前删除没有依据的说法，区分观察事实、可能解释和下一步行动。不要把教学合成数据写成现实学校、企业或个人的事实。

不要把密码、访问令牌、SSH私钥、验证码、他人的私有数据或未经授权的个人信息交给AI，也不要写进仓库。提交前查看 `git diff --cached`。
