# 每课支持路线说明

如果你打开某一课的 README 后仍不知道第一步做什么，请打开同一目录中的 `SUPPORT.md`。它把一课拆成可以逐项完成的小步骤，并提供三种完成层次：

- **入门跟做**：先运行示例、核对一条记录、完成一个最小问题和报告。适合第一次接触数据分析、终端或统计术语的同学。
- **标准完成**：在入门基础上，比较一个合理的替代口径，补齐分母、单位、缺失和使用边界。这是完整项目的默认目标。
- **提高与拓展**：选择方法、稳健性、复现或决策方向中的一项深入，不要求堆叠代码或模型。

支持文件中的示例数字只用于核对操作。最终报告必须使用你自己的运行结果，并说明结果能支持什么、不能支持什么。遇到错误时先保存命令和报错，再按“卡住时按这个顺序排查”逐项处理。
