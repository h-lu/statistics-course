# 第1–8课支持路线

当前学习材料为第1–8课。第9–32课尚未制作新课包；其目录只用于表示课程安排，运行和提交工具只处理第1–8课。

先打开本课 `README.md`，了解问题、成果与三层任务；可按需要选择同目录SUPPORT的起点/检查提示，熟悉者直接自主分析。遇到概念时按需阅读 `LEARN.md` 的解释与手算例子，最后回到 README 完成标准任务。

- **基础练习（可信起点）**：从一个小问题、一条记录或手算关系开始，写出预计，运行并核对成功信号。
- **标准任务（本课应完成）**：完成 README 的实质分析，说明分析单位、数据范围、分母、单位、缺失处理与结论依据；比较有理由的替代方案。
- **提高与拓展（提前完成后）**：深入方法取舍、敏感性、反向追踪、复现检查或决策后果；不以重复操作或图表数量增加难度。

示例数字用于检查操作，不能替代自己的正式结果。出现问题时记录命令与报错，按 SUPPORT 的排错顺序处理。每课提交前核对 `submission.json`、报告路径与结果文件；工具检查通过后仍需审核统计解释。
