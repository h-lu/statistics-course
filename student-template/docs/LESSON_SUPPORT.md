# 第1–8课支持路线

当前学习材料为第1–8课。第9–32课尚未制作新课包；其目录只用于表示课程安排，运行和提交工具只处理第1–8课。

先打开本课 `README.md`，了解分析问题、成果要求和三层任务，再自主安排分析。遇到困难时，可选择同目录 `SUPPORT.md` 中的提示；遇到不熟悉的概念，可查阅 `LEARN.md` 的解释与手算例子。提交前回到 `README.md`，核对标准任务。

- **基础练习（可信起点）**：可从一个小问题、一条记录或手算例子开始，尝试判断，再运行并核对结果。
- **标准任务（本课应完成）**：完成 README 的实质分析，说明分析单位、数据范围、分母、单位、缺失处理与结论依据；比较有理由的替代方案。
- **提高与拓展（提前完成后）**：可比较不同方法或假设，查看结果是否稳定；也可从异常结果查回原始记录、检查结果能否重现，或分析建议的后果。重点是形成新的统计判断。

示例数字用于检查操作，不能替代自己的正式结果。出现问题时记录命令与报错，按 SUPPORT 的排错顺序处理。每课提交前核对 `submission.json`、报告路径与结果文件；工具检查通过后仍需审核统计解释。
