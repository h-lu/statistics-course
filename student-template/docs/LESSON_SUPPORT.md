# 每课支持路线

打开某一课后，先看同目录的 `README.md`，了解基础练习、标准任务和提高拓展的边界。然后打开同目录的 `SUPPORT.md`；每课都有这份逐步支持，会说明第一个动作、命令、成功信号、结果核对和排错顺序。再看 `LEARN.md`，把术语和小例子弄懂。

基础练习只是可信起点，完成后还要继续做 README 中的标准任务。提前完成标准任务时，再从“提高与拓展”中选一项；它会要求你检查替代方法、敏感性、复现性或决策后果，不是单纯多画几张图。

每份支持路线分三层：

- **基础练习（可信起点）**：完成一个最小问题，核对一条记录或一个计算，获得可核对的起点；
- **标准任务（本课应完成）**：完成 README 的全部主任务，比较合理的替代方案，说明分母、单位、缺失和适用范围；
- **提高与拓展（提前完成后）**：完成主任务后，选择方法比较、敏感性分析、复现检查或决策说明。

示例数字只用于检查操作，不能直接当作自己的结果。遇到错误时先保存命令和报错，再按支持路线的排障顺序处理。
