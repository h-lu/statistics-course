# 每课支持路线

打开某一课后，先看同目录的 `README.md`。如果不知道第一步，打开同目录的 `SUPPORT.md`；它会说明概念、命令、结果文件和反思问题。再看 `LEARN.md`，把术语和小例子弄懂。

每份支持路线分三层：

- **入门跟做**：完成一个最小问题，核对一条记录或一个计算，并留下最小报告；
- **标准完成**：完成 README 的全部任务，比较合理的替代方案，说明分母、单位、缺失和适用范围；
- **提高与拓展**：完成主任务后，选择方法比较、敏感性分析、复现检查或决策说明。

示例数字只用于检查操作，不能直接当作自己的结果。遇到错误时先保存命令和报错，再按支持路线的排障顺序处理。
