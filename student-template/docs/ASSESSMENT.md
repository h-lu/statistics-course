# 成果与评分

课程总成绩由平时成绩和期末考试组成，各占50%。平时评价分析报告和相关成果，允许全程使用AI；不按代码行数、模型数量、提示词数量或AI使用比例评分。

## 课堂完成：25分

第1、2课是入门项目，需要完成但不计分。第3—32课分为五组：第3—8、9—14、15—20、21—26、27—32。每组六次项目取最好五次，每项最高1分。分值是：项目：0.8分；完成A题：0.1分；完成学习和B题：0.1分。当堂提交时，项目部分可得全部的0.8分。

项目在下一次课开始前补齐时，项目部分最高0.5分；已经获得的自查分保留。网络或统一环境故障按课堂说明处理。

完成项目意味着回答当课主要问题，报告有分析依据，程序能够重新生成结果。只有空报告、默认示例输出或文件列表不算完成。

第1—8课重点是建立描述数据、核对结果和说清适用范围的基本功。不表示前8课每份报告都必须加入置信区间或显著性检验；但结果核对仍须完成。

## 代表作品：25分

每组选择一件代表作，每件5分，分为五项：问题与用途、数据与方法、分析依据与不确定性、建议与适用范围、可复现性与表达，每项最高1分。简单方法只要依据扎实，也可以得到好评价；复杂模型或漂亮界面不能替代证据。

有依据地暂不发布误导性排名、限制使用或拒绝作决定，也是合理成果。代表作可按规定修订一次，保留原版本并在报告中说明改动和依据。
