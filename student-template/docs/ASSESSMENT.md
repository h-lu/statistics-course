# 成果与评分

平时成绩占课程总成绩50%，期末考试占50%。平时成绩评价你提交的分析报告及相关成果，允许全程使用AI，不按代码行数、模型数量、AI使用比例或提示词数量评分。

## 课堂完成：25分

第1、2课是入门项目，不计分，但需要完成。之后分五组：第3—8、9—14、15—20、21—26、27—32课；每组六次取最好五次，每次最高1分。

- 当堂完成并提交项目：0.8分。
- 当堂完成知识自查A：0.1分。
- 当堂完成概念学习与B：0.1分。

项目在下一次课开始前补齐，项目部分为0.5分；已获得的当堂自查分保留，合计最高0.7分。更晚仍可修订学习，但不再获得这次项目完成分。自查正确率与信心不直接计分。网络或统一环境故障按课堂说明处理。

完成项目意味着回答了当课的主要问题，报告有分析依据，程序能够重新生成结果；只有空报告、示例程序的默认输出或完整的文件列表，并不算完成项目。

## 代表作品：25分

每组选一件代表作，每件5分，评价：问题与用途、数据与方法、分析依据与不确定性、建议与适用范围、可复现性与表达。每项最高1分。

评价依据相应课次的任务。“分析依据与不确定性”不表示前8课每份报告都必须加入置信区间或显著性检验；本阶段重点是说明数据局限、分析选择和假设怎样影响结论。所要求的替代方案、敏感性分析和结果核对仍须完成。

优秀作品可能采用简单方法，但对关键选择有扎实依据；复杂模型或漂亮界面不能替代有效证据。有依据地暂不作决定、拒绝发布误导性排名，也是合理成果。

每组结束后可以修订代表作一次，保留原版本，在报告末说明改动和依据。截止下一次课开始前；最后一组截止课程结束后7个自然日，如因学校成绩提交安排调整，将提前公告。修订不改变原版本的按时完成分。
