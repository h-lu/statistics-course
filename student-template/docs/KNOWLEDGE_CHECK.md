# 课末知识自查

每课最后约15分钟打开[知识自查](https://hblu.top/stat-check/)，用Gitea账号登录，确认页面课次与当天相符。

1. **A：约5分钟。** 回答5道基本概念题，标记确定、不太确定或猜测。建议先留下自己的判断，AI可以使用。
2. **学习：约4分钟。** 选择不确定的概念，向AI询问解释、不同情境的例子或反例。
3. **B：约5分钟。** 在新情境中再次判断同类概念。
4. **反馈。** 查看两次判断和解释，留意下次项目还会用到的知识。

可以这样问AI：“请解释这个概念，用不同情境举例，再问我一个问题，先不要直接给答案。”这是学习建议，不是技术限制。系统不检测AI，也不会因为直接代答处罚；你需要考虑这种使用方式是否帮助自己学习。

首次提交会锁定，教师切换阶段时页面自动更新。按时完成A、学习和B获得自查完成分，正确率和信心只用于反馈。一次答对不表示已经稳定掌握，后续课程会用新例子复习。
