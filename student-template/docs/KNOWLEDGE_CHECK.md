# 课末知识自查

每课最后约15分钟打开[知识自查](https://hblu.top/stat-check/)，用Gitea账号登录，并确认页面显示的是当天课次。

1. **A题，约5分钟**：回答5道基础概念题，并标记自己是确定、不太确定还是猜测；
2. **学习，约4分钟**：选择不确定的概念，让AI换一个情境解释、举例或出一道小题；
3. **B题，约5分钟**：在新情境中重新判断同类概念；
4. **反馈**：比较两次判断，记录下次项目还要注意的概念。

可以问AI：“请先解释这个概念，再用不同情境举例，最后问我一道题，先不要直接给答案。”系统不检测AI使用，也不会因直接代答处罚；但直接代答可能减少练习效果。

提交后该题会锁定，不能返回修改。提交前先检查课次、答案和把握程度；如果页面没有进入正确阶段，不要反复提交，联系教师处理。第1、2课完成自查但不计分；从第3课起，完成A、学习和B获得相应完成分，正确率和信心只用于反馈。
