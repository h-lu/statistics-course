# 按需查阅

不需要逐一读完。遇到不明白的概念时，先看本课 `LEARN.md`，再挑相关章节；也可以让 AI 帮你解释其中的例子。

- [OpenIntro Statistics](https://www.openintro.org/book/os/)：基础统计的开放教材入口，适合补查抽样、区间估计、实验与回归。
- [NIST：探索性数据分析](https://itl.nist.gov/div898/handbook/eda/eda.htm)：从分析问题、图形到方法假设的查阅目录，适合前期数据项目。
- [scikit-learn：常见问题与建议](https://scikit-learn.org/stable/common_pitfalls.html)：模型项目中的预处理一致性、训练与测试分离、信息泄漏。软件可以由 AI 操作，但这些概念决定评估结果能否用于新数据。

以上为英文资料，可借助翻译阅读。本课没有指定必须购买的教材或付费工具。
