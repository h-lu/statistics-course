# 按需查阅的资料

不需要一次读完。先看本课 `LEARN.md` 和 `data/` 中的数据说明，再按问题查阅：

- [OpenIntro Statistics](https://www.openintro.org/book/os/)：抽样、区间估计、实验和回归等基础内容；
- [NIST探索性数据分析](https://itl.nist.gov/div898/handbook/eda/eda.htm)：从问题、图形到方法假设；
- [scikit-learn常见问题](https://scikit-learn.org/stable/common_pitfalls.html)：预处理一致性、训练测试分离和信息泄漏。

这些资料主要是英文，可以借助翻译或AI阅读。不要求购买教材或使用付费工具。
