# 环境与排障

先确认版本和目录：

```bash
python --version
git --version
git status
```

所有课程命令从仓库根目录运行；电脑使用 `python3` 时替换命令名称。课程工具和示例优先使用Python标准库；某课需要第三方库时，按该课说明安装并把依赖写进 `requirements.txt`，不要提交 `.venv`。

| 问题 | 先做什么 |
|---|---|
| 提示不是Git仓库 | `cd` 到刚克隆的私有仓库，再运行 `git status` |
| 找不到文件 | 确认当前目录能看到 `scripts`、`data` 和课次目录 |
| 找不到Python包 | 确认安装包和运行脚本使用的是同一个Python |
| 中文乱码 | 按UTF-8读取CSV；带BOM的文件可使用 `utf-8-sig` |
| 数字和示例不同 | 查数据范围、筛选条件、缺失值、分母和输出目录，不手改结果 |
| `check`失败 | 按提示补齐 `submission.json`、报告和结果路径；它不判断结论 |
| Git推送失败 | 检查自己私有仓库地址、权限和SSH登录；不要把密码贴给AI |
| 标签已存在 | 不覆盖旧标签，改用新的revision标签 |
| 网络或自动检查排队 | 保存文件和本地commit，向教师说明，不重复建仓库 |

向AI求助可以提供操作系统、Python版本、命令和完整报错，但不要提供密码、令牌、私钥或私人数据。
