# 第9—14课如何接起来

这是一张查阅地图，不是新增作业或统一操作步骤。

|课次|已有基础|本课新问题|留给下一步的问题|
|---|---|---|---|
|9|第8课观测单位与分母|阳性中有多少真故障？条件方向不同|有多少复核需求，会怎样波动？|
|10|条件概率与按概率加权|已知日需求分布时怎样订容量|模型中的概率或需求依据从哪里来？|
|11|描述、比较与数据取得|谁被联系、谁回答，能代表谁|即便取得机制合适，换样本会怎样？|
|12|总体、样本与加权|抽样分布、SE、偏差与MSE|只有一次样本，怎样表达不确定性？|
|13|抽样波动与正态近似|区间方法的覆盖、宽度与决策|预算有限，下一次应怎样抽？|
|14|权重、SE与不确定性|分层设计、费用与总体/小组精度取舍|形成可执行调查建议，保留无回答边界|

第9、10课的设备概率模型，与第11—14课的4000人名册不是同一数据。日请求次数与人的0/1需求比例不能互换。第11—14课沿用同一合成总体，但第11课观察取得机制，第12—14课常用完整回答作理想基准；这种简化必须显式声明，不意味着现实无回答问题已被解决。
