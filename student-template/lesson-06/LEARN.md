# 第6课知识准备 · 业务构成不同，怎样比较办结比例

一个中心承接的复杂业务较多，合并办结比例可能较低，即使它在同类业务中表现并不差。本课学习把业务构成与同类业务中的结果分开来看。

## 1. 先看一张计数表

下表是另设的例子。“办结数/工单数”中的分母包括该类业务的全部登记工单。

| 中心 | 常规业务：办结数/工单数 | 复杂业务：办结数/工单数 |
|---|---:|---:|
| A | 18/20 | 48/80 |
| B | 64/80 | 10/20 |

把两类业务合在一起计算，得到**合并比例（也称边际比例）**。A为(18＋48)÷(20＋80)＝66%；B为(64＋10)÷(80＋20)＝74%。合并时要合计分子和分母，不能直接平均两个百分比。

## 2. 在同类业务中比较

**分层比较**是按业务类型等特征分组，再在每组内部比较。每组也称一层；该层办结数除以该层工单数，就是分层办结比例。

A在常规、复杂业务中的比例分别为90%、60%；B分别为80%、50%。A在两类业务中都高于B，合并后却较低。这种合并方向与各层方向相反的现象称为**辛普森悖论**。

这里应先看构成：A的复杂业务占80%，B只占20%。两中心承接的业务组合不同，所以合并结果与分层结果可以同时算对，却回答不同问题。

## 3. 用共同权重进行直接标准化

**权重**表示各部分在加权计算中所占的份额。**直接标准化**是用同一组目标人群或业务构成权重，对各中心的分层比例加权。这样比较时，所用业务构成相同。

假定常规、复杂业务各占50%，则A的标准化比例为0.5×90%＋0.5×60%＝75%，B为65%。若另设计划让复杂业务占75%，常规占25%，则A为67.5%，B为57.5%。后一计划是教学情境，不是原数据事实。

所有中心必须采用同一组权重，权重均不小于0且合计为1。只改变A的权重而让B继续使用自身构成，不是共同标准下的比较。标准化结果也不能用来改写实际办结数：A原来的实际办结比例仍是66%。

## 4. 改变共同构成后，方向会不会变

本例A在两层都比B高10个百分点。因此，无论共同构成中两类业务各占多少，加权后的差异仍为10个百分点。这是方向稳定的结果，不必为了做敏感性分析而制造反转。

百分点是两个百分比相减的单位。75%比65%高10个百分点，不是相对增加10%。结论稳定只针对这里的分层结果和共同权重，不能据此保证未来时期也一样。

## 5. 没有记录的业务层怎样处理

某中心没有承接某类业务时，该层比例没有分母，不能记为0或100%。若目标构成给这一层正权重，就不能直接根据现有数据计算完整的标准化比例。

可以限制到各中心都有资料的业务类型，并说明结论只适用于这些业务。不能让每个中心各删不同的缺失层，再声称使用了相同构成。计算应使用原始计数，最后显示时再四舍五入。

## 在项目中使用

并列展示实际合并比例、分层比例和共同构成下的结果。至少比较当前整体构成与另一个有明确用途的共同构成，再决定是否发布排名或改用分层表。

标准化只调整了已分层的业务构成。业务内部的难度、人员配置等仍可能不同，所以它不直接证明调人或改变管理办法会产生相同效果。

## 按需阅读：把共同权重写成公式

令w为共同构成中复杂业务的比例，则常规比例为1−w，0≤w≤1。本例：

`A的标准化比例＝(1−w)×0.9＋w×0.6`；

`B的标准化比例＝(1−w)×0.8＋w×0.5`。

两式相减为0.1，即10个百分点。其他数据不一定有相同结果：若各层差异方向不同，共同权重改变时比较方向可能变化，可以借助表格、图或计算查看。

```python
# learning-example
import json
counts = {"A": [(18, 20), (48, 80)], "B": [(64, 80), (10, 20)]}
rates = {c: [s/n for s, n in cells] for c, cells in counts.items()}
def standard(w):
    return {c: (1-w)*r[0]+w*r[1] for c, r in rates.items()}
result = {"actual": {c: sum(s for s,n in cells)/sum(n for s,n in cells) for c,cells in counts.items()},
          "w50": standard(.5), "w75": standard(.75),
          "endpoint_differences": [standard(w)["A"]-standard(w)["B"] for w in (0, 1)]}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
