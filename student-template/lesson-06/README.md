# 第6课 · 业务构成不同的机构应如何比较

## 项目背景

一个合作部门准备按当日办结率发布三个中心排名。但各中心承接复杂业务的比例不同；排名可能反映业务构成，也可能反映同类业务中的差异。你受托审核排名是否值得发布，并提供可被公众理解的替代呈现。

## 可用数据

使用第一期 `data/service/tickets.csv`、`windows.csv` 和 `business_types.csv`。以工单为分析单位，默认办结状态是0/1；可以提出有依据的其他范围。[数据说明](../data/service/README.md)。

本课数据均为教学合成数据，不代表真实机构。先阅读[知识准备](LEARN.md)，再选择分析方法。你可以全程使用AI完成代码、分析和写作；报告需解释主要结论的统计依据、适用条件和局限性。

## 分析任务

分别计算合并结果、同类业务内的结果及共同业务构成下的结果，研究比较结论随目标业务构成变化的稳定性。决定是否发布排名、附加适用条件或只呈现分层结果，并清楚说明这些结果能回答什么问题。

### 必须遵守的约束

- 比例必须使用对应工单分母，不能把各组百分比不加权平均成合并比例。
- 共同权重用于所有中心；说明权重代表实际总体、计划业务构成，还是假设场景。
- 至少比较当前整体构成与另一个有明确使用含义的共同构成；可用完整权重曲线更直观地表达稳定范围。
- 某层缺少数据时不能凭空填写率，需限制比较范围或明确估计假设。
- 即使标准化后某中心表现更好，也不能据此认定调人或改名会造成相同效果。

### 由你决定

你决定比较面向现有业务还是计划人群、哪些差异值得强调、是否有必要给出单一顺序。拒绝简单排名也是有效成果，但必须用完整比较说明替代信息为何更有用。

## 成果要求

- 读者能复核各中心总量、分层分母、分层比例、业务构成和共同权重结果。
- 说明合并与分层方向是否不同，不能只贴“辛普森悖论”标签。
- 给出排名或差异随权重变化的结果，并解释其适用人群。
- 发布文案区分当前业务结果、同构成比较和因果评价。

在本目录的 `report.md` 中撰写分析报告，篇幅与结构可按问题需要调整。关键表、图或分析数据保存到 `artifacts/`，并在报告中引用。可以修改或替换 `analysis.py`；提供的示例代码只生成数据概览，不是本课的完整分析。
