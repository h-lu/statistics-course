# 第6课支持路线：业务构成不同，怎样公平比较中心

## 先做一个小判断

如果中心A承接的复杂业务更多，直接比较办结比例是否公平？先写下你认为应该保留哪些分层信息。

## 这课的概念和原理

- **边际比例（合并比例）**把所有业务合在一起，受各中心业务构成影响；
- **条件/分层比例**在相同业务类别内比较；
- **直接标准化**用同一组目标业务构成权重重新加权，得到可比的假设结果；它不是把变量变成均值为0；
- **辛普森悖论**指合并方向与各层方向相反，必须先核算分层和权重再讨论。

标准化结果不是中心真实发生的办结比例，而是“如果各中心面对同一业务构成”的比较。

## 入门跟做

### 1. 列出分层表

运行：

```bash
python scripts/course.py start 06
python scripts/course.py run 06
```

查看 `counts`：`n` 是登记工单数，`completed` 是其中当日办结数。先计算每个中心、每种业务的 `completed/n`，再计算合并比例，不能简单平均各组百分比。

### 2. 手算权重

假设目标构成为复杂业务40%、常规业务60%，中心A复杂业务办结率80%、常规业务90%，标准化结果是 `0.4×0.8+0.6×0.9=86%`。这不是A实际的合并比例，而是共同构成下的估计。

### 3. 比较两种目标构成

至少使用当前全体业务构成和一个有用途的共同构成，例如计划构成或情境假设。列出权重、各中心标准化结果和百分点差异。改变权重时只报告实际检查过的范围。

### 4. 写发布建议

分别说明实际办结情况、同类业务比较、标准化比较和局限。可以拒绝单一排名，但不能省略计算。

## 反思与提高

反思：标准化结果改变了中心实际办结数吗？如果某中心没有某一业务层，能否直接填0或复制其他中心？提高任务可画权重变化图，说明排名何时稳定或改变。

## 卡住和提交

先检查每层分母和共同权重是否合计1；不要把百分比直接平均或把标准化结果写成真实比例。提交前运行 `check 06`。
