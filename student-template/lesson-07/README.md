# 第7课 · 满意度调查的覆盖与无回答问题

## 项目背景

服务中心准备公布满意度。一部分工单未被邀请参加调查，另一些受邀工单没有提供评价。负责人问：“已有评价大多满意，能否据此判断全部办事经历都令人满意？”你需要区分调查覆盖与无回答问题，说明全体满意度可以估计到什么程度。

## 可用数据

用 `data/service/tickets.csv` 与 `satisfaction.csv` 按 `ticket_id` 连接，限定第一期3,600张工单。调查表覆盖两期，不能把全部4,800条作为第一期分母。按需连接窗口、业务字典。[数据说明](../data/service/README.md)。

本课数据均为教学合成数据，不代表真实机构。先阅读[知识准备](LEARN.md)，再选择分析方法。你可以全程使用AI完成代码、分析和写作；报告需解释主要结论的统计依据、适用条件和局限性。

## 分析任务

为满意度报告提出分析与发布建议：先统计邀请和回答情况，检查办理经历与能否取得评价之间的关系；再对缺失评价作出至少两种有实际差别的假设，估计全体满意比例或其可能范围，并提出应优先补充调查的人群及理由。

### 必须遵守的约束

- 明确满意定义、目标对象和时间范围；评分1—5是有序评价，空白不是0分。
- 区分未被邀请与受邀后无回答，说明邀请率、受邀者回答率和全体评价覆盖比例各自的分母。
- 完整案例、分组调整、插补和上下界都依赖不同信息或假设，应写清哪些是观测到的、哪些是假设。
- 可见变量相近不能证明没有取得的评价相同；不能仅因检验不显著就认定完全随机缺失。
- 如估计范围很宽，给出诚实范围和补充调查优先级，不能为获得一个数随意缩窄。

### 由你决定

你可以重点报告满意比例，也可以展示完整评分分布。可使用极端上下界、对缺失评价设定不同满意比例的情景分析，或有依据的分组调整。分析应回答这样的问题：“没有取得评价的工单，其满意比例低到什么程度时，会改变发布建议？”也可以提出同样具有实际意义的其他问题。

## 成果要求

- 报告邀请率、受邀者回答率、全部工单中有评价的比例，以及已回答工单的满意度；说明这些结果各自描述谁。
- 展示缺失评价假设与最终结论的对应，关键上下界或情景结果能重新计算。
- 发布建议中明确哪些结论不依赖强假设，哪些仅在指定假设下成立。
- 补充调查计划具体到目标人群、希望消除的不确定性和停止或更新条件。

在本目录的 `report.md` 中撰写分析报告，篇幅与结构可按问题需要调整。关键表、图或分析数据保存到 `artifacts/`，并在报告中引用。可以修改或替换 `analysis.py`；提供的示例代码只生成数据概览，不是本课的完整分析。

## 建议时间安排

0—13分钟知识与缺失例子；13—27分钟核对目标总体、邀请和回答情况；27—55分钟假设、界限和调整比较；55—68分钟写发布与补充调查建议；68—75分钟核对提交；75—90分钟知识自查。没有足够信息时把不确定范围作为成果，不虚构精确答案。
