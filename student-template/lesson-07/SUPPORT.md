# 第7课支持路线：调查没有回答时，能说到什么程度

## 先知道今天要交出什么

基础练习帮助你分清目标、邀请、回答和满意的分母，并手算未知范围；标准任务要求完成已知经历比较、至少两种缺失评价假设、建议改变条件和补充调查计划；提高与拓展只在标准任务完成后进行。

## 先做一个小判断

100张工单中只有40张有满意度，能不能直接说“满意度就是这40张的满意比例”？先写这个数字适用谁。

## 核心概念与原理

- **总体**是希望描述的全部工单；
- **无回答**是被邀请后没有提供评价；未受邀与无回答含义不同；
- **覆盖率/回答率**必须说明分母；
- **完整案例分析**只使用所需字段完整的记录，不能自动代表所有工单；
- **缺失机制**描述哪些因素与评分缺失有关，不能凭空认定随机。

已回答者的满意比例是观察事实，不自动等于总体满意比例。可用范围分析和敏感性分析说明未知回答怎样影响建议。

## 基础练习（可信起点）：入门跟做

### 1. 先区分三类数量

运行：

```bash
python scripts/course.py start 07
python scripts/course.py run 07
```

打开 `lesson-07/artifacts/starting_overview.json`，记录目标工单数、匹配调查登记数、邀请数、回答数和各评分数量。分别计算邀请覆盖、受邀后回答、全体回答和回答者满意比例，写出每个分母。

**成功信号：**你能说明 `target_tickets`、`matched_surveys`、`invited` 和 `responded` 为什么不是同一个数量，并能从 `observed_score_counts` 复算回答者满意数。

### 2. 手算未知范围

假设100张目标工单中40张有评价，32张满意。回答者满意比例是32/40=80%。其余60张全部不满意时总体比例为32%，全部满意时为92%，所以未知范围是32%—92%，不是95%置信区间。

## 入门反思

分别写出回答者满意比例与全体满意比例上下界的分母。说明未知范围为什么来自缺失评价的极端假设，而不是抽样误差形成的置信区间。

## 标准任务（本课应完成）

### 3. 做假设情景

令未知工单满意比例为q，则全体比例为 `(32+60q)/100`。选择q=0.25、0.5、0.75，计算三种结果，并说明q是假设，不是补回的真实答案。

### 4. 写建议

说明什么情况下建议会改变，优先补充哪类人的调查，以及为什么。有评价的工单可能与无回答工单不同，不能把“回答者比例”直接推广到所有人。

完成后对照 README，补齐正式数据中的已知经历比较和调查计划中的联系方式、成本假设及更新或停止条件。`check` 通过不能证明缺失假设合理。

## 提高与拓展（提前完成后）

先反思：如果回答率提高，是否一定消除了无回答偏差？完成标准任务后，可任选一项：按业务、等待或放弃状态分层做敏感性分析；找出建议改变所需的未知满意比例；比较两种补充调查优先顺序；或独立复算邀请、回答、上下界和一个假设情景。各组样本量和分母都要报告，并说明新增结果是否改变发布或补充调查建议。

## 卡住时按顺序排查
