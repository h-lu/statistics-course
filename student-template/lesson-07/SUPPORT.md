# 第7课可选支持 · 区分观察、假设与未知范围

本页按困难提供帮助，不是统一分析食谱。可以自行定义满意、选择缺失假设和比较方法、设计补采；只需明确目标、证据与使用条件。小例子不代替正式分析。

## 先知道今天要交出什么

发布者需要能描述对象、保留未知、说明假设与补采取舍的报告和可复算结果。文件结构自定；README 的标准证据不能因选择宽范围而省略。

## 核心概念与原理

未受邀与受邀无回答是不同过程；缺登记或未知邀请另列。完整案例分析直接描述已有所需信息者。上下界来自固定目标中未知评分的可能值，不是抽样置信区间。按组调整需要回答者代表组内全体的假设，不能由已知特征相近证明。

## 基础练习（可信起点）：需要时选一项

**调查范围不清楚。** 先预测一期工单应怎样对应两期调查表，再从学生仓库根目录运行：

```bash
python3 scripts/course.py run 07
```

打开 `lesson-07/artifacts/starting_overview.json`。动作目的只是核对调查起点；成功信号是目标3600、本期缺登记与未知邀请均为0，状态合计为目标。反思：若缺登记，为什么不能称未受邀？

**四个比例分母混淆。** 用输出的邀请、回答、满意数分别写四个算式，再与程序核对。成功信号是每项标对象、分子、分母；5级1291条只是评分计数之一。反思：回答者满意比例是否观察到了未知者评分？

**不会保留未知。** 用 LEARN 小例子100张目标、40份评分、32张满意，先预测极端结果，再手算。成功信号是回答者80%，目标界限32%—92%。反思：空白填零是在恢复事实，还是采用极端假设？

## 入门反思

给报告每项结果标“观察”“假设下计算”或“未知范围”。分类是帮助解释，不要求额外表格；若一句混合三者，拆开说清。

## 标准任务（本课应完成）：可用资源，不指定假设

默认程序核覆盖和已知评分，不自动生成情景、调整估计或发布结论。可复用这些通用帮助，也可自行实现：

- `records()`：按一期目标保留工单，区分缺调查、邀请未知、未受邀与无回答；
- `overview(rows, happy_cutoff)`：核目标、状态、比例和可见经历，满意界限仍基于所给定义；
- `unknown_score_bounds(happy, responded, target)`：核固定目标中未知评分的逻辑界限；
- `weighted_rate(rates, weights)`：按你选的分层和权重合并，正权重未知层保留 `None`。

重要的决定由你设计，至少两项须有理由与备选结果，例如满意定义、哪些未知过程分别作假设、如何调整可见特征、什么证据足以发布、哪类对象优先补采。无需使用全部帮助，也无需为每张未知工单填值。

若情景不会算，可查 LEARN 的“小组数量×假设满意比例”例子；要写清比例用于谁，并保持目标和满意定义一致。若分组调整受阻，先核目标数与回答数各承担什么角色，再说明组内代表性及零/少回答组。不要把程序点值直接当成唯一发布数。

## 提高与拓展（提前完成后）

从自己的报告选一个真正影响建议的未知问题，自由改方法或提出资料需求。README 的分过程敏感性、细分调整与补采收益只是方向示例；可做其它有理由的研究。更细、更精确或更窄不自动表示更可信。

## 卡住时按顺序排查

目录 → 新结果 → 一期目标与编号 → 匹配和状态 → 分子分母 → 假设针对的组 → 报告对象。看到 `None` 先查零分母、未知邀请或零回答组，保留未确定。写不下去时先区分已知与未知，再问什么新资料能改变决定。

## 提交前自检

目标与满意定义一致；状态合计正确；缺调查不猜成未邀；界限不称置信区间；假设不称已知事实；重要决定比较了备选；补采含再次无回答。用自己的运行入口更新 `submission.json`，运行 `python3 scripts/course.py run 07`、`python3 scripts/course.py check 07`，再手算一个正式情景。保留原始数据与旧版本；本课只交方案，不联系个人。
