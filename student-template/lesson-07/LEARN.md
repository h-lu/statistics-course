# 第7课知识准备 · 没有取得的评价会怎样影响满意度

“留下评分的工单中，大多数被评为满意”可以由已有评价算出。但第一期全部登记工单对应的满意比例，还取决于没有取得的评分。本课先分清这两个对象，再研究不同假设下的结果。这里一张工单算一个分析单位；同一位来访者可能有多张工单。

## 先做一个小判断

100张登记工单中，只有40张留下评分。能不能直接把这40张的满意比例说成全部100张的满意比例？先写下你的理由。

## 1. 先区分未受邀与无回答

**目标总体**是报告希望描述的全体对象，本课通常为第一期全部登记工单。有的工单没有收到调查邀请，有的收到邀请却没有提供评分。后一种情况称为**无回答**，也称无应答。两者都使评分缺失，但不属于同一调查过程。

空白表示评分未知，不是0分，也不表示满意或不满意。先按第一期工单编号找到调查登记，再看 `invited`：0表示未受邀，1且评分空白表示受邀后无回答。若连调查登记都没有匹配到，还应单独核实邀请情况，不能直接归入未受邀。邀请字段缺失或与评分矛盾时也应单列待核实。

## 2. 同一调查中的四个比例

另设100张目标工单；假设每张都能匹配调查登记，邀请状态也已知。其中50张受邀，40张留下评分，评分不低于4的32张算作满意。

于是三类工单分别为未受邀50张、受邀后无回答10张、已回答40张，合计100张。这个相加关系以“没有未匹配或邀请状态未知的工单”为前提；正式数据如果有这两类记录，应另列，不能猜其邀请状态。

| 指标 | 计算 | 分母包括谁 |
|---|---|---|
| 邀请率 | 50÷100＝50% | 全部目标工单 |
| 受邀者回答率 | 40÷50＝80% | 收到邀请的工单 |
| 全部工单中有评价的比例 | 40÷100＝40% | 全部目标工单 |
| 回答者满意比例 | 32÷40＝80% | 已取得评价的工单 |

两个80%虽然相同，却不是同一个指标：一个以受邀工单为分母，另一个以有评分工单为分母。**完整案例分析**只使用计算所需信息齐全的记录；本例如果只分析有评分的40张，可以描述它们，却不能不加说明就推广到全部100张。

## 3. 没有评价时，能够给出什么范围

其余60张工单的满意情况未知。若它们全部不满意，全部工单的满意比例为32÷100＝32%；若它们全部满意，则为(32＋60)÷100＝92%。这两个极端结果构成**上下界**：在本例条件下，比例最低32%、最高92%。它不是由抽样估计的不确定性计算的**置信区间**。上下界仍以目标范围清楚、满意定义明确、已记录答案有效为前提，也不保证未来时期的满意比例落在其中。

还可以作**敏感性分析**，即改变一个尚不知道的假设值，检查结论怎样变化。设60张无评价工单中满意的比例为 `q`；`q` 从0到1，分别表示这60张中没有一张满意到全部满意。此时：

`全体满意比例＝(32＋60q)÷100`。

公式分母100是全部目标工单数，结果是比例。`q` 是未知评分中假设的满意比例，不是这些人会回答的概率。例如 `q=0.5` 表示假设60张未知评价中有30张满意，并不是给每张工单补一个0.5分。`q` 为0.25、0.5、0.75时，结果分别为47%、62%、77%。这些是不同假设下的结果，不是三份实际调查结果。

## 4. 什么情况下建议会改变

另设一个发布条件：全部100张工单中至少70%满意，才采用某项建议。这意味着至少70张满意；已知32张，所以未知的60张中至少还需要38张满意，即 `q` 至少为38÷60，约63.33%。70%只是这个例子的假设业务要求，不是统计学规定的标准；算出条件也不表示未知工单实际满足它。

未受邀的50张与受邀无回答的10张也可以采用不同假设。若前者40%满意、后者80%满意，全部工单的比例为(32＋50×0.4＋10×0.8)÷100＝60%；交换两种假设，结果为76%。这说明要写明假设针对哪一组。补充调查时还要说明优先了解哪个群体、为什么，以及成本和再次无回答可能带来的影响。

## 5. 用已有信息调整，需要哪些假设

**分组调整**可以先按业务类型、等待情况等已知特征分组，再假设每组回答者的满意比例也适用于该组没有评价的工单。计算全部目标工单的结果时，用各组目标工单数确定权重，而不是再次用回答人数加权。这项假设要同时覆盖未受邀者与受邀后无回答者。

用已有信息给缺失评分填入估计值，称为**插补**。插补和分组调整都不能恢复未经观察的真实评分。完全没有回答的组无法直接计算组内满意比例；用其他组预测，需要额外假设。回答很少的组，也应说明组内比例可能不稳定。

**缺失机制**讨论“哪些因素与评分是否取得有关”。统计学常区分以下三种情况；它们是理解假设的方式，不能只凭已有评分判断哪一种真实成立：

| 术语 | 本课中怎样理解 |
|---|---|
| 完全随机缺失 | 是否取得评分与已观察的业务、等待等信息以及未取得的评分都无关。例如，假设问卷在系统中被随机丢失，丢失与工单特征及评分无关。 |
| 随机缺失 | 考虑分析中使用的已观察信息后，是否取得评分不再依赖尚未取得的评分。例如，假设是否取得评分只与已记录的业务类型有关；在同一业务类型内，不再取决于满意程度。 |
| 非随机缺失 | 即使考虑这些已观察信息，是否取得评分仍与尚未取得的评分有关。例如，在同类业务、等待相近的工单中，越不满意者仍越不愿回答。 |

这里的“随机”不是指随机抽样。比较已知特征能发现差异，却无法直接看到缺失的评分，因此不能据此证明某种缺失机制成立。

本课不要求先确定真实的缺失机制，才能继续分析。先说明采用什么假设，再比较不同假设下的结果，并指出哪些未知信息会影响建议；无法验证的假设要保留为使用条件。

## 在项目中使用

先说明满意定义和第一期范围，报告邀请、回答和满意比例。比较有评价与无评价工单的已知经历，再给出至少两种有实际差别的缺失评价假设及计算结果。

说明什么情况下建议会改变，或回答同样有实际意义的问题。补充调查要具体到对象、希望了解的信息和何时更新建议。范围很宽也可以是诚实的结论，不必为了得到一个精确数字而强行插补。

## 按需阅读：分组调整怎样算

另设100张目标工单，分成两类业务。以下数字与前面的调查例子无关。

| 业务组 | 目标工单数 | 有评价数 | 其中满意数 | 回答者满意比例 |
|---|---:|---:|---:|---:|
| 甲 | 20 | 10 | 8 | 8÷10＝80% |
| 乙 | 80 | 20 | 12 | 12÷20＝60% |

全部回答者的满意比例为(8＋12)÷(10＋20)，约66.67%。若假设每组回答者能够代表该组全部工单，则目标工单中甲占20%、乙占80%，调整结果为0.2×0.8＋0.8×0.6＝0.64，即64%。

如果仍按回答人数加权，计算的依然是回答者满意比例，并没有调整到目标工单构成。64%依赖组内代表性假设，不是新观察到的事实；甲或乙完全没有评价时，就不能直接计算该组比例。

```python
# learning-example
import json
n, invited, responded, happy = 100, 50, 40, 32
missing = n - responded
def scenario(q):
    return (happy+missing*q)/n
def two_process(q_u, q_n):
    return (happy+(n-invited)*q_u+(invited-responded)*q_n)/n
result = {"invitation": invited/n, "response_invited": responded/invited,
          "response_all": responded/n, "happy_respondents": happy/responded,
          "bounds": [scenario(0), scenario(1)],
          "scenarios": [scenario(q) for q in (.25, .5, .75)],
          "q_for70": (.7*n-happy)/missing,
          "two_process": [two_process(.4,.8), two_process(.8,.4)]}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
