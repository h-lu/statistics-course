# 知识准备 · 满意度调查的覆盖与无回答

## 必须理解：未知不能当作不满意

基础阅读建议7—10分钟。**目标总体**是希望描述的全部工单；未邀请是调查覆盖问题，受邀却未提供评价是**无回答（无应答、非响应）**。两者都使评价缺失，但不能写成同一个过程。空白不是0分，也不是中立。

**完整案例分析**只使用所需字段完整的记录，可直接描述回答者，推广需依据。缺失数据理论中的**完全随机缺失MCAR**指缺失与相关已观测和未观测值均无关；**随机缺失MAR**指给定已观测信息后，缺失不再依赖未观测结果；仍依赖时可能是**非随机缺失MNAR**。这里“随机”不等于采用随机抽样。

如果同业务、同等待条件下越不满意仍越不愿答，就可能是MNAR。可见特征相似不能证明MCAR或MAR；软件给出插补值，也不等于恢复真实回答。

## 完整例子：三个群体，四个比例

另设100张目标工单，50受邀、40回答、其中32满意。三类互斥数量是未受邀50、受邀无回答10、回答40，总数100。

| 指标 | 计算 | 描述的对象 |
|---|---|---|
| 邀请率 | 50/100=50% | 全部目标工单 |
| 受邀者回答率 | 40/50=80% | 收到邀请的工单 |
| 全体有评价比例 | 40/100=40% | 全部目标工单 |
| 回答者满意比例 | 32/40=80% | 已取得评价的工单 |

两个80%恰好相同，不表示分母和事件相同。若整条调查登记未匹配，邀请情况也未知，应另列，不直接放入未受邀。

## 未知评价的范围与建议门槛

令其余60张的满意比例为q，`P(q)=(32+60q)/100`。q=0或1时得到32%—92%，这是不额外规定未知者满意程度时的可能范围，**不是95%置信区间**，仍依赖目标覆盖、满意定义与已记录答案有效。

q=0.25、0.5、0.75分别得到47%、62%、77%，是三种假设下的结果，不是三份观测到的总体真值。另设发布参考门槛70%，则需q≥(70−32)/60≈63.33%；门槛是教学假设，正式项目由用途论证。若推得所需q>1，当前资料下不可能达到该门槛；q≤0表示即便未知者都不满意也已达到，不能把门槛值截成0或1后改变原解释。

## 区分两个未知过程

令未受邀者满意比例q_U，受邀无回答者q_N，则 `P=(32+50q_U+10q_N)/100`。取q_U=0.4、q_N=0.8，得到60%；交换两者为76%。未受邀组q提高0.1使总体提高5个百分点，无回答组同样变化只影响1个百分点。

这提示补采应兼顾未知群体规模、可能差异和行动代价；还要考虑成本、联系渠道及再次无回答，不能仅按人数或便利性排序。

## 调整与支持范围

按业务、等待等分组时，可将组内回答者满意率按**目标工单数**加权。其代表性假设覆盖全部无评价者，包括未受邀，不只覆盖受邀无回答。没有回答的组不能直接估组内满意率；用其他组预测会增加跨组假设。只有少量回答的组也可能不稳定，多加变量或平滑不创造新信息。

## 回到项目与进一步学习

核对三类记录和四个分母，比较可见经历，给至少两种实质不同假设及结果，再讨论建议改变条件或同样有意义的问题，提出具体补采计划。宽范围可能就是诚实成果，不必用复杂插补强行得到精确答案。可向AI询问新例子、核查假设，无需提交对话。

## 按需核算：范围、门槛与两种过程

```python
# learning-example
import json
n, invited, responded, happy = 100, 50, 40, 32
missing = n - responded
def scenario(q):
    return (happy+missing*q)/n
def two_process(q_u, q_n):
    return (happy+(n-invited)*q_u+(invited-responded)*q_n)/n
result = {"invitation": invited/n, "response_invited": responded/invited,
          "response_all": responded/n, "happy_respondents": happy/responded,
          "bounds": [scenario(0), scenario(1)],
          "scenarios": [scenario(q) for q in (.25, .5, .75)],
          "q_for70": (.7*n-happy)/missing,
          "two_process": [two_process(.4,.8), two_process(.8,.4)]}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
