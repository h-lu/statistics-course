# 知识准备 · 满意度调查的覆盖与无回答问题

## 先区分两种没有评价的情况

部分工单未被邀请参加调查，另一些工单虽然收到邀请，却没有提供评价。前者是调查覆盖范围的问题；后者称为**无回答（也称无应答或非响应）**。两种情况都使评价缺失，但成因不同，不能混为一谈。

有评价工单的满意度可以直接计算。若要描述全部登记工单，还需要考虑未取得评价的部分。本课要说明：已有数据能确定什么，哪些结论依赖额外假设。

## 必须理解

| 概念 | 含义 | 本课用途 |
|---|---|---|
| 目标总体与回答率的分母 | 明确要描述的全部工单，以及各比例以谁为分母 | 区分邀请率、受邀工单回答率和全部工单中有评价的比例 |
| 完整案例分析 | 只使用所需字段完整的记录 | 可描述有评价工单；推广到全部工单需要额外依据 |
| 缺失机制 | 缺失与已观测、未观测信息之间的关系 | 判断删除、调整或插补需要哪些假设 |
| 插补与调整假设 | 利用模型或组内信息估计未观测结果 | 估计值不等于恢复了每个对象的真实答案 |
| 敏感性分析与上下界 | 在不同未知评价假设下计算结果 | 说明哪些结论较稳妥，哪些需要补充调查 |

缺失数据理论可用于分析这些评价缺失。完全随机缺失（MCAR）指缺失与相关已观测和未观测值均无关；随机缺失（MAR）指给定已观测变量后，缺失不再依赖未观测结果；非随机缺失（MNAR）则仍依赖未观测结果。例如，在相同等待时间、业务类型的人群中，越不满意者仍越不愿回答，就可能存在MNAR。

这些名称中的“随机”不等于采用了随机抽样。仅凭可见变量相近，不能证明某种缺失机制成立。

## 小例子：先判断，再计算

100张目标工单中50张被邀请，40张回答，其中32张评分≥4。邀请率为50%，受邀工单回答率为40/50＝80%，全部工单中有评价的比例为40%。有评价工单的满意比例是32/40＝80%，但它不自动等于全体满意比例。

其余60张没有取得评价：其中50张未被邀请，10张受邀后无回答。令这60张工单的满意比例为q，全体满意比例为：

P(q)＝(32＋60q)/100。

若q=0，比例为32%；若q=1，比例为92%。因此，不增加未知评价假设时，上下界为32%—92%。若假设q=50%，得到62%；这是假设下的情景结果，不是实际观察到的全体满意比例。要使全体满意比例达到70%，需要q≥38/60≈63.3%。

若按业务类型调整，就需要假设：在相应业务组内，有评价工单可以代表没有评价的工单。加入更多变量不保证这一假设正确；完全没有评价的组，也无法直接估计组内满意比例。

## 在项目中应用

先限定第一期工单范围，分别统计未受邀、受邀无回答和已回答的数量。比较有评价与无评价工单的已观测特征，但不要把特征相近写成“已证明无偏”。展示上下界或有依据的假设情景，说明哪些假设变化会影响发布建议。

## 借助AI分析与进一步学习

AI可以实现分组调整、加权或多重插补。使用加权时，要说明回答概率如何估计、哪些组有足够评价记录；如果同时调整调查邀请与回答过程，应分别说明两步假设。补充调查应优先考虑既影响结论又缺少信息的人群，而不只是最容易联系的人。

可以请AI换一个失访随访的例子，解释“已观测比例”与“假设下总体比例”的差别，再让你判断哪一句结论超出了数据依据。
