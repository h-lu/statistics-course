# 第20课 · 序贯分析与实验停止规则

产品组每天看到新实验数据，想“达到显著就停”，但每多运行一天都要花资源。你要为持续更新的试验制定停止和发布规则，并说明现有30天证据是否足以行动。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

每天做一次5%检验、第一次显著就宣布成功，与第30天只检验一次是同一个统计程序吗？先预测哪个更容易出现假警报。

先阅读[知识准备](LEARN.md)。必要概念用于解释你的成果，计算和复杂实现可以交给工具。

## 可用材料

- [daily_experiment.csv](../data/experiments/daily_experiment.csv)
- [experiment_costs.csv](../data/experiments/experiment_costs.csv)

先读[数据字典与项目要求](../data/experiments/README.md)，核对观测单位、字段、分组/时间和已知局限。示例代码演示如何读取数据、计算简单的描述统计量。你需要继续完成本课分析，也可以改用其他可重现结果的程序。

## 分析任务

1. 从逐日汇总重建累计分配人数、观察人数和转化；区分完整案例转化率与按全部分配者计算的“被确认转化”。明确主要目标以及缺失如何影响它。

2. 预先写出可执行规则，再按时间顺序用30天数据模拟执行规则：比较固定终点、常见逐日查看和一条控制总体错误的序贯规则。可用少数预定查看与分配α、置信序列或其他有依据方法；对零效应机制模拟整体误报与停止时间。

3. 结合时间成本、最小有实际意义的改善和缺失敏感性决定停止、继续或仅限试用。报告规则若用于不同需求和失访情境会怎样；不能把本条已知轨迹挑出的停止点称作预先规则。

## 需要你作出的选择

选择主要结局、查看频率、因有效、无效或安全问题而停止的条件和错误控制目标。简单三次预定查看可以合格，不要求高复杂度序贯算法；但必须说明为什么概率控制对应实际规则。

报告各组累计分配人数、观察人数和用于计算比例的分母，并区分单次检验与整体规则的α。报告模拟次数及模拟误差。汇总表无法恢复缺失者的真实转化结果；不能把缺失填0后称为无须假设的真实转化效应。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

停止规则说明、逐日累计结果、停止规则的执行记录与零效应模拟、实际停止/继续决定及对未观察结果的敏感性。作为模块三代表作时保留原始方案和修订说明。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。“被确认转化”包含观测机制，是可计算的复合结局；真实转化效应仍依赖缺失假设。在这30天数据上模拟规则执行，只说明根据这些已观察数据会何时停止；不能据此知道另一次实验的结果。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。

## 90分钟建议安排

| 时间 | 工作 |
|---|---|
| 0—5分钟 | 阅读项目背景，写下初步判断及理由 |
| 5—15分钟 | 阅读知识准备，核对小例子与必要概念 |
| 15—55分钟 | 完成主要分析或研究设计，比较替代方案，尽早写出报告草稿 |
| 55—68分钟 | 检查估计的不确定性、分析假设和适用范围，修订建议 |
| 68—75分钟 | 本地重跑、整理成果并提交 |
| 75—90分钟 | 知识自查、概念学习与变式反馈 |

遇到全班普遍存在的操作问题时，可适当调整时间。尽量在课堂完成；不以写代码行数、模型数量或耗满时间衡量成果。

## 运行与提交

从仓库根开始：

```bash
python scripts/course.py start 20
python scripts/course.py run 20
```

完成成果后，在`submission.json`填写支持报告结论的结果文件路径、运行入口并将状态改为`complete`，再运行：

```bash
python scripts/course.py check 20
```

按[课堂工作流](../docs/WORKFLOW.md)提交代码、报告与分析结果，本课最终标签为`v2-l20-final`。自动检查只确认文件和运行方式符合提交要求；分析是否合理，需要看报告中的方法说明和结果解释。

课末打开[知识自查](https://hblu.top/stat-check/)，确认页面为当日课次；可以先自己判断，再向AI询问概念并完成变式。参见[自查说明](../docs/KNOWLEDGE_CHECK.md)。
