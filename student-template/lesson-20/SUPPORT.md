# 第20课支持路线 · 预先制定实验停止规则

## 先知道今天要交出什么

你要交出一套可执行的查看与停止规则，并用30天数据按时间顺序模拟它如何运行。最终包括逐日累计表、固定终点与序贯规则对照、零效应下整体误报和停止时间模拟、缺失敏感性，以及停止、继续或有限试用的决定。

入门跟做只完成累计分母和一次查看核对，不能代替预先规则、整体错误率模拟与行动决策。

## 核心概念与原理

每天用5%水平检验并在首次显著时停止，与第30天只检验一次不是同一个统计程序。反复查看增加至少一次假警报的机会，这叫**可选停止**问题。

一种简单合格方案是在少数预定日期查看，并把整体显著性水平分配到这些查看。希腊字母`α`表示第一类错误概率的控制水平；各次门槛与真正执行的查看频率必须一致。

本课每天进入的是新参与者。累计分配人数是逐日`n_assigned`相加，累计观察人数是`n_observed`相加。完整案例转化率的分母是观察到结局的人；“被确认转化”比例的分母是全部分配者。后者是包含观察机制的复合结局，不能无条件解释为真实转化率。

## 基础练习（可信起点）：入门跟做

先在**仓库根目录**打开终端，完整运行：

```bash
python scripts/course.py start 20
python scripts/course.py run 20
```

第二条命令成功时，终端会提示概览已经写入`lesson-20/artifacts/starting_inventory.json`。打开这个文件；它只是数据起点，不是本课答案。若文件没有生成，先按后面的排错顺序处理，再继续。

### 第一步：检查逐日数据结构

- **动作**：从仓库根运行`python scripts/course.py run 20`，读取概览与数据说明；按`day`、`arm`检查每天各一行。
- **目的**：确认每天是新参与者，不把逐日汇总误当累计值。
- **成功信号**：能指出`n_assigned`、`n_observed`和`conversions`各自分母关系，且`conversions≤n_observed≤n_assigned`。
- **反思**：为什么不能把每天的转化率直接相加得到累计转化率？

### 第二步：手算前两天累计值

- **动作**：任选一组，把前两天分配、观察和转化分别相加，计算完整案例转化率和被确认转化比例，再与程序核对。
- **目的**：确保累计分母正确，避免重复计数或平均比例错误。
- **成功信号**：程序与手算一致；两个比例分别标明分母。
- **反思**：组间失访率不同会怎样影响这两个指标的比较？

### 第三步：先写规则再看轨迹

- **动作**：在查看完整逐日差异前，写下主要结局、查看日、有效/无效/安全停止条件、整体错误控制和实际门槛。
- **目的**：避免从这条已知轨迹挑出最漂亮的停止日。
- **成功信号**：规则能让另一名工作人员仅凭当日累计结果执行，不含“视情况而定”的空白条件。
- **反思**：若实际每天查看，但报告只写第10、20、30天，错误率声明还成立吗？

### 第四步：按时间顺序执行三种规则

- **动作**：比较第30天固定终点、每天用同一门槛查看、以及一条控制整体错误的预定查看规则；记录每次是否停止及原因。
- **目的**：看到查看频率如何改变停止时间和证据门槛。
- **成功信号**：程序只能使用当前日及以前的数据；每条规则都有完整执行记录。
- **反思**：在这一条轨迹较早停止，能否说明该规则在新实验中也会较早且正确停止？

### 入门反思

写出主要结局的分母、整体`α`、预定查看日期和最小有实际意义的改善。再写一句缺失结局需要哪项假设才能解释为真实转化效应。

## 标准任务（本课应完成）

1. 重建两组逐日累计分配、观察和转化，区分两种结局定义及其分母。
2. 预先写出规则，再按时间顺序比较固定终点、常见逐日查看和一条控制整体错误的序贯规则。
3. 在已知零效应机制下模拟整个实验，报告整体误报、停止时间、重复次数和模拟误差。
4. 对未观察结局采用合理情境做敏感性分析，不把缺失直接记0后称为真实效应。
5. 结合时间成本、实际改善门槛和规则表现，决定停止、继续或有限试用，并说明适用条件。

## 提高与拓展（提前完成后）

- 比较不同预定查看次数或显著性水平分配方式的误报、功效和期望停止时间。
- 加入因达到目标的可能性太低而停止的无效规则，并检查它对错误率和资源的影响。
- 模拟组间失访差异或共同日效应，检查原规则是否仍适用。
- 比较简单预定查看与一条有依据的置信序列方法，清楚说明概率保证。

## 卡住时按顺序排查

1. 累计数异常时，检查源数据是每日新增量而非累计量。
2. 比例超过1时，确认`conversions`分母用了观察人数或分配人数中的正确一个。
3. 程序使用未来数据时，确保每次查看只筛选`day≤当前日`。
4. 整体误报仍接近逐日0.05门槛累积时，检查是否真正执行了校正规则。
5. 模拟结果不稳定时，记录随机种子、重复次数和蒙特卡洛误差。
6. 报告先按“规则、实际轨迹、零效应性能、缺失情境、决定”组织。
