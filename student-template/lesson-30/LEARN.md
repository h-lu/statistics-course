# 第30课知识准备 · 时间序列预测与容量规划

## 本课要解决的问题

哪种方法在真实预测时点表现可接受？预测区间如何影响容量和异常判断？可以借助AI完成复杂计算；你需要理解以下概念，并据此解释方法选择与分析结论。

## 核心概念（约7—10分钟）

| 概念 | 含义与适用条件 | 在本课中的应用 |
|---|---|---|
| 趋势与季节性 | 趋势是长期变化；季节性是按相对固定周期重复。 | 选择预测结构 |
| 自相关 | 相邻或固定滞后结果相关。 | 评价误差与拆分 |
| 滚动回测 | 在多个历史预测时点仅用当时已知资料预测未来。 | 模拟排班流程 |
| 预测区间 | 对未来观测范围的不确定性描述，比均值区间包含更多变动。 | 决定容量余量 |
| 异常与结构变化 | 大误差可能是偶然、输入问题或关系变化，需要后续证据。 | 制定预警复核 |

平均绝对误差（MAE）写作 MAE=(1/n)Σ|y−ŷ|，单位为每周需求件数。用过去绝对误差的90%分位数形成ŷ±q只是经验预测带；时间依赖和环境改变时，不能自动保证未来覆盖率达到90%。

式中y为目标周的实际需求，ŷ为在过去预测时点生成的需求预测，n为纳入评价的预测记录数。本课标准路线每四周更新一次，因此每个目标周对应一个预测跨度；若在拓展分析中改为每周更新，使同一目标周出现多个预测，则要分别记录预测跨度并明确汇总权重。

## 先思考，再看例子

在第100周预测101—104周，使用104周真实需求估计趋势，就是使用了预测时尚不可得的信息，属于时间泄漏。季节朴素法用上一年对应周需求，趋势季节模型用截至100周资料拟合；它们都应在相同预测时点与跨度比较。

把例子中的对象、单位和比较条件换成本课数据：哪些定义可以沿用，哪些需要根据分析任务重新确定？先用自己的话回答，再借助AI核对。

## 在项目中应用

用滚动回测选择方法：区间按目标周划分，80—115周用于模型开发与评价，116—131周用于预测区间校准，132—155周用于按时间顺序独立评估。标准路线从第79周末开始，每四周更新一次并预测随后四周；保留每次的预测时点、目标周、预测跨度和实际误差。不能随机打乱周次。

可以让AI协助实现分析，但要检查变量的可得时点、单位、分析人群和计算结果是否对应报告中的问题，并核对软件默认设置是否符合所用统计定义。在`report.md`中选择一项主要结论，说明研究问题、分析方法、结果依据和适用范围如何对应。

## 适用条件与局限性

预测准确不意味着识别了政策原因。后期覆盖不足时应如实报告，不事后加宽区间再称其为预先验证。

## 学习自查

进入项目后应能解释：

1. 需求趋势与季节性有什么不同，是否可以同时存在？
2. 相邻周误差相关时，为什么随机拆分会误导评价？
3. 在某周预测未来四周，哪些输入在当时已经可得？
4. 未来观测的预测区间与平均需求的区间有什么不同？
5. 连续多周低估需要怎样复核，为什么不能直接归因为政策？

## 进一步学习

可按需使用指数平滑、自回归积分移动平均模型（ARIMA）或机器学习方法。保留相同预测时点和预测跨度，先与简单基线比较，再决定复杂方法是否值得维护；预测带的生成和实际覆盖须分开说明。复杂方法可以借助工具实现，但应在报告中说明为什么使用它，以及它的适用条件。

可向AI提出：“请用不同于本课的情境解释一个我不确定的概念，然后问我一道判断题，等我回答再解释。”无需提交对话记录。你也可以直接让AI协助完成项目，并核对最终报告的分析结论。
