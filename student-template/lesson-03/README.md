# 第3课｜数据质量与用途

从第二期原始导出中整理工单，再判断哪些信息适合所选用途。

## 学习顺序

先读[知识讲解](LEARN.md)，完成手算与自检，再按本页设计正式分析。遇到具体操作问题查[运行帮助](SUPPORT.md)。已完成的作业无需重交。

## 数据与条件

本课数据为教学合成资料，不对应真实机构或个人。

`data/service/tickets_raw.csv` 包含第二期2026-04-13至24日的1,265行导出、1,200个工单编号。第一期与第二期工单不同；配套窗口、业务表及字段约定见[数据说明](../data/service/README.md)。

版本按数值选择；最高版本冲突保留核实。等待999和−1先标缺失，再按有效单位换算；未知字段不猜填。已服务等待只纳入明确未放弃且等待有效的工单。

## 标准任务

1. 至少选择两个分析用途，逐项写明分析单位、所需字段、纳入条件、指标和分母。
2. 处理重复、修订、单位及未知信息，保存原值、选用版本、处理结果和问题原因。
3. 至少为一个指标实际比较另一种有理由的记录选择，说明各自覆盖谁、少用了什么信息。
4. 分别提出每个用途的采用、部分采用或先核实建议，并给出依据。

重要选择包括分析用途，以及各指标所需记录与比较方案。提交数据适用性报告、可重跑程序及可追踪处理结果。

## 运行与提交

在学生仓库根目录运行：

```sh
python3 scripts/course.py start 03
python3 scripts/course.py run 03
```

默认输出是分析起点，正式作品还需上述比较与建议。保存原始CSV，自己的结果放在 `lesson-03/artifacts/`。在 `submission.json` 中登记报告路径、产物和重建命令参数列表，完成后设 `status=complete`。

```sh
python3 scripts/course.py check 03
```

`check`核对状态、路径和文件，不重新运行分析。按[提交工作流](../docs/WORKFLOW.md)提交，标签沿用 `v2-l03-final`，修订保留旧标签。课堂选择题按教师开放场次完成，说明见[知识自查](../docs/KNOWLEDGE_CHECK.md)。

围绕同一作品增加一个有实际用途的检查，如另一种范围、指标或假设，并解释新增证据怎样影响建议。AI可辅助学习、编程与写作；分析选择和结果解释由你完成。评分与原作业要求不变。
