# 第3课知识准备 · 哪些记录可以用于这次分析

等待时间报告需要等待记录，窗口工作量报告需要窗口信息，办结比例需要办结结果。一个字段缺失，不一定让整张工单对所有问题都没有用。

## 1. 先分清重复记录与修订记录

**主键**是用于唯一识别记录的字段。例如，整理后的工单表可以用工单编号识别每张工单。但是同一张工单可能被重复导出，也可能后来更新过信息，因此原始表的行数不一定等于工单数。

**重复记录**是同一条记录多次出现。**修订记录**是同一对象的信息更新。应根据数据说明选择较新的版本，而不是按文件中出现的先后顺序随意保留一行。

## 2. 缺失、单位与离群值

**缺失值**表示需要的信息没有取得，不能自动当作0。本课数据约定999和−1表示等待没有测量；应先识别这些编码，再把秒换成分钟。变量名中含有minutes，也不保证原始值已经统一为分钟。

**离群值**是与多数观测值明显不同的值。例如，60分钟可能是很长的等待，但仅凭“很长”不能认定它录入错误。删除前应查明原因；无法确认时，可以保留并讨论它对结果的影响。

## 3. 五行数据应该怎样整理

下表是另设的例子，三张工单都没有放弃排队。办结状态1表示当日办结，0表示未当日办结；UNKNOWN表示窗口未知。

| 工单 | 版本 | 原等待值 | 单位 | 当日办结 | 窗口 |
|---|---:|---:|---|---:|---|
| R1 | 1 | 120 | 秒 | 1 | A1 |
| R1 | 1 | 120 | 秒 | 1 | A1 |
| R1 | 2 | 180 | 秒 | 1 | A1 |
| R2 | 1 | 999 | 秒 | 1 | UNKNOWN |
| R3 | 1 | 60 | 分钟 | 0 | A1 |

先核对数量：5行对应3张工单，另有1行完全重复和1行旧版本。先去除完全重复的行，再数被新版本替代的行，避免把同一行计算两次；“有修订的工单数”不一定等于“去掉的旧版本行数”，一张工单可能有多个旧版本。R1保留第2版，等待180÷60＝3分钟。R2的999是未测量编码，不能换算成999÷60分钟。R3保留60分钟。

接着按分析目的选择记录：

| 要计算什么 | 可以使用哪些工单 | 结果 |
|---|---|---|
| 平均等待时间 | R1、R3有等待测量 | (3＋60)÷2＝31.5分钟 |
| 当日办结比例 | 三张工单的办结状态都已知 | 2÷3，约66.7% |
| 已确认属于A1窗口的工单数 | R1、R3有已知窗口 | 2张；另1张窗口待核实 |

平均等待31.5分钟只描述两张有测量的工单，不是三张工单的完整平均情况。R2也可能属于A1，所以这里只能说“已确认2张”，不能说“A1全部只有2张”。

## 4. 为什么不总是删除整行

**完整案例分析**只使用本次分析所需字段都完整的记录。假如要求等待、办结和窗口三个字段全部完整，R2会被排除，剩余工单的办结比例变为1÷2＝50%。

这个50%与前面的约66.7%描述不同的工单集合。对办结比例而言，R2的办结状态本来已知，删除它不一定合理。对每项指标，应说明实际用了哪些记录、分母是多少、没有纳入谁。只为计算办结比例时，“完整”只需办结字段有效，三张工单都可以使用；同时要求等待、办结和窗口完整，是另一组字段要求。不能把完整案例分析一概理解为必须检查表中所有字段。

**插补**是根据已有信息和假设给缺失值补入估计值。补出的数字不是已经查实的答案。可以比较插补与不插补的结果，但要解释所用假设。

## 在项目中使用

为至少两个分析目的列出所需字段、处理规则、参与计算的记录数和是否适合使用。这里“排除”是指不让某条记录参与某项计算，并不删除原始文件中的记录。保留原始数据，另存处理结果及排除原因；同一工单可能有多个问题，不能把各问题数量直接相加当作不同工单数。

缺失编码、版本优先和单位换算是数据约定，不是可以任意改变的分析假设。合理的比较可以是按指标选择记录与完整案例分析，或有依据的插补与不插补。第二期与第一期日期不同，两期均值之差不能直接当作数据清洗的效果。

## 按需了解：程序遇到异常记录时

同一最新版本出现冲突时，应保留冲突并查明原因。不能把未知放弃状态当成“没有放弃”；空白、不能解析的文字以及程序中的无穷大等也不能当作正常等待值。这些是处理新数据时需要防范的问题，不表示本课文件包含所有这些情况。

```python
# learning-example
import json
rows = [{"wait": 3, "completed": 1, "window": "A1"},
        {"wait": None, "completed": 1, "window": None},
        {"wait": 60, "completed": 0, "window": "A1"}]
waits = [r["wait"] for r in rows if r["wait"] is not None]
complete = [r for r in rows if all(v is not None for v in r.values())]
result = {"target_n": len(rows), "wait_n": len(waits), "wait_mean": sum(waits) / len(waits),
          "completion_rate": sum(r["completed"] for r in rows) / len(rows),
          "complete_case_rate": sum(r["completed"] for r in complete) / len(complete),
          "known_window_n": sum(r["window"] is not None for r in rows)}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
