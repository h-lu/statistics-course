# 知识准备 · 数据质量必须与用途一起判断

## 必须理解：没有一张适合所有指标的清洁表

基础阅读建议7—10分钟。**分析单位与主键**决定数什么对象、怎样识别它；导出行不一定是独立工单。**重复**是同一记录再次出现，**修订**是同对象的信息更新，不能把新版再计成一张工单。

**缺失值**表示本应记录但没有得到的信息，编码要按字典解释。**有效取值与单位**决定数值可否使用；字段叫 `wait_minutes` 不保证原值都以分钟记录。**离群值**与多数记录不同，但未必错误。**数据适用性**应针对用途：窗口报告需要窗口归属，等待报告需要有效测量，办结率需要已知结果。

## 完整例子：先处理版本，再形成有效集合

以下另设三张工单，均假设未放弃；它们不是正式数据的缺失真值。

| 工单 | 版本 | 原等待 | 单位 | 当日办结 | 窗口 |
|---|---:|---:|---|---:|---|
| R1 | 1 | 120 | 秒 | 1 | A1 |
| R1 | 1 | 120 | 秒 | 1 | A1 |
| R1 | 2 | 180 | 秒 | 1 | A1 |
| R2 | 1 | 999 | 秒 | 1 | UNKNOWN |
| R3 | 1 | 60 | 分钟 | 0 | A1 |

5原行=3工单+1完全重复行+1被新版本替代的行。R1取第2版，180/60=3分钟。R2先识别999为未测量，不能算成999/60分钟；R3的60分钟很长，但没有证据证明错误。

等待有效集合是R1、R3，均值(3+60)/2=31.5分钟，有效n=2、目标工单n=3。办结结果三张都有效，比例2/3。窗口可归属的工单为2张，另1张未知。若统一完整案例删除R2，办结率变1/2；这是描述对象变化，不是自动纠正偏差。

## 处理规则从哪里来

先识别重复和版本，再处理字段含义，最后按用途决定有效集合。已知缺失编码、较新版本优先和秒/分钟换算不能任意改成“备选方案”。可以比较的是按用途限用与完整案例、带假设插补与不插补，并实际量化影响。

保留原字段、处理值和原因；插补值不是观察真值。未知窗口不能靠编号相似猜归属。缺等待与缺窗口可能出现在同一工单，各项问题数量不能直接相加成唯一工单数。缺失比例也应以版本处理后的目标工单为分母，而非让重复导出改变权重。

## 面对下一期数据

若同一最新版本内容冲突，保留冲突并停止自动选择，不能按文件顺序任选。空白、非数值、非有限等待要标明，不当作正常测量；未知放弃状态不能因“不是1”就认定已服务。这些是程序边界例子，不声称当前CSV含有所有问题。

保留被排除或限用的记录及原因；对全表不能采用的结论，不等于所有字段都没有价值。第3课的第二期与第一期时间不同，不能把均值差直接归因于清洗。

## 回到项目与进一步学习

至少两个用途各自对应字段、处理规则、有效分母和发布决定；比较一种合理替代，并说明补核什么会改变建议。AI可以实现清洗、日志和检查，不要只让它输出一张“没有空白”的表。可按需了解插补或记录链接，但不要求填满未知值，也不提交对话。

## 按需核算：处理后的用途差异

下面从上述已按约定处理的三张工单开始，展示有效集合，不是完整清洗程序。

```python
# learning-example
import json
rows = [{"wait": 3, "completed": 1, "window": "A1"},
        {"wait": None, "completed": 1, "window": None},
        {"wait": 60, "completed": 0, "window": "A1"}]
waits = [r["wait"] for r in rows if r["wait"] is not None]
complete = [r for r in rows if all(v is not None for v in r.values())]
result = {"target_n": len(rows), "wait_n": len(waits), "wait_mean": sum(waits) / len(waits),
          "completion_rate": sum(r["completed"] for r in rows) / len(rows),
          "complete_case_rate": sum(r["completed"] for r in complete) / len(complete),
          "known_window_n": sum(r["window"] is not None for r in rows)}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
