# 第4课知识准备：不同指标为什么会给出不同评价

评价服务时，有人关心通常要等多久，有人关心有没有少数特别长的等待，还有人关心哪些中心需要优先调查。先明确问题，再选指标。

## 1. 集中趋势、离散程度和尾部

**集中趋势**描述数据的大致位置，常用算术平均数（简称均值）和中位数。回顾前两课：均值是数值总和除以记录数；中位数是排序后的中间值，记录数为偶数时取中间两个值的平均数。

**离散程度**描述数据相差多大。**第一四分位数**和**第三四分位数**分别描述排序后25%和75%位置；**四分位距（IQR）**是第三四分位数减第一四分位数，描述中间一半数据的跨度。

等待分布的**右尾**指较大数值的一端，可用来观察特别长的等待。**第90百分位数**描述排序后接近90%位置的等待时间，不是最大值。小样本采用插值时，实际不超过这个值的记录比例未必恰好是90%。

本课示例和程序采用位置 `(n−1)×p` 的**线性插值**计算分位数。`n` 是有效记录数，`p` 是所求位置的比例，例如第一四分位数取 `p=0.25`。位置从0开始计数，0对应最小值；若位置落在相邻两个数之间，就按距离在两者之间取值。不同软件的默认算法可能不同，报告中要写明采用的算法。

另设两组已服务工单的等待时间，单位都是分钟：X为4、5、5、6、40，Y为8、9、10、11、12。

- X均值为 `(4+5+5+6+40)/5=12` 分钟，中位数为第3个数，即5分钟；Y均值为 `(8+9+10+11+12)/5=10` 分钟，中位数为10分钟。
- 每组都有5个数，第一、第三四分位数的位置分别是 `(5−1)×0.25=1` 和 `(5−1)×0.75=3`。从0开始计数，它们对应排序后的第2、第4个数。X对应5和6分钟，四分位距为1分钟；Y对应9和11分钟，四分位距为2分钟。
- X的第90百分位数位置为 `(5−1)×0.9=3.6`，落在6与40分钟之间，结果为 `6+0.6×(40−6)=26.4` 分钟。本例实际有4/5=80%的记录不超过26.4分钟，说明小样本插值结果不保证实际累计比例恰好为90%。

只看中位数，X等待更短；只看均值或超过15分钟的比例，Y更好。这些结果回答的问题不同，并不矛盾。

**稳健性**指少量极端值变化时，结果是否会大幅改变。例如把X中的40改为400，中位数和四分位距不变，均值会明显增大。中位数和四分位距在这个例子中较稳健，但仍需另看长等待，不能据此忽略极端值。

## 2. 从指标到规则

**指标**是为一个判断定义的可计算量。要写明描述的对象、计算方法、单位、数值变大意味着什么，以及怎样处理缺失；比例还要说明分子和分母。**阈值**是触发行动的界限：“超过15分钟”不含15，“不少于15分钟”含15。

这里有两个单位不同、作用不同的阈值：**15分钟用来判断一张工单**是否属于长等待；**10%用来判断一组工单**中的长等待比例是否触发调查。不能把15分钟和10%当作同一种界限。

在X、Y例子中，若超过15分钟的比例大于10%就调查，X为1/5=20%，触发调查；Y为0/5=0%，不触发。**10%是本例为了演示规则另设的调查门槛**，不是统计学标准。没有触发这一条件不等于服务全面合格。

## 3. 分母不能混用

已服务工单的等待只用明确未放弃且等待有效的工单；放弃比例用登记工单中放弃状态已知的记录。

若定义“放弃或超时”，同一张工单同时满足两项时只能计一次。这里的“事件”指工单满足某个条件，例如“放弃”或“超过等待阈值”。已知满足其中一项，就能判断符合“放弃或超时”；若尚不能判断是否符合，则列为未知，并说明这类记录怎样影响分母。分母为零时，比例不能计算，不能写成0%。

## 4. 综合指标的风险

多个指标可以分别报告，也可以合成一个总分。这里的**尺度**是指标使用的单位和数值范围，例如等待可以用分钟或秒表示，比例可以写成0到1或0%到100%。不同指标合成前要说明怎样转换尺度、怎样设置权重，以及一项较好结果是否可以抵消另一项严重问题，因此仍应保留原指标和不能超过的门槛。

按业务使用15分钟和30分钟不同阈值，只是给不同业务设定不同的管理规则，并没有让各中心拥有相同的业务构成。中心排序描述这批记录在所选规则下的结果，不能自动解释为工作人员造成的效果。

## 5. 回到项目

写一套能计算、能解释、能支持行动的办法，再实际比较替代办法。保留记录数、放弃和业务构成，说明何时发布、调查、试运行或暂缓。

**敏感性分析**是改变一项有依据的分析选择，检查结果怎样变化；结论只能用于已经检查的变化范围。评价规则还可能产生**行为激励**，即促使机构改变行为。例如，为了得到更好看的数字，机构可能少接困难业务或改变记录范围；这只是需要核查的风险，不是已经证明发生的事实。

替代办法计算后，中心名单或建议可能改变，也可能不变。**评价没有改变也有意义**：它说明结论在已经检查的规则范围内较稳定，但不能推广成所有阈值、分母和权重下都不变。

## 6. 先判断再写规则

可以用四句话检查每个指标是否说清楚：

1. 它描述谁；
2. 怎样计算；如果是比例，分子和分母是什么；
3. 数值变大是好、坏，还是需要结合其他指标；
4. 达到什么条件会采取什么行动。

然后用一条恰好等于阈值的记录测试规则。这样可以发现“超过”和“不少于”的差别，也能避免在看结果后偷偷改变等号。

## 小练习

三张工单等待2、5、10分钟。若规则是“严格超过5分钟调查”，只有10分钟这一张触发，比例为1/3；若规则是“不少于5分钟调查”，5分钟和10分钟两张触发，比例为2/3。两种规则都能运行，但必须在看结果前说明选择理由。

下面的小程序只核对上面的手算，不读取项目数据。先预测 `x` 和 `y` 两组等待的结果，再运行它。函数 `profile` 计算各组指标，其中 `mean` 是均值，`median` 是中位数，`iqr` 是四分位距，单位都是分钟；`over15` 是严格超过15分钟的比例，用0到1表示。分位数使用本课约定的线性插值位置 `(n−1)×p`。

```python
# learning-example
import json
import math
import statistics


def quantile(values, p):
    ordered = sorted(values)
    if not ordered:
        return None
    position = (len(ordered) - 1) * p
    lower = math.floor(position)
    upper = math.ceil(position)
    return ordered[lower] + (position - lower) * (ordered[upper] - ordered[lower])


def profile(values):
    values = [float(value) for value in values]
    if any(not math.isfinite(value) for value in values):
        raise ValueError("等待时间必须是有限数")
    if not values:
        return {"mean": None, "median": None, "iqr": None, "over15": None}
    return {
        "mean": statistics.mean(values),
        "median": statistics.median(values),
        "iqr": quantile(values, .75) - quantile(values, .25),
        "over15": sum(value > 15 for value in values) / len(values),
    }


x = [4, 5, 5, 6, 40]
y = [8, 9, 10, 11, 12]
result = {
    "x": profile(x),
    "y": profile(y),
    "x_mean_after_exclusion": statistics.mean([4, 5, 5, 6]),
    "x_over15_after_exclusion": 0,
}
print(json.dumps(result, ensure_ascii=False, sort_keys=True))
```

运行后检查：X 的均值为12、中位数为5、四分位距为1、超过15分钟的比例为20%；Y的均值为10、中位数为10、四分位距为2。删除40后得到的均值5只说明删除后的数据，不是服务改善的证据。

回到项目时，保留原始的放弃数量、业务构成和记录数。一个评价办法即使排名不变，也可能改变调查数量或发布条件；评价的目的不是制造名次，而是支持可执行的决定。

## 独立练习：五个概念及其迁移

这些是另设的小情境，先写计算、理由和使用建议，再按本页定义复核。AI可以帮助解释或换题，但不要用本页小例子代替正式数据。

1. **集中趋势与尾部：**甲的5张已服务工单等待2、2、2、2、22分钟，乙的5张已服务工单都等待7分钟。计算两组均值、中位数及超过15分钟比例；“甲服务全面更好”有何问题？变式：把22改为42，哪些结果变化、哪些不变，为什么？
2. **离散程度与稳健性：**0、0、0、0、100的四分位距按线性插值是多少？这能说明每张工单都等待一样久吗？变式：把100改为1000，中间一半的跨度和总等待分别怎样变化？
3. **指标尺度与权重：**一个演示总分为平均等待分钟数/10分钟＋放弃比例，比例用0到1。12分钟和10%算多少？变式：等待改为秒记录，如何使相对权重保持相同？为什么仍要保留两个原指标？
4. **事件、分母与阈值：**10张工单有3张放弃、4张超时，其中2张同时符合两项，“放弃或超时”有几张？变式：另有10张已服务工单，其中2张恰好等待15分钟、1张等待16分钟，其余不足15分钟。规定严格超过15分钟为超时，超时比例严格超过10%时调查，是否触发调查？
5. **规则目的与行为激励：**中心减少复杂业务后，按统一15分钟规则的超时比例下降。能否据此认定同类业务服务改善？变式：现有表只有已经登记工单，你需要新增哪些记录，才能检查是否少接困难业务，而不是假定它已经发生？

自检关注计算关系与解释范围：一般等待和尾部可以支持不同决定；四分位距只描述中间一半；秒与分钟转换不能改变权重；同一事件只计一次；行为风险需要额外记录核实。可以用自己的短例子或AI换题再检验理解；线下练习不替代当课选择题。
