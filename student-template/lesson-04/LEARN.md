# 第4课知识准备：不同指标为什么会给出不同评价

评价服务时，有人关心通常要等多久，有人关心有没有少数特别长的等待，还有人关心多少工单触发调查。先明确问题，再选指标。

## 1. 中心、离散和长尾

**集中趋势**描述数据大致位置，常用均值和中位数。**离散程度**描述数据相差多大；**四分位距**是中间一半数据的跨度。等待分布的**右尾**是少数特别长的等待。第90百分位数描述排序较高位置，不是最大值。本课示例和参考程序采用位置 `(n−1)×p` 的线性插值计算分位数；不同软件的默认算法可能不同，报告中要写明采用的算法。

两组数据：X=4、5、5、6、40，Y=8、9、10、11、12。X均值12、中位数5，Y均值10、中位数10。只看中间位置偏向X，只看均值或超过15分钟比例偏向Y；不是计算矛盾，而是评价目标不同。

## 2. 从指标到规则

**指标**是为一个判断定义的可计算量。必须写明对象、分子、分母、单位、好坏方向和缺失处理。**阈值**是触发行动的界限：“超过15分钟”不含15，“不少于15分钟”含15。

在X、Y例子中，若超过15分钟的比例大于10%就调查，X为1/5=20%，触发；Y为0，不触发。10%是本例的管理假设，不是统计学标准。没有触发这一条件不等于服务全面合格。

## 3. 分母不能混用

已服务工单等待只用明确未放弃且等待有效的工单；放弃比例用登记工单中放弃状态已知的记录。某张工单同时放弃和超时，定义“放弃或超时”时只能计一次。没有可判断信息时列为未知，零分母不能写成0%。

## 4. 综合指标的风险

多个指标可以分别报告，也可以按明确尺度和权重合成总分。分钟和百分比不能直接相加；即使完成单位转换，权重仍是使用者取舍。综合分数还可能允许一个好结果抵消另一个严重问题，因此应保留原指标和不能超过的门槛。

按业务使用15分钟和30分钟不同阈值，是业务规则，不是直接标准化。中心排序描述这批记录在所选规则下的结果，不能自动解释为工作人员造成的效果。

## 5. 回到项目

写一套能计算、能解释、能支持行动的办法，再实际比较替代办法。保留记录数、放弃和业务构成，说明何时发布、调查、试运行或暂缓。敏感性分析只支持已检查的变化范围。

## 6. 先判断再写规则

对每个指标填写四句话：

1. 它描述谁；
2. 分子和分母是什么；
3. 数值变大是好、坏，还是需要结合其他指标；
4. 达到什么条件会采取什么行动。

然后用一条恰好等于阈值的记录测试规则。这样可以发现“超过”和“不少于”的差别，也能避免在看结果后偷偷改变等号。

## 小练习

三张工单等待2、4、10分钟。若规则是“超过5分钟调查”，只有1张触发；若规则是“不少于5分钟调查”，有2张触发。两种规则都能运行，但必须在看结果前说明选择理由。

下面的小程序只核对上面的手算，不读取项目数据。先预测 `x` 和 `y` 的结果，再运行它；`profile` 使用本课约定的线性插值位置 `(n−1)×p`。

```python
# learning-example
import json
import math
import statistics


def quantile(values, p):
    ordered = sorted(values)
    if not ordered:
        return None
    position = (len(ordered) - 1) * p
    lower = math.floor(position)
    upper = math.ceil(position)
    return ordered[lower] + (position - lower) * (ordered[upper] - ordered[lower])


def profile(values):
    values = [float(value) for value in values]
    if any(not math.isfinite(value) for value in values):
        raise ValueError("等待时间必须是有限数")
    if not values:
        return {"mean": None, "median": None, "iqr": None, "over15": None}
    return {
        "mean": statistics.mean(values),
        "median": statistics.median(values),
        "iqr": quantile(values, .75) - quantile(values, .25),
        "over15": sum(value > 15 for value in values) / len(values),
    }


x = [4, 5, 5, 6, 40]
y = [8, 9, 10, 11, 12]
result = {
    "x": profile(x),
    "y": profile(y),
    "x_mean_after_exclusion": statistics.mean([4, 5, 5, 6]),
    "x_over15_after_exclusion": 0,
}
print(json.dumps(result, ensure_ascii=False, sort_keys=True))
```

运行后检查：X 的均值为12、中位数为5、四分位距为1、超过15分钟的比例为20%；Y的均值为10、中位数为10、四分位距为2。删除40后得到的均值5只说明删除后的数据，不是服务改善的证据。

回到项目时，保留原始的放弃数量、业务构成和记录数。一个评价办法即使排名不变，也可能改变调查数量或发布条件；评价的目的不是制造名次，而是支持可执行的决定。
