# 第4课知识准备 · 不同指标为什么会给出不同评价

评价服务时，使用者可能关心通常要等多久、总共耗费多少等待时间，或有多少工单等待很长。这些问题不同，不能只靠一个名次回答。

读完本页，应能解释不同指标为何得出不同评价，写出可执行的判断规则，并检查分母、单位和规则改变后的结果。可以先完成小例子，再借助AI核对。

## 1. 位置、离散程度和较长等待

**集中趋势**描述数据大致位于哪里，常用算术平均数（简称均值）和中位数表示。均值等于总和除以记录数；中位数描述排序后的中间位置，不是说大多数记录恰好等于它。

**离散程度**描述数值之间相差多大，常用标准差和四分位距表示。**四分位距（IQR）**等于第三四分位数减第一四分位数，主要反映中间一半数据的跨度。计算四分位数沿用[第2课](../lesson-02/LEARN.md)的线性插值约定，不同软件的默认方法可能不同。

等待时间分布的**右尾**是较长等待所在的部分。第90百分位数（P90）描述较高位置的等待，不是最大值。**稳健性**关注少量极端变化对结果的影响；中位数、四分位距对个别极端变化可能不敏感，但不能因此忽略真实的长等待。

## 2. 先判断，再计算两组记录

另设两组已服务工单：X为4、5、5、6、40分钟；Y为8、9、10、11、12分钟。两组各5张，均有有效等待记录，没有放弃者。先猜：关注中间位置和关注长等待，会偏向同一组吗？

| 指标 | X | Y |
|---|---:|---:|
| 均值（分钟） | 12 | 10 |
| 中位数（分钟） | 5 | 10 |
| 四分位距（分钟） | 1 | 2 |
| 超过15分钟的工单数 | 1 | 0 |
| 超过15分钟的比例 | 1÷5＝20% | 0÷5＝0% |

X的总等待是4＋5＋5＋6＋40＝60分钟，均值为60÷5＝12分钟；Y的总等待是50分钟，均值为10分钟。两组第三个值分别为5和10，即中位数。本例按线性插值，第一、第三四分位数正好是排序后的第2、第4个值，因此X的四分位距为6−5＝1，Y为11−9＝2。

X的中间位置较低，但有一张等待40分钟的工单。只看中位数会偏向X，只看均值或超时比例会偏向Y。这不是计算矛盾，而是评价目标不同。

均值不是总等待时间。两组记录数不同的时候，平均每张等待较短的一组，总等待仍可能更多。同样，超时数量从5张增至20张，只有知道两期各有多少张工单，才能判断超时比例是否增加。

若删除X的40分钟记录，均值变成5分钟，超时比例变成0。数字变好不说明服务改善，因为那次长等待仍然发生过；不能只为得到更好的评价而删除它。

## 3. 从指标到一条完整评价办法

**阈值**是判断是否符合某个条件的数值界限。“超过15分钟”使用严格大于，不包含恰好15分钟；“不少于15分钟”则包含它。

仍用X、Y：办法甲按中位数从小到大比较，同时列出记录数和超时比例，X在前。办法乙先检查“超过15分钟的比例是否大于10%”：触发时列为需要调查的组，其余组再按中位数比较。因此X需要调查，Y没有触发这项条件。

10%是本例另设的**管理假设**，不是统计学标准或从五条记录证明的最佳门槛。未触发调查条件只表示没有超过这一条门槛，不代表服务各方面都合格。两套办法都可以计算，但优先关注的问题不同，必须说明采用哪套以及理由。

15分钟用来判断一张工单是否超时，10%用来判断一组工单的超时比例是否需要关注。**时间阈值和比例门槛的单位不同，两个等号也要分别说明。**

先查看题目给出的业务要求；未给定的门槛可以自行提出，但要解释所服务的目标，再比较其他有理由的取值。比较后评价没有改变也有意义，不必一直调到排名反转。并列应按事先声明的规则处理；显示时四舍五入相同，不一定表示原值相等。

## 4. 同一张工单怎样进入分子和分母

“已服务工单中的超时比例”只采用已服务且等待有效的工单；“全部登记工单中的放弃比例”采用全部已登记且放弃状态已知的工单。第一期提供的状态均已知，所以后者的分母就是全部登记工单数；换数据时不能将未知状态猜成0。

也可以定义“放弃排队，或者等待超过对应业务参考时间”。这个“或”表示至少符合一项，同一张工单即使同时符合两项也只计一次。例如，10张资料完整的工单中3张放弃、4张超时、2张两者兼有，符合至少一项的有3＋4−2＝5张，比例为5÷10＝50%，不是70%。这里放弃者的等待是离开前等待，并不是获得服务前的等待。

不能把两个采用不同分母的比例直接相加，来代替上述计数。若没有足够信息判断某张工单是否符合事件，应单列未知、说明能描述的范围，不把未知记为“没有发生”。某组没有可用记录时，比例不能计算，JSON中的 `null` 不是0%，不能按最佳表现排名。

## 5. 多个指标可以分别报告，也可以合成

分别报告中位数、P90、超时比例和放弃比例，不必合成总分。**综合指标**把多个指标按明确规则合为一个数，仍须保留原指标，让读者知道哪些差异被合并了。

下面只演示尺度转换，使用与X、Y无关的另一组数据。另设一种“数值越低越好”的总分：平均等待分钟数÷10＋放弃比例，比例用0到1表示。某组平均等待12分钟、放弃比例10%，总分为12÷10＋0.10＝1.30。不能把10%写成10后相加。

除以10分钟后，时间项没有单位；若改用秒，原来的10分钟也必须改成600秒。因此720÷600＋0.10仍为1.30，而720÷10＋0.10改变了评价办法。10分钟和各项系数表达使用者的取舍，不是客观唯一的权重；处理了单位也不表示权重已经合理。

还要说明“能否相互抵消”。上述规则允许较低的平均等待抵消较高的放弃比例。若使用者不接受这种抵消，就应另列不能超过的门槛，而不是只看总分。这里仅比较算式与含义，不要求正式项目采用该公式。

按常规业务15分钟、复杂业务30分钟判断超时，是采用不同业务要求；它没有把各中心的业务构成变成相同，不能称为已完成第6课的直接标准化。

## 7. 评价办法可能影响行为

只奖励短等待，可能鼓励少接复杂业务；只报已服务记录，可能使放弃者的经历被忽略。这些是需要检查的风险，不是由当前数据证明的实际行为。

可以保留登记总数、纳入数和排除原因，单列放弃和各类业务数量，核对真实长等待是否被删除。现有资料没有未登记的申请和拒接记录，所以不能计算拒接率或声称已排除选择业务的可能；可以提出下一期补记哪些资料。

比较另一套合理规则，并解释结果与使用建议是否改变，就是本课的**敏感性分析**。一次充分的比较可以同时用于两套办法的比较与敏感性分析，不必重复制作表格。

## 用Python核对例子（可选）

代码只使用学习例子，不读取项目数据。分位数函数仍采用线性插值 `(n−1)p`，但不再把四分位距写死为五条数据的下标。

<details>
<summary>展开核算代码</summary>

```python
# learning-example
import json
import math
import statistics as st
x, y = [4, 5, 5, 6, 40], [8, 9, 10, 11, 12]
def quantile(values, p):
    if not 0 <= p <= 1:
        raise ValueError("p应在0到1之间")
    ordered = sorted(values)
    if not ordered:
        return None
    if any(not math.isfinite(v) for v in ordered):
        raise ValueError("请先核对无效数值")
    position = (len(ordered) - 1) * p
    lower = int(position)
    upper = min(lower + 1, len(ordered) - 1)
    return ordered[lower] + (position - lower) * (ordered[upper] - ordered[lower])
def profile(values):
    if not values:
        return dict.fromkeys(("mean", "median", "iqr", "over15"))
    q1, q3 = quantile(values, .25), quantile(values, .75)
    return {"mean": st.mean(values), "median": st.median(values),
            "iqr": q3 - q1, "over15": sum(v > 15 for v in values) / len(values)}
result = {"x": profile(x), "y": profile(y),
          "x_mean_after_exclusion": st.mean(x[:-1]),
          "x_over15_after_exclusion": sum(v > 15 for v in x[:-1]) / len(x[:-1])}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
