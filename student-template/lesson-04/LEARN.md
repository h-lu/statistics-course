# 第04课｜从统计指标到评价规则

前两课比较了均值、中位数和较长等待。本课进一步问：怎样把这些数字用于服务评价？需要区分“指标描述什么”和“达到什么条件就行动”。

|组别|五张已服务工单的等待（分钟）|
|---|---|
|X|4、5、5、6、40|
|Y|8、9、10、11、12|

## 1. 同一分布可以有不同侧面

**集中趋势**（central tendency）描述数值的大致位置；**离散程度**（dispersion）描述彼此差异；**右尾**（right tail）是较大数值的一端。

沿用第2课的线性插值约定：

|指标|X|Y|
|---|---:|---:|
|均值（分钟）|12|10|
|中位数（分钟）|5|10|
|第一四分位数（分钟）|5|9|
|第三四分位数（分钟）|6|11|
|IQR（分钟）|1|2|
|超过15分钟的比例|20%|0%|

X的中间等待较短，但平均等待与长等待比例较高。其第90百分位数为：

$$
Q_{0.9,X}=6+0.6(40-6)=26.4\text{ 分钟}.
$$

这里的0.6来自排序位置 $(5-1)\times0.9=3.6$ 。分位数算法的完整说明见[第2课](../lesson-02/LEARN.md)。

把40改为400，X的中位数和IQR不变，均值却变为84分钟。这说明中位数与IQR对这个极端值较**稳健**（robust），也说明需要另报能够反映长等待严重程度的信息。

## 2. 两种阈值，两个判断层次

**指标**（indicator）是为某个判断定义的可计算量；**阈值**（threshold）是触发判断或行动的界限。

本例规定：一张工单等待超过15分钟算长等待；一组工单中长等待比例大于10%时开展调查。

- 15分钟判断单张工单；
- 10%判断一组工单是否触发调查。

X有 $1/5=20\%$ 超过15分钟，因此触发；Y为0%，不触发。10%是教学设定的管理门槛，不是统计学统一标准。

等号也属于规则。若比例恰好10%，它没有满足“大于10%”；若改为“不少于10%”，结果才不同。先确定规则，再用恰好等于门槛的记录检查实现。

## 3. 为每个指标确定分母

已服务等待使用明确未放弃且等待有效的工单；放弃比例使用放弃状态已知的登记工单。分母为零时，结果未定义。

若统计“放弃或超时”，同一张工单满足两项也只计一次。已确认放弃、等待未知的工单仍满足这个条件；已确认未放弃、等待未知的工单则暂不能判断。

例如10张工单中3张放弃、4张超时，其中2张同时符合，则满足“放弃或超时”的有：

$$
3+4-2=5\text{ 张}.
$$

未知记录应单列，说明对所选分母和结果的影响。

## 4. 合成总分前，先解释尺度与权重

**尺度**（scale）包括单位与数值范围。等待可用分钟或秒，比例可写成0至1或百分数。多个指标合成前，要说明尺度转换、权重，以及一项较好结果能否抵消另一项严重问题。

另设演示总分：

$$
S=\frac{\text{平均等待}}{10\text{ 分钟}}+\text{放弃比例}.
$$

等待12分钟、放弃比例10%时， $S=12/10+0.10=1.30$ 。改用秒时，应同时将分子和分母换为720与600，得到同样结果。只改分子会改变等待的相对权重。

总分只是一种选择，也可以并列报告原指标。保留各指标有助于看见目标间的取舍。

## 5. 比较规则，再给建议

**敏感性分析**（sensitivity analysis）在有依据地改变指标、阈值或统计范围后重算，检查名单与建议是否变化。按业务使用不同阈值，与让各中心采用相同业务构成，是两个不同处理；第6课再讨论后者。

规则还可能产生**行为激励**（behavioral incentive）。例如只考核已登记工单的平均等待，可能需要监测机构是否少接困难业务。这是待核查的风险，现有表没有拒接记录，不能据此认定风险已经发生。

按[任务页](README.md)比较两套有理由的评价办法，保留登记数、已服务数、放弃数及业务构成。说明规则用于什么决定、计算依据和需要补充的信息。

<summary>自检做完后，展开答案与理由</summary>

1. X中位数5低于Y的10，Y均值10低于X的12。X的典型等待短，但有严重长等待，不能用一个指标宣称全面更好。
2. 按本课插值约定，第一、第三四分位数都是0，所以IQR为0；仍存在100这个长等待，不能说全部相同。
3. 超过5分钟为 $1/3$ ，不少于5分钟为 $2/3$ 。等号是否计入必须与规则一致。
4. 分子与标准化分母同时换单位，例如 $720/600+0.10=1.30$ 。只把12改为720而仍除以10会改变相对权重。
5. 需要各业务类别的数量、构成和类别内超时比例等资料，区分接了更容易的业务与同类业务确有改善；单看总比例不足。

```python
# learning-example
import json
import math
import statistics


def quantile(values, p):
    ordered = sorted(values)
    if not ordered:
        return None
    position = (len(ordered) - 1) * p
    lower = math.floor(position)
    upper = math.ceil(position)
    return ordered[lower] + (position - lower) * (ordered[upper] - ordered[lower])


def profile(values):
    values = [float(value) for value in values]
    if any(not math.isfinite(value) for value in values):
        raise ValueError("等待时间必须是有限数")
    if not values:
        return {"mean": None, "median": None, "iqr": None, "over15": None}
    return {
        "mean": statistics.mean(values),
        "median": statistics.median(values),
        "iqr": quantile(values, .75) - quantile(values, .25),
        "over15": sum(value > 15 for value in values) / len(values),
    }


x = [4, 5, 5, 6, 40]
y = [8, 9, 10, 11, 12]
result = {
    "x": profile(x),
    "y": profile(y),
    "x_mean_after_exclusion": statistics.mean([4, 5, 5, 6]),
    "x_over15_after_exclusion": 0,
}
print(json.dumps(result, ensure_ascii=False, sort_keys=True))
```
