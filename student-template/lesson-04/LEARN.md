# 第4课知识准备 · 不同指标为什么会给出不同评价

评价服务时，使用者可能关心多数人的等待，也可能关心总等待时间或少数人的长等待。统计量能描述不同方面，但不能替使用者决定哪个目标最重要。

## 1. 位置、分散程度和尾部

**集中趋势**描述数据大致位于哪里，常用均值和中位数表示。**离散程度**描述数值之间相差多大，常用标准差和四分位距表示。

**四分位距（IQR）**等于第三四分位数减第一四分位数，主要描述中间一半数据的跨度。等待时间分布的**右尾**是较长等待所在的部分。四分位距小，并不表示没有少数很长的等待。

**稳健性**关注少量极端变化对结果的影响。中位数较少受到单个极端值影响，但这不意味着可以忽略真实发生的长等待。

## 2. 两组服务记录的例子

另设两组已服务工单：X的等待为4、5、5、6、40分钟；Y为8、9、10、11、12分钟。先确定想评价什么，再比较下表。

| 指标 | X | Y |
|---|---:|---:|
| 均值（分钟） | 12 | 10 |
| 中位数（分钟） | 5 | 10 |
| 四分位距（分钟） | 1 | 2 |
| 等待超过15分钟的比例 | 1÷5＝20% | 0÷5＝0% |

X的均值为60÷5＝12，中位数为5；本例采用线性插值计算四分位数，四分位距为6−5＝1。Y的均值为10，中位数为10，四分位距为11−9＝2。

X中间位置的等待较短，但有一条40分钟的记录。只看中位数会更偏向X，只看均值或超过15分钟的比例会更偏向Y。这不是计算矛盾，而是指标关注的方面不同。

若删除X的40分钟记录，均值会变为5分钟，超过15分钟的比例变为0。数字变好并不说明服务改善，因为那次长等待仍真实发生。

## 3. 怎样把指标写成可以执行的规则

每个指标都应写明对象、计算方法、单位和分母。例如，“已服务工单中等待超过15分钟的比例”与“全部登记工单中放弃排队的比例”，采用的分母不同。

**阈值**是判断是否达到某个条件的数值界限。“超过15分钟”不含15；“不少于15分钟”包含15。两种规则可能得到不同结果，应明确选择。

若定义“放弃排队，或者等待超过相应业务参考时间”为需要关注的经历，同时满足两项的工单只计一次。某组没有可用记录时，比例不能计算；不能把它记成0并排为最好。指标相同可以并列，不必强行排出先后。

## 4. 多个指标可以怎样使用

可以用一张表分别报告均值、较高分位数、超时比例和放弃比例，不必合成总分。分钟与百分比不能未经处理直接相加。确实要计算总分时，应说明怎样转换到可比较的尺度、数值越大是否越好、各指标权重是多少，以及是否有不能被其他优点抵消的问题。

按业务分别采用15分钟、30分钟的参考时间，是对不同业务提出不同要求。它不是第6课将学习的、用相同业务构成进行比较的直接标准化。

## 5. 评价办法也可能影响行为

只奖励较短等待，可能使复杂业务受到忽视；允许删除最慢记录，可能鼓励选择性报告。这是需要防范的风险，不是已经由本例证明的实际行为。

可以保留登记总数、列出排除原因、单列放弃比例和复杂业务数量，检查评价有没有遗漏重要经历。比较另一套合理规则，就是对评价办法作**敏感性分析**。规则改变后，说明结果和建议怎样变化，而不只是重新列一张排名。

## 在项目中使用

提交可以照着计算的评价办法和实际结果，兼顾日常表现与长等待。比较另一套有依据的办法，并研究一个会影响结论的条件变化；同一项充分的比较可以同时完成这两项要求。中心排序只是描述结果，不能据此认定差异由工作人员造成。

```python
# learning-example
import json
import statistics as st
x, y = [4, 5, 5, 6, 40], [8, 9, 10, 11, 12]
def profile(values):
    ordered = sorted(values)
    return {"mean": st.mean(values), "median": st.median(values),
            "iqr": ordered[3] - ordered[1],
            "over15": sum(v > 15 for v in values) / len(values)}
# 这里IQR的下标仅适用于本例五个值的线性插值位置。
result = {"x": profile(x), "y": profile(y),
          "x_mean_after_exclusion": st.mean(x[:-1]),
          "x_over15_after_exclusion": sum(v > 15 for v in x[:-1]) / len(x[:-1])}
print(json.dumps(result, ensure_ascii=False, allow_nan=False))
```
