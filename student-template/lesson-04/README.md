# 第4课｜从指标到服务评价

为服务中心设计一套能计算、能解释的评价办法，再与另一套合理办法比较。

## 学习顺序

先读[知识讲解](LEARN.md)，完成手算与自检，再按本页设计正式分析。遇到具体操作问题查[运行帮助](SUPPORT.md)。已完成的作业无需重交。

## 数据与条件

本课数据为教学合成资料，不对应真实机构或个人。

使用第一期3,600张教学工单及窗口、业务表。常规15分钟、复杂30分钟是教学参考管理规则，字段见[数据说明](../data/service/README.md)。

已服务等待只纳入明确未放弃且等待有效的工单；放弃者的等待计到离开。比例按字段有效的指定范围计算，分母为零标为未定义。

## 标准任务

1. 明确使用者及要支持的决定，同时描述通常等待与较长等待。
2. 为每个指标写清记录范围、计算方法、单位、好坏方向；比例注明分子和分母。
3. 按中心给出实际结果，保留登记数、已服务数、放弃数及业务构成。
4. 实际比较另一套有理由的办法，解释指标、名单或建议怎样变化。
5. 提出采用条件、需要监测的问题及何时修改或暂停规则。

至少自主决定评价目标与指标，以及从数字到行动的规则。可并列指标、公布调查名单或采用总分；总分须说明尺度、权重和不可被抵消的严重问题。提交评价报告或规则摘要及计算证据。

## 运行与提交

在学生仓库根目录运行：

```sh
python3 scripts/course.py start 04
python3 scripts/course.py run 04
```

默认输出是分析起点，正式作品还需上述比较与建议。保存原始CSV，自己的结果放在 `lesson-04/artifacts/`。在 `submission.json` 中登记报告路径、产物和重建命令参数列表，完成后设 `status=complete`。

```sh
python3 scripts/course.py check 04
```

`check`核对状态、路径和文件，不重新运行分析。按[提交工作流](../docs/WORKFLOW.md)提交，标签沿用 `v2-l04-final`，修订保留旧标签。课堂选择题按教师开放场次完成，说明见[知识自查](../docs/KNOWLEDGE_CHECK.md)。

## 可选拓展

围绕同一作品增加一个有实际用途的检查，如另一种范围、指标或假设，并解释新增证据怎样影响建议。AI可辅助学习、编程与写作；分析选择和结果解释由你完成。评分与原作业要求不变。
