# 第12课支持路线 · 用模拟检查估计方法

## 先知道今天要交出什么

你要交出一份方法测试报告，而不是只计算一次均值。最终应有：不同总体情境和样本量下的方法性能表或图、可复现模拟程序，以及告诉报表使用者“何时可用、何时警告或追加数据”的说明。

入门跟做只建立一轮抽样和检查统计量，不能替代有基准的重复模拟研究。

## 核心概念与原理

**总体分布**描述所有单次成本；**样本均值的抽样分布**描述在同一抽样设计下反复抽样时，样本均值会怎样变化。两者不是同一组数。

**标准差**描述单次成本的离散程度；**标准误**描述估计量在重复抽样中的变动。独立同分布抽样时，均值标准误常用`s/√n`估计。它与成本单位相同。

由于本课有完整教学总体，可以计算真均值并核对估计量。偏差是重复估计的平均值减真值；均方误差同时包含方差和偏差。若两个方法估计的不是同一个总体参数，就不能直接按偏差排成一个排行榜。

## 基础练习（可信起点）：入门跟做

先在**仓库根目录**打开终端，完整运行：

```bash
python scripts/course.py start 12
python scripts/course.py run 12
```

第二条命令成功时，终端会提示概览已经写入`lesson-12/artifacts/starting_inventory.json`。打开这个文件；它只是数据起点，不是本课答案。若文件没有生成，先按后面的排错顺序处理，再继续。

### 第一步：认识三个教学总体

- **动作**：从仓库根运行`python scripts/course.py run 12`，打开概览并阅读数据说明；按`scenario`统计单位数、均值、中位数和高分位数。
- **目的**：确认三种总体的中心与尾部不同，并记录可核对的总体均值。
- **成功信号**：每个`scenario`有独立汇总；结果没有把三种总体混在一起。
- **反思**：高分位数明显不同而均值接近时，样本均值的稳定性是否一定相同？

### 第二步：手算标准误方向

- **动作**：用小例子`s=20`分别计算`n=25`和`n=100`时的`s/√n`。
- **目的**：分清增加每次样本量与增加模拟次数的作用。
- **成功信号**：样本量增至4倍时，估计的标准误约减半；单位仍是成本单位。
- **反思**：把模拟重复次数从1000增至4000，会不会让真实调查的标准误减半？

### 第三步：完成一次可复核抽样

- **动作**：选择一个总体和一个样本量，明确有放回或无放回，设置随机种子，抽一次样本并计算均值、样本标准差和标准误估计值。
- **目的**：让抽样设计、估计量和区间算法保持一致。
- **成功信号**：同一种子可得到同一结果；样本行数与设定相符；原始总体未修改。
- **反思**：无放回抽样比例很高时，独立同分布公式会遗漏什么？

### 第四步：扩展为重复模拟

- **动作**：重复抽样，保存每次样本均值、标准误估计值和区间是否覆盖真均值，再按情境与样本量汇总。
- **目的**：观察抽样分布并比较估计偏差、重复抽样所得估计值的标准差和区间覆盖率。
- **成功信号**：重复次数等于保存的模拟行数；估计量的抽样标准误由多次估计值的标准差近似；覆盖率分母是模拟重复次数。
- **反思**：覆盖率偏低可能来自哪些环节：抽样设计、尾部、标准误估计还是区间方法？

### 入门反思

写清本课的总体参数、估计量、一次估计值和模拟重复次数。再说明“样本量”和“模拟次数”分别影响什么。

## 标准任务（本课应完成）

1. 针对三种完整总体和多个有理由的样本量进行重复抽样，记录设计和随机种子。
2. 比较偏差、估计值的经验标准差、平均标准误估计和区间表现，并报告模拟误差。
3. 加入至少一个合理替代方案；若改为中位数或稳健位置，明确目标参数也随之改变。
4. 至少详细分析一种长尾或稀有高成本情境，并提供一个常规经验规则失效的反例。
5. 写出报表工具的使用条件、警告规则和追加数据建议。

## 提高与拓展（提前完成后）

- 比较有放回与无放回抽样，并在高抽样比例下检查有限总体修正。
- 对长尾总体比较常规区间和一种有依据的自助或稳健方法，保持目标参数一致。
- 根据蒙特卡洛标准误决定需要多少模拟重复，而不是任意选择大整数。
- 检查极少数高成本单位被抽中次数与区间失败之间的关系。

## 卡住时按顺序排查

1. 确认按`scenario`分组，没有从三种总体合并抽样。
2. 模拟结果完全相同时，检查随机种子是否错误地在循环内部每次重置。
3. 样本量不对时，检查抽样函数的`replace`设置和每轮是否重新抽样。
4. 覆盖率恒为0或1时，核对区间端点顺序、真值和分组键。
5. 标准误与经验波动差异大时，先确认两者单位、抽样设计和目标量相同。
6. 报告先按“在哪种总体、哪种样本量、哪种方法、表现怎样”组织。
