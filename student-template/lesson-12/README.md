# 第12课 · 换一批人，调查比例会差多少？

服务部门发现两次调查的需求比例不同。你要研究：同一种调查换一批人，结果通常差多少？增加调查人数，是否值得？

## 先按这条路线学

1. 打开 [LEARN](LEARN.md)，跟着图和小例理解本课概念。
2. 需要运行时查 [SUPPORT](SUPPORT.md)，不用先背命令和文件名。
3. 回到本页完成一个公平比较，再写出自己的建议。

## 数据是什么

继续使用第11课同一份4000人合成名册。每人下个周末至少需要一次服务记为1，否则记为0。A组3200人、B组800人，总体真实比例为41%。本课把已知真值作为模拟研究的基准。

数据仍在 `lesson-11/data/`，不生成新总体、不修改CSV。`frame.csv`是联系名册，`simulator/weekend_population.csv`是完整合成需求，`strata.csv`提供组人数与邀请费用。工具重复从同一总体抽人；不同次调查可以抽到同一个人，一次调查内部不重复。

## 基础练习：把六个样本列出来

[LEARN](LEARN.md)从2、4、6、8中抽两个数，逐步区分原始数据、样本均值和抽样分布。在学生仓库根目录运行：

## 标准任务：给部门一份调查稳定性建议

自主确定一个比较问题，例如“增加样本量能减少多少波动”或“同样邀请人数下，换取得方式有什么影响”。至少保留一个完整名册、完全回答的等概率样本作为基准。

1. 事先确定每个条件的邀请人数、取得机制、估计方法、重复次数和种子。至少一个比较只改变样本量、机制或估计方法中的一项。
2. 对每个条件反复调查，记录每一次估计。追踪第一轮，从回答人数与有需求人数解释该轮比例如何得到。
3. 比较真值、估计平均数、偏差、标准误以及邀请费用。展示估计分布；它的每个观测值是一轮调查的估计，不是一个人的需求。
4. 增加重复次数或另用一个事先选定的种子，检查主要判断是否只是模拟波动造成的。不追求次数越多越好。
5. 说明增加样本量或改用另一机制是否值得。自主选择一个有解释的精度目标或资源约束，说明建议适用于哪些条件。可以保留原方案或提出证据不足。

你决定要比较的样本规模/方法，也决定如何权衡精度与资源。完全回答是用来分清机制的理想基准；当前费用只统计邀请，不包含实现完全回答的追访成本，不能据此宣称它在现实中最便宜。

## 怎样得到一轮与多轮结果

[SUPPORT](SUPPORT.md)给出一个条件的完整示范：配置→重复抽样→读取第一轮→汇总与画图。你再按自己的问题另存第二份配置，保持其余条件相同。

每个条件生成 `plan.json`、`trials.csv`、`first_observations.csv` 和 `summary.json`。其中trials一行是一轮调查；first_observations一行是一个人的取得状态。两种行的含义不能混淆。

无人回答或某组无回答时，相应估计可为未知。记录多少轮未定义，不删掉这些轮后声称方法在所有调查中都适用。
