# 第12课 · 比较估计方法的适用条件

部门看到两批调查的需求比例不一样，想知道这是否只是抽样波动。继续固定L11的名册、周末和需求定义，通过反复抽样给出调查稳定性建议；把等机会抽样且人人回答作为参照，判断其他方法何时适用。

**本课问题：换一批样本，估计会差多少？**

所有数据均为教学合成。AI可以完成方案、代码、分析、写作和提交，不要求编程先修、提示词日志或额外答辩。先用本页明确目标，再自行选择工作方式；[LEARN](LEARN.md)解释概念，[SUPPORT](SUPPORT.md)按卡点提供帮助，不要求按统一操作顺序完成。

## 数据、条件与选择

仍读weekend_population.csv这4000人，每次都从同一份名单重新抽人，不能重新生成总体。用样本中有需求的人数除以实际回答人数得到一次估计。基准方案要求等机会抽人、抽中者全部回答；它用于分清换人带来的波动和调查方式造成的偏离。

[数据字段、抽人和回答规则](../data/inference-09-14/README.md)写明字段、预算和方法边界；最小程序为[analysis.py](analysis.py)，Python 3.10+标准库即可。共同数据是默认可运行路线，可替换计算工具，比较时应说明是否改变了目标人群、抽人或回答规则。

你选择值得付出成本的样本量，以及要比较的抽人和回答规则，或计算比例的方法。可比较80与200人，也可有理由选择其他规模；要保留一条完整名册、完全回答的概率样本作基准。

## 基础练习（可信起点）

从2、4、6、8等概率无放回取2个，六个均值3、4、5、5、6、7；平均5，标准误√(5/3)≈1.291。原始四个数的总体标准差√5≈2.236。 可以手算、读代码或请AI换一个例子解释。基础例子的运行不代表完成标准任务。

## 标准任务（本课应完成）

从固定总体重复抽样，记录每次比例。至少在一个公平比较中只改变样本量、抽人和回答规则，或计算比例的方法之一；报告真值、估计平均、偏差和标准误，展示一次样本估计与重复估计分布的不同。用同一个总体需求比例比较准确性和稳定性，解释增加样本量是否值得。保存随机种子设置以便重跑，记录重复次数，每次抽样都以人为单位；每次重复须抽出一批新样本，不能每轮重置同一个种子而反复得到同一批人。建议先500次再检查结果是否稳定，不比谁跑的次数多。

最低证据是：**追踪一个例子、做一个公平比较、说明限制**。这里公平比较指清楚写出保持什么相同、只改变什么；不是各方案必须得出同样结论。至少两项有后果的决定由你选择并解释，结论不同、有证据的保留意见或暂缓建议均可。

## 提高与拓展（提前完成后）

另设明确标注的稀有需求或相关单位小例，检查正态近似何时不适用；或者比较更大样本与较少偏差的取得机制，报告均方根误差。不要改变主任务的固定总体而不说明。
