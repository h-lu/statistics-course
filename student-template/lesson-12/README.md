# 第12课 · 比较估计方法的适用条件

成本管理团队想把均值和常用区间计算封装成通用报表。他们担心长尾和稀有高成本事件。你要提交一份方法测试报告，说明什么数据条件和样本规模下，这个工具可靠或应提醒使用者。

**数据均为教学合成，不代表真实机构或真实效果。** 本课可以全程使用AI完成编程、分析、写作与提交。报告中应说明主要分析结论、支持这些结论的结果，以及所用方法的假设和适用范围。

## 先想一想

样本量达到30，均值区间是否就一定可靠？先写出一种可能破坏这种经验判断的数据情境。

先打开[支持路线](SUPPORT.md)确认第一个动作和成功信号，再阅读[知识准备](LEARN.md)理解必要概念；计算和复杂实现可以交给工具。

## 学习路线与任务层级

前置回顾：[第10课](../lesson-10/README.md)中的蒙特卡洛模拟与随机种子，以及[第11课](../lesson-11/README.md)中的偏差与精度区别。先按[支持路线](SUPPORT.md)建立可信起点，再用[知识准备](LEARN.md)解释结果。

### 基础练习（可信起点）

按情境核对完整教学总体，完成一次明确有放回或无放回的抽样，并分清标准差、标准误和模拟重复次数。此层只建立分析起点，**不能冒充本课完成**。

### 标准任务（本课应完成）

完成下方三项分析任务：在多种样本量和总体情境下比较偏差、重复抽样所得估计值的标准差、各次样本的标准误估计和区间表现，加入合理替代方案，并写出失效情境、警告规则和蒙特卡洛误差。

### 提高与拓展（提前完成后）

比较有限总体修正、稳健区间或不同重尾情境；比较方法时保持目标参数一致，或明确说明目标量已经改变。提高任务应改变统计判断，不能只增加代码、模型或图表数量。

## 分析任务

1. 先固定目标：估计总体平均每次成本。利用三种完整教学总体计算可核对基准，明确每次抽样是有放回还是无放回，并使评价方法与该设计一致。

2. 实施有基准的模拟研究，比较样本量变化下估计偏差、重复抽样所得估计值的标准差、各次样本计算的标准误估计值和区间表现。加入至少一条有理由的替代分析方案，例如稳健位置报告或不同区间；若改变目标量必须明确标注。

3. 给工具写使用条件、失效情境与警告规则。结果需要区分样本量、尾部和方法的影响，并报告模拟重复次数、蒙特卡洛误差及一个反例。

## 需要你作出的选择

你选择样本量范围、重复次数和替代方法，依据是将来报表的精度/成本目标。比较中位数与均值时，不能把估计不同目标的偏差混在一个排行榜里。

报告用于比较的总体参数、随机种子、抽样方式和重复次数。至少详细分析一种长尾情境下的方法局限，不能只展示对称分布中的良好表现。 可以采用不同方法、得出不同结论，但需要说明依据。比较的方案或假设应与实际问题有关，并解释这些选择怎样影响建议。

## 成果要求

可复现模拟研究、方法性能表/图与一页使用说明，能让新使用者判断何时用常规报表、何时应改报或追加数据。

- [report.md](report.md)应面向使用者说明分析过程和结论；关键数字要注明对应结果文件，不能仅写“分析表明”。
- 保留可重新运行的分析代码，将必要结果保存在本课`artifacts/`；保留数据原貌，说明数据处理方法、随机种子和分析方法的适用条件。
- 区分观察结果、模型/情境假设与行动建议。完整总体是教学仿真的便利；真实应用没有已知真值。在这三种情境中表现良好，不代表方法适用于所有数据。模拟采用的抽样方式还应与实际分析假定的抽样设计一致。
- 核对报告中的替代方案和不同假设下的结果，确保结论与实际分析一致。
