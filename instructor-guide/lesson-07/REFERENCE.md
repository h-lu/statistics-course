# 第7课参考分析与评价要点 · 满意度调查的覆盖与无回答问题

本文件用于核对目标范围、分母与假设，不规定唯一满意定义或发布决定。任务见[学生README](../../student-template/lesson-07/README.md)，评分见[GRADING](../GRADING.md)。允许全程使用AI，不以把未知值“全部填好”评价质量。

## 运行与结果字段

从仓库根运行：

```bash
python instructor-guide/lesson-07/reference.py --student-root student-template
```

从教师目录运行 `python lesson-07/reference.py --student-root ../student-template`，独立部署改显式路径。标准库程序只输出JSON。`no_assumption_bounds` 是未知评价的界限，`scenarios` 是假设情景，`stratum_adjusted_under_within_cell_MAR` 是带组内代表性假设的估计；三者含义不同。

## 固定第一期数据与各自分母

满意参考定义为评分≥4；目标3,600张工单，邀请3,199张，回答2,099张，其中满意1,856张。

| 数量或比例 | 核对式 | 结果 |
|---|---|---:|
| 未受邀 | 3600−3199 | 401张 |
| 受邀无回答 | 3199−2099 | 1100张 |
| 全部无评价 | 401+1100 | 1501张 |
| 邀请率 | 3199/3600 | 88.8611% |
| 受邀者回答率 | 2099/3199 | 65.6143% |
| 全体评价覆盖 | 2099/3600 | 58.3056% |
| 回答者满意比例 | 1856/2099 | 88.4231% |

三类工单401+1100+2099=3600。调查表覆盖两期4,800条，不能把这4,800当成上述任何第一期目标分母。评分空白不是0或中立评分。

## 界限、情景与改变建议的条件

设无评价者满意比例为q，`P(q)=(1856+1501q)/3600`。在固定目标、满意定义和已记录结果可信的前提下，q从0到1得到51.5556%—93.25%。这是未知评价造成的范围，**不是置信区间、可信区间或未来时期保证**。代码字段名中的 `no_assumption` 意指未额外限制未知者的满意程度，不是免除所有数据有效性前提。

| 无评价者满意比例q（假设） | 全体满意比例（情景） |
|---|---:|
| 0.25 | 61.9792% |
| 0.50 | 72.4028% |
| 0.75 | 82.8264% |

以“全体达到80%”为**教师另设的演示门槛**，需要无评价工单中至少1024张满意，即 `q≥(0.8×3600−1856)/1501=1024/1501≈68.2212%`。不把80%写成正式项目的统一标准。学生应依据自己的用途解释门槛，也可提出同等有意义的问题。

分开两种未知过程时，`P=(1856+401q_U+1100q_N)/3600`；q_U指未受邀者，q_N指受邀无回答者。可以解释哪一组的未知结果更影响决定，但补采优先级还须考虑成本、联系成功率、可能的选择偏差和缺少支持的群体。

## 组内调整：假设在哪一步进入

参考按业务、等待是否超过15分钟和是否放弃排队分组，以各组回答者的满意比例代表该组全部目标工单，再按目标组人数加权，得86.7350%。这同时外推到未受邀及受邀无回答者；只论证第二步回答机制不足以支持全部外推。

“常规、超15分钟、放弃”组目标13张，仅3份评价；组内比例可能很不稳定。应展示 `target_n`、`responded` 与 `missing`，不能用总体大样本量掩盖稀疏组。完全无回答组无法从本组回答计算满意率；代码以 `target_units_in_zero_response_cells` 标记并不输出整体调整点值，不能把未定义值当0。

可见特征接近不证明MCAR/MAR成立；分组、加权、插补也不创造未测量信息。若假设给定特征后，满意者仍更容易被邀请或作答，原组内代表性假设就可能不成立。生成脚本描述教学机制，不是从观察数据识别出了现实无回答机制。

## 评价与反馈

认可界限与情景、分组调整、带假设插补等路线。合格要求是四类比例、至少两种实质不同假设及结果、经历与评价取得的比较、发布及有针对性的补采。高质量能解释建议敏感来源和零/少回答群体，并为补采写出更新或停止条件；不要求所有人采用同一种算法。

教师反馈可从“88.42%满意”改为：“本期取得评价的2099张中88.42%满意；全部3600张的满意比例还取决于1501张未知评价。在所声明的情景下，发布建议如何变化？”所有数字为教学合成结果，不能作为现实机构评价。讲解与核算见[RUNBOOK](RUNBOOK.md)及[审核记录](../lesson-05/REVIEW_05_08.md)。
