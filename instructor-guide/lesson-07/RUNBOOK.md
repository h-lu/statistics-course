# 第7课教学指导 · 满意度调查的覆盖与无回答问题

## 本课目标与范围

承接前面“分母和目标总体”的认识，让学生把已回答者描述、未知评价的范围、带假设的估计及补充调查建议分开。主要判断不是选择一个最复杂的插补算法，而是明确**哪个未知部分、哪项假设、在哪一步改变了结论**。

## 90分钟组织

| 时间 | 学生工作 | 可查看的学习证据 |
|---|---|---|
| 0—13分钟 | 核算邀请、回答及上下界例子 | 明确三个覆盖分母和满意比例分母 |
| 13—27分钟 | 限定第一期，统计三类记录并比较可见特征 | 未受邀＋受邀无回答＋回答＝目标总数 |
| 27—55分钟 | 至少两种有实质差别的未知评价假设，计算范围或估计 | 参数变化对应哪组工单，假设没有伪装成已观察事实 |
| 55—68分钟 | 发布建议、敏感阈值或同样有意义的问题、补采计划 | 说明何种未知情况会改变建议及优先了解谁 |
| 68—75分钟 | 核对分母、结果、代码与提交 | 空白不是0，输出数字对应所写假设 |
| 75—90分钟 | A/学习/B/反馈 | 正确率用于发现误解，不作个人掌握证明 |

观察报告草稿和结果即可，不要求学生逐人回答。可以让AI完成分组、加权或插补，但不能用增加方法数量代替两种实质不同假设。对信息不足的项目，诚实的宽范围与可执行补采建议就是成果；时间不足时复用读表，不删去假设比较。

## 完整讲解：先分母，再范围，再行动

### 1. 用100张工单建立三类记录

沿用LEARN算例：目标100张，邀请50张，其中40张回答、32张满意。列三类互斥记录：未受邀50、受邀无回答10、已回答40，合计100。

邀请率50/100=50%；受邀者回答率40/50=80%；全体评价覆盖40/100=40%；回答者满意32/40=80%。教师指出最后两个80%恰好相等，却描述不同事件和对象。未受邀不是受邀后无回答，二者不能用一个“回答率”混写。

### 2. 从未知评价推导上下界

令60张无评价工单中满意比例为q，则 `P(q)=(32+60q)/100`。q=0时32%，q=1时92%；这是固定目标工单中未知评价的逻辑范围，不是95%置信区间。范围端点不额外规定未知者满意程度，但仍以满意定义、目标覆盖和已记录答案有效为前提，不能简称“完全没有任何假设”。

取q=0.25与0.75，分别为47%与77%。两者不是两个观察到的总体真值，而是相应假设下的结果。q=0.5时为62%，便于核算公式。

### 3. 让条件变化真正影响发布建议

另设教学行动门槛70%（不是课程评分标准或真实业务规定）。需要 `q≥(70−32)/60=38/60≈63.33%`。学生应说明门槛依据和建议对它的敏感性，而不是教师统一指定所有报告使用70%。现有任务允许提出同样有实际意义的其他问题。

进一步分开两种缺失过程：令未受邀者满意比例为q_U，受邀无回答者为q_N，则 `P=(32+50q_U+10q_N)/100`。例如q_U=0.4、q_N=0.8时为60%；q_U=0.8、q_N=0.4时为76%。这说明把两种过程合并为同一个q是一种汇总，不能据此声称两个群体相同。未知者满意比例每提高0.1，在未受邀组使总体变动5个百分点，在受邀无回答组只变动1个百分点；实际补采还须考虑成本、可联系性和可能的再度无回答，不能只按人数机械决定。

## 方法支撑与纠错

完整案例直接描述回答者；推广到全部工单需要依据。分组调整可把各组回答者满意率按各组**目标工单数**加权，而不是再次按回答人数加权。其假设是给定用于调整的已观测特征后，有评价者能够代表无评价者；这里无评价包括未邀请与受邀无回答，不能只讨论后一个过程。

| 学生表述或结果 | 教师反馈 |
|---|---|
| “没有评价，所以不满意，填0” | 空白是未知；填0是一种极端情景，必须标明，不能当记录事实 |
| “两组特征相近，证明MAR/MCAR” | 特征比较只能提供诊断，不能观察不存在的评价；“随机”也不是随机抽样 |
| “插补恢复了每个人真实回答” | 插补给出模型或假设下的估计，不恢复已证实的个体事实 |
| 完全无回答组的满意率设为0或总体均值 | 前者不等于观测事实，后者增加外推假设；保留范围或明确假设 |
| 一组只有3个回答仍输出很多小数 | 同时报告组内目标数与回答数，讨论不稳定性，不把平滑当新增信息 |
| 补采只写“扩大样本” | 指明未受邀还是无回答、目标群体、联系方式、成本与更新/停止条件 |

不必在本课强制教授所有缺失数据算法。上下界与情景分析可以达到完整项目要求；采用复杂方法时检查新增假设，而不因名称高级加分。

## 知识、自查与评价

五组概念为目标与回答率分母、完整案例、缺失机制、插补与调整假设、敏感性及界限；分别进入三类记录表、回答者描述、假设说明、调整结果、发布与补采建议。现行自查不增加题量或版本；下一课可用“内连接丢掉无评价工单”复习这些知识。

最低完成要求：各比例描述对象清楚；至少两种实质不同假设有可重算结果；检查可见经历与评价取得的关系；解释何时建议会变或提出同等价值问题；补采具体到人群、不确定性和条件。高质量体现在把两种过程、稀疏组和成本纳入优先级，并据此修改表述，而不是必须采用多重插补或把范围缩窄。

## 发布前六问

1. **谁使用？** 满意度报告发布者决定发布哪些描述、何时需要补采。
2. **何种选择开放？** 满意定义、目标范围、调整分组、情景假设和补采优先级。
3. **计算后判断什么？** 可见信息能支持什么，未观测机制仍使哪些结论不确定。
4. **知识在哪里使用？** 三类记录与四个比例、组内代表性、上下界与情景表；自查核对概念而非代替论证。
5. **质量如何区分？** 合格有完整假设比较和建议，高质量解释决定敏感的来源并设计有针对性的补采。
6. **推进与复用？** 复用目标、分母及敏感性，新增评价缺失下的结论范围，衔接抽样及多表连接。
