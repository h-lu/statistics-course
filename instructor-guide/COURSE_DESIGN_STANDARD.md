# 统计学课程设计标准 V2

生效：2026-09-05。维护对象：16周32次课、学生模板、教师材料、形成性知识自查。V1已归档；本文件取代历史方案中冲突的课程设计要求。期末考试由教师另行设计，不在本标准中扩展。

## 首要原则

默认学生全程使用AI。每课的分析任务本身应达到明显超出传统本科练习的规模和复杂度；基础知识通过知识准备与课末自查落实，不作为项目难度的上限。AI可以读取完整仓库、编程、分析、写作与提交。学生对提交的分析结论、依据、适用范围和建议负责。

课程不以模型出错、AI不能一次完成、证明学生亲自编写或让任务恰好耗尽90分钟为目标。AI完成合格成果是允许的。开放项目的质量来自问题与证据的匹配、竞争方案的取舍和成果的实际用途。

## 课程基本安排

- 每课90分钟，每节课形成独立可提交的成果；可以使用同一组数据，并复用之前的分析程序。
- 留出背景与知识学习、项目工作、成果核对以及末尾约15分钟知识自查。前75分钟包含知识准备、工具操作和提交，不能误算成75分钟纯编程。
- 平时50分，期末50分；平时成绩包括课堂项目完成情况25分、五件代表作品质量25分。L01—02为不计分的入门项目；L03—32按五模块、每模块六课取最好五次。
- 每人一个私有学期仓库，课堂鼓励完成；不要求人人答辩、互评、提交完整AI对话或依赖学生口头回应。
- 小班够用即可。复用Gitea和现有自查系统，不因教学规范新建平台、复杂权限系统或新的数据服务。

## 项目设计的七项要求

1. **有明确用途的分析任务。** 说明报告面向谁、要解决什么问题、数据来自哪里，以及实际有哪些限制条件。成果可以是分析报告、调查方案、评价办法、实验方案、模型评估或决策工具，不统一要求制作网页。
2. **保留有意义的自主选择。** 学生可以自主确定研究问题、统计口径、分析方法或备选方案；这些选择应有实际依据，并能影响分析结果。任意指定参数再补写理由不构成开放性。教师材料说明可采用的方法和适用条件，不规定唯一结论。
3. **统计挑战居于主线。** 比较的可比性、目标冲突、抽样机制、方法假设、不确定性、稳定性、预测泛化或识别条件至少有一项是完成主任务必需的判断。不能仅以数据更多、代码更长、图更多或部署更复杂宣称升级。
4. **基础与应用相连。** 每课列出必须理解的概念、在项目中的用途及对应自查。复杂方法可以由AI实现；材料提供含义与适用条件的入口，不将函数名当成知识。
5. **成果可以复核。** 学生提交可阅读的报告和可复现的分析程序。关键数字能追溯，原始数据不被手工修改；比较替代分析方案或评估不确定性时，应解释这些结果对结论有何影响。不强制规定“3种模型、5张图”等数量要求。
6. **合理安排课堂时间。** 提前准备数据和通用工具。第一次课也有完整的数据分析任务；通过课前检查、复用程序和备用方案处理技术故障。时间不足时优先减少重复操作与无关任务，不擅自把分析任务降为简单计算。
7. **递进而不机械重复。** 学期映射记录新能力、前置知识和复用内容；可以探索、比较、设计、模拟、评估和修订。并非每课都必须发布突发事件和后到数据。

## 项目难度示例

| 不宜作为主要任务的练习 | 符合课程要求的分析任务 |
|---|---|
| 补均值、中位数函数，选A/B窗口 | 设计服务质量评价，比较不同目标及业务构成下的结果，说明制度可能产生的激励 |
| 算几个阈值的误报漏报 | 在有限复核容量和不同损失下比较告警策略，给出可试运行规则及新批次表现 |
| 运行t检验并判断显著 | 根据实验目的、效应大小、区间和实施成本决定是否推广，说明设计限制 |
| 训练模型并追求最高准确率 | 为指定使用条件建立无泄漏比较，检查校准、阈值后果和群体表现，决定是否部署 |

这些例子说明任务应达到的要求，不限定题材。不能用“AI依然能全做”判定任务不合格；应看分析问题是否有价值、重要选择是否有实际依据、评价标准能否区分成果质量。

## 学生材料

每课`README.md`直接面对学生，包含项目背景、可用数据、分析任务、成果要求和提交方式。按分钟切分的课堂安排和预计完成用时只放教师材料，不放学生 README。不要出现“教师材料不在这里”“后台审核”“延迟测试”等课程编写说明。文字遵循[术语与基础知识规范](TERMINOLOGY_AND_FOUNDATIONS.md)，逐段检查表达是否自然、含义是否明确。

`LEARN.md`包含背景、规范术语与通俗解释、必要公式含义、小例子、适用条件和学习问题。按必须理解、可以借助工具应用、按需深入区分层次；不为满足字数或概念数而堆砌。每课保留解释和自行判断的机会，AI始终可用。

每课的 `README.md` 和 `SUPPORT.md` 明确区分“基础练习（可信起点）”、“标准任务（本课应完成）”与“提高与拓展（提前完成后）”。基础练习帮助初学者开始并获得可核对的结果，不代表整课已完成；标准任务保留现行主项目的统计判断；提高与拓展为提前完成者提供更深的方法比较、敏感性、复现或决策任务。不以额外图表、代码行数或重复排版充当提高难度。

每课提供 `SUPPORT.md`，说明第一个动作、成功信号、从小例子到正式数据的过渡、至少一个结果核对和排错顺序。支持路线不预填正式项目的结论，也不取代学生的分析选择。

直接提供通用读表、检查和提交工具，不反复要求补写同一统计函数。示例程序应能运行，但不应被描述为项目的完整解答。自动检查核对提交配置与可复现性，不检查学生是否选择了教师偏好的方法。

数据是教学合成数据时，必须醒目标注，不冒充真实学校、真实企业或真实效果。说明字段、观测单位、抽样或生成背景、时间/组别含义、已知局限；教师参考计算不能把模拟设定误当学生已经识别出的事实。

## 知识自查

每课5个概念、A/B各5道平行题；建议先自行作答，再问AI解释概念。允许AI，不监控、不处罚直接代答。只给少量完成分，正确率用于反馈，不当作个人掌握的证明。

B更换情境或论证结构，不仅重排选项；干扰项应对应可信的混淆。后续课适当复习已有概念，不增加每课总题量。保留反馈到下一场次开始，不以立即关闭阻止学生回看。题库ID含版本，旧场次继续关联原题。

## 每课发布前六问

在各课教学指导中结合具体材料回答，无需另建审核平台：

1. 本课成果由谁使用，用于什么问题？
2. 哪些重要选择留给学生，何种情境依据支持它们？
3. AI完成所有计算后，仍须论证哪些统计问题？
4. 必须理解的知识在项目与自查的哪里出现？
5. 最低合格与高质量成果的实质差别是什么？
6. 本课相对前后课推进了什么，哪些工具可直接复用？

另外记录运行检查：数据文件存在、字段一致、程序能运行、参考分析可复现、关键解释准确、链接有效。区分“作者与AI运行验证”与“真实学生90分钟试教”，不得混称。不能用自动文件检查替代这六问的实质评审。

## 维护规则

现行教学进度表为`COURSE_MAP.md`，评分规则以`GRADING.md`为准。课次变化时同步更新进度表、学生材料、教师参考与自查题；旧版材料明确标注并归档，不维护多份内容不同的现行总计划。规范变更时记录日期、理由和受影响课次。

安全与部署仍遵守现有权限方案；课程重写不授权删除学生提交、账号、成绩或历史自查数据。不要指定本机、4080或NAS承担新用途。
