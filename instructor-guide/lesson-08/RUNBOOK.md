# 第8课教学指导 · 多表数据整合与统计指标核查

面向首次系统学习统计学的非统计专业学生。第1–7课已教，今天以小例子进入，再用自己的程序或AI实现完整两期分析，通用工具按需使用，避免重写全部上游程序。评分沿用GRADING，模块一代表作仍从03–08自选。学生入口：[README](../../student-template/lesson-08/README.md)，讲解页：[TEACHING_PAGES](TEACHING_PAGES.md)，过程答案：[EXERCISE_SOLUTIONS](EXERCISE_SOLUTIONS.md)。

## 目标、先修与本课新增能力

复用03修订/缺失/单位、04–06指标和比较、07调查分母；新增能力是在工单/接触/窗口日三个层次证明指标含义未被连接改变，解释覆盖和口径选择的后果。主任务必须处理完整两期，三层、实际核对、一个合理替代分析或解释与发布范围；提高任务不隐藏必做内容。

## 90分钟设计

| 时间 | 工作与出口 |
|---|---|
| 0–10 | 教师：问题与核心概念、2/10工单短示范、开放任务入口；只开场讲解 |
| 10–25 | 学生独立：自学小例/七表关系、清洗追加并回一条原记录核对 |
| 25–50 | 学生独立：工单/接触/窗口日分析，核对分母、总量和未匹配原因 |
| 50–63 | 学生独立：选left/inner或逐指标/共同完整比较，先预计再解释 |
| 63–75 | 学生独立：发布决定、代表作选择、自己的分析重现与提交 |
| 75–90 | 课堂选择题：A、概念学习、B与反馈 |


固定10分钟教师开场、65分钟学生操作、15分钟课堂选择题，总90；内部子段为设计分配；未经实班计时。较快者完成标准要求后进入EXERCISES一项挑战，课后可继续；不能把全挑战硬塞当堂。受阻者先完成手算/规则/发布草稿，再按原环境故障办法补程序。程序秒级运行不代表学习时长。

## 讲解和反馈重点

重复计权可能把均值变大或变小。修正不同工单数不能修正已重复的分子。未知窗口有效等待可留在全体描述，窗口报告单列未分配；满意比例以有效回答工单，不能用接触行当分母。工单date与contact_date分开；窗口归属是代理假设。无活动计划日保留，活动缺计划量为null，分钟/60；计划量并非实测个人投入。

正式数据没有最新版本冲突或无活动排班日等特定异常；用醒目标注的experiments反例迁移，不能假称正式CSV含这些问题。默认stop在冲突时停止；quarantine保留一致字段与存在事实，冲突字段不当真值。合理选择须说明发布范围和用途。

## 发布前六问

1. **用途：** 运营管理者用三层结果评价容量、流程或体验并理解暂缓范围。
2. **开放选择：** 主用途、连接范围、逐指标/共同集合与冲突处理，由测量含义支持；标准必比较一个合理方案。
3. **AI计算后：** 仍论证对象、分母、日期、未知信息、代理归属及计划工时的解释条件。
4. **知识位置：** 键表/核对体现主键基数，微例与等待权重体现单位，审计体现未匹配，三层结果体现总量核对；r3五概念平行自查。
5. **质量差别：** 合格完整两期三层和实际比较；高质量能反追数字、量化影响并明确下一期停止条件，允许有依据地暂缓。
6. **递进：** 03清洗、04–06比较、07调查分母合成可重跑流程，09概率将复用条件分母而非重复清洗。

核验记录见 [REVIEW_2026-10-09](REVIEW_2026-10-09.md)；冷读/作者运行不等同真实学生试教。

## 开放设计修订

继承旧课完整两期/三层/实算检查/范围的约束，不指定等待、办结、满意度的唯一套餐。学生至少自主决定用途/目标量与另一项重要选择，可选不同规则、方法、证据形式与报告结构。SUPPORT是遇阻资源，不作为所有人的执行脚本。原先试写的indicators和两配置一键方案已退出学生目录，完整流程只保留为教师一条参考；另一合理路线可得到不同数字，只要对象/分母/总量与范围有依据。教师讲解页只用于开场10分钟，学生65分钟内概念按需自学，不追加长讲。
