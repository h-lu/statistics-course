# 第32课参考分析与评价要点 · 面向新问题的统计分析综合报告

本文件提供一种可复现的参考分析方案，不规定学生必须采用相同的方法或结论。资料全部为合成教学数据。

## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-32/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

默认参考面向“可支付的调查费用上限6个损失单位，延迟成本另计3个损失单位”的新使用者：原调查费用8，因超过费用上限而不能采用。另明确提出一个教学备选报价：调查费用4、延迟成本3，高需求状态下阳性概率0.70、低需求状态下0.25；其性能为情境假设，不是估计值。重算样本信息价值为3.9，扣除调查费用4和延迟成本3后的净值为−3.1，即使调查费用可支付也不值得购买，维持当前pilot行动。默认费用敏感性分析可在给定的信号性能不变时将调查费用从0到6逐步改变，延迟成本始终另计3。可接受学生寻找不同可行调查或直接不购买，但必须重算性能和成本，而不是只修改预算文字。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

## 可接受的分析方案与评价重点

`reference.py`仅演示本课所提供的决策分析主题；自选其他主题时，应结合相应前课的参考分析评价，不能因数值与本课示例不符而扣分。评价时须核对新问题要求的具体修订，以及支持这些修订的分析结果。

合格报告应明确新的使用者，能够复现分析结果，并有实质修订；更好的报告还会根据不确定性和局限性，给出具体的使用条件及暂停使用或重新分析的规则。

## 常见误解与解释限制

允许复用并诚实标明来源。合成数据的结果只能作为教学示范；不能将教学示范作为真实政策有效或个体能够获益的证明。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
