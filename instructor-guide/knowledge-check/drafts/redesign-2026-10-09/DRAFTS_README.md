# 2026-10-09课堂选择题草稿：第1–4课

本文件只记录第1–4课的新题准备。全课程每次90分钟采用“教师开头10分钟 → 学生独立65分钟 → 课堂选择题15分钟”。这里为末段准备每课5组概念、A/B各5道题，共20组、40题。题中情境与数字均另设用于教学，不冒充真实机构资料。

草稿ID为 `v2-l01-r4` 至 `v2-l04-r4`，文件名 `lesson-v2r4-01.yml` 至 `lesson-v2r4-04.yml`。每份用JSON形式表达兼容YAML的对象；可用Python标准库直接读取，也通过现有 `QuestionBank` 解析与检查。

教师源位于本目录。服务准备副本位于 `stat-check/app/question_bank/drafts/redesign-2026-10-09/`，同名文件逐字节相同。实际loader只读取题库根目录与显式历史目录；不会扫描drafts。这四个新ID未进入 `BANKS` 或 `CURRENT_BANKS`，没有新建生产场次或部署。当前运行目录仍为第1–4、6–8课r3、第5课r4；全部历史ID与答案继续保留。

## 概念与A/B迁移

A侧重明确情境中的概念、记录或计算；B转向不同对象、定义冲突、测量假设或决策边界，不是简单重排选项。新题没有复制学生独立练习的成套数值。每题说明最佳选项与其余三项为何不合题设；错误选项使用具体混淆标记。

|---|---|---|---|

## 15分钟使用结构

保留现有时长 `attempt_a: 300`、`learn: 240`、`attempt_b: 300`，即A题5分钟、概念学习4分钟、B题5分钟，余1分钟查看反馈。推荐先自行判断，再在学习阶段向AI请求新例子；AI可全程使用，不监测或处罚代答。题目正确率用于反馈，不当作个人稳定掌握的证明，评分规则没有新增项目。

这些文件可供教师在课前阅读和检查；草稿准备不意味着已安装到线上新场次列表。旧场次继续按旧ID读取原题和原答案。
