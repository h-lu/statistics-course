# 第29课参考分析与评价要点 · 政策效果的双重差分评估

本文件提供一种可复现的参考分析方案，不规定学生必须采用相同的方法或结论。资料全部为合成教学数据。

## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-29/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

各地区等权时，以附近地区为对照的DiD估计约为−2.68752，以远处地区为对照约为−3.41153；按地区自助抽样得到的区间分别约为[−3.52196,−1.91271]和[−4.05864,−2.82250]。事前两窗口的安慰剂差约1.210/1.076，值得讨论。该差异不自动证明哪组对照正确。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

## 可接受的分析方案与评价重点

参考两时期组均值等价DiD、按地区重抽样1000次和完整各事件时点的组间差异结果。可采用固定效应、不同窗口、人口目标或不归因结论；必须讨论附近传播和远处可比性。

合格简报应说明对照组、目标权重、聚类单位和识别假设；更好的简报会根据更换对照组后的结果调整结论，不仅依赖一个p值判断政策效果。

## 常见误解与解释限制

相似的政策前趋势与平行趋势假设相容，但不能证明没有政策时两组必然保持平行趋势。事前检验未拒绝原假设，也不等于证明因果识别条件成立；合成数据的生成参数同样不能证明现实政策的因果效应。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
