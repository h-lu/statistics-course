# 第17课教学指导 · 配对、独立样本与重复测量的比较

## 课堂目的与备课

使用者与任务：分析组收到了三份“比较两种方式”的数据：同一参与者交叉试用、不同人的独立比较、对同一批参与者连续跟踪6周。经理发现不同脚本给出很不一样的区间，你需要制定可复用的比较分析说明并判断哪些结论可以发布。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/experiments/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-17.yml`，场次ID`v2-l17-r1`。课中不必另行发布材料，也不要求学生逐人口头汇报。

## 90分钟课堂安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并写下初步判断 | 投影“数据有288行，计算标准误时就能把样本量当作288吗？先指出必须弄清的一项数据结构。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 阅读LEARN并核算小例子 | 只澄清分母、单位、分析目标和适用条件；不替学生决定分析结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理普遍存在的软件操作问题 |
| 35—55 | 比较替代分析方案或进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 说明结果的不确定性和适用范围，提出建议 | 检查下方审核要点，不追求统一答案 |

| 75—80 | A版基础题5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版变式题5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要分析要求对所有学生相同，不转移为选做任务。若时间不足，减少重复排版、软件安装和无关图表，保留方法比较和假设检查。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

巡视时可结合正在形成的报告，检查下列问题；它们依次对应本课五组自查题。

- 什么关系构成配对？为什么不能仅凭行数相等就作配对分析？
- 怎样计算配对差的均值及其标准误估计值？
- 重复测量中的相关性会怎样影响标准误与有效信息量？
- 怎样区分方法、时期、顺序与残留效应？
- 比较六周平均效果与第六周效果时，为什么可能需要不同分析？

重点核对：报告每份数据中的独立单位数，按person_id识别配对，并检查不同试用顺序的结果。把保留与忽略相关性的分析作比较，是为了说明假设如何影响推断。

需要说明的局限：交叉设计需要考虑时期与残留效应；个人汇总可能舍去时间变化信息；稳健标准误也不修复目标错配或非随机选择。

## 课程设计的六项检查

1. **谁使用、解决什么问题？** 分析组收到了三份“比较两种方式”的数据：同一参与者交叉试用、不同人的独立比较、对同一批参与者连续跟踪6周。经理发现不同脚本给出很不一样的区间，你需要制定可复用的比较分析说明并判断哪些结论可以发布。
2. **哪些重要选择留给学生、依据是什么？** 配对差、独立Welch比较、个人汇总、混合效应或采用聚类稳健标准误的方法均可，取决于目标与结构；重复测量的平均效应与随时间变化效应不是同一问题。
3. **AI完成计算后仍须论证什么？** 报告每份数据中的独立单位数，按person_id识别配对，并检查不同试用顺序的结果。把保留与忽略相关性的分析作比较，是为了说明假设如何影响推断。 交叉设计需要考虑时期与残留效应；个人汇总可能舍去时间变化信息；稳健标准误也不修复目标错配或非随机选择。
4. **知识在项目与自查哪里出现？** 配对与独立样本用于结构诊断，对应第1组A/B；差值的均值与标准误用于交叉数据比较，对应第2组A/B；重复观测与相关用于6周研究，对应第3组A/B；时期、顺序与残留效应用于AB/BA检查，对应第4组A/B；方法假设与目标量用于方法选择说明，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要分析任务：数据分组与重复测量情况表、三类比较的可复核结果，以及忽略配对或重复观测相关性时的对照结果，以及分析方法选择说明。 高质量成果进一步说明替代分析方案为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 把L16团队依赖推广到配对、重复和不同目标量；为L18样本量设计避免把观测行数当独立实验数。

## 运行与内容检查

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生`analysis.py`是只依赖标准库的示例代码；运行后仍需按本课要求完成分析和报告。
- 教师`reference.py`运行参考分析，输出保存在`reference_result.json`；结果解释与其他可采用的方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
