# 课程作者工作规则

完整阅读`COURSE_DESIGN_STANDARD.md`、`COURSE_MAP.md`、`TERMINOLOGY_AND_FOUNDATIONS.md`后再编写课次。编写、改写或审核学生材料时，还须阅读并遵循`STUDENT_MATERIALS_STANDARD.md`。正文规范是唯一现行依据，历史归档不得反向覆盖新标准。

所有主任务按学生全程使用AI设计；学生应完成有实际用途的统计分析，而非补函数、指定算式或填模板。保留会影响结论的开放选择，评价统计依据，不评价是谁打字、模型是否出错或是否耗满90分钟。

学生材料与教师材料分离。学生材料不出现授课指导、参考答案、题库部署、内部审查记录等教师专用说明。使用统计学通行术语，配以通俗解释；按《术语与基础知识规范》和《面向初学者的学生材料编写规范》逐段检查标题、正文、代码输出与自查题，不套用咨询或产品开发话术。首次出现的关键概念须解释，不能用自创词或未经解释的缩写代替。基础知识不是项目难度上限。

学生阅读顺序为 `README.md` 了解任务 → `SUPPORT.md` 获得第一份可核对的结果 → 按需读 `LEARN.md` 理解概念 → 返回 README 完成标准任务。逐课提示、通用指南和 `start` 输出保持一致。按分钟拆分的课堂安排属于教师规划，不放进学生 README；学生只需看到操作与知识自查入口。

每课编写后执行规范六问，并在`lesson-NN/RUNBOOK.md`记录具体回答。核对知识映射、数据字段、项目要求、题库和评分一致；代码与数据需要试跑。运行成功不等于统计判断已审核，也不等于学生90分钟实测通过。

普通编辑不授权部署或批量改学生仓库。保留归档与原答题记录；当前题库版本与双份文件约定见`knowledge-check/question-bank/SCHEMA.md`。已发布的V1、V2初版和各修订版均保持原样，改题必须另设版本ID；旧场次继续使用原题。不在教师文档写真实口令、令牌或私钥。设备用途由教师决定。
