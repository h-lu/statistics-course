## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-30/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可接受的分析方案与评价重点

参考分析比较三种具有明确统计含义的预测方法。确定方法后，在每个历史预测时点仅用当时已知的数据更新参数，并用校准期误差生成预测区间。允许指数平滑、ARIMA、机器学习或其他有根据方法；所有候选必须同跨度、同一预测时点。

合格的历史评估应保持时间顺序，并报告预测区间覆盖率；更好的分析会根据覆盖不足的情况调整容量余量或复核规则，同时考虑实际资源约束，而不是只增加模型复杂度。

## 常见误解与解释限制

预测准确不意味着识别了政策原因。后期覆盖不足时应如实报告，不事后加宽区间再称其为预先验证。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
