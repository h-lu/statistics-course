## 冷读发现与修改

| 模拟疑问或可复现问题 | 调整 |
|---|---|
| 已有指标表是否就是评价办法？ | 保留目标、数据范围、判断与行动条件，教师指标reference与完整walkthrough明确分工。 |
| 平均等待短，就代表总等待少吗？ | 用记录数区分总和与均值、超时数量与比例，不把中位数说成多数记录都等于它。 |
| 时间15分钟和比例10%是否都包含等号？ | 两个严格不等号分开讲；10张中1张超时等于10%，不触发大于10%的条件。 |
| 未触发是否就是全面合格？ | 明确只判断这一项条件，不忽略放弃和其他维度。 |
| 综合分怎样转换单位？ | 先手算12/10+0.10=1.30，再用720/600验证改用秒时等价；说明方向、权重和能否抵消，不强制使用总分。 |
| 学习代码换成2条或6条还可以用吗？ | 四分位数采用通用线性插值，不再固定五条记录的下标；原五值结果不变。 |
| 没有拒接记录，怎样计算拒接率？ | 区分已有数据核查与下一期补记，不要求编造，不能用现有工单证明不存在选择。 |
| 一页是否必须装下整份报告？ | 一页仅指规则摘要；详细结果可放正文及结果文件。 |
| 教师函数复用出现状态2或未知中心D | 实际构造输入得到200%放弃比例，或输入1张却汇总0张。现在先校验并明确报错；主命令原本使用已验证数据，因此不是说现有CSV算出这些错误。 |
| 导入学生程序就会读表并写结果 | 分为read/build_overview/main；导入不读数据、不写结果，必要列缺失有明确提示。保留“起始概览，不是项目答案”。 |

原始任务全部保留：明确用途和可执行规则、同时描述日常及长等待、保留放弃/业务构成/记录数、两套实际办法与至少一项敏感性判断、防范措施和调整条件。一个充分比较仍可同时满足两项；不强制新总分、插补、排名反转、七表整合、图数或新评分。

## 学习例子实际解答

X=[4,5,5,6,40]、Y=[8,9,10,11,12]。X总和60、均值12、中位数5、四分位距6−5=1；Y总和50、均值10、中位数10、四分位距11−9=2。超15分钟分别1/5和0/5。删掉40后X均值5和超时0%只说明记录被排除，不是服务改善。

40改80时，中位数5和四分位距1不变，总和100、均值20。3张放弃、4张超时、其中2张重叠的10张工单，至少一项事件为(3+4−2)/10=50%。10张中2张恰好15、1张16，其余小于15，超时1/10=10%，未触发严格大于10%。

综合分12/10+0.10=1.30，与720/600+0.10相同；时间换秒却仍除10，或把10%写作10，都改变取舍。该例使用与X、Y无关的数据，避免将没有放弃者的五值例子与10%放弃混同。

本地新增测试的六值IQR预期曾误写12.25。按位置1.25和3.75重算，Q1=2.5、Q3=14、IQR=11.5，修正的是新增测试预期，不是把正确算法改成错误答案。此项不是旧教材错误。
