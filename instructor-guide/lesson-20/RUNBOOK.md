# 第20课教学指导 · 序贯分析与实验停止规则

## 课堂目的与备课

使用者与任务：产品组每天看到新实验数据，想“达到显著就停”，但每多运行一天都要花资源。你要为持续更新的试验制定停止和发布规则，并说明现有30天证据是否足以行动。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/experiments/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-20.yml`，场次ID`v2-l20-r1`。课中不必另行发布材料，也不要求学生逐人口头汇报。

## 90分钟课堂安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并写下初步判断 | 投影“每天做一次5%检验、第一次显著就宣布成功，与第30天只检验一次是同一个统计程序吗？先预测哪个更容易出现假警报。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 阅读LEARN并核算小例子 | 只澄清分母、单位、分析目标和适用条件；不替学生决定分析结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理普遍存在的软件操作问题 |
| 35—55 | 比较替代分析方案或进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 说明结果的不确定性和适用范围，提出建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重跑、提交报告与分析结果 | 课末检查完成记录；提交服务拥堵时先记录本地完成情况；文件检查通过不等于掌握知识 |
| 75—80 | A版基础题5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版变式题5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要分析要求对所有学生相同，不转移为选做任务。若时间不足，减少重复排版、软件安装和无关图表，保留方法比较和假设检查。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

巡视时可结合正在形成的报告，检查下列问题；它们依次对应本课五组自查题。

- 反复查看并在显著时停止，为什么会改变整体错误率？
- 预定查看时点与α分配怎样构成可执行的停止规则？
- 累计样本量怎样避免重复计数？分配人数与观察人数为什么要分开？
- 失访会怎样改变转化率的分母和结局含义？
- 除了统计门槛，成本、风险和实际价值如何影响停止决定？

重点核对：报告各组累计分配人数、观察人数和用于计算比例的分母，并区分单次检验与整体规则的α。报告模拟次数及模拟误差。汇总表无法恢复缺失者的真实转化结果；不能把缺失填0后称为无须假设的真实转化效应。

需要说明的局限：“被确认转化”包含观测机制，是可计算的复合结局；真实转化效应仍依赖缺失假设。在这30天数据上模拟规则执行，只说明根据这些已观察数据会何时停止；不能据此知道另一次实验的结果。

## 课程设计的六项检查

1. **谁使用、解决什么问题？** 产品组每天看到新实验数据，想“达到显著就停”，但每多运行一天都要花资源。你要为持续更新的试验制定停止和发布规则，并说明现有30天证据是否足以行动。
2. **哪些重要选择留给学生、依据是什么？** 选择主要结局、查看频率、因有效、无效或安全问题而停止的条件和错误控制目标。简单三次预定查看可以合格，不要求高复杂度序贯算法；但必须说明为什么概率控制对应实际规则。
3. **AI完成计算后仍须论证什么？** 报告各组累计分配人数、观察人数和用于计算比例的分母，并区分单次检验与整体规则的α。报告模拟次数及模拟误差。汇总表无法恢复缺失者的真实转化结果；不能把缺失填0后称为无须假设的真实转化效应。 “被确认转化”包含观测机制，是可计算的复合结局；真实转化效应仍依赖缺失假设。在这30天数据上模拟规则执行，只说明根据这些已观察数据会何时停止；不能据此知道另一次实验的结果。
4. **知识在项目与自查哪里出现？** 可选停止与重复查看用于规则比较，对应第1组A/B；序贯规则与α分配用于可执行的实验方案，对应第2组A/B；累计样本量与独立单位用于逐日累计计算，对应第3组A/B；失访与意向性分析（复习）用于结局定义与缺失值敏感性分析，对应第4组A/B；停止决定与实际价值用于行动建议，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要分析任务：停止规则说明、逐日累计结果、停止规则的执行记录与零效应模拟、实际停止/继续决定及对未观察结果的敏感性。作为模块三代表作时保留原始方案和修订说明。 高质量成果进一步说明替代分析方案为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 整合L16—19的分配、失访、效应、功效和多重检验问题，把持续决策程序作为统计分析方案；进入回归预测前完成实验模块代表作。

## 运行与内容检查

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生`analysis.py`是只依赖标准库的示例代码；运行后仍需按本课要求完成分析和报告。
- 教师`reference.py`运行参考分析，输出保存在`reference_result.json`；结果解释与其他可采用的方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
