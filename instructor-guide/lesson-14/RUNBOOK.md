# 第14课教学指导 · 在有限预算下设计一项调查

## 课堂目的与备课

使用者与任务：服务团队接受了自愿调查不能自动代表所有人的结论，批准6000预算开展新一轮调查。不同层联系成本、回答率和满意度波动不同；还需保证小层有可用结果。你要提交可以实际抽出名单的方案。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/inference/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-14.yml`，场次ID`v2-l14-r1`。课中不必另行发布材料，也不要求学生逐人口头汇报。

## 90分钟课堂安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并写下初步判断 | 投影“把预算平均分给六层，是最公平也最精确的方案吗？先指出至少一个可能冲突的目标。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 阅读LEARN并核算小例子 | 只澄清分母、单位、分析目标和适用条件；不替学生决定分析结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理普遍存在的软件操作问题 |
| 35—55 | 比较替代分析方案或进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 说明结果的不确定性和适用范围，提出建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重跑、提交报告与分析结果 | 课末检查完成记录；提交服务拥堵时先记录本地完成情况；文件检查通过不等于掌握知识 |
| 75—80 | A版基础题5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版变式题5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要分析要求对所有学生相同，不转移为选做任务。若时间不足，减少重复排版、软件安装和无关图表，保留方法比较和假设检查。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

巡视时可结合正在形成的报告，检查下列问题；它们依次对应本课五组自查题。

- 怎样划分抽样层并在层内实施随机抽样？
- 总体均值精度、各层结果的可用性和成本如何影响样本分配？
- 纳入概率、设计权重和无回答调整有什么区别？
- 预算固定时，怎样比较不同抽样方案的近似精度？
- 设计效应和无回答会怎样改变预期精度与偏差？

重点核对：检查抽样框是否重复，保存层内无放回抽样的随机种子与各层纳入概率。预计完成人数不等于实际一定能完成的人数。给出近似误差限或精度目标，并说明所用标准差与回答率的来源。

需要说明的局限：以回答者标准差规划可能低估未回答者差异；概率抽样解决纳入机制，不自动解决调查中的无回答。参考精度是简化设计近似，不代表任何复杂回答概率模型都满足。

## 课程设计的六项检查

1. **谁使用、解决什么问题？** 服务团队接受了自愿调查不能自动代表所有人的结论，批准6000预算开展新一轮调查。不同层联系成本、回答率和满意度波动不同；还需保证小层有可用结果。你要提交可以实际抽出名单的方案。
2. **哪些重要选择留给学生、依据是什么？** 可采用比例、等额、考虑成本的最优分配或多目标分配。最低每层预计完成15是当前约束，可讨论提高它的成本；不能用同一个号码重复抽出来填满样本。
3. **AI完成计算后仍须论证什么？** 检查抽样框是否重复，保存层内无放回抽样的随机种子与各层纳入概率。预计完成人数不等于实际一定能完成的人数。给出近似误差限或精度目标，并说明所用标准差与回答率的来源。 以回答者标准差规划可能低估未回答者差异；概率抽样解决纳入机制，不自动解决调查中的无回答。参考精度是简化设计近似，不代表任何复杂回答概率模型都满足。
4. **知识在项目与自查哪里出现？** 分层随机抽样用于实施抽样，对应第1组A/B；样本分配用于方案比较，对应第2组A/B；纳入概率与设计权重用于名单与权重，对应第3组A/B；精度与成本用于近似误差限与预算，对应第4组A/B；设计效应与无回答用于敏感性分析，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要分析任务：调查实施方案、各层分配与成本表、可重跑抽样程序和抽中名单，以及预算/回答率变化时的调整规则。 高质量成果进一步说明替代分析方案为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 将L11的代表性诊断、L12/13精度转为调查设计；完成模块二作品选择，复用权重与模拟工具，而不是再交一份同样的估计报告。

## 运行与内容检查

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生`analysis.py`是只依赖标准库的示例代码；运行后仍需按本课要求完成分析和报告。
- 教师`reference.py`运行参考分析，输出保存在`reference_result.json`；结果解释与其他可采用的方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
