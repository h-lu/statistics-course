# 第15课教学指导 · 设计能回答实际问题的随机实验

## 课堂目的与备课

使用者与任务：服务团队准备试用一套处理工具，希望知道它能否降低处理时间并值得推广。480名成员分属24队、4区组；同队会交流工作方法。你要在看实验结果前提交可执行的实验方案，而不只是随机分A/B。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/experiments/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-15.yml`，场次ID`v2-l15-r1`。课中不必另行发布材料，也不要求学生逐人口头汇报。

## 90分钟课堂安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并写下初步判断 | 投影“将480人随机分成两组，就一定足以得到可信的推广结论吗？先指出一个会使实际实施偏离分配的环节。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 阅读LEARN并核算小例子 | 只澄清分母、单位、分析目标和适用条件；不替学生决定分析结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理普遍存在的软件操作问题 |
| 35—55 | 比较替代分析方案或进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 说明结果的不确定性和适用范围，提出建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重跑、提交报告与分析结果 | 课末检查完成记录；提交服务拥堵时先记录本地完成情况；文件检查通过不等于掌握知识 |
| 75—80 | A版基础题5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版变式题5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要分析要求对所有学生相同，不转移为选做任务。若时间不足，减少重复排版、软件安装和无关图表，保留方法比较和假设检查。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

巡视时可结合正在形成的报告，检查下列问题；它们依次对应本课五组自查题。

- 本课的实验单位、随机化单位和观测单位分别是什么？
- 随机分配处理和从总体随机抽样分别解决什么问题？
- 区组随机化为什么可能提高组间可比性与估计精度？
- 怎样明确实验要估计的人群、处理、对照、结局和时间？
- 组间污染、未按方案实施和事后选择指标会怎样影响实验解释？

重点核对：明确随机化单位与分析单位；种子与分配比例；预定结局和缺失处理；解释为什么设计可以回答目标问题而不是只看分组均值接近。

需要说明的局限：随机化使处理分配遵循预先规定的随机机制，但不保证每个变量完全相同、所有人依从或团队互不影响。未看到结果时无法保证显著，也不应承诺一定有效。

## 课程设计的六项检查

1. **谁使用、解决什么问题？** 服务团队准备试用一套处理工具，希望知道它能否降低处理时间并值得推广。480名成员分属24队、4区组；同队会交流工作方法。你要在看实验结果前提交可执行的实验方案，而不只是随机分A/B。
2. **哪些重要选择留给学生、依据是什么？** 可选团队或个人随机、不同区组/匹配，依据是干扰与实施条件。主要结局、成本门槛和分析方案在看结果前确定；不能用后续结果为当前实验方案挑指标。
3. **AI完成计算后仍须论证什么？** 明确随机化单位与分析单位；种子与分配比例；预定结局和缺失处理；解释为什么设计可以回答目标问题而不是只看分组均值接近。 随机化使处理分配遵循预先规定的随机机制，但不保证每个变量完全相同、所有人依从或团队互不影响。未看到结果时无法保证显著，也不应承诺一定有效。
4. **知识在项目与自查哪里出现？** 实验单位与随机化单位用于实验方案及分配程序，对应第1组A/B；随机化用于分配名单，对应第2组A/B；区组随机化用于四区组安排，对应第3组A/B；目标效应用于主要目标量，对应第4组A/B；干扰、污染与预先计划用于防止组间污染的措施与预分析计划，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要分析任务：实验方案、分配名单与代码、基线平衡描述、预分析计划及实施偏离登记表（空模板即可）。本课不需要实验后结果。 高质量成果进一步说明替代分析方案为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 从L14抽样设计转到处理分配，区别代表性与因果可比性；L16复用实验方案，检查实际实施差异。

## 运行与内容检查

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生`analysis.py`是只依赖标准库的示例代码；运行后仍需按本课要求完成分析和报告。
- 教师`reference.py`运行参考分析，输出保存在`reference_result.json`；结果解释与其他可采用的方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
