# 第9课教学指导 · 筛查阳性之后怎样安排复核

## 课堂目的与备课

使用者与任务：设备保障部门每天面对2000台来自不同来源的设备。初筛阳性不能直接停机，准确复核每天只有1440分钟；初筛预算4500。部门需要一套明天可以执行的初筛与复核方案，兼顾漏掉故障的后果和不必要停机。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/inference/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-09.yml`，场次ID`v2-l09-r1`。不需要课中秘密事件、高频逐人回应或新平台。

## 90分钟建议安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并留下首次判断 | 投影“一张阳性通知在不同来源组意味着同样的风险吗？先预测有限复核名额应怎样分配，再读知识准备。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 读LEARN并核算微例 | 重点讲清分母、单位、目标和适用条件；不代选项目结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理常见软件问题 |
| 35—55 | 比较备选方法，进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 整合不确定性、局限性和行动建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重新运行、提交报告与证据 | 课末检查完成记录；技术问题暂未解决时，先根据本地结果记录完成情况，不将自动检查通过视为已经掌握知识 |
| 75—80 | A版5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要任务难度不转移到选做。若时间受阻，减少重复排版、软件安装和无关图表，保留不同统计方法或方案之间的关键比较。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

- 条件概率：在每组流量表中查看是否实际使用，对应本课自查概念。
- 基础率：在三种基础率情境中查看是否实际使用，对应本课自查概念。
- 敏感度与特异度：在初筛性能核对中查看是否实际使用，对应本课自查概念。
- 贝叶斯公式与阳性预测值：在阳性后的复核排序中查看是否实际使用，对应本课自查概念。
- 期望损失与容量：在可实施复核方案与损失比较中查看是否实际使用，对应本课自查概念。

重点核对：至少比较一种备选复核方案，计算其费用与预期损失。说明条件概率的分母，并将未能复核的初筛阳性设备中预计存在的故障计入漏检数量。

解释中的常见问题：历史验证人群与现场可能不同；规划基础率和损失是条件输入。复核准确、同组设备可交换是本次简化，阳性预测值不是某台设备已经故障的确定判断。

## 发布前六问：课程设计检查

1. **谁使用、解决什么问题？** 设备保障部门每天面对2000台来自不同来源的设备。初筛阳性不能直接停机，准确复核每天只有1440分钟；初筛预算4500。部门需要一套明天可以执行的初筛与复核方案，兼顾漏掉故障的后果和不必要停机。
2. **哪些重要选择留给学生、依据是什么？** 你决定复核优先目标、分组初筛方式和必要的最低服务份额。公平服务与期望损失最小可能冲突；份额须由部门用途解释。可以优化，也可以比较清晰的候选规则；无需假定两种检验独立。
3. **AI完成计算后仍须论证什么？** 至少比较一种备选复核方案，计算其费用与预期损失。说明条件概率的分母，并将未能复核的初筛阳性设备中预计存在的故障计入漏检数量。 历史验证人群与现场可能不同；规划基础率和损失是条件输入。复核准确、同组设备可交换是本次简化，阳性预测值不是某台设备已经故障的确定判断。
4. **知识在项目与自查哪里出现？** 条件概率用于每组流量表，对应第1组A/B；基础率用于三种基础率情境，对应第2组A/B；敏感度与特异度用于初筛性能核对，对应第3组A/B；贝叶斯公式与阳性预测值用于阳性后的复核排序，对应第4组A/B；期望损失与容量用于可实施复核方案与损失比较，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要任务：一页复核方案、各组初筛与复核人数及结果表、预算核对，以及基础率变化下的方案表现。方案应能回答工作人员先复核谁、名额不足时如何取舍。 高质量成果进一步说明备选分析方法为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 复用L05误报漏报和容量，新增条件概率反向、基础率修正及多来源资源安排；为L10损失模拟、L23概率决策铺路。

## 试运行与检查记录

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生示例代码`analysis.py`采用Python标准库，可直接运行；学生仍需完成本课分析任务。
- 教师`reference.py`实际计算参考分析方法，输出保存在`reference_result.json`；解释与可接受的分析方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
