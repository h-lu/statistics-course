# 第11课教学指导 · 自愿调查能够代表哪些人

## 课堂目的与备课

使用者与任务：校园服务团队收到一批自愿满意度问卷，准备向抽样框内3600人公布总体满意度并分配改进经费。问卷不是随机抽取，回答比例在不同校区和学习阶段之间不同。你要决定怎样报告，以及还缺什么信息。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/inference/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-11.yml`，场次ID`v2-l11-r1`。课中不必另行发布材料，也不要求学生逐人口头汇报。

## 90分钟课堂安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并写下初步判断 | 投影“问卷数量超过1000，能否直接称为全体3600人的意见？先写出需要核对的一个代表性问题。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 阅读LEARN并核算小例子 | 只澄清分母、单位、分析目标和适用条件；不替学生决定分析结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理普遍存在的软件操作问题 |
| 35—55 | 比较替代分析方案或进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 说明结果的不确定性和适用范围，提出建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重跑、提交报告与分析结果 | 课末检查完成记录；提交服务拥堵时先记录本地完成情况；文件检查通过不等于掌握知识 |
| 75—80 | A版基础题5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版变式题5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要分析要求对所有学生相同，不转移为选做任务。若时间不足，减少重复排版、软件安装和无关图表，保留方法比较和假设检查。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

巡视时可结合正在形成的报告，检查下列问题；它们依次对应本课五组自查题。

- 目标总体与抽样框有何区别？本课结论可以推广到哪些人？
- 哪些人更可能回答问卷？这种差异为什么可能造成选择偏差？
- 后分层权重调整了什么，又不能解决什么问题？
- 标准误小或置信区间窄，为什么仍可能存在偏差？
- 如何用无回答敏感性分析判断是否需要补充调查？

重点核对：列出总体人数、回答人数、权重含义；将“样本抽取带来的随机误差”与“未回答者可能不同带来的偏差”分开。

需要说明的局限：当前自愿回答没有已知随机纳入概率。N_h/n_h是后分层校正权重，不自动成为真实抽样设计权重。只调整校区和学习阶段构成，不能保证每层回答者都能代表该层。

## 课程设计的六项检查

1. **谁使用、解决什么问题？** 校园服务团队收到一批自愿满意度问卷，准备向抽样框内3600人公布总体满意度并分配改进经费。问卷不是随机抽取，回答比例在不同校区和学习阶段之间不同。你要决定怎样报告，以及还缺什么信息。
2. **哪些重要选择留给学生、依据是什么？** 可以采用后分层、校准或基于辅助变量的模型；决定什么差异范围值得认真考虑。不能任意删掉难代表的层来提高回答率，也不能用精确小数掩盖选择机制。
3. **AI完成计算后仍须论证什么？** 列出总体人数、回答人数、权重含义；将“样本抽取带来的随机误差”与“未回答者可能不同带来的偏差”分开。 当前自愿回答没有已知随机纳入概率。N_h/n_h是后分层校正权重，不自动成为真实抽样设计权重。只调整校区和学习阶段构成，不能保证每层回答者都能代表该层。
4. **知识在项目与自查哪里出现？** 目标总体与抽样框用于报告对象，对应第1组A/B；选择偏差与无回答用于回答者与总体构成比较，对应第2组A/B；后分层权重用于加权比较，对应第3组A/B；精度与偏差用于报告不确定性，对应第4组A/B；敏感性分析用于适用范围与补充调查建议，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要分析任务：面向3600人总体的调查报告（或明确限于回答者的报告）、权重分布与抽样框覆盖情况分析、无回答敏感性结果与补采建议。 高质量成果进一步说明替代分析方案为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 复习L07缺失假设与L08连接；新增目标总体、选择机制和权重的区别，为L14设计真正可执行的概率调查提供问题。

## 运行与内容检查

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生`analysis.py`是只依赖标准库的示例代码；运行后仍需按本课要求完成分析和报告。
- 教师`reference.py`运行参考分析，输出保存在`reference_result.json`；结果解释与其他可采用的方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
