# 第25课参考分析与评价要点 · 预测性能与模型维护成本

本文件提供一种可复现的参考分析方案，不规定学生必须采用相同的方法或结论。资料全部为合成教学数据。

## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-25/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

在验证集上，以训练均值预测的基线模型MAE约为9.66229分钟，加性模型约为4.82591分钟；包含非线性和交互项、岭回归惩罚参数为10的模型约为4.58898分钟；不使用workload的低维护成本方案约为5.34206分钟。这个差异足以讨论取舍，但不能由此直接决定0.5成本是否值得。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

## 可接受的分析方案与评价重点

参考分析采用事先确定且有实际含义的变量尺度，比较一组岭回归惩罚参数，并评估不使用workload的方案。可用树、集成或其他正则化；须包含可执行低维护成本的替代方案并说明误差与成本转换假设。

合格报告应分别列出预测误差与维护成本，并提供可运行的备用方案；更好的报告还会说明何时值得增加维护成本，并实际检验输入缺失时的预测表现。

## 常见误解与解释限制

验证集最优是当前开发情境中的结果。成本转换、未来字段可用性与目标范围改变，可能使排名改变。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
