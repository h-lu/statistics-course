# 第26课参考分析与评价要点 · 风险模型的校准与试运行评价

本文件提供一种可复现的参考分析方案，不规定学生必须采用相同的方法或结论。资料全部为合成教学数据。

## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-26/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

后续评价数据含960条记录，阳性率为32.8125%。原模型的平均预测概率为22.8019%，AUC约为0.71310，Brier分数约为0.20176。用历史资料校准后，平均预测概率为23.1964%，Brier分数约为0.20170，仍低估风险。西部实际48.75%而平均预测约33.25%；传感器质量缺失24.375%。校准不是漂移的自动解法。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

本参考模型未使用sensor_quality，因此该字段缺失率上升不能被直接归为参考模型失准的原因，也不应机械触发“必需输入缺失”降级。它只是供应链变化的背景信号；实际风险低估需由标签、校准分箱与群体结果支持。学生若选择使用该字段，应另外验证其缺失处理与部署可用性。

## 可接受的分析方案与评价重点

参考分析先用逻辑回归预测风险，再用历史资料进行逻辑校准，随后检查后续数据的分箱校准结果和分地区表现。可接受拒绝上线、仅人工辅助或有限试用；不能先在20—23月选最有利方案，再把其成绩叫独立验证。

合格使用说明能让值班人员按规则行动；高质量作品针对实际出现的风险低估和缺失设置可执行复核方案，避免空泛“持续监测”。

## 常见误解与解释限制

在历史批次校准不保证未来仍校准。观察到输入漂移不证明性能一定变差；没有结果标签时也不能声称性能已经验证。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
