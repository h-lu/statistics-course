# 第31课参考分析与评价要点 · 追加调查是否值得：信息价值分析

本文件提供一种可复现的参考分析方案，不规定学生必须采用相同的方法或结论。资料全部为合成教学数据。

## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-31/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

当前三种行动的期望损失分别为：等待（wait）56、先试点（pilot）39、全面推出（rollout）63.75，因此选择先试点。调查出现阳性信号的概率为0.41；收到阳性信号后，高需求状态的后验概率为0.68293；收到阴性信号后，该概率为0.11864。依据调查结果重新选择行动，期望损失降为27.1，样本信息的期望价值EVSI为11.9，完美信息的期望价值EVPI为33.75。扣除调查与延迟成本8+3后，净价值为0.9，是否调查对成本设定较为敏感。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

## 可接受的分析方案与评价重点

参考分析逐一计算两种状态、三种行动下的期望损失，并提供先验概率敏感性表。允许风险厌恶、最低服务约束或不同调查；必须明确与给定损失情境的区别。

合格分析应正确更新概率，并计入调查和延迟成本；更好的分析还会找出最优决策发生变化的条件，解释哪些信息能改善决策，哪些精度改进不会改变行动。

## 常见误解与解释限制

概率、损失和调查性能均为教学情境设定，不是从其他CSV文件自动估计的结果。若用前课的估计值替换，必须说明转换依据及其不确定性。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
