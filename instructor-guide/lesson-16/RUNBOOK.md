# 第16课教学指导 · 根据实验结果决定推广、试用或停止

## 课堂目的与备课

使用者与任务：团队试用已经完成。实际按4区组内团队随机，工具组与常规组均12队240人，存在未使用工具、对照组使用工具及失访。经理需要决定是否推广，并想知道每人8单位成本是否值得。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/experiments/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-16.yml`，场次ID`v2-l16-r1`。课中不必另行发布材料，也不要求学生逐人口头汇报。

## 90分钟课堂安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并写下初步判断 | 投影“只比较真正使用工具的人与没有使用的人，是否更接近工具效果？先说明这种比较可能改变什么。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 阅读LEARN并核算小例子 | 只澄清分母、单位、分析目标和适用条件；不替学生决定分析结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理普遍存在的软件操作问题 |
| 35—55 | 比较替代分析方案或进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 说明结果的不确定性和适用范围，提出建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重跑、提交报告与分析结果 | 课末检查完成记录；提交服务拥堵时先记录本地完成情况；文件检查通过不等于掌握知识 |
| 75—80 | A版基础题5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版变式题5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要分析要求对所有学生相同，不转移为选做任务。若时间不足，减少重复排版、软件安装和无关图表，保留方法比较和假设检查。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

巡视时可结合正在形成的报告，检查下列问题；它们依次对应本课五组自查题。

- 效应量怎样表达改善的方向和大小？它与p值有什么不同？
- 意向性分析原则要求按什么分组？失访为什么仍需额外处理？
- 怎样同时把效应区间与零效应、实际价值门槛作比较？
- 随机化检验为什么必须保留原有的团队和区组分配方式？
- 缺失结局、未依从和组间污染有什么不同？怎样检查结论对缺失假设的敏感性？

重点核对：报告全部随机化人数、实际有随访结果的人数、独立团队数；不将使用后分组当随机分组。效果符号明确：tool−usual为负表示处理时间下降。

需要说明的局限：缺失和污染不会因随机化而自动消失；观察到的使用者效果不等于提供工具这一措施的效应。按原分配机制重新分配标签的随机化检验在存在处理影响缺失时需要额外假设，不能当作无条件精确证据。

## 课程设计的六项检查

1. **谁使用、解决什么问题？** 团队试用已经完成。实际按4区组内团队随机，工具组与常规组均12队240人，存在未使用工具、对照组使用工具及失访。经理需要决定是否推广，并想知道每人8单位成本是否值得。
2. **哪些重要选择留给学生、依据是什么？** 可以分析随访值并调整基线、变化量或团队汇总，条件是估计目标明确、推断保留实际随机分配单位。缺失假设和政策门槛需要有依据；可以不推广，但不能只说p大或小。
3. **AI完成计算后仍须论证什么？** 报告全部随机化人数、实际有随访结果的人数、独立团队数；不将使用后分组当随机分组。效果符号明确：tool−usual为负表示处理时间下降。 缺失和污染不会因随机化而自动消失；观察到的使用者效果不等于提供工具这一措施的效应。按原分配机制重新分配标签的随机化检验在存在处理影响缺失时需要额外假设，不能当作无条件精确证据。
4. **知识在项目与自查哪里出现？** 效应量用于决策报告，对应第1组A/B；意向性分析原则用于主要分析与失访情况核对，对应第2组A/B；置信区间（复习）用于效应/成本表，对应第3组A/B；随机化检验用于与随机分配方式一致的检验，对应第4组A/B；失访与实施偏离用于敏感性结果，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要分析任务：实验决策报告、分配/实施流程核对表、效应与不确定性分析、至少一项敏感性分析及成本判断。 高质量成果进一步说明替代分析方案为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 将L15实验方案转为实际执行评价，复用L13区间、L09损失；L17进一步系统处理相关结构。

## 运行与内容检查

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生`analysis.py`是只依赖标准库的示例代码；运行后仍需按本课要求完成分析和报告。
- 教师`reference.py`运行参考分析，输出保存在`reference_result.json`；结果解释与其他可采用的方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
