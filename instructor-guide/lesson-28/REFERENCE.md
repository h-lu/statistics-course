# 第28课参考分析与评价要点 · 观察数据中的效应估计与共同支持

本文件提供一种可复现的参考分析方案，不规定学生必须采用相同的方法或结论。资料全部为合成教学数据。

## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-28/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

参考分析先用全体样本拟合倾向得分模型，将倾向得分限制在[0.1,0.9]后保留919人、排除481人，再在保留样本中重新拟合倾向得分并计算权重。Hájek加权均值差约−5.12793，结果标准化差约−5.24345；固定保留样本后，进行120次自助重抽样，得到95%区间约[−6.23728,−3.89746]。加权SMD绝对值均低于0.04，ESS约339/349，仍不能证明无未测混杂。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

## 可接受的分析方案与评价重点

参考分析仅示范一种限定人群的效应估计；代码说明了重新拟合模型和自助抽样时保持不变的条件。允许匹配、重叠权重、不同的共同支持区域或仅报告关联而不作因果解释；不能将截断权重和删去人群混为一谈。

合格报告应说明目标人群、重叠情况和区间估计；更好的报告还会比较不同的共同支持区域或调整方法，并据此修改结论的适用范围及补充数据的建议。

## 常见误解与解释限制

权重平衡不证明没有未测量混杂。在固定保留样本中计算的自助法区间，未涵盖样本保留规则的选择、模型设定错误及未测混杂造成的全部不确定性。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
