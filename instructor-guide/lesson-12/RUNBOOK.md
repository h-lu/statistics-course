# 第12课教学指导 · 比较估计方法的适用条件

## 课堂目的与备课

使用者与任务：成本管理团队想把均值和常用区间计算封装成通用报表。他们担心长尾和稀有高成本事件。你要提交一份方法测试报告，说明什么数据条件和样本规模下，这个工具可靠或应提醒使用者。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/inference/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-12.yml`，场次ID`v2-l12-r1`。课中不必另行发布材料，也不要求学生逐人口头汇报。

## 90分钟课堂安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并写下初步判断 | 投影“样本量达到30，均值区间是否就一定可靠？先写出一种可能破坏这种经验判断的数据情境。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 阅读LEARN并核算小例子 | 只澄清分母、单位、分析目标和适用条件；不替学生决定分析结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理普遍存在的软件操作问题 |
| 35—55 | 比较替代分析方案或进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 说明结果的不确定性和适用范围，提出建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重跑、提交报告与分析结果 | 课末检查完成记录；提交服务拥堵时先记录本地完成情况；文件检查通过不等于掌握知识 |
| 75—80 | A版基础题5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版变式题5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要分析要求对所有学生相同，不转移为选做任务。若时间不足，减少重复排版、软件安装和无关图表，保留方法比较和假设检查。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

巡视时可结合正在形成的报告，检查下列问题；它们依次对应本课五组自查题。

- 样本均值的抽样分布与原始成本的分布有何区别？
- 标准差和标准误分别描述什么？怎样用重复抽样结果检查标准误估计？
- 中心极限定理需要哪些条件？为什么不能只凭n达到30就放心使用正态近似？
- 对同一个总体参数，怎样用偏差与均方误差比较估计方法？
- 增加模拟次数和增加调查样本量有什么不同？怎样报告蒙特卡洛误差？

重点核对：报告用于比较的总体参数、随机种子、抽样方式和重复次数。至少详细分析一种长尾情境下的方法局限，不能只展示对称分布中的良好表现。

需要说明的局限：完整总体是教学仿真的便利；真实应用没有已知真值。在这三种情境中表现良好，不代表方法适用于所有数据。模拟采用的抽样方式还应与实际分析假定的抽样设计一致。

## 课程设计的六项检查

1. **谁使用、解决什么问题？** 成本管理团队想把均值和常用区间计算封装成通用报表。他们担心长尾和稀有高成本事件。你要提交一份方法测试报告，说明什么数据条件和样本规模下，这个工具可靠或应提醒使用者。
2. **哪些重要选择留给学生、依据是什么？** 你选择样本量范围、重复次数和替代方法，依据是将来报表的精度/成本目标。比较中位数与均值时，不能把估计不同目标的偏差混在一个排行榜里。
3. **AI完成计算后仍须论证什么？** 报告用于比较的总体参数、随机种子、抽样方式和重复次数。至少详细分析一种长尾情境下的方法局限，不能只展示对称分布中的良好表现。 完整总体是教学仿真的便利；真实应用没有已知真值。在这三种情境中表现良好，不代表方法适用于所有数据。模拟采用的抽样方式还应与实际分析假定的抽样设计一致。
4. **知识在项目与自查哪里出现？** 抽样分布用于重复抽样输出，对应第1组A/B；标准误用于重复抽样的标准差与标准误估计值的比较，对应第2组A/B；中心极限定理用于尾部与样本量比较，对应第3组A/B；偏差与均方误差用于方法性能表，对应第4组A/B；蒙特卡洛误差用于重复次数选择，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要分析任务：可复现模拟研究、方法性能表/图与一页使用说明，能让新使用者判断何时用常规报表、何时应改报或追加数据。 高质量成果进一步说明替代分析方案为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 把L10蒙特卡洛从评价容量方案转为评价估计方法，首次明确抽样分布与标准误；L13直接复用这套区间覆盖率模拟。

## 运行与内容检查

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生`analysis.py`是只依赖标准库的示例代码；运行后仍需按本课要求完成分析和报告。
- 教师`reference.py`运行参考分析，输出保存在`reference_result.json`；结果解释与其他可采用的方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
