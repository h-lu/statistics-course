# 第2课参考分析与评价要点 · 分析结论对统计口径有多敏感

本文件用于判断证据与结论是否相配，不是唯一答案。学生可全程使用AI；不按代码由谁输入评分，不因结论与参考不同自动扣分。

## 可重复计算

从本仓库根目录运行（Python 3.10或以上、仅标准库）：

```bash
python instructor-guide/lesson-02/reference.py
```

也可从 `instructor-guide/` 运行 `python lesson-02/reference.py`。使用独立学生仓库时传入 `--student-root /path/to/student-repository`；显式路径无效时不会悄悄改读其他数据。默认先定位本仓库的 `student-template/`，再兼容原有相邻目录。输出为标准输出上的JSON；需要保存时重定向到教师自己的结果目录，不修改学生数据。

共享读取与统计函数位于第1课 `reference.py`。分位数采用线性插值 `(n−1)p`；`std_n` 用分母n描述已有记录，不是标准误；空集合的统计量或零分母比例返回JSON的 `null`，不是0。结果带有教学合成数据标记。

## 固定数据下的核对证据

A−B的已服务均值差约+1.9928分钟，常规业务层内约−2.8536，复杂业务层内约−6.3256。下午已服务P90差为−0.509分钟，而均值差仍为+1.4088。

数值按固定生成种子核算，显示时允许合理四舍五入。学生若选不同对象、变量定义或指标，不应强行匹配这些数字；应追查其分子分母、规则和输入是否支持所报结果。

## 如何阅读参考比较表

六个`scenario`是可复核的参考路线，不是学生必须全做的菜单。`definition`说明相对基准改变了什么；各中心`n`随范围改变；`A_minus_B_mean/median/p90`统一以分钟表示。某中心没有符合条件的记录时，差值为`null`，不能把它写成没有差异。

全登记与已服务改变了纳入对象和等待终点；常规、复杂业务及上下午改变了目标人群；均值、中位数和P90改变了所描述的分布特征。上述差异要用于限制或改写结论，不能只选一项最支持预期的结果，也不能把不同目标的数值差异误说成计算不一致。课堂示范和具体完成要求见[教学指导](RUNBOOK.md)。

## 可接受的分析方法

可比较已服务与所有登记对象、业务分层、时间范围，或其他有理由的方案。无需得出所有结论都不稳；例如合并均值方向在上午/下午均相同，但业务内比较方向相反，正好区分两类敏感性。

## 解释结果时应说明的适用条件与局限性

业务内差异与合并差异对应不同构成，不可宣称其中之一才是无条件真值。不能通过只保留让分析结论稳定的方案来证明稳健；所有尝试都在同一期时仍是探索。

## 如何区分质量

合格需一项明确的初步结论或研究假设、一个基准方案及至少一种有依据且实际计算的替代口径；第二种替代口径可以进一步支持标准任务，也可以进入提高分析。高质量给出分析结论成立范围，并识别选择之间的结构关系，而非海量参数扫描。

先检查报告是否回答分析问题、关键数字能否重新计算，以及备选分析是否实际影响结论解释，再参照[统一评分维度](../GRADING.md)给出形成性反馈。本课为不计分的入门项目，不据此另加完成分或作品分。绘图数量、模型数量与界面复杂度不单独加分。对统计上合理的暂缓发布、补充调查或不进行排名的建议同样认可；缺少证据的“各种情况都有可能”不构成充分结论。
