## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-22/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

加性模型在验证集上的MAE约为4.82591，包含地区交互和积压平方项后约4.60235；加入高度相关排班指数后约4.60265，性能几乎不变。条件数约18.58、53.05、90.75，量纲与结构都会影响该诊断，不能设机械阈值。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

## 可接受的分析方案与评价重点

参考分析比较加性模型、包含交互和非线性项的模型，以及进一步加入相关变量的模型；允许分层描述、GAM、正则化或少变量报告。关键是与目标情境匹配，不能把验证误差最小当成唯一解释标准。

合格报告应说明变量编码、比较条件和结果含义；更好的报告还会根据共线性或数据覆盖不足调整解释，不将每个回归系数都当作可以通过管理措施改变结果的依据。

## 常见误解与解释限制

多变量调整有助于比较条件相近的观测，但仍可能受到遗漏变量、测量误差和模型形式不合适的影响。增加调整变量不等于满足因果识别条件。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
