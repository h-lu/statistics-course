# 第24课参考分析与评价要点 · 模型比较与泛化能力评价

本文件提供一种可复现的参考分析方案，不规定学生必须采用相同的方法或结论。资料全部为合成教学数据。

## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-24/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

训练集、验证集和测试集分别含2400、960、960条记录。参考分析选择包含交互项的逻辑回归模型，其测试集Brier分数约为0.14964，AUC约为0.70029。测试期中，月0—11拟合资料见过的设备有800条记录，未在拟合资料出现的设备有160条记录；两组的Brier分数分别约为0.15243和0.13573。后者的月12—15结果已经参与模型选择，因此不是完全未使用的新设备独立测试，也不能只据这一小批比较断言新设备普遍更易预测。另一次设备留出验证使用160台设备拟合、320条不共享设备的记录作验证；它用于检查冷启动情境，同样不能冒充冻结方案后的独立测试。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

## 可接受的分析方案与评价重点

参考按时间选择再测试，另做不共享设备的冷启动验证。允许嵌套时间验证或同时按设备和时间限制数据划分；必须说明哪批资料决定了哪项选择。

合格分析应能复现同一数据划分，且不使用预测时尚不可得的事后变量；更好的分析会分别评价两种使用场景，不因某批新设备的分数较高就断言新设备普遍更易预测。

## 常见误解与解释限制

同一测试集一旦被反复用于比较和调整方案，就已参与模型开发。报告应说明其实际用途，不再称其为未经使用的独立测试集。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
