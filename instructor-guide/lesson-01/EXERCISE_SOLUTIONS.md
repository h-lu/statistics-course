# 第1课过程解、自检解释与允许替代解

仅供教师。学习例子帮助建立概念；正式项目有多条合理路线，不把以下示范结论整段提供给学生代填报告。

## 过程一：先明确对象与终点

E1–E5 共五张工单、四位来访者。全登记经过时间总和 60 分钟，均值 `60/5=12`；已服务总和 20 分钟，均值 `20/4=5`，中位数 4.5；放弃 `1/5=20%`。以已服务来访者为单位，P1 个人均值 3.5、P2 为 5、P3 为 8，再对三人求均值得 5.5。它与工单均值 5 的差来自 P1 两张工单的权重，不是计算错误；P4 未获服务，必须另报其经历。

允许替代：研究登记负担可用全登记经过时间；研究已服务通常等待可用已服务中位数；研究按人公平可先定义个人汇总。无论采用哪种，不把结果移到别的对象或终点上。

## 过程二：一条记录到全体检查

先由首条 `ticket_id` 定位 CSV，查窗口所属中心和业务含义，确认等待为分钟、状态取值。再计数和核对唯一编号：3,600 行=3,600 工单；来访者去重 1,986；未放弃 3,510 与放弃 90 合计 3,600；90 个服务时长空白与放弃者相配。不要因此删除空白服务时长的工单，等待/放弃问题仍可使用这些记录。

教师观察成功标志是学生可解释核对关系，而非日志很长。原表已整理不代表可直接外推，检查无误也不能证明随机抽样。

## 一条可接受的示例路线及其他路线

示范用途：“改进会议是否需要补看未获服务经历，而不只引用已服务均值？”

1. 基准为第一期按工单的已服务等待，备选为全部登记队列经过时间，业务理由是前者遗漏放弃经历。
2. 按中心报告登记、已服务、放弃数，均值/中位数和比例。数值见 REFERENCE；A 的 `1160+40=1200`，可由原表复核。
3. 三中心全登记均值均高于已服务均值；例如 A 为 14.3235 对 13.4813 分钟。解释是所纳入范围和终点变化，不是某种服务改进。
4. 观察事实写“这期登记资料中……”，原因解释另列；合理建议是先调查放弃过程、人流和业务构成。不能直接对工作人员奖惩。
5. 报告用实际表支持数字、写如何重跑并检查状态/路径。此路线完成五项标准任务，但不是唯一问题。

允许替代：按业务/时段检查总体差异；按人汇总；长等待与通常经历；预约或办结问题。学生选满意度等额外表时须同一期并正确处理未取得评价，本课不强制引入多表复杂度。

## 可接受的深入判断（非全班操作流程）

- **业务构成：**可以在学生自选问题需要时按中心与业务共同分组。参考 A−B 已服务合并均值差 +1.9928，常规业务 −2.8536，复杂业务 −6.3256 分钟。可建议先核查业务构成/流程；不以层内反转宣布因果或无条件排名。
- **通常与长等待：**严格超过 15 的已服务数量 A=339/1160、B=240/1178、C=330/1172；15 是另设门槛而非统一标准。允许另一门槛，但先解释用途。中位数较低也不意味着全部长等待负担消失。
- **按人/工单：**若限定为至少一张已服务工单者，并先取每人的个人工单等待均值：全体 1,953 人，平均个人均值约 12.6047 分钟；3,510 张已服务工单均值约 12.5430。中心内对应 A 935 人/13.5528，B 958/11.4221，C 954/12.7132。中心内人数不能加为全体独立人数，同一人可跨中心。全部等待和已服务等待也不能混用。
- **独立复算＋调查设计：**换实现须重新读原始 CSV。允许更具体的问题：若补记业务阶段发现拥堵在某流程，先改流程；若主要在人流峰值，先查容量。指出补记对象、变量、时期及至少两种可能后果才构成取舍。

## 五组线下自检过程解释

1. **单位。**A 四行是四张工单、两人，不是四人；按工单把三张者权重计三次，按个人均值先汇总后每人一次。B 一台设备五天是五次观测、一台设备；说明重复结构，不把五行说成五台。
2. **类型。**A 编号只标识窗口，其均值不是服务水平。B 病房类别用分类计数；入院次数是数值型计数，可描述分布；体温是有单位数值。允许根据研究问题将计数分档，但说明信息变化。
3. **位置。**A 2、4、6、28 均值 10、中位数 5；28→48 后均值 15，中位数仍 5。B 5、5、20 均值 10、中位数 5 分钟，前者描述平均负担，后者中间位置，不删掉 20 宣称负担改善。
4. **分母。**A 放弃 `2/10=20%`，已服务长等待 `3/8=37.5%`。B 回答者满意 `9/12=75%`，已确认满意占受邀者 `9/20=45%`；非回答者满意未知，两者不能互换。
5. **适用范围。**A 只能描述本期上午/下午记录；业务、人流和到访对象可能不同，同一人时段改变的效果未被识别。B 只对扫码回答者的记录描述均分，未扫码者未取得，需补采或说明选择机制；可提出具体补采方法。

答案不要求同一措辞。评价是否识别对象、分母和适用范围，解释合乎统计含义，不能按是否复述教师句子评价。

## 复核所用额外计算

以下标准库片段可在学生模板根运行，只打印教师核对值，不写原始表：

```python
import csv
import statistics
from collections import defaultdict
from pathlib import Path
base = Path('data/service')
with (base / 'tickets.csv').open(encoding='utf-8', newline='') as handle:
    rows = list(csv.DictReader(handle))
with (base / 'windows.csv').open(encoding='utf-8', newline='') as handle:
    centers = {r['window_id']: r['center'] for r in csv.DictReader(handle)}
for center in ('all', 'A', 'B', 'C'):
    selected = [r for r in rows if r['abandoned'] == '0'
                and (center == 'all' or centers[r['window_id']] == center)]
    people = defaultdict(list)
    for row in selected:
        people[row['person_id']].append(float(row['wait_minutes']))
    print(center, len(selected), len(people),
          statistics.mean(float(r['wait_minutes']) for r in selected),
          statistics.mean(statistics.mean(v) for v in people.values()))
```

运行和数值审查是作者验证，不能证明所有初学者理解或新版本 90 分钟可完成。
