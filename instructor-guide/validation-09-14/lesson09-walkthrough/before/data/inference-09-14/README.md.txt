# 第9–14课共享数据与工具

**全部是教学合成数据与人为设定的业务条件，不是真实机构观察。** Python 3.10及以上，只用标准库；不需要安装requirements中的任何可选库。可以用AI改写代码、用电子表格或另建可复现程序。共同数据是默认路线，不要求全班采用相同操作或结论。

## 第9–10课：告警复核

延续第5课的告警复核用途，另设规划数据，不改第5课数据字节。`alert_groups.csv`一行一个来源组；daily_devices是每天待初筛设备数；base_low/base/base_high是故障基础率情境；miss_cost为每台未查出故障的损失单位。`screening.csv`一行一种初筛，sensitivity是在故障设备中阳性的比例，specificity是在非故障设备中阴性的比例；cost_per_device是初筛每台成本。性能是情境假设，不是现场已验证的效果。

L09：初筛预算2000成本单位；复核每天90台，每台复核成本3，复核无误且复核出的故障均可修复。复核优先顺序须只依赖组别和初筛结果；同组阳性随机选取。对全部待筛设备选定初筛方法，预算只计初筛；报告另外列出复核成本和未发现故障损失。可留名额保障低基础率组，也可按每个名额可避免的期望损失排序。未复核阳性中的故障和初筛阴性中的故障都计入未发现故障。

L10：`demand.csv`一行是一个日需求状态，demand为当日阳性复核请求台数，probability是该状态在相应scenario下的概率。每个情境概率和为1。这是另设的日流量规划模型，**不是**从L09固定日人数自动推导出来的抽样分布；它补入批次波动，同一天设备可能共同受影响。base与stress拥有相同平均需求但不同尾部。每日预订容量每台2成本单位，未满足一台请求若能当日转送，综合后果为8（默认主情境）；若需延迟转送，可用12或20作有业务依据的敏感性，闲置不退款；每日预算240只约束预订费用。需求超容量的请求转下一渠道，短缺代价已含转送后果，不再重复加L09漏检损失。容量取非负整数且不超过120；可比较60、80、90、120，也可提出其他可行容量。不同方案须共用同一组日需求以公平比较。

## 第11–14课：周末服务需求总体

固定对象：某教学名册中的4000名服务对象，每人一行。`need_weekend=1`表示在指定的下一个周末有至少一次服务需求，0表示没有。四课的主要估计对象始终是这4000人的需求比例；B组比例是辅助目标，**不把回答者比例或每次重新生成的人群混作同一总体参数**。A是常规联络组3200人，B是联络较贵的小群体800人。组别不是受保护属性、真实身份或因果因素。

`weekend_population.csv`字段：person_id为唯一虚构编号；group为A/B；need_weekend为固定的完整潜在结果；online_frame为是否在网上联系名册内。完整结果只用于教学模拟的真值和事后审计，抽样/邀请/追访规则不得依据未观察的need_weekend。现实调查不会事先得到完整结果。`generate.py`以种子20261011生成固定总体，A中1120个1，B中520个1，再随机排布；网上框按A的0.90、B的0.55概率一次生成，此后固定。生成程序可审计；课堂直接读取现成CSV，避免每轮改变总体。

### 取得与回答机制（四课固定）

- **完整名册概率样本（srs）**：每次从4000人中等概率无放回抽n人邀请，每人入样概率n/4000。
- **网上自愿机制（volunteer）**：只在online_frame=1的人中等概率无放回抽n人收到网上邀请；有需求者以0.85概率回答，无需求者以0.25回答。未覆盖者邀请概率0。邀请随机不意味着最后回答者无偏。
- srs的**ordinary普通联系**：受邀A以0.8、B以0.6概率回答，在组内回答与需求独立。这是用于比较的简化假设；现实必须论证。
- srs的**complete完成联系**：理想化约定确保每位抽中者回答。L12的主要精度比较、L13默认区间和L14主实验使用此机制，将选择/回答偏差与抽样变动分开。L11同时考察ordinary和volunteer；现实无法确保回答时须另做敏感性分析，不套用理想精度。

`toolkit.acquire`返回全体人的in_frame、invited、answered、invite_probability和observed_need。未回答者的observed_need为None，不能填0；生成器内部使用真实需求产生回答，分析程序只能把完整结果用于明确标注的模拟评价。每次重复用新seed，固定seed重跑可复现。volunteer的回答依赖需求，即便按A/B总体份额调整也不能保证消除组内偏差。

`strata.csv`给已知总体规模、完成联系每人成本complete_cost（A=1，B=3）和普通联系回答率。L14主实验每层独立、等概率、无放回抽取，完成联系，成本n_A+3n_B、预算240。每人设计权重分别为3200/n_A和800/n_B；总体估计也可写作0.8×A样本比例+0.2×B样本比例。按样本人数合并比例一般不是这个目标。普通联系不保证同样完成数，预算压力扩展需明确邀请费用、追访费用和回答假设，不能把预期回答数当保证。

## 工具边界

`toolkit.py`提供读表、自然频数、取得机制、分层抽样、重复估计摘要、Wilson/简单正态近似区间和可选百分位bootstrap。各课analysis只生成另设小例和输入概览，正式比较、参数理由、图表和建议由学生构建，可由AI完整实现。`summary`的SE是重复估计值的样本标准差；不是原始0/1记录的标准差，也不是把这个SE再除以重复次数平方根。重复次数只影响模拟精度。

Wilson用于二元比例，是默认可选工具，不是唯一允许方法。这里从有限总体低比例抽样且完整回答时把二项区间作为近似；高抽样比例、复杂设计或选择偏差不能沿用此解释。百分位bootstrap按样本行有放回重抽，只在概率样本、低抽样比例、样本量适当且覆盖实验表现可接受时作为可选示范；它不是偏差修复，也不适合直接对L14合并行重抽。4个观测全1时会得到[1,1]，并不证明总体全1。
