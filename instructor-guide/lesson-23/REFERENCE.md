# 第23课参考分析与评价要点 · 风险预测与复核决策

本文件提供一种可复现的参考分析方案，不规定学生必须采用相同的方法或结论。资料全部为合成教学数据。

## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-23/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

验证集含960条记录，阳性率为19.2708%。包含交互项的逻辑回归模型AUC约为0.73929，Brier分数约为0.13606。按每月风险排序选取前25%，共复核240条，其中真阳性92条、假阳性148条，另有假阴性93条；查准率为38.33%，查全率为49.73%，按给定损失计算总损失为892。使用概率阈值0.4时只复核69条，总损失为1207。查准率较高的规则不一定更符合降低总损失的目标。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

## 可接受的分析方案与评价重点

参考分析采用逻辑回归，并按每月复核上限截取风险排序靠前的记录。允许其他校准或排序方法、地区保障政策、暂缓部署；不把某一种模型、阈值或公平性定义当唯一答案。

合格方案应只使用预测时可得的变量，每月复核量不超过上限，评价指标的分母正确；更好的方案还会解释为何保留或用满名额，并比较各地区的服务安排及损失假设变化后的选择。

## 常见误解与解释限制

目标是可行的风险筛查规则。样本上的预测关系和代价表不提供个体干预收益，不能宣称高风险者一定最能从干预获益。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
