# 第27课参考分析与评价要点 · 从观察关联到因果研究设计

本文件提供一种可复现的参考分析方案，不规定学生必须采用相同的方法或结论。资料全部为合成教学数据。

## 参考计算的运行方法

在教师仓库根目录执行（把学生路径改为实际克隆路径）：

```bash
python lesson-27/reference.py --student-root ../course-student-template
```

依赖numpy、scipy；共用计算实现在`../lesson-21/reference_common.py`，各课的脚本调用相应分析方法。运行写入本目录`reference_results.json`，不修改学生文件。示例工作区可改用`../lesson-01-first-green`。

## 可复核结果

合成资料1400人，接受支持比例62%；未经调整后续负担差约+12.7790。未支持/支持者基线严重程度均值约2.6807/6.2517，构成明显不同。正差不能直接证明项目有害。

完整数值和计算过程见参考代码及JSON结果文件。不同软件、重抽样次数和合理的方法选择可能带来数值差异，不按最后一位小数评分。

## 可接受的分析方案与评价重点

一份可接受的示例协议：纳入尚未接受支持且基线测量完整、确有服务需求的人；时间零点为完成基线和确认可入组的当日。比较“立即提供标准支持套餐”与“现有通常服务”，随访12周，主要结果为12周负担分数，目标为所有符合条件入组者的平均提供支持效应。若受容量限制，可在事先严重程度分层内随机分配支持名额；按最初分配分析，同时记录实际接受、交叉接受、流失和不良后果。预算、允许延迟的最长时间及既有救助底线须由负责人确认；不能对紧急需要者以课堂设计为由撤回必要服务。

因果结构示例：严重程度、可达性、既往负担→支持选择；这些基线变量也可能→随访负担。未测动机可能同时影响选择和结果。支持→联系强度→结果是可能的中介路径；支持→是否回访←结果提示按回访筛选可能引入偏差。这是待论证的研究因果假设图，不是由相关系数推导的事实。对现有CSV，仅报告构成与未经调整差异；需要有条件的观察调整时衔接L28。

另一种可接受方案是继续采用观察研究设计，但事先限定可比较人群、补测决策前影响选择的因素、记录所有资格者及未参与原因，并给出未测混杂敏感性分析。不能把这一方案描述为等同于随机分配。

参考计算仅提供描述统计结果；评价因果图和研究方案时，还须检查假设及其研究依据。可接受名额随机化、分阶段实施或有重叠限制的观察设计；必须说明处理后的contact_after和responded_after不能不加辨别地当普通基线协变量。

合格研究方案明确时间零点、处理和目标效应；更好的研究方案把图中的未知因素转成可行补采或设计选择，并解释为什么不盲目控制事后变量。

## 常见误解与解释限制

数据由固定种子合成，生成脚本可用于理解模拟机制，但不能把代码里设定的效应当作观察资料在现实中已经识别的证据。课堂分析应依据可观测变量和明确列出的假设展开。

程序能够运行并不表示报告的结论恰当。评价时还须检查：比较对象是否有数据依据，是否解释了替代方案，以及使用条件改变后是否相应修订建议。
