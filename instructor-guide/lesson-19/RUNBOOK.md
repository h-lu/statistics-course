# 第19课教学指导 · 大量发现中哪些可以对外发布

## 课堂目的与备课

使用者与任务：试用工具后记录了12项指标，业务方想挑出“有显著改善”的内容作发布。预先计划中有主指标、安全指标和探索指标。你需要制作完整的各指标分析结果表与发布规则，既不遗漏风险，也不把偶然发现包装成验证。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/experiments/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-19.yml`，场次ID`v2-l19-r1`。课中不必另行发布材料，也不要求学生逐人口头汇报。

## 90分钟课堂安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并写下初步判断 | 投影“12项指标各做一次5%检验，整份报告出现至少一个误报的机会仍是5%吗？先说明哪些假设检验需要共同控制错误率。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 阅读LEARN并核算小例子 | 只澄清分母、单位、分析目标和适用条件；不替学生决定分析结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理普遍存在的软件操作问题 |
| 35—55 | 比较替代分析方案或进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 说明结果的不确定性和适用范围，提出建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重跑、提交报告与分析结果 | 课末检查完成记录；提交服务拥堵时先记录本地完成情况；文件检查通过不等于掌握知识 |
| 75—80 | A版基础题5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版变式题5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要分析要求对所有学生相同，不转移为选做任务。若时间不足，减少重复排版、软件安装和无关图表，保留方法比较和假设检查。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

巡视时可结合正在形成的报告，检查下列问题；它们依次对应本课五组自查题。

- 一组需要共同控制错误率的检验应如何界定？
- 族错误率控制什么事件的概率？
- 错误发现率控制什么比例的期望？为什么不保证本次报告的错误数？
- 探索性发现与验证性结论有什么区别？
- 校正后显著、实际重要和安全性分别需要哪些证据？

重点核对：明确每次多重检验校正包含哪些假设。分析仍需考虑团队随机分配造成的组内相关。报告每项结果的效应方向、区间、实际阈值，以及它属于主要、安全性还是探索性指标。

需要说明的局限：FDR不是每条被挑中结论为假的概率；未显著不证明安全或等同。检验族的定义或错误率控制方法不同，允许作出的检验结论也可能不同；应事先说明选择依据，不能按显著结果多少来切换。

## 课程设计的六项检查

1. **谁使用、解决什么问题？** 试用工具后记录了12项指标，业务方想挑出“有显著改善”的内容作发布。预先计划中有主指标、安全指标和探索指标。你需要制作完整的各指标分析结果表与发布规则，既不遗漏风险，也不把偶然发现包装成验证。
2. **哪些重要选择留给学生、依据是什么？** 可对验证性假设使用Holm等FWER控制、对探索使用合适FDR；检验族根据发布用途事先定义。方法和检验族不能在看哪一种保留更多亮点后才决定。
3. **AI完成计算后仍须论证什么？** 明确每次多重检验校正包含哪些假设。分析仍需考虑团队随机分配造成的组内相关。报告每项结果的效应方向、区间、实际阈值，以及它属于主要、安全性还是探索性指标。 FDR不是每条被挑中结论为假的概率；未显著不证明安全或等同。检验族的定义或错误率控制方法不同，允许作出的检验结论也可能不同；应事先说明选择依据，不能按显著结果多少来切换。
4. **知识在项目与自查哪里出现？** 多重比较用于待检验的假设集合，对应第1组A/B；族错误率FWER用于验证发布规则，对应第2组A/B；错误发现率FDR用于探索清单，对应第3组A/B；探索与验证用于后续计划，对应第4组A/B；统计显著与实际重要（复习）用于发布措辞，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要分析任务：完整的各指标分析结果表，包括每项效应、区间、原始p值及校正结果、分析报告与后续验证计划；保留无显著结果和不利指标。 高质量成果进一步说明替代分析方案为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 复用L16效应量和L18错误率，把一个比较扩展为多指标分析与报告规则；为L20跨时间多次查看建立联系。

## 运行与内容检查

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生`analysis.py`是只依赖标准库的示例代码；运行后仍需按本课要求完成分析和报告。
- 教师`reference.py`运行参考分析，输出保存在`reference_result.json`；结果解释与其他可采用的方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
