# 术语与基础知识规范 V2

本文件规定项目课中背景、术语和基础知识的最低呈现方式。目标不是把传统讲授搬进 README，而是保证学生在作出统计决定以前拥有共同语言，并在项目和课末自查中实际调用这些概念。

## 课程语言要求（2026-09-05修订）

采用统计学教材、统计调查和应用统计分析中常见的中文表达。专业概念要准确，任务说明要自然、具体；不能把咨询、产品开发或软件工程中的说法直接套进课堂材料。本次只修订表述，不降低项目要求，不改变数据、方法或评分。

- 用“阅读项目背景，明确分析问题和任务要求”，不用“认识委托”；栏目用“项目背景”“分析任务”“成果要求”。
- 用“数据集”“专题数据”说明材料，不用“数据世界”；用“示例代码”“运行分析程序”说明工具，不用“发展起点”。
- 根据句意用“分析结论”“研究假设”“分析依据”“适用条件”“局限性”，不用含义模糊的“主张”“证据成果”“边界”。研究假设不能直接改成已成立的结论。
- 用“提交分析报告”“评价标准”“检查结果”，不把学生作业写成“交付产品”“验收签署”。代码文件路径、API和必要软件术语保持原样。
- 用“敏感性分析”“替代分析方案”“不同假设下的结果”说明分析要求；“回放”须写清是用历史数据评估，还是按时间顺序模拟执行规则。
- 区分参数、统计量、估计量与估计值；区分标准差与标准误、相关与因果、统计显著性与实际重要性。不得用生硬缩写替代必要说明。
- 术语首次出现给出规范名称和简短解释，有多个译名时选定一个用于全文。抽样调查中的nonresponse统一称“无回答”，首次可注明“也称无应答或非响应”；不要将它与一般数据缺失、实际非故障等概念混用。
- “标准化”须注明此处指共同构成权重的直接标准化，还是变量的尺度标准化；不能把一种含义写成所有课通用的唯一定义。

逐段通读后核对标题、正文、图表说明、代码输出、自查题与教师参考。批量替换只能处理含义一致的词组，不能代替对整句和统计含义的审查。

## 一条统一学习路径

每个核心概念在同一节课至少出现三次：

1. **认识**：学生在 `LEARN.md` 中读到规范术语、通俗表达和一个小例子；
2. **使用**：学生在确定分析问题、选择方法、解释结果或说明适用范围时运用该概念；
3. **迁移**：A/B 自查用不同表面情境检查同一概念，B 题不能只是换选项顺序。

知识准备约10—17分钟，按课次任务调整，不强制所有课按同一分段执行。可先预测再读，也可先用例子进入概念。短讲解决分母、单位、适用条件与共同混淆，不替学生预选项目结论。

## `LEARN.md` 与教师材料的关系

每个学生课次目录的 `LEARN.md` 是本规范的学生端实现，基础部分应能在约7—10分钟内阅读，其余内容明确标为按需查阅。它与教师材料分工如下：

| 材料 | 面向对象 | 放什么 | 不放什么 |
|---|---|---|---|
| 学生 `lesson-xx/LEARN.md` | 学生 | 情境背景、学习问题、核心术语、必要知识、微型例子、AI求助建议与按需深入 | 教师评分参考、题库答案、课程生产说明 |
| 教师 `lesson-xx/RUNBOOK.md` | 教师 | 时间安排、简要讲解重点、概念应用位置、常见误解、六项设计检查 | 与本课无关的管理材料 |
| 教师 `lesson-xx/REFERENCE.md` | 教师 | 参考计算、预期分析结果和评价依据 | 面向学生的任务说明 |

学生知识材料变更后，应同时检查授课指导中的知识准备、自查题目标和项目要求是否一致。教师扩展阅读不应自动复制到学生知识材料。

## 规范术语与通俗表达

首次出现时采用“**规范术语（必要时附英文）＋通俗表达**”，后续保持同一名称。通俗表达帮助进入问题，不能替代统计含义。本课程优先参照现行 `GB/T 3358` 统计学词汇系列和国内统计学教材的通行表述；存在多个常用译名时，第一次并列说明，随后只用课程首选名称。

| 规范术语 | 可用的通俗表达 | 必须同时说清 |
|---|---|---|
| 观测单位（也常称观察单位） | 每条观测在描述谁或什么 | 一行常对应一个观测单位，但汇总数据或重复测量中不一定如此 |
| 变量 | 对观测单位记录的属性 | 名称、取值、单位及变量类型 |
| 算术平均数（简称均值） | 总量平均分给每个单位 | 对极端值敏感，单位与原变量相同 |
| 中位数 | 排序后处在中间的位置 | 描述位置，不等于“大多数人的取值” |
| 四分位距（IQR） | 中间一半数据的跨度 | 必须说明课程采用的分位数算法 |
| 稳健性 | 少量极端变化是否会大幅改变结果 | 稳健不等于永远更正确 |
| 分析单位 | 当前结论究竟针对什么对象 | 必须与去重键、分母和行动对象一致 |
| 缺失值 | 本应有但没有记录的值 | 缺失编码不一定只有空白 |
| 离群值（也常称异常值） | 与多数记录明显不同的值 | 离群不自动等于录入错误，也不自动应删除 |
| 标准差 | 数据在均值周围的离散程度 | 单位与原变量相同；说明计算采用分母 `n` 还是 `n−1`。用 `n` 描述现有数据，不代表这些数据就是目标总体；标准误描述估计量的抽样变动 |
| 经验累积分布函数（ECDF） | 不超过某个值的样本比例 | 是累计比例，不是区间频数 |
| 假正例（误报）与假阳性率 | 实际非故障却报警 | 假阳性率的分母是真实非故障记录，即 `FP/(FP+TN)`；分母为 0 时未定义 |
| 假负例（漏报）与假阴性率 | 实际故障却未报警 | 假阴性率的分母是真实故障记录，即 `FN/(FN+TP)`；分母为 0 时未定义 |
| 边际比例（合并比例） | 不分层看到的合并比例 | 会受各层构成影响 |
| 条件／分层比例 | 在同一层内比较的比例 | 分层变量和各层分母必须明确 |
| 直接标准化（用于分层比较） | 按同一组构成权重计算各对象的加权指标 | 说明标准人群或权重的选择；与建模中对变量进行尺度标准化的含义不同 |
| 无回答 | 被邀请参加调查的单位未作答，或部分问题未获回答 | 区分单位无回答和项目无回答；未被抽样框覆盖或未被邀请不属于同一种问题 |
| 辛普森悖论（Simpson's paradox） | 合并后的方向与各层方向相反 | 先核算分层和构成，再讨论解释；不能只凭名称下因果结论 |

公式出现时必须紧邻说明：每个符号代表什么、分母是谁、输出单位是什么、该数值能支持和不能支持什么结论。不要只给公式截图或函数名。

## 核心术语的选择

每课围绕少量核心概念或紧密概念组组织基础部分，通常4—6组；数量不是禁止使用更丰富方法的上限。核心表示学生需要解释其含义和在项目中的用途，不要求每个词都是首次出现。自查选择其中5个值得带走或复习的概念。

选择顺序为：

1. 决定观测单位、分母、单位或目标量的词；
2. 决定方法选择与结果解释的词；
3. 决定适用条件和错误代价的词；
4. 仅用于扩展、软件实现或学科分类的词放入“按需查阅”，不进入核心表。

前六课的基础知识侧重点为：

| 课次 | 核心概念组（最多 6 组） |
|---|---|
| L01 | 观测单位；变量；变量类型；均值；中位数；阈值比例与样本代表性 |
| L02 | 分位数；离散程度；分析口径；稳健性；敏感性；探索与验证 |
| L03 | 分析单位；变量类型；缺失；重复；离群值；数据适用性 |
| L04 | 集中趋势；离散程度；尾部；稳健性；评价目标；规则敏感性 |
| L05 | ECDF；分位数；条件分母；假阳性率；假阴性率；损失与容量 |
| L06 | 边际比例；条件／分层比例；构成权重；直接标准化；辛普森悖论；因果解释的条件 |

## 单份学生知识卡模板

`LEARN.md` 建议保持如下顺序：

1. **为什么会有这个问题**：说明使用者、行动和判断错误的后果，不为凑字数加背景；
2. **学完能够回答**：少量问题，使用“解释、选择、判断”等动作词；
3. **本课核心术语**：规范术语、通俗表达、在本项目中出现的位置、常见误解；
4. **需要掌握的基础知识**：每个概念回答“是什么、为什么在这里用、何时不适用”；
5. **微型例子**：一组可手算数据或不超过 6 行的小表，先要求预测，再给核算路径；
6. **回到项目**：明确指出应在哪个现有字段、产物或决定中使用这些概念；
7. **向 AI 求助**：建议学生要求 AI 换一个数据情境解释并反问一道题，不要求保存或评价提示词。

基础部分以可在课堂阅读和应用为约束。按“必须理解、借助工具应用、按需深入”分层，更多公式或方法可以作为工具支持项目；不把函数名当核心知识，也不因实现复杂就削弱主任务的统计要求。

## 与项目和自查的对齐检查

每次发布前，教师逐项确认：

- 每个核心术语至少能在一个项目产物中找到真实使用位置；
- 首次判断无需先知道标准答案，但学习后可以给出更有依据的修订；
- 微型例子与项目同构但不复用正式数据，不泄露项目结论；
- A 题检查概念含义、分母／单位、适用条件或结果解释；
- AI 学习阶段允许自由提问，提示重点是解释与举例，而不是假定 AI 会出错；
- B 题更换数字或情境，检查迁移，不把术语默写当作理解；
- 项目评价关注方法选择的理由、分析结果及其适用范围，不以背诵术语或展示 AI 对话计分。

学生可以让AI直接完成知识卡或题目，这不是额外违规检测的理由。即时正确不证明稳定掌握；通过后续项目复用、旧知识变式与具体反馈继续学习。不强制每课用课中事件或重复提交制造参与证据。

- 国家统计局：[什么是统计调查误差](https://www.stats.gov.cn/zs/tjws/jbtjzswd/tjdc/202505/t20250516_1959835.html)，用于核对抽样框、无回答和测量误差的表述。
