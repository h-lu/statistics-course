# 第10课教学指导 · 为随机需求设计容量方案

## 课堂目的与备课

使用者与任务：服务中心需要购买每日处理容量。容量不足会产生未服务损失，买得过多又浪费。未来日需求随机，活动日与平常日不同；经理需要常态方案、活动预案和对预测失准的准备。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/inference/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-10.yml`，场次ID`v2-l10-r1`。不需要课中秘密事件、高频逐人回应或新平台。

## 90分钟建议安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并留下首次判断 | 投影“按平均需求购买容量，是否意味着大多数天都不会缺额？先预测哪些天最容易使这个规则失效。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 读LEARN并核算微例 | 重点讲清分母、单位、目标和适用条件；不代选项目结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理常见软件问题 |
| 35—55 | 比较备选方法，进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 整合不确定性、局限性和行动建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重新运行、提交报告与证据 | 课末检查完成记录；技术问题暂未解决时，先根据本地结果记录完成情况，不将自动检查通过视为已经掌握知识 |
| 75—80 | A版5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要任务难度不转移到选做。若时间受阻，减少重复排版、软件安装和无关图表，保留不同统计方法或方案之间的关键比较。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

- 随机变量与分布：在模拟输入中查看是否实际使用，对应本课自查概念。
- 期望与方差：在需求模型检验中查看是否实际使用，对应本课自查概念。
- 蒙特卡洛模拟：在策略共同情境比较中查看是否实际使用，对应本课自查概念。
- 期望损失：在容量目标函数中查看是否实际使用，对应本课自查概念。
- 留出数据评估：在42天评估中查看是否实际使用，对应本课自查概念。

重点核对：记录随机种子、情境参数和各项成本的单位；检查模拟均值、方差或分位数是否符合所设需求模型。用留出期结果说明建议能否保持，而不是看完留出期再选最优并称其为验证。

解释中的常见问题：重抽样只覆盖历史支持的情境；留出期短，未包含不代表不会发生。这里没有跨日积压、排队时长或班次人员差异，不能把件数容量结论扩大成全部服务体验。

## 发布前六问：课程设计检查

1. **谁使用、解决什么问题？** 服务中心需要购买每日处理容量。容量不足会产生未服务损失，买得过多又浪费。未来日需求随机，活动日与平常日不同；经理需要常态方案、活动预案和对预测失准的准备。
2. **哪些重要选择留给学生、依据是什么？** 可以用经验重抽样、分层模型或合适的计数分布；决定优化期望成本还是对未服务风险加约束。方案必须来自可购买容量，不能创造没有报价的无限弹性资源。
3. **AI完成计算后仍须论证什么？** 记录随机种子、情境参数和各项成本的单位；检查模拟均值、方差或分位数是否符合所设需求模型。用留出期结果说明建议能否保持，而不是看完留出期再选最优并称其为验证。 重抽样只覆盖历史支持的情境；留出期短，未包含不代表不会发生。这里没有跨日积压、排队时长或班次人员差异，不能把件数容量结论扩大成全部服务体验。
4. **知识在项目与自查哪里出现？** 随机变量与分布用于模拟输入，对应第1组A/B；期望与方差用于需求模型检验，对应第2组A/B；蒙特卡洛模拟用于策略共同情境比较，对应第3组A/B；期望损失用于容量目标函数，对应第4组A/B；留出数据评估用于42天评估，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要任务：容量模拟工具或可运行分析、采购建议报告、历史选择与留出数据评估对照表，清楚区分预测、模拟和已经发生的实际需求。 高质量成果进一步说明备选分析方法为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 把L09条件概率及期望损失扩展为随机情境模拟，复用描述工具；蒙特卡洛工具将在L12覆盖研究和L18功效中复用。

## 试运行与检查记录

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生示例代码`analysis.py`采用Python标准库，可直接运行；学生仍需完成本课分析任务。
- 教师`reference.py`实际计算参考分析方法，输出保存在`reference_result.json`；解释与可接受的分析方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
