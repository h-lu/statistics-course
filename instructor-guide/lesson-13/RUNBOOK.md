# 第13课教学指导 · 置信区间能否支持决策

## 课堂目的与备课

使用者与任务：部门拿到80次成本观测，若平均成本持续高于45就值得启动改进，但全面改造有实施风险。你要说明现有证据支持全面行动、有限试点还是继续收集，而不只是输出一个区间。

课前运行学生入口和本课参考；核对[数据说明](https://hblu.top/gitea/statistics/course-student-template/src/branch/main/data/inference/README.md)及对应CSV。题库为`knowledge-check/question-bank/lesson-v2r1-13.yml`，场次ID`v2-l13-r1`。课中不必另行发布材料，也不要求学生逐人口头汇报。

## 90分钟课堂安排

| 时间 | 学生活动 | 教师处理 |
|---|---|---|
| 0—5 | 阅读项目背景并写下初步判断 | 投影“样本均值超过45，是否已经足以证明平均成本超过45？先说明你还想知道什么。”；必要时用上一课共同误区的变式替换引入 |
| 5—15 | 阅读LEARN并核算小例子 | 只澄清分母、单位、分析目标和适用条件；不替学生决定分析结论 |
| 15—35 | 定义问题，完成初始分析/设计 | 看目标与数据是否一致；处理普遍存在的软件操作问题 |
| 35—55 | 比较替代分析方案或进行敏感性分析 | 抽看两三份证据与理由，不逐份口试；反馈一个共同问题 |
| 55—68 | 说明结果的不确定性和适用范围，提出建议 | 检查下方审核要点，不追求统一答案 |
| 68—75 | 重跑、提交报告与分析结果 | 课末检查完成记录；提交服务拥堵时先记录本地完成情况；文件检查通过不等于掌握知识 |
| 75—80 | A版基础题5题 | 开放本课V2自查，建议先自行判断，AI可用 |
| 80—84 | 概念学习 | 允许问AI；不记录或检查提示词 |
| 84—89 | B版变式题5题 | 使用新情境反馈，不把A/B提升当稳定掌握 |
| 89—90及课后 | 查看反馈 | 保持反馈至下一场次；记下一课需要复习的一项概念 |

主要分析要求对所有学生相同，不转移为选做任务。若时间不足，减少重复排版、软件安装和无关图表，保留方法比较和假设检查。尚无真实学生90分钟试教记录；这里只记录作者/AI运行核验。

## 知识与巡视重点

巡视时可结合正在形成的报告，检查下列问题；它们依次对应本课五组自查题。

- 点估计与区间估计分别提供什么信息？
- 95%置信水平描述的是本次区间，还是产生区间的方法？
- 自助法怎样利用已有样本？重抽样单位为什么重要？
- 如何在已知总体的模拟中估计区间覆盖率？
- 置信区间同时包含决策阈值两侧的值时，还需要哪些信息才能提出建议？

重点核对：自助法必须按原始独立观测单位重抽样；报告重复次数、区间水平和端点算法；覆盖率实验需给出重复次数与模拟误差。

需要说明的局限：置信水平描述区间程序长期覆盖率，不能把它解释为固定真值以该概率落入本次已经算出的固定区间。自助法不能凭空创造样本未包含的极端机制，也不能修复选择偏差。

## 课程设计的六项检查

1. **谁使用、解决什么问题？** 部门拿到80次成本观测，若平均成本持续高于45就值得启动改进，但全面改造有实施风险。你要说明现有证据支持全面行动、有限试点还是继续收集，而不只是输出一个区间。
2. **哪些重要选择留给学生、依据是什么？** 可选均值t区间、自助百分位或其他有依据的方法；可以保守试点，但需说明代价和证据。不允许把区间跨过45自动翻译成“没有问题”，也不允许用总体基准替代抽样报告。
3. **AI完成计算后仍须论证什么？** 自助法必须按原始独立观测单位重抽样；报告重复次数、区间水平和端点算法；覆盖率实验需给出重复次数与模拟误差。 置信水平描述区间程序长期覆盖率，不能把它解释为固定真值以该概率落入本次已经算出的固定区间。自助法不能凭空创造样本未包含的极端机制，也不能修复选择偏差。
4. **知识在项目与自查哪里出现？** 点估计与区间估计用于行动简报，对应第1组A/B；置信区间与置信水平用于区间解释，对应第2组A/B；自助法用于替代区间，对应第3组A/B；覆盖率用于方法检查，对应第4组A/B；实际阈值与决策用于推广/试点/补采建议，对应第5组A/B。
5. **最低合格与高质量差别？** 合格成果必须完成本课主要分析任务：行动简报、可复核区间和覆盖实验、阈值/样本变化的敏感性结论。明确当前建议哪些部分依赖估计方法，哪些依赖决策者风险态度。 高质量成果进一步说明替代分析方案为什么改变或不改变决定，量化关键假设的后果；只堆图、模型或代码不算提高。
6. **相对前后课推进了什么、复用什么？** 承接L12抽样分布与覆盖，将方法评价用于实际行动阈值；为L16效应区间和L18精度设计铺路。

## 运行与内容检查

- 数据生成脚本固定种子，输入字段与学生任务一致；所有数据明确合成。
- 学生`analysis.py`是只依赖标准库的示例代码；运行后仍需按本课要求完成分析和报告。
- 教师`reference.py`运行参考分析，输出保存在`reference_result.json`；结果解释与其他可采用的方法见[REFERENCE.md](REFERENCE.md)。
- 依赖：教师参考需要NumPy、SciPy；学生示例代码不依赖第三方库。自查文件使用新的题库ID，不覆盖历史答题关联。
- 代码能运行、链接和题库校验与实际课堂时长是不同证据；不以文件齐全宣称课堂已验证。

课后只记一条共性概念问题与一条作品质量问题，下一课短时反馈；无需每课完整深评全部作品。
